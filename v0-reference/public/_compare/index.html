验收说明

  • 结构 / 布局 / 配色 / 文案 1:1 吻合：标题、讲师卡（周易大师 / 好评4.9 / 咨询1280次 / 10币每分钟）、连麦方式双卡、日期横滑、时段分组、图例、底部固定栏全部一致。
  • diff 红色区域仅两类噪声：① 时段格子占用色差　② 由占用行数不同引发的整页几像素垂直位移 + 文字边缘红边。
  • 根因：原型时段占用用 Math.random() 实时随机生成，每次刷新都不同。Vue 版逻辑逐行照抄一致，差异纯由两端随机种子不同造成，非迁移失真。
  • 决策：按铁律一/二，保持原型随机逻辑，不加固定种子。
