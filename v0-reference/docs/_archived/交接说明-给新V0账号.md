## 5. 标准迁移 SOP（每页都照做）

详见 `docs/迁移准备/05-页面改造标准流程.md`，精简版：

1. **读原型**：`Read app/<板块>/<页>/page.tsx`，读全（大文件分段读）。连同它依赖的子组件、lib 数据一起读。
2. **截基准图**（像素标尺）：原型 Next dev server 在 v0 沙箱自动跑，
   `curl --max-time 90 http://localhost:3000/<路由>` 探活 → `agent-browser` 截图。
   - ⚠️ 若 curl 返 000/截图是英文报错页 → **dev server 挂了**，不是沙箱坏。
     重启：`pnpm dev > /tmp/devserver.log 2>&1 &`，sleep 后再探活。
3. **核对图标**：缺的加进 gen-icons.mjs 并重生成。
4. **建数据层**：`vue3/src/lib/<板块>-data.ts`（mock 数据 + 类型 + 装配函数）。
5. **写 SFC**：`vue3/src/<分包>/<路径>.vue`，逐字段 1:1 还原。跨端约定见第 6 节。
6. **注册路由**：`vue3/src/pages.json`（主包页进 pages，分包页进对应 subPackage）。
7. **编译校验**（关键，因为 uni 无法在 v0 预览运行）：
   用 `@vue/compiler-sfc` 的 parse+compileScript+compileTemplate 校验（脚本见下）。
8. **commit + push + 验证远程**。
9. **更新用户记忆**（v0_memories/user/MEMORY.md）记录进度。

### SFC 编译校验脚本（直接复制用）
```bash
cd /tmp/sfc-check 2>/dev/null || (mkdir -p /tmp/sfc-check && cd /tmp/sfc-check && npm i @vue/compiler-sfc -s)
cd /tmp/sfc-check && node - << 'JS'
const { parse, compileScript, compileTemplate } = require('@vue/compiler-sfc')
const fs = require('fs')
const files = ['/vercel/share/v0-project/vue3/src/<你的文件>.vue']  // 改成你的文件
let ok=true
for (const f of files){ try{
  const {descriptor,errors}=parse(fs.readFileSync(f,'utf8'),{filename:f})
  if(errors.length){console.log('PARSE',f,errors.map(e=>e.message));ok=false;continue}
  if(descriptor.scriptSetup||descriptor.script)compileScript(descriptor,{id:'x'})
  if(descriptor.template){const r=compileTemplate({source:descriptor.template.content,filename:f,id:'x'});if(r.errors.length){console.log('TPL',f,r.errors);ok=false;continue}}
  console.log('OK',f.split('/').pop())
}catch(e){console.log('FAIL',f,e.message);ok=false}}
console.log(ok?'=== ALL OK ===':'=== ERRORS ===')
JS
```

## 6. 跨端约定（踩坑固化，必须遵守）

- **图片/封面/头像**（unsplash/dicebear/picsum/本地）：统一经 uni `<image>` 组件显示，不用 `<img>`。
- **轮播**：用 uni `<swiper>` 替 react 轮播库。
- **文本截断**：`-webkit-line-clamp` + `-webkit-box`（小程序支持）。
- **backdrop-blur**：小程序不支持，降级为半透明实底色。
- **样式**：scoped scss + rpx 为主，unocss 补充。Tailwind v4 @theme 不支持，令牌走 tokens.scss。
- **动态 class**（如五行配色 .wx-*/.wxb-*）：须放 scoped 之外的全局样式，否则编译器 tree-shake 掉。
- **AppIcon 颜色**：传具体色值（如 `#c41e3a`），**不要传 `var(--xxx)`**（运行时取不到）。
  装饰/内容性图案若原型用 emoji 且需跨端一致 → 用 GenerateImage 生成图替换（先改原型再同步 vue3）。
- **媒体**：录音 `#ifndef H5`→uni.getRecorderManager / `#ifdef H5`→MediaRecorder；播放→uni.createInnerAudioContext；
  选图→uni.chooseImage；预览→uni.previewImage。
- **网络事件**：小程序无 window.online/offline，用 `uni.getNetworkType` + `uni.onNetworkStatusChange`。
- **底部导航**：自定义（排盘居中凸起太极），非原生 tabBar。
- **未迁移的目标页跳转**：`navigateTo` 的 fail 回调统一 `toastComingSoon('功能开发中')` 兜底。
- **自定义导航栏**：所有页 `pages.json` 设 `"navigationStyle": "custom"`，页内自绘顶栏 + safe-area 适配。

## 8. 三大已知风险（迁移时注意）

1. **Canvas 字体**：思源字体须 loadFontFace + 子集化，真机 PoC（见 `docs/迁移准备/02-Canvas适配层方案.md`）。
2. **小程序无法主动分享**：分享按钮改 `open-type="share"` + 保存相册。
3. **运行验收**：v0 沙箱只能跑原型 Next dev server，**uni-app 无法在 v0 预览运行**。
   像素验收须在 uni 工具链侧（HBuilderX / `npm run dev:h5` / 微信开发者工具）。
   v0 侧的质量保障 = 精读原型代码 + SFC 编译校验 + 对照基准图。
