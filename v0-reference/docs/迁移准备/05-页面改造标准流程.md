# 页面改造标准流程（SOP）

> 适用：把原型页面转化为 Vue3/uni-app，或后期在平台新增页面。
> 任何人按此流程执行，都能产出 100% 高保真、风格一致的页面。这是可复现质量的核心。

## 流程总览

```
① 原型先行 → ② 建立基准 → ③ 资产对照 → ④ 转化实现 → ⑤ 像素验收 → ⑥ 对接登记 → ⑦ 沉淀提交
```

## ① 原型先行（新增页面时）
- 先在 `prototype/`（原型）中实现页面，遵循《项目规范》设计红线（国风/令牌/字体/母版）。
- 用 GenerateDesignInspiration 获取设计方向（如视觉不明确）。
- 原型中通过浏览器验收交互后，才进入转化。
- 若是迁移既有原型页面，跳过本步，直接 ②。

## ② 建立基准（验收标尺）
- 用 agent-browser 打开原型页面，按目标视口（414×896）截图存档为基准图。
- 记录该页用到的：母版组件、API 模块、动态路由参数、特殊交互（分享/canvas/上传等）。

## ③ 资产对照（查表，不靠记忆）
逐项对照准备资产，列出本页需要的适配点：
- 浏览器 API → 查 `01-浏览器API适配清单.md`，标出本页用到的 API 及替代。
- canvas 物料 → 查 `02-Canvas适配层方案.md`，走适配层 + 字体加载。
- 数据来源 → 查 `03` A 节，内联 mock 收敛到 data/ 或接 API（契约见 `04`）。
- 设计令牌 → 查 `03` B 节，颜色不变、px→rpx、动画迁移。
- 路由 → 查 `03` C 节，注册 pages.json + query 传参 + 归入正确分包。

## ④ 转化实现（高保真红线）
- **结构**：JSX → Vue3 `<template>`，组件层级与原型 1:1。
- **样式**：Tailwind 工具类 → unocss（presetWind + 项目 theme），令牌值逐字段抄录，不重写。
- **逻辑**：React hooks → Vue3 composition API（useState→ref、useEffect→onMounted/watch、useRouter→uni.navigate）。
- **数据**：复用 lib/types 契约；API 调用走 `utils/request`（信封不变）。
- **母版**：能用 components/common 母版就复用（PlatformEntry/BadgeUnlock/AchievementMoment 等），不重写。
- **平台 API**：storage/share/canvas/scroll 等一律走封装的 utils/composables。
- **分享**：峰值时刻「分享」按钮改 `<button open-type="share">` + 保存相册兜底（小程序限制，已决策）。

## ⑤ 像素验收（编译通过≠验收通过）
- 真机/模拟器运行，截图与 ② 的基准图**逐像素肉眼比对**。
- 重点核对：字体字形/字宽换行、颜色、圆角、间距、印章/二维码位置、动画时长与缓动、交互反馈。
- canvas 物料按 `02` 第五节方法专项比对。
- 跑类型检查；查 runtime 日志无报错。

## ⑥ 对接登记（联调可追溯）
- 若本页引入新接口需求，更新 `04-ClaudeCode对接说明.md`：模块、路径、字段（types）、鉴权。
- 新增/调整 type 时先改 `types/`，再两端同步。

## ⑦ 沉淀提交
- 遇到的坑/可复用做法 → 写入 `经验沉淀.md`。
- 新形成的通用组件/封装 → 放入 components/common 或 utils，并在《母版系统索引》或规范登记。
- 提交规范：`feat(模块): 标题 + 要点 + 验收结论 + Co-authored-by`。

## 新增可复用组件的判定（避免重复造轮子）
出现以下情况，**先抽成可复用组件/封装再用**，并登记到索引：
- 同一 UI 模式在 ≥2 处出现（如卡片、空状态、骨架屏、列表项）。
- 同一平台能力在 ≥2 处调用（如 storage、分享、上传、定位）。
- 同一业务展示在多角色/多分站复用（如商品卡、用户卡、订单项）。

## 质量红线检查表（每页过一遍）
- [ ] 仅用设计令牌配色，无令牌外颜色、无非角色紫色
- [ ] 标题思源宋体 / 正文思源黑体，≤2 字族
- [ ] 国风调性，未偏离（无脱离主题的背景/配色）
- [ ] 移动优先，flexbox 优先，gap 不混 margin/padding
- [ ] 图标用统一库，无 emoji 充当图标
- [ ] 峰值时刻带品牌露出 + 扫码入口（PlatformEntry）
- [ ] 与原型基准图逐像素一致
- [ ] 平台 API 走封装，无裸用浏览器专有 API
- [ ] 类型检查通过，runtime 无报错
