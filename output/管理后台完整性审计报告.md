> **审计日期**：2026-05-21
> **审计范围**：管理后台页面、路由、菜单与后端 67 个模块的覆盖完整性

## 二、管理后台覆盖缺口（P0 — 后端有模块，管理端完全无页面）

### 2.1 签到管理 (checkin) — ❌ 零覆盖

**后端能力**：
- 每日签到（连续天数追踪、奖励公式 5+floor((连续-1)/3)*3）
- 每日任务模板（签到/阅读/评论/分享/观看）
- 月度日历视图
- 积分发放

**管理后台缺什么**：
- 签到规则配置（每日奖励、连续签到倍数、上限）
- 签到数据总览（日活/月活/签到率/流失曲线）
- 每日任务模板管理（增删改查、任务类型、奖励配置）
- 签到排行榜/用户签到明细
- 签到积分发放日志

**影响**：运营人员完全无法调整签到策略，所有规则写死在代码里。

---

### 2.2 浏览历史管理 (browse-history) — ❌ 零覆盖

**后端能力**：
- 用户浏览记录存储
- 列表查询 / 删除 / 清空全部

**管理后台缺什么**：
- 浏览数据统计（PV/UV/热门内容/浏览路径）
- 浏览行为分析（用户兴趣推断、内容热力图）
- 自动清理策略配置（保留天数、最大条数）
- 用户维度的浏览历史查看

**影响**：浏览数据只存不用，无法支撑推荐算法调优。

---

### 2.3 发现页配置 (discover) — ❌ 零覆盖

**后端能力**：
- 发现页内容推荐
- 基于兴趣标签的个性化推荐
- 缓存（120 秒 TTL）

**管理后台缺什么**：
- 发现页模块配置（哪些模块展示、排序）
- 推荐内容人工精选/置顶/屏蔽
- 热门话题管理
- 发现页数据看板（点击率/转化率/内容分布）

**影响**：发现页完全由算法驱动，运营无法人工干预。

---

### 2.4 语义缓存管理 (semantic-cache) — ❌ 零覆盖

**后端能力**：
- AI 调用语义缓存
- 相似度搜索（最高 200 候选）
- 命中率/过期管理

**管理后台缺什么**：
- 缓存命中率实时监控（总请求 / 命中 / 未命中 / 命中率）
- 缓存用量统计（条目数、存储占用）
- 缓存清理/刷新（按场景/按时间）
- 过期缓存自动清理策略配置

**影响**：核心 AI 成本优化手段完全黑盒，运维盲区。

---

### 2.5 知识同步管理 (knowledge-sync) — ❌ 零覆盖

**后端能力**：
- 圈子知识同步到知识库
- embedding + 向量搜索
- isRunning 防并发

**管理后台缺什么**：
- 同步状态大屏（哪些圈子/多少条/进度/耗时）

- 同步策略配置（频率、范围）

**影响**：知识库同步全自动无人工干预，失败时无人知晓。

## 三、已有页面功能深度不足（P1 — 有页面但管不全）

### 3.1 内容管理 (ContentList / ContentEdit)

| 缺什么 | 说明 |
|--------|------|
| 批量操作 | 批量审核、批量分类、批量标签、批量删除 — 一条条操作效率极低 |
| 排期日历 | 内容发布排期可视化日历视图 — 运营无法整体规划内容节奏 |

## 四、结构与导航问题（P2）

### 4.1 路由冲突

```
路径 `categories` 被两个路由同时注册：
- #40: CategoryList（商品分类）— shop/CategoryList.vue
- #149: CategoryManage（品类标签管理）— content/CategoryManage.vue

Vue Router 中后注册的路由会覆盖前者，导致"商品分类"入口被隐藏。
```

### 4.2 菜单架构问题

菜单由后端 `GET /auth/menus` 动态生成，有其优势（权限过滤），但存在以下问题：
- 所有管理员看到相同的菜单结构，无法个性化定制
- 新增页面需要后端同步添加菜单项，前后端耦合
- 没有菜单搜索/收藏/快捷入口

### 4.3 缺少的功能入口

| 后端已有能力 | 管理后台入口 |
|-------------|-------------|
| 签到奖励/任务配置 | 无 |
| 浏览数据统计 | 无 |
| 发现页内容运营 | 无 |
| AI 缓存命中率 | 无 |
| 知识同步状态 | 无 |
| 连麦监控 | 无 |
| 存储用量 | 无 |
| 分享统计 | 无 |
| WebSocket 连接监控 | 无 |
| TTS 配置 | 无 |
| 地图配置 | 无 |

| 方面 | 亮点 |

## 七、总结

**核心结论**：管理后台并不"单薄"——163 个路由、130 个充实页面已经是一个相对成熟的中型平台。你的"单薄感"主要来自两点：

1. **覆盖缺口**：11 个后端模块在管理后台完全看不到——这是一块明显的盲区。每当你想到"签到怎么配置""浏览数据怎么用""发现页能不能调"，就会发现没有入口。
2. **深度不足**：已有页面大部分是"列表 + 增删改查"模式，缺少批量操作、数据分析、策略配置等运营深度功能。

补齐这 11 个缺口 + 深化 6 个核心页面，预计 **总工时约 22 人天**，管理后台将从"能管"升级到"管得好"。
