## 四、最关键的几条铁律（详见权威指南，这里只摘最容易翻车的）

1. **唯一真源是原型 `app/<route>/page.tsx`**，逐行比对，禁止凭交接文字或记忆动手。
2. **验收必须两端实测**：原型(3000) 与 Vue(5173) 同视口 375×812 并排截图 + 量像素，不能只读源码。
3. **AppIcon `size` 默认单位是 rpx**：原型 Tailwind `w-N`(px) → `:size = px×2`。逐页量，不可全局批量改。
4. **AppIcon `color` 必须传 hex，禁止传 `var(--xxx)`**（CSS 变量在 SVG data-URI 内失效 → 图标不可见）。
5. **pages.json 不要预注册未创建的页**（会导致整个 app 白屏）；每建好一页再加一条注册。
6. **三种红/金不可混**：品牌故宫红 `#C41E3A` / 语义纯红 `#ef4444` / 评分金 `#C9A96E`，逐处对原型类名。
7. **乱码 U+FFFD 零容忍**：编辑含中文的数据文件传 `dangerously_disable_autofix: true`，提交前全量扫描。
8. **每接一页先报「定 A/B/C 类 + 理由」，等用户确认再动手**（分级标准见权威指南 §1）。

## 五、跑起来（双端预览）

```bash
# 原型（真源，端口 3000）
pnpm install && pnpm next dev

# Vue（迁移目标，端口 5173）
cd vue3 && pnpm install && pnpm dev:h5
```

- Vue H5 是 **history 路由**：访问 `http://localhost:5173/pkg-xxx/route/index`（**不带 `#/`**）。
- 子包页首次访问需先 `curl` 预热编译；编译错误看 `/tmp/vue-dev.log`。

祝顺利，保持上一个账号的质量标准即可。有任何"这页该定几类/配色取哪个红"的判断，先问用户再动手。
