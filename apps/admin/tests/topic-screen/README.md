# 专题大屏组件验收

所有夹具均为模拟数据。此入口不在生产路由中引用，API 使用本地 Axios adapter，不请求独立 QA 或真实服务；只允许声明的四个大屏接口。

在 `apps/admin` 执行（使用已安装的冻结依赖）：

```sh
node --test --test-isolation=none tests/platform-screen.test.mjs tests/topic-screen.test.mjs
node node_modules/vite/bin/vite.js --config tests/topic-screen/vite.config.mts
```

纯数据测试需要支持 TypeScript 类型擦除的 Node，已在 Node 24 验证。`--test-isolation=none` 避免 Windows 环境为测试额外启动子进程。

打开 `http://127.0.0.1:54181/tests/topic-screen/index.html`。顶部黄色验收条可切换交易、内容、AI、线下，及丰富数据、零数据、部分缺失、长名称、模拟断线、权限失效；切换场景后点击“刷新数据”。不要把这个组件夹具当作真实业务数据或后端集成测试。

重点检查：

- 交易金额/单量切换与品类联动；“智能体”仅有历史成交、今日应为零。
- 内容矩阵的真实面积和可键盘聚焦的类别入口；极小分类不得放大占比。
- AI 场景为累计、模型为本月；双轨不是成功率或进度。
- 城市筛选与名称/城市/地址搜索交叉作用，清空后恢复全部；长名称完整换行。
- 先加载丰富数据，再模拟断线刷新：保留快照、显示延迟、无全局错误弹窗；恢复后清除延迟。
- 权限失效（403）：清除快照和时间。401、请求去重、换令牌和卸载隔离由纯逻辑测试覆盖。
- 1920×1080、390×844 布局与键盘焦点。真实角色权限、登录续期及真实网络恢复应另在独立 QA 验证。

停止测试服务即可关闭夹具；无需清理任何远端数据。
