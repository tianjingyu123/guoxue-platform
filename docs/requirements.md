## 一、平台总览

国学传统文化综合平台，基于 NestJS + Prisma + PostgreSQL + Redis 的 monorepo 架构，前端 UniApp 跨端（小程序/iOS/Android/H5），管理后台 Vue3+TS。

### 产品矩阵
| 端 | 技术栈 | 说明 |
|---|---|---|
| 用户端小程序 | UniApp (Vue3+TS) | 主小程序 + 多分站小程序 |
| 管理后台 | Vue3 + TS + Element Plus | 6种角色按权限访问 |
| 后端服务 | NestJS 10 + Prisma 5 | REST API，/api/v1 前缀 |

### 用户角色体系
| 角色 | 权限范围 |
|---|---|
| SUPER_ADMIN | 超级管理员，全部权限 |
| OPERATION_ADMIN | 运营管理员，内容/用户/营销 |
| CONTENT_AUDITOR | 内容审核员 |
| FINANCE_ADMIN | 财务管理员 |
| CUSTOMER_SERVICE | 客服 |
| GOODS_AUDITOR | 商品审核员 |
| 普通用户 | 前端注册使用 |
| 站长/运营商 | 分站管理，收益分佣 |
| 圈主/合伙人 | 圈子内容管理，知识库管理，达人咨询配置 |
| 讲师/达人 | 课程/作业/连麦咨询 |
| 商家 | 商品/订单管理/入驻申请 |

## 七、技术基础设施

### 7.1 认证与安全
- JWT 双 Token 机制（2 小时 accessToken + 30 天 refreshToken 原子一次性轮换防重放）
- 6种系统角色 + 自定义角色 + 分站/圈主/商家/讲师身份
- RolesGuard + JwtAuthGuard 双重守卫
- StrictRedisThrottleGuard 接口限流（登录/注册/验证码/排盘/AI分析）
- TencentCallbackGuard 腾讯云回调签名验证（直播/VOD/支付）
- XSS防护（SanitizePipe）
- 敏感词过滤（腾讯云CMS + 本地敏感词库）
- 数据加密（生辰信息AES加密、银行卡信息加密存储、API Key SHA256哈希）

### 7.2 缓存体系
- Redis多级缓存（内存→Redis→数据库）
- 课程列表/详情缓存
- 文章列表/详情缓存
- 圈子列表/详情/成员关系缓存
- 排盘计算结果缓存（24h TTL，公开GET端CDN缓存）
- 分站品牌配置缓存（10min）
- 通知偏好缓存（30天TTL）
- TTS音频缓存（7天MD5 Buffer缓存）
- 小程序首页组件级缓存（Redis mget）
- 定价结果缓存（5min）
- 地图地址缓存（24h/5min/10min分级）

### 7.3 消息队列
- BullMQ + Redis 后端
- 三个独立队列：notification / ai-callback / reconciliation
- 指数退避重试（3次）
- 延迟任务 + 优先级
- BullBoard 管理界面（/admin/queues）
