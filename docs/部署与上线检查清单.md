# 部署与上线检查清单

> 基于 2026-06-23 审计经验教训，每次部署和新功能上线前必须执行。

## 一、部署前检查

### 数据库
- [ ] 运行 `npx prisma migrate deploy` 应用所有待执行 migration
- [ ] 运行 `prisma/migrations/manual_20260623_audit_fixes/migration.sql`（如 Prisma migrate 未覆盖）
- [ ] 验证索引已创建：`\di "LiveRoom_status_viewCount_idx"` `\di "Circle_status_memberCount_idx"`
- [ ] 验证 User.deletedAt 字段存在：`\d "User"`

### 后端
- [ ] `npx tsc --noEmit` 零错误
- [ ] `npx jest --no-coverage` 全通过
- [ ] `curl localhost:3000/api/v1/health` 返回 200
- [ ] 关键 API 烟雾测试：首页/课程/圈子/诗词/古籍/排盘

### 移动端
- [ ] `.env.production` 中 `VITE_USE_MOCK=false`
- [ ] `VITE_API_URL` 指向正确的后端地址
- [ ] `pnpm build:mp-weixin` 或对应平台构建成功

## 二、新功能上线前强制检查

### 代码层面
- [ ] 所有 `coin.spend/refund/freeze/unfreeze/transferFrozen` 调用与后续DB写入在同一事务
- [ ] 所有 fetch(外部URL) 使用 `fetchWithTimeout` + 白名单校验
- [ ] 所有上传入口拦截 SVG + 魔数校验
- [ ] 所有验证码/密码验证有失败计数+锁定
- [ ] 所有 write API 有 `@UseGuards(JwtAuthGuard, RolesGuard)` + `@Roles(...)`
- [ ] 所有金额字段有 `@IsPositive()` 装饰器
- [ ] 敏感字段（身份证/银行卡/手机号）返回值已脱敏

### 测试层面
- [ ] 新增 service 方法有单元测试
- [ ] 新增 controller 端点有 e2e 测试
- [ ] 修改函数签名后同步更新所有 mock

### 移动端
- [ ] 新页面不直接 import mock 数据
- [ ] 新数据文件有 API 对象 + `useMock()` 双模式
- [ ] 页面实现 loading / error / empty 三态
- [ ] 写操作按钮有 `submitting` 防重复
