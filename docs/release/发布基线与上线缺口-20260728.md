## 4. 新环境切换前的冻结规则

1. 新服务器、数据库和正式域名未确定前，不在旧生产库执行新增迁移。
2. 新服务器到位后，先恢复备份到隔离数据库，再执行：
   - `pnpm migration:check-env`
   - `pnpm migration:audit-domain`
   - `pnpm release:baseline -- --strict`
   - `pnpm release:audit -- --strict`
   - `pnpm release:check-nav`
3. 隔离库核验通过后再安排短暂停写、最终增量备份和域名切换。
4. H5、小程序、App、管理后台必须统一 API、静态资源、WebSocket、分享链接和回调域名。
5. 旧服务器至少保留一个观察周期，回滚只切流量，不反向覆盖新库。

```powershell
pnpm release:baseline

```

