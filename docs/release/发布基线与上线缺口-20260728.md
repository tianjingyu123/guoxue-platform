## 发布前硬门禁

本地代码门禁：

```powershell
pnpm release:verify:local
```

新服务器环境门禁：

```bash
pnpm release:gate:full
docker compose \
  -f docker/docker-compose.yml \
  -f docker/docker-compose.prod.yml \
  --env-file docker/.env.production config -q
```

`release:verify:local` 会串行执行上线审计、全仓 ESLint、三端类型检查、共享算法包构建与测试、16 套排盘/历法逐值回归、服务端全量测试，以及 Server、Admin、H5、微信小程序和 App 生产构建。`release:gate:full` 会先校验真实生产环境文件，再执行同一套本地完整验证，避免把“只通过审计”误认为“已经具备发布条件”。

数据库恢复后：

```bash
bash scripts/migration/verify-postgres.sh
pnpm --filter @guoxue/server exec prisma migrate status
```

任何 P0/P1、环境校验错误、Compose 配置错误、测试/构建失败或数据库计数差异都必须阻断发布。
