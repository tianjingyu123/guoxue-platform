Claude 填写此模板时：

### ⚠️ V0 特别注意 `[必填]`

```
（Claude 列出的关键注意事项——这些东西不能错）

1. 四柱中的天干地支颜色不是装饰，是五行属性的标识
   → 木=#4CAF50 火=#F44336 土=#FF9800 金=#FFC107 水=#2196F3
   → 不要换成你认为更好看的绿色/红色

2. 数据区必须用等宽字体
   → 确保每个字符对齐，尤其是四柱表

3. 日柱是整个八字的核心
   → 需要在视觉上突出（但不是大红大绿的突出，微妙地区分即可）

4. 结果区不要放 AI 对话式的分析文字
   → 排盘工具是固定格式输出，AI 分析在另一个入口

5. 神煞的吉凶色：
   → 吉=深绿 凶=深红 平=灰色
   → 不要自行改为浅色或亮色
```

## 填写示例

以下是一个完整填写示例（八字排盘工具页）：

---

### 📌 基本信息

```yaml
需求编号: PAIPAN-V0-001
工具名称: 八字排盘
页面类型: 工具页（模板A）
目标用户: 易经老师
使用设备: 手机（优先）
```

### 🎯 页面功能

```
老师输入客户的出生年月日时，系统输出四柱八字、十神、神煞、大运流年。
老师能在结果上进行批注标注，点击神煞可查看古籍出处。
```

### 📊 数据说明

```
四柱：年柱/月柱/日柱/时柱，每柱包含天干+地支+藏干+十神+神煞
十神：比肩/劫财/食神/伤官/正财/偏财/正官/七杀/正印/偏印
神煞：名称列表，每条有吉凶属性。例如 [天乙贵人(吉), 文昌(吉), 羊刃(凶)]
大运：每步10年，包含干支+起止年龄
```

### 🖼️ 竞品参考

```
1. 问真八字排盘页
2. 热卜八字排盘页
```

Claude 竞品分析：
```
竞品优势：信息展示全面，老用户习惯
竞品劣势：视觉老旧，无古籍溯源，神煞只是罗列没有解释
我们要突破：古籍溯源 + 教学推导 + 老师批注系统
```

### 📐 模板约束

```
模板A（工具页：左输入 + 右结果 + 底部信息栏）
桌面端：输入320px | 结果填充剩余
移动端：上下堆叠
```

### 🧩 需要的组件

| 组件名 | 状态 | 说明 |
|--------|------|------|
| SiZhuDisplay | 🔨 待设计 | 四柱 + 十神标注 |
| DaYunTimeline | 🔨 待设计 | 横向时间轴 |
| ShenShaList | 🔨 待设计 | 可点击的 Tag 列表 |
| ChartInput | 🔨 待设计 | 8 个输入字段 |
| CiteBlock | 🔨 待设计 | 古籍引用卡片 |

### ⚠️ V0 特别注意

```
1. 天干地支颜色是五行标识，不能随意改色
2. 排盘数据必须用等宽字体
3. 日柱需要视觉突出
4. 结果区不显示 AI 对话
5. 神煞吉凶用深绿/深红/灰
```
