# 排盘工具 — 页面模板映射

> 排盘工具所有页面，只能从以下 5 种模板中选择。
> 新功能开发第一步：在此文件中登记，确定模板。不许自创布局。

---

## 五种模板速览

| 模板 | 名称 | 结构 | 适用场景 |
|------|------|------|----------|
| **A** | 工具页 | 左输入 + 右结果 | 排盘/占卜等计算类工具 |
| **B** | 工作台页 | 侧栏导航 + 内容区 | 管理型页面（客户/命例/设置） |
| **C** | 对比页 | 多列并排 + 差异列 | 多版本对比、合盘 |
| **D** | 仪表盘页 | 卡片网格 + 图表区 | 概览、报告预览 |
| **E** | 列表管理页 | 搜索筛选 + 表格/卡片列表 + 分页 | CRUD 型 |

---

## 模板 A：工具页（排盘核心）

```
┌──────────────────────────────────────────┐
│ 工具栏（流派切换 / 参数调整 / 导出）        │
├────────────┬─────────────────────────────┤
│            │                             │
│  输入面板   │      结果展示区              │
│  (320px)   │                             │
│            │                             │
│  [排盘按钮] │                             │
│            │                             │
├────────────┴─────────────────────────────┤
│ 底部信息栏（古籍引用 / 算法说明 / 推导步骤） │
└──────────────────────────────────────────┘
```

**约束：**
- 输入面板固定宽度 320px（桌面端），移动端占满宽度
- 结果区占剩余空间，可滚动
- 底部信息栏默认折叠，点击展开
- 工具栏始终可见（sticky top）

## 模板 B：工作台页

```
┌──────────────────────────────────────────────┐
│ 顶部标题栏（面包屑 + 操作按钮）                 │
├──────────┬───────────────────────────────────┤
│ 侧边导航  │                                   │
│ （图标+文字│        内容详情区                  │
│  可折叠） │                                   │
│          │                                   │
│ 📋 客户   │                                   │
│ 📊 排盘   │                                   │
│ 📝 批注   │                                   │
│ 📄 报告   │                                   │
│ ⚙️ 设置   │                                   │
│          │                                   │
└──────────┴───────────────────────────────────┘
```

**约束：**
- 侧边导航宽度：220px（可折叠为 60px 仅图标）
- 详情区占剩余空间，可滚动
- 导航项二级不展开（用页面内 Tab 代替）

**适用页面：**

| 页面 | 侧栏项 | 详情区内容 |
|------|--------|-----------|
| 客户管理 | 客户列表（搜索+筛选） | 客户详情（信息+排盘历史+批注汇总） |
| 工作台首页 | 快捷入口 | 概览卡片（今日排盘数/客户数/待回复） |
| 知识库 | 分类导航 | 古籍原文 + 注释 |

## 模板 C：对比页

```
┌──────────────────────────────────────────────┐
│ 顶部：对比标题栏（A 参数 vs B 参数 / 切换）     │
├─────────────────┬────────────────┬───────────┤
│                 │                │           │
│   方案 A        │   方案 B        │  差异列    │
│   (等宽)        │   (等宽)        │  (可折叠)  │
│                 │                │           │
└─────────────────┴────────────────┴───────────┘
```

**约束：**
- A/B 列等宽，各占剩余空间的 50%
- 差异列默认收起，点击展开（宽度 280px），从右侧滑入
- 移动端：A/B 上下堆叠，差异列为底部抽屉

**适用页面：**

| 页面 | A 列 | B 列 | 差异列 |
|------|------|------|--------|
| 八字对比 | 传统派早晚子时 | 现代派早晚子时 | 日柱差异 + 空亡差异 |
| 八字对比 | 日柱起空亡 | 年柱起空亡 | 各柱空亡差异 |
| 合婚 | 男方八字 | 女方八字 | 五行互补 + 冲合分析 |
| 奇门对比 | 转盘排法 | 飞盘排法 | 九宫差异标记 |
| 排盘历史对比 | 客户上次排盘 | 客户本次排盘 | 变化高亮 |

## 模板 D：仪表盘页

```
┌──────────────────────────────────────────────┐
│ 概览卡片行（4-6 个指标卡，等宽）                │
├──────────────────────────────────────────────┤
│                                              │
│  图表/可视化区域                              │
│  （grid 布局，可配置 1/2/3 列）               │
│                                              │
├──────────────────────────────────────────────┤
│  明细列表（可选）                              │
└──────────────────────────────────────────────┘
```

**约束：**
- 概览卡片每行最多 6 个，最少 3 个
- 图表区 grid：桌面端默认 2 列，移动端 1 列
- 卡片内部数字用 `font-mono tabular-nums`

**适用页面：**

| 页面 | 概览卡片 | 图表/可视化 |
|------|----------|-----------|
| 排盘统计 | 总排盘数/今日/本月/活跃用户 | 排盘趋势折线图 + 工具使用饼图 |
| 报告预览 | 客户信息/排盘摘要 | 四柱 + 大运 + 神煞预览 |
| 工作台首页 | 今日排盘/待处理客户/新命例 | 最近排盘时间线 |

## 模板 E：列表管理页

```
┌──────────────────────────────────────────────┐
│ 搜索框 + 筛选条件 + 操作按钮行                  │
├──────────────────────────────────────────────┤
│                                              │
│  数据表格 或 卡片列表                          │
│                                              │
├──────────────────────────────────────────────┤
│  分页器                                      │
└──────────────────────────────────────────────┘
```

**约束：**
- 搜索 + 筛选在一行（桌面端），移动端搜索在顶、筛选可横滑
- 表格行高：紧凑 40px / 默认 48px
- 分页器固定在底部（表格过长时 sticky）
- 空态用 EmptyState 组件

**适用页面：**

| 页面 | 数据类型 | 展示形式 |
|------|----------|----------|
| 命例库 | 排盘记录 | 卡片列表（八字摘要卡片） |
| 客户列表 | 客户信息 | 表格（姓名/手机/最近排盘/操作） |
| 批注列表 | 批注记录 | 卡片列表（批注内容+关联排盘） |
| 报告列表 | 生成的报告 | 表格（客户/时间/操作） |
| 参数配置 | 偏好设置 | 表单列表 |
| 定制需求管理 | 用户需求 | 卡片列表（需求+状态+投票数） |
