# 排盘工具 — 交互行为规则

> Claude 不确定交互怎么做时，**不对标竞品就对标已有机理**，不自己发明。
> 此文件是交互设计的"锚"。

---

## 核心原则

```
排盘是工具，不是 AI 玩具。
交互应该让人感觉"准确、可预期、专业"。
动画少、反馈快、操作路径短。
```

## 排盘输入交互规则

### 即时排盘（默认）
```
用户修改任意输入项 → 300ms 后自动重新计算
                    └── 期间显示输入框右侧小型 loading 指示器
                    └── 结果区保持旧数据，新数据返回后无缝替换
                    └── 替换时无动画，直接更新（避免闪烁）
```

### 手动排盘模式（用户设置中开启）
```
用户修改输入 → 不自动计算
             └── [排盘] 按钮变为可用态（从灰色变为品牌色）
             └── 点击按钮或按 Ctrl+Enter 触发计算
```

### 输入校验
- 日期：公历范围 1900-2100，超出提示"仅支持1900-2100年"
- 时间：0-23 时，严格校验
- 八字输入时，允许直接输入干支（不必填公历），自动校验干支组合合法性

## 排盘结果交互规则

### 四柱交互
- 鼠标悬停某柱 → 该柱背景变为 `UI.headerBg`
- 点击某柱 → 该柱高亮（`UI.brandLight`），其他柱恢复默认
- 选中状态下，下方展开该柱详细信息面板：
  ```
  ┌───────────── 日柱详情 ─────────────┐
  │ 甲木坐午火 → 自坐伤官               │
  │ 藏干：丁火(伤官) 己土(正财)          │
  │ 纳音：沙中金                        │
  │ 空亡：辰巳                          │
  │ 十二长生：死                        │
  │ 相关神煞：[天乙贵人] [文昌] [羊刃]    │
  └────────────────────────────────────┘
  ```

### 神煞交互
- 神煞 Tag 排列在四柱下方
- 悬停 Tag → 显示 Tooltip（神煞名 + 简释 + 古籍出处）
- 点击 Tag → 在侧边栏展开完整古籍引用（CiteBlock）
- 神煞支持筛选（吉/凶/平），默认全部显示

### 大运时间轴交互
- 横向滑动查看（桌面端鼠标滚轮水平滚动，移动端左右滑动）
- 点击某步大运 → 展开该运的流年列表（下方滑出）
- 当前所在大运自动滚动到可见区域
- 流年列表可继续点击展开流月（三级展开，仅桌面端）

### 九宫格交互
- 悬停宫位 → 宫位边框变为 `UI.brand` + 轻微放大
- 点击宫位 → 侧边栏展开该宫详细信息
  - 星/门/神/天地盘 + 长生状态 + 入墓/击刑/门破说明
  - 象意解读（来自知识库）
  - 相关古籍引用

## 对比模式交互规则

### 进入对比
- 排盘结果区右上角 [⚖ 对比] 按钮
- 点击 → 弹出参数选择面板（修改参数 B 的配置）
- 确认 → 打开模板 C（对比页）

### 差异标记
- 自动计算 A/B 的差异项
- 差异列列出所有不同之处
- 点击差异项 → A/B 两侧对应位置同时高亮（淡黄背景）

## 工作台交互规则

### 客户选择
- 点击客户列表中的客户 → 右侧详情区更新（不动画，直接替换）
- 支持键盘 ↑↓ 切换 + Enter 选中
- 选中客户后，TopBar 出现 [排盘] [对比] [导出] 操作按钮

### 快捷操作
- 排盘结果区悬浮快捷工具栏（右下角固定位置）
- 包含：[复制八字] [分享链接] [导出PDF] [保存到命例库] [新建对比] [添加批注]
- 工具栏在页面滚动时保持可见
- 复制操作后显示 toast "已复制"（持续时间 1.5s）

## 响应式行为

| 断点 | 布局 | 特殊处理 |
|------|------|----------|
| ≥1024px | 完整布局（左侧输入+右侧结果） | 全功能 |
| 768-1023px | 输入面板可折叠 | 工具栏折叠为汉堡菜单 |
| <768px | 上下布局（输入区→结果区） | 输入区默认折叠，大运时间轴改为纵向列表，九宫格缩小 |

## 键盘快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+Enter` | 强制重算排盘 |
| `Ctrl+S` | 保存到命例库 |
| `Ctrl+Shift+S` | 保存并添加批注 |
| `Ctrl+P` | 导出 PDF |
| `Ctrl+K` | 命令面板（搜索工具/客户/命例） |
| `Esc` | 关闭弹窗/面板/折叠输入区 |

## 数据刷新规则

- 排盘结果不自动刷新（八字排一次即可，不会变）
- 奇门/六壬等基于当前时间的工具，结果区显示时间戳
- 超过 5 分钟 → 在结果区顶部显示淡黄色提示条"排盘时间距今已超过5分钟，点击刷新"
- 不强制刷新，用户决定

---

## 错误处理

- API 超时（>10s）：显示"计算超时，请重试" + [重试] 按钮
- API 返回错误：显示错误信息 + [重试] 按钮，不显示技术细节
- 输入不合法：在输入面板内联显示错误提示（红色文字），不弹窗
- 网络断开：检测到 offline 事件，全局顶部显示"网络已断开"提示条

---

## 导出交互

### PDF 导出
- 点击 [导出PDF] → 显示 2s 倒计时遮罩"正在生成报告..."
- 生成完成后触发浏览器下载（不打开新标签页）
- 失败 → toast 提示 + [重试]

### 分享链接
- 点击 [分享链接] → 调用 API 生成短链接
- 链接复制到剪贴板 + toast "链接已复制"
- 分享链接有效期为 7 天（用户可在设置中调整）
- 查看方不需要登录（公开分享）

---

## 禁止行为清单

- ❌ 排盘结果区不要任何自动弹出的 AI 分析（AI 解读必须手动触发）
- ❌ 不要自动播放动画（首次加载的神煞/星曜不要"逐个弹出"）
- ❌ 不要弹窗遮挡排盘结果（结果区是神圣的）
- ❌ 不要在排盘过程中显示进度百分比（"计算中..." 骨架屏即可）
- ❌ 不要自动保存到任何地方（用户主动操作才保存）
- ❌ 不要在结果区添加任何广告/推荐/交叉销售
- ❌ 不要偷偷收集用户的排盘数据（所有保存需明确授权）
