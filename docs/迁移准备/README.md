## 三个必须先解决的关键风险（决定 go/no-go）

1. **Canvas 字体加载**（最高）：思源字体须 loadFontFace + 子集化，否则分享物料排版走样。须真机 PoC 验证。
2. **小程序主动分享受限**：navigator.share 无法照搬，峰值时刻母版「分享喜悦」迁移时改 open-type=share 转发按钮 + 保存相册。（已确认方案）
3. **Tailwind v4 @theme 不被 uni-app 原生支持**：建议引入 unocss 还原工具类，最大保真且改动小。

## 已知需统一的历史不一致（迁移时顺手修正）

- 证书页（`app/courses/certificate/page.tsx`）是早期独立实现（深蓝背景/星号/Arial），未接成就卡母版（宣纸/印章/思源）。迁移时统一到 `lib/achievement/render-card.ts` 母版。
- mock 开关口径：多数模块默认开 mock，`lib/api/comments.ts` 相反，对接时统一。

## 保真验收方法（贯穿全程）

1. 迁移前用 agent-browser 对每个页面/母版截**基准图**存档。
2. 迁移后真机/模拟器截图与基准**逐像素比对**。
3. 设计令牌、动画时长、间距数值**逐字段抄录**，绝不凭记忆重写。
