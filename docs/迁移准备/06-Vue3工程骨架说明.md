# Vue3 / uni-app 工程骨架说明

> 位置：仓库根的 `vue3/` 目录（与原型双轨并存）。
> 状态：骨架 + 三大适配层 + 首页样板页已就位，可作为后续按模块迁移的基座。

## 一、目录结构

```
vue3/
├─ package.json / vite.config.ts / tsconfig.json / uno.config.ts / env.d.ts
└─ src/
   ├─ main.ts                 # 入口：注册 uno.css、令牌、动画、字体加载
   ├─ App.vue                 # 全局根 + page 基础样式（宣纸底/思源字体）
   ├─ manifest.json           # 应用配置（h5/mp-weixin/app）
   ├─ pages.json              # 页面注册 + 分包(subPackages) + 全局样式
   ├─ uni.scss / styles/      # tokens.scss(设计令牌) + animations.scss
   ├─ lib/                    # brand.ts(品牌常量) + icons.ts(图标注册表)
   ├─ utils/                  # storage / request / router + canvas/(适配层)
   ├─ components/             # app-header / bottom-nav / home / common(app-icon)
   └─ pages/                  # index(首页样板) + circles/paipan/discover/profile(占位)
```

## 二、关键架构决策（与原型差异及原因）

1. **自定义底部导航（非原生 tabBar）**：排盘 tab 是居中凸起的太极按钮，原生 tabBar 无法实现该造型。
   采用 `components/bottom-nav` 自定义组件，各主页面引入，tab 间用 `uni.reLaunch` 切换。
2. **图标方案（自动提取，1:1 还原）**：小程序 wxml 不支持内联 `<svg>`。
   用 `scripts/gen-icons.mjs` 从原型 `tool-icons.tsx`(57 工具图标，保留 fill-opacity 层次) 与 lucide-react(20 通用图标) 自动提取，
   生成 `lib/icons-registry.ts`；运行时 `lib/icons.ts` 的 `iconDataUri` 按 kind 处理（tool 替换 currentColor / lucide 注入 stroke），
   经 `AppIcon` 用 `<image>` 跨端显示。重新生成：`node vue3/scripts/gen-icons.mjs`。详见经验沉淀第八节。
3. **太极图标**：`static/taiji.svg`，经 `<image>` 显示。
   ⚠️ 注意：旧版微信基础库 `<image>` 对本地 svg 支持有限，真机若不显示需转 PNG 兜底。
4. **设计令牌**：`tokens.scss` 从原型 globals.css 1:1 迁移（颜色值逐字段抄录），
   布局类 px→rpx（750 基准）。颜色统一走 CSS 变量，暗色用 prefers-color-scheme + `.theme-dark` class 双轨。
5. **样式策略**：关键布局用 scoped scss + rpx（跨端最稳），unocss 工具类作补充（uno.config.ts 还原口径）。

## 三、三大适配层（平台差异收敛点）

| 适配层 | 文件 | 替代的原型能力 |
|---|---|---|
| 存储 | `utils/storage.ts` | localStorage / useAuth token 存取 → uni.*StorageSync |
| 请求 | `utils/request.ts` | api-client fetch → uni.request；信封/前缀/鉴权/mock 开关与原型一致 |
| 路由 | `utils/router.ts` | next/navigation → uni.navigateTo/redirectTo/reLaunch/navigateBack |
| Canvas | `utils/canvas/*` | 纯绘制函数原样复用，平台差异（node/dpr/字体/图片/导出）收敛在 adapter+export+font-loader |

## 四、如何运行与验收（uni 工具链侧）

> ⚠️ v0 沙箱运行的是 Next.js 原型 dev server，无法在其预览中运行 uni-app。
> 运行与像素验收须在 uni 工具链侧进行：

```bash
cd vue3
npm install            # 安装 @dcloudio 工具链（版本以官方 uni-preset-vue 为准，必要时校正）
npm run dev:h5         # H5 预览
npm run dev:mp-weixin  # 微信开发者工具打开 dist/dev/mp-weixin
```

验收：按 `05-页面改造标准流程.md`，与原型基准截图逐像素比对。
