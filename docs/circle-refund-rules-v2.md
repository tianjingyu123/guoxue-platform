# 圈子退出与退款规则说明文档 V2.0

> 来源：用户 2026-06-25 制定，作为圈子退款资金子系统的实现依据。

## 一、核心原则
- **不鼓励退款，但不阻止退款**：退款入口刻意隐蔽，用户需经引导说明后才能触发真正的退款流程
- **退款有成本**：申诉退款收取 20% 手续费，让用户慎重
- **分销佣金追回**：退款后相关推广佣金记负数，后续赚取佣金时正向冲抵
- **圈主分成全额退还**：退款后圈主分得部分全额追回
- **100% 退款走人工**：用户要求全额退款时只能通过客服申诉，后台人工处理

## 二、收入分配规则
### 2.1 加入圈子收入分配
- 平台 50%（后台可动态调整）
- 圈主 50%（圈主可自行分配给合伙人、嘉宾）
- 关联方佣金：通过分站站长推广链接加入，站长获推广佣金（从平台分成支出，比例后台可配）

### 2.2 支付方式限制
- 微信支付 ✅ / 支付宝 ✅ / 虚拟币国学币 ❌（圈子加入不能用虚拟币）

## 三、退款触发场景
- 用户主动申请退出 → 进入退款流程
- 圈主主动移除成员 → 进入退款流程

## 四、退款入口设计（用户端）
- **入口位置**：圈子主页 → 设置/成员管理区域最底部，次要文字按钮（灰色小字，不醒目）
- **点击"退出圈子"后先展示引导说明页**（不直接进退款流程）：
  - 强调"本圈为虚拟数字产品，一经使用不支持无理由退款"
  - 列出受影响权益：成员身份取消 / 帖子评论保留 / 已购课程不受影响
  - 主按钮"我已知晓，继续使用"（视觉权重高，引导不退款）
  - 次要文字按钮"仍要退出？→ 申请申诉退款"（灰色小字）
- **申诉退款申请页**：展示退款金额预览 + 申请原因（选填）+ 确认申请

### 退款计算公式
```
应退金额 = 已付费用 − (每日费用 × 已使用天数)
每日费用 = 已付费用 ÷ 总服务天数（年费按 365 天）
手续费 = 应退金额 × 20%（归平台所有）
实际到账 = 应退金额 − 手续费
```

## 五、分销佣金追回规则
| 角色 | 追回内容 | 追回方式 |
|---|---|---|
| 分站站长 | 该用户加入时获得的推广佣金 | 记负数，后续赚佣金正向冲抵，冲抵完成方可提现 |
| 圈主 | 该用户加入时分得的 50% | 全额退还（从圈主收益账户扣除，余额不足记负数后续冲抵） |

示例：张三经站长李四链接加入付 ¥365 → 平台 ¥182.5 / 圈主 ¥182.5 / 站长 ¥36.5(10%)。使用 30 天退款：应退 ¥335，手续费 ¥67(归平台)，实退 ¥268；圈主账户 -¥182.5，站长账户 -¥36.5(记负数后续冲抵)。

## 六、100% 全额退款
- 触发：用户要求退回全部（不接受按天扣费+20%手续费）
- 处理：不走线上自动流程，引导联系客服，后台手动处理

## 七、审核流程
```
用户提交申诉退款 → 系统自动计算 → 圈主审核 →(同意)→ 平台审核 →(同意)→ 执行退款 → 退款到账通知 → 追回圈主分成 → 追回站长佣金(记负数) → 成员身份失效
```
- 圈主审核建议 3 工作日；平台审核建议 5 工作日；执行退款原路退回微信/支付宝 1-3 工作日
- 任一环节拒绝 → 驳回(可填原因)，用户可重新申请

## 八、数据表设计
### circle_refund_request（圈子退款申请表）
字段：id, circle_id, user_id, paid_amount, daily_cost, used_days, refund_base(应退/手续费前), fee_rate(默认0.20), fee_amount, actual_refund, reason, refund_type(normal/full), owner_status, owner_reviewed_at, owner_reject_reason, admin_status, admin_reviewed_at, admin_reject_reason, refund_status, refunded_at, owner_recalled, station_recalled, created_at, updated_at

### commission_recall（佣金追回记录表）
字段：id, refund_id, user_id(被追回者), user_type(owner/station_master), amount(负数), balance_after, status(pending/offsetting/completed), offset_completed_at, created_at

## 九、状态说明
引导说明 / pending_owner(圈主审核中) / owner_rejected(可重申) / pending_admin(平台审核中) / admin_rejected(可重申) / refunding(退款处理中) / refunded(已到账) / full_refund(联系客服)

## 十、异常情况处理
- 应退 ≤ 0 → "已超过付费周期，无法退款"
- 重复申请 → 同一用户对同一圈子只能有一个待处理申请
- 退款失败(通道异常) → 自动重试 3 次，仍失败转人工
- 站长佣金已提现 → 追回记负数，后续冲抵
- 圈主余额不足 → 记负数，后续冲抵
- 圈主已解散圈子 → 退款自动进入平台审核，无需圈主审核
