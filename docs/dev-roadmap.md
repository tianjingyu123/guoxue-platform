## 风险与依赖

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 腾讯云 API 限频 | AI翻译/实名认证/直播服务中断 | 本地缓存+排队重试+降级方案 |
| 八字计算性能瓶颈 | 高并发下响应超时 | 预计算+CDN缓存+计算卸载 |
| 微信支付回调丢失 | 订单状态不同步 | 主动查询+定时对账+告警 |
| 分站数据隔离缺陷 | 跨站数据泄漏 | 中间件强制stationId过滤+自动化测试 |
