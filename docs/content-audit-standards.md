# 热卜国学平台 · 内容审核标准 V1.0

## 一、总则

### 1.1 制定依据

- 《中华人民共和国网络安全法》
- 《中华人民共和国中医药法》
- 《中华人民共和国非物质文化遗产法》
- 《关于促进中医药传承创新发展的意见》
- 《关于进一步加强非物质文化遗产保护工作的意见》
- 平台定位：中华优秀传统文化传承与创新综合平台

### 1.2 审核原则

| 原则 | 说明 |
|------|------|
| **文化传承优先** | 鼓励优质传统文化内容创作，保护非遗传承人合法权益 |
| **科学理性引导** | 中医内容坚持"健康科普"定位，易经内容坚持"文化研究"定位 |
| **风险前置防控** | 禁止类内容机审拦截，敏感类内容人工复核，免责声明自动附加 |
| **合规可追溯** | 所有审核操作记录执行者、时间、理由，支持回溯和申诉 |

### 1.3 审核状态流转

```
创作者提交 → PENDING（待审）
  ├─ 机审通过 → 人工复审 → APPROVED（通过）
  ├─ 机审命中 → 人工复审 → REJECTED（驳回，附原因）  
  └─ AI生成内容 → AI_GENERATED（标记后进入人工复审队列）
```

## 二、中医养生品类审核标准

### 2.1 品类范围

一级品类"中医养生"下的所有内容：中医基础、食疗药膳、经络穴位、四季养生、中药科普、养生功法

### 2.2 禁止内容（一票否决）

| 类别 | 具体禁止表述 | 示例 |
|------|-------------|------|
| **替代医疗** | 声称中医药可以替代正规医学治疗、暗示患者放弃正规治疗 | "不用去医院，这个方子就能治""西医害人，中医才是正道" |
| **绝对疗效** | 使用"根治""治愈""包好""100%""保证有效""永不复发"等绝对化表述 | "三副药根治糖尿病""这个穴位按摩100%降压" |
| **夸大宣传** | 超出中医药理论和实践范围的疗效声称 | "这个食疗方可治百病""一针下去癌症消失" |
| **非法行医** | 未取得中医医师资格者进行在线诊断、开方 | "你舌苔白，是阴虚，我给你开个方子…" |
| **毒性药材** | 宣传未经炮制的毒性中药材使用方法 | 生草乌、生附子、斑蝥等内服方法指导 |
| **处方药推广** | 推广需凭处方购买的药品或宣传其具体用法用量 | — |

### 2.3 需人工复核的敏感内容

| 类别 | 触发条件 | 处理方式 |
|------|---------|---------|
| **疗效声称** | 包含"有效""明显改善""疗效显著"等词汇但未附研究来源 | 要求补充文献出处或修改为"民间经验""传统认为"等定性表述 |
| **名医背书** | 假借知名中医师、医疗机构名义推荐 | 要求提供授权证明，否则删除相关表述 |
| **秘方公开** | 声称"祖传秘方""宫廷秘方""失传古方" | 标注"民间验方，个体差异大，请在医师指导下使用" |
| **现代医学比较** | 对比中西医优劣 | 修改为各自适用范围说明，不做优劣评判 |

### 2.4 强制免责声明

**适用范围：** 所有中医品类内容（文章、视频、课程、帖子）

**前置免责（内容开头自动或手动添加）：**

> ⚠️ 健康科普，仅供参考。本文内容为中医传统文化知识分享，不构成医疗建议。如有健康问题，请及时咨询专业医师，切勿自行诊断用药。

**后置免责（内容结尾自动或手动添加）：**

> 📖 本文仅供中华传统文化学习交流之用。个体体质差异较大，文中提及的养生方法请在中医师指导下根据自身情况辨证使用。

**实现方式：**

1. **AI生成内容：** AI网关在生成中医品类内容时，自动在 prompt 中注入免责声明要求
2. **用户发布内容：** 前端发布表单中医品类默认勾选"已添加免责声明"，未勾选则阻止提交
3. **接口层：** POST/PUT content 时，若 categoryLevel1 === "中医养生" 且 body 中不含 "健康科普，仅供参考"，返回 400 错误提示

### 2.5 资质要求

| 内容类型 | 发布者资质要求 |
|---------|--------------|
| 中医科普文章 | 无需资质，但需添加免责 |
| 中医在线课程 | 讲师需提交中医医师资格证或相关学历证明进行认证 |
| 中医直播 | 主播需通过中医资质认证 |
| 中医问答 | 回答者需标注是否具备中医资质（认证/非认证） |

## 三、非遗传承品类审核标准

### 3.1 品类范围

一级品类"非遗传承"下的所有内容：传统技艺、传统美术、传统音乐、传统戏剧、曲艺、民俗活动、传统体育/游艺/杂技

### 3.2 知识产权保护规则

| 规则 | 说明 | 违规示例 |
|------|------|---------|
| **传承人身份认证** | 声称"XX级非遗传承人"须提供官方认定文件进行平台认证 | 未认证用户自称"国家级非遗传承人" |
| **作品来源标注** | 展示非遗作品需标注：作者/传承人姓名、制作年代（或"当代作品"）、所属非遗项目名称 | 只放图不标注来源，或模糊标注"传统工艺" |
| **授权转载** | 转载非遗传承人作品须提供授权证明，平台默认保护原创传承人权益 | 未经授权批量搬运非遗大师作品图 |
| **非遗项目名称** | 不得冒用国家级/省级非遗项目名称销售非相关产品 | 非"苏绣"项目产品标称"苏绣精品" |
| **传统工艺与现代制品** | 手工非遗作品与机制仿品必须明确区分标注 | "纯手工紫砂壶"实为模具注浆制品 |

### 3.3 禁止内容

| 类别 | 具体禁止表述 | 处理 |
|------|-------------|------|
| **假冒非遗** | 非非遗项目产品冒用非遗标识、使用"国家级非物质文化遗产"等字样 | 直接驳回 |
| **传承人侵权** | 未经授权使用传承人姓名、肖像、作品图片 | 驳回+告知申诉渠道 |
| **破坏性工艺** | 涉及象牙、犀角、穿山甲鳞片等违禁野生动物制品的非遗内容 | 直接驳回+报告 |
| **文物非法交易** | 以"非遗"为名进行文物或疑似文物交易 | 直接驳回+报告 |
| **地域歧视** | 贬损特定地区非遗技艺、挑起地域对立 | 驳回 |

### 3.4 需人工复核内容

- 新注册用户首次发布非遗品类内容（防批量注册假冒）
- 标注价格超过 ¥10,000 的非遗作品（高价品重点核查）
- 被投诉知识产权的非遗内容（2次投诉自动下架待审）
- 使用"大师""国礼""国宝级"等高级别称谓的（需提供官方认证）

### 3.5 非遗项目名录参考

审核时应参照国务院公布的五批国家级非遗名录（1557项）及各省市非遗名录。平台在 `config_system` 中以 `ich_protected_list` 键维护受保护非遗项目名称清单，机审阶段直接匹配比对该清单。

## 四、易经智慧品类审核标准

### 4.1 品类范围

一级品类"易经智慧"下的所有内容：八字命理、紫微斗数、风水堪舆、姓名学、六爻占卜、奇门遁甲、梅花易数

### 4.2 平台定位表述（强制遵循）

易经品类内容必须坚持以下定位，不得偏离：

> **"传统命理学研究 · 人生智慧参考"**

具体含义：

- **传统命理学研究** = 易经是中华传统哲学体系的一部分，其研究具有文化学术价值
- **人生智慧参考** = 命理分析提供的是参考视角，不是决定论，不替代个人自主判断

### 4.3 禁止内容（一票否决）

| 类别 | 具体禁止表述 | 合规替代表述 |
|------|-------------|-------------|
| **封建迷信** | "命中注定""天意不可违""改命逆天""神仙下凡""前世今生因果报应" | "命理趋势分析""先天禀赋参考""人生阶段特征" |
| **绝对断言** | "你一定…""注定会…""命里就该…""逃不掉的" | "命盘显示有…倾向""传统命理学认为…可能…" |
| **恐吓营销** | "你命中有灾""今年有大劫""不化解就…""血光之灾" | "命盘显示某时段需注意…""传统说法认为此阶段宜…" |
| **违规服务** | 声称可通过做法事、画符、开光、念咒等方式改变运势（涉及欺诈） | —（禁止，无替代） |
| **赌博引导** | 利用易经进行博彩预测（六合彩、彩票号码、赌球等） | —（禁止，无替代） |
| **医疗诊断** | 以命理分析替代医学诊断，建议停药、拒绝治疗 | —（禁止，无替代） |
| **法律规避** | 以命理建议引导用户规避法律责任、从事违法活动 | —（禁止，无替代） |
| **未成年人诱导** | 对未成年人进行命理分析并诱导消费 | —（禁止，无替代） |

### 4.4 需人工复核内容

| 触发条件 | 处理 |
|---------|------|
| 涉及历史政治人物命理分析 | 禁止涉及1949年后政治人物；历史人物需学术化表述 |
| 价格超过 ¥500 的单次命理服务 | 重点核查服务描述是否合规、是否存在虚假承诺 |
| 使用"大师""天师""道长""活佛"等宗教/大师称谓 | 要求提供合法宗教教职人员证明，否则禁用 |
| 用户投诉命理服务存在欺诈 | 客服优先介入，核实后下架并冻结服务收入 |
| 传播"童子命""还阴债""替身"等特定民俗概念 | 视为敏感内容，人工逐条审核 |

## 五、通用审核补充规则

### 5.1 AI生成内容标记

所有通过 AI 网关生成的内容（scene 为 content_generation），在 `tags` 数组中自动追加 `"AI生成"` 标签。运营机器人产生的内容（评论、帖子）自动追加 `"AI互动"` 标签。前端展示时清晰标注，不得隐藏或误导用户认为是人工创作。

### 5.2 内容原创性

- 用户发布内容：通过腾讯云文本相似度检测，相似度 >80% 标记为"疑似转载"，人工复核
- AI生成内容：系统内置三级去重（MD5哈希 + 向量相似度 ≥90% + 人工确认），避免批量生成高度雷同内容

### 5.3 广告与商业推广

传统文化内容允许适度的商业推广（课程推广、作品售卖），但需遵守：
- 广告内容不得超过全文30%
- 商业推广部分需与传统文化内容有实质关联
- 禁止纯广告内容（无实质文化内容仅发广告）

### 5.4 未成年人保护

涉及未成年人的内容：
- 禁止未成年人进行付费命理咨询
- 未成年人传统文化课程需家长知情同意
- 禁止收集未成年人个人信息用于营销

## 六、实施路径

### 6.1 第一阶段：机审拦截（立即）

| 任务 | 实现方式 |
|------|---------|
| 敏感词库补充 | Redis `system:sensitive_words:v1` 追加中医/易经专项词（见 4.5 节） |

### 6.2 第二阶段：人工复核流程（本周）

| 任务 | 实现方式 |
|------|---------|
| 审核规则后台可见 | ContentAudit.vue 增加"审核标准"帮助面板或侧边栏 |
| 品类专项审核队列 | 审核列表增加 categoryLevel1 筛选，中医/易经/非遗可分队列审核 |
| 非遗保护名录 | config_system 新增 `ich_protected_list` 键，CONTENT_AUDITOR 可维护 |

### 6.3 第三阶段：策略优化（持续）

| 任务 | 实现方式 |
|------|---------|
| 审核通过率统计 | AIOperationDashboard.vue 已有按品类健康度统计 |
| 敏感词命中率分析 | 记录每次敏感词命中日志，定期调整词库 |
| 审核标准迭代 | 本文档每季度根据实际案例和监管要求更新 |

## 附录A：审核操作规范

### A.1 驳回操作

驳回时必须填写 `auditReason`，从以下模板选择或自定义：

| 驳回原因模板 | 适用场景 |
|-------------|---------|
| "包含夸大疗效声称，中医内容需添加免责声明" | 中医缺少免责声明 |
| "涉及封建迷信表述，请修改为传统文化研究定位" | 易经违规表述 |
| "缺少非遗传承人授权证明，请提供后重新提交" | 非遗知识产权 |
| "包含绝对化疗效承诺，请修改为参考性建议" | 中医/易经绝对断言 |
| "缺少原创来源标注，请补充后重新提交" | 非遗作品未标注来源 |
| "命中平台敏感词规则，请修改后重新提交" | 敏感词命中 |

### A.2 申诉处理

用户可在收到驳回通知后 7 天内通过"申诉"按钮提交复审请求。申诉由非原审核人处理（SUPER_ADMIN 或指定的 OPERATION_ADMIN 角色）。
