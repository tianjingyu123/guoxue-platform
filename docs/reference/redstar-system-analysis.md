## 六、核心算法 (从JS提取)

### 6.1 天干地支基础数组
```javascript
var Gan = ["甲","乙","丙","丁","戊","己","庚","辛","壬","癸"];
```

### 6.2 年干支计算 (year2jiazi)
```
基准年: 1984 (甲子年)
天干位置 = (abs(year-1984) % 10) 或 (10 - abs%10) % 10
地支位置 = (abs(year-1984) % 12) 或 (12 - abs%12) % 12
```

### 6.3 流年十神计算 (liunianShen)
```
1. 确定日干位置 (riGan)
2. 确定流年天干位置
3. 根据日干阴阳使用对应十神数组
4. 天干十神 = (流年干位置 >= 日干位置) ? 十神[差] : 十神[差+10]
5. 地支十神 = 同法，用藏干主气计算
返回: 天干十神 + 地支十神 (如 "杀枭")
```

### 6.4 节气数据
- 文件: `/Mobile/js/jieqi2.js?v=114`
- 范围: 1600-2100年节气时间戳
- 用途: 农历转换、大运起运时间、流月计算

### 6.5 日干支计算
```
基准: 1984年1月1日 0:00 (甲子日) = timestamp 449510400
天干位置 = floor(天数差) % 10
地支位置 = floor(天数差) % 12
```
