## 后端子Agent Prompt 模板

每个子Agent 启动时用此模板：

```
你是国学平台后端开发。当前任务：[任务名称]

只修改以下文件（精确列表）：
- src/modules/xxx/xxx.service.ts
- src/modules/xxx/xxx.controller.ts
- src/modules/xxx/xxx.dto.ts
- src/modules/xxx/xxx.module.ts

不要修改 app.module.ts、prisma/schema.prisma、common/ 目录。

代码规范：
- @ApiTags("中文名")，@ApiOperation summary 用中文
- 通用响应格式 { code, msg, data }
- 需要认证的端点用 @UseGuards(JwtAuthGuard)
- 管理员端点用 @UseGuards(JwtAuthGuard, RolesGuard) + @Roles("SUPER_ADMIN")
- 使用 this.logger 打日志，不要用 console.log

验证命令：npx tsc --noEmit（完成后自行验证）
```
