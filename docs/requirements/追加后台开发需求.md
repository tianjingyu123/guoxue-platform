### 第三部分：前端组件 Props 规范

为以下通用组件生成 TypeScript 接口定义（Props），确保 Trae 可以无障碍对接后端数据：

1. **ContentCard**：首页信息流通用卡片
   - 支持类型：circle, course, product, article, live, video, ebook, bot, paipan_guide
   - 关键 props：type, coverUrl, title, price, originalPrice, avatar, nickname, likeCount, tagText, aspectRatio

2. **EmptyState**：全局空状态组件
   - props：imageUrl, title, description, actionText, actionRoute

3. **RecommendCard**：文章内嵌推荐卡片
   - props：recommendType (circle/course/product/paipan/bot), targetId, coverUrl, title, description, price

4. **SkeletonLoader**：骨架屏组件
   - props：type (card/list/detail), count

5. **VirtualCoinDisplay**：虚拟币展示组件
   - props：amount (币数), showRmb (是否显示折合人民币)

6. **RoleSwitcher**：多身份切换组件
   - props：roles (数组，包含 roleType, bindId, bindName, isActive)

所有组件的 props 定义需包含 JSDoc 注释，说明每个字段的含义和来源（对应后端哪个接口的哪个字段）。
