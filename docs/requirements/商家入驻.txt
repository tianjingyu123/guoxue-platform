## 给 Claude Code 的指令：商家入驻功能前置开发


「热卜国学」平台后期需支持第三方商家入驻平台，丰富供应链。当前暂不开放此业务，但需要**把完整的入驻流程、管理功能、规则引擎提前开发好**，后期只需在运营后台一键开启即可。

### 一、商家入驻入口

商家入驻的申请入口，放在**个人中心 → 功能入口区**，与“我的课程”、“我的圈子”平级。

| 入口 | 位置 | 展示条件 |
|:---|:---|:---|
| **商家入驻** | 个人中心 → 功能入口网格 | 功能开启后，所有已实名认证的用户可见 |
| **商家后台** | 个人中心 → 身份切换区 | 入驻审核通过后，自动出现「商家后台」身份入口 |

**交互流程**：
```
个人中心 → 点击「商家入驻」
  → 首次进入：展示入驻须知 + 资质要求
  → 填写入驻资料 → 提交审核
  → 审核中：显示进度
  → 审核通过：开通商家后台，个人中心出现「商家后台」入口
  → 审核驳回：显示驳回原因，可重新提交
```

| 联系人姓名 | 文本 | ✅ | 实名 |
| 联系人手机号 | 文本 | ✅ | 需验证 |
| 身份证号 | 文本 | ✅ | 个人商家 |
| 身份证正反面 | 图片 | ✅ | 需上传 |
| 营业执照 | 图片 | ⚠️ | 企业商家必填，个人商家可选 |
| 品牌授权书 | 图片 | ⚠️ | 如代理品牌商品需提供 |
| 保证金 | 数字 | ✅ | 按经营类目自动计算 |

### 四、商家后台功能

入驻成功后，用户在个人中心切换至「商家后台」身份，可看到以下功能：

| 功能模块 | 具体内容 | 说明 |
|:---|:---|:---|
| **商品管理** | 发布商品、编辑、上下架、库存管理 | 商品发布后需平台审核，审核通过方可上架 |
| **订单管理** | 查看订单、发货、处理退款 | 订单状态实时同步 |
| **物流管理** | 填写快递单号、查看物流轨迹 | - |
| **收益管理** | 查看销售收入、分佣明细、提现 | 按商城分佣规则自动计算 |
| **评价管理** | 查看回复用户评价 | 不可删除评价 |
| **商家资料** | 编辑店铺信息、更换Logo | 关键信息修改需平台审核 |
| **数据看板** | 商品浏览量、销量排行、收入趋势 | 简化版数据图表 |

### 五、平台对商家的管控

| 管控维度 | 具体措施 |
|:---|:---|
| **商品管控** | 商家发布的所有商品必须经平台审核后方可上架；平台有权随时下架违规商品 |
| **资金管控** | 所有交易资金走平台统一商户，商家收入按周期结算，不可自行收款 |
| **保证金管控** | 商家必须缴纳保证金方可开店；有违规行为可从保证金中扣罚；退店时保证金按规定退还 |
| **履约监控** | 平台监控商家的发货时效、退款率、投诉率；超标的商家将被限制经营或清退 |
| **内容管控** | 商家发布的所有内容需通过平台AI+人工审核；敏感词自动拦截 |
| **协议约束** | 商家需签署电子《商家入驻协议》，明确权责、分佣、处罚规则 |

### 六、运营后台（商家管理）

在运营管理后台的「内容管理」模块下，新增「商家管理」子模块：

| 功能 | 说明 |
|:---|:---|
| **商家列表** | 查看所有入驻商家，按状态/类目筛选 |
| **入驻审核** | 审核商家的入驻申请，查看资质材料，通过/驳回（填写原因） |
| **商家详情** | 查看商家完整信息、经营数据、违规记录 |
| **商家状态管理** | 正常/暂停经营/永久关闭，状态变更需通知商家 |
| **保证金管理** | 查看保证金缴纳记录、扣罚记录、退还状态 |
| **商品审核** | 商家发布商品的审核队列（与平台自营商品审核共用） |
| **违规管理** | 记录商家违规行为，设置处罚（警告/扣保证金/下架商品/暂停经营/清退） |

### 七、分佣与结算规则（可配置）

| 商品类型 | 商家所得 | 平台抽成 | 推广站长分佣 |
|:---|:---|:---|:---|
| 商家自有商品 | 80%-90%（可配置） | 10%-20% | 从平台抽成中分配 |
| 平台代销商品 | 商家无 | 100% | 从平台抽成中分配 |

### 八、功能开关

在运营后台「系统设置 → 功能开关」中，增加以下控制项：

| 开关项 | 默认状态 | 说明 |
|:---|:---|:---|
| **商家入驻功能** | 🔴 关闭 | 开启后，个人中心出现「商家入驻」入口 |
| **商家后台功能** | 🔴 关闭 | 开启后，审核通过的商家可访问商家后台 |
| **商品上架自动审核** | 🔴 关闭 | 开启后，商家发布的商品无需人工审核自动上架 |
| **保证金自动计算** | ✅ 开启 | 根据经营类目自动计算保证金金额 |

### 九、数据表设计（补充到 Prisma Schema）

```sql
-- 商家入驻表
CREATE TABLE merchant (
  id BIGSERIAL PRIMARY KEY,
  user_id BIGINT NOT NULL,          -- 关联用户ID
  name VARCHAR(100) NOT NULL,        -- 商家名称
  logo VARCHAR(500),                 -- 商家Logo URL
  intro VARCHAR(200),                -- 商家简介
  categories JSONB,                  -- 经营类目
  contact_name VARCHAR(50),          -- 联系人姓名
  contact_phone VARCHAR(20),         -- 联系人手机号
  id_card_number VARCHAR(20),        -- 身份证号（加密存储）
  id_card_images JSONB,              -- 身份证正反面URL
  business_license VARCHAR(500),     -- 营业执照URL
  brand_authorization VARCHAR(500),  -- 品牌授权书URL
  deposit_amount DECIMAL(10,2),      -- 保证金金额
  deposit_status VARCHAR(20),        -- 保证金状态
  status VARCHAR(20) DEFAULT 'pending', -- 审核状态
  reject_reason TEXT,                -- 驳回原因
  agreement_url VARCHAR(500),        -- 签署的协议URL
  signed_at TIMESTAMP,               -- 签约时间
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- 商家违规记录表
CREATE TABLE merchant_violation (
  id BIGSERIAL PRIMARY KEY,
  merchant_id BIGINT NOT NULL,
  violation_type VARCHAR(50),        -- 违规类型
  description TEXT,                  -- 违规描述
  penalty_type VARCHAR(50),          -- 处罚类型
  penalty_amount DECIMAL(10,2),     -- 处罚金额
  status VARCHAR(20) DEFAULT 'active',
  created_at TIMESTAMP DEFAULT NOW()
);
```
