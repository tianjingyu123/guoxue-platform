## 热卜国学平台 · 战略升级与AI辅助运营需求文档 V1.0


### 一、平台定位升级

| 维度 | 当前定位 | 升级后定位 |
|:---|:---|:---|
| **一句话** | 以易经排盘为核心的国学工具平台 | **中华优秀传统文化传承与创新综合平台** |
| **Slogan** | 探寻东方智慧 | 可升级为“**传承东方智慧，发现生活之美**”或保持原Slogan |
| **新增内容品类** | - | 国学经典、中医养生、诗词歌赋、民俗节庆、非遗传承、茶道香道、书法绘画、传统音乐、武术太极 |
| **目标用户** | 易学从业者+爱好者 | 传统文化全品类爱好者、从业者、学习者 |
| **政策定位** | 易学工具+文化研习 | **中华优秀传统文化传承与创新**，主动对接国家“文化自信”“非遗保护”等政策方向 |


### 二、技术架构调整

#### 2.1 内容品类标签体系

在现有数据库基础上，新增内容品类字段，支持多级分类：

```
一级品类：国学经典、中医养生、诗词歌赋、民俗节庆、非遗传承、茶道香道、书法绘画、传统音乐、武术太极、易经智慧

二级分类（示例）：
- 国学经典：儒家经典、道家典籍、佛学经典、诸子百家
- 中医养生：中医基础、食疗药膳、经络穴位、四季养生
- 诗词歌赋：唐诗、宋词、元曲、现代诗词创作
- 非遗传承：传统技艺、传统美术、传统音乐、民俗活动
- 易经智慧：八字命理、紫微斗数、风水堪舆、姓名学
```

**技术要求**：
- 在 `course`、`circle`、`product`、`article`、`post`、`video`、`ebook` 等表中新增 `category_level1`、`category_level2` 字段
- 在 `config_system` 表中维护品类标签树，支持动态增删改
- 用户注册时可选择兴趣品类，系统据此生成个性化推荐

#### 2.2 首页与发现页调整

- 首页信息流支持多品类混合推荐，每个内容卡片标注品类标签
- 发现页增加品类导航入口（宫格或Tab形式）
- 发现页以“内容专栏”形式展示各品类内容（详见下文运营部分）

#### 2.3 内容审核标准更新

- 中医品类：禁止“包治百病”“替代正规医疗”等夸大宣传，需添加“健康科普，仅供参考”免责提示
- 非遗品类：保护传承人知识产权，禁止假冒非遗产品
- 易经品类：坚持“传统命理学研究”“人生智慧参考”定位，杜绝封建迷信表述


### 三、AI辅助内容运营体系（核心）

这是本次升级的关键。在初期没有足够老师和内容的情况下，由 Claude Code 搭建的AI系统辅助平台进行内容填充和运营维护，确保各板块“不空、有内容、能看”。

#### 3.1 各品类“种子内容框架”

为每个新增品类规划以下基础内容框架，由AI辅助生产：

| 内容类型 | 数量 | 说明 | 示例 |
|:---|:---|:---|:---|
| **基础知识库** | 3-5篇/品类 | 该领域的入门指南、核心概念解释 | 中医：《九种体质自测指南》、诗词：《格律基础入门》 |
| **经典精华库** | 5-10条/品类 | 该领域经典著作的核心观点、名句赏析 | 国学：《论语》精华20句、中医：《黄帝内经》四季养生要点 |
| **玩法教程库** | 2-3篇/品类 | 告诉用户“怎么在这个平台上学XX” | 《如何在平台学中医》、《非遗手艺人如何开店》 |

**AI生产流程**：
1. Claude Code 调用 DeepSeek API 生成初稿
2. AI联网搜索权威信源丰富内容（如引用《中医体质分类与判定》标准）
3. 运营人员审核润色，添加平台调性后发布
4. 发布时自动打上对应品类标签，进入首页推荐池

#### 3.2 智能推荐与空板块处理

**问题**：新品类内容少，用户点进去可能看到空列表。

**解决方案**：

（1）**公共页面“专栏”化，而非“列表”化**

在发现页，不按传统方式列出“空栏目”，而是展示为“内容专栏”或“专题卡片”。每张专栏卡片包含：
- 专栏标题、简介
- 该品类下已有的2-3篇热门内容（以横向滑动形式展示）
- 数据标签（如“12篇文章”、“3门课程”）

即使内容总量不大，也能呈现“精心策划”的充实感。

（2）**首页模块化配置**

V0设计首页时，不要搞大类目Tab。改为灵活的模块化设计，通过运营后台配置：
- 内容少时：多推热门圈子、核心课程、排盘工具
- 内容多时：逐步增加分类推荐模块

运营后台可随时增、删、改首页各模块的展示内容和顺序。首页始终展示最优质的内容，避免暴露某些领域的匮乏。

（3）**内容不足时展示“即将上线”**

对于内容暂时匮乏的领域，在界面上使用“即将上线”的卡片占位，写明“XX领域即将开启，敬请期待”。让首页显得丰富，同时给用户制造期待感。

#### 3.3 AI驱动的自动化运营引擎

需要开发一个**自动化运营引擎**，核心功能包括：

**（1）智能内容推荐与填充**

| 功能 | 说明 | 触发条件 |
|:---|:---|:---|
| **新品填充** | 新品类上线时，自动从知识库中选取基础内容填充首页和发现页 | 新品类创建时 |
| **内容轮换** | 定期更新首页推荐内容，避免用户反复看到相同内容 | 每日/每周定时 |
| **空板块检测** | 检测某个品类内容是否不足（如<5篇），自动提醒运营补充 | 每日检测 |
| **热门内容自动推荐** | 根据互动数据（点赞/评论/收藏）自动标记热门内容，加入推荐池 | 实时/每小时 |
| **关联推荐** | 根据用户浏览的品类，自动推荐相关品类的内容（如看了中医文章，推荐中医课程和圈子） | 用户浏览时实时触发 |

**（2）虚拟运营机器人**

在平台运营初期，可以部署多个“虚拟运营机器人”，模拟真实用户的活跃行为：

| 机器人角色 | 行为模式 | 目的 |
|:---|:---|:---|
| **内容点赞机器人** | 对新发布的优质内容自动点赞（1-3个赞/篇） | 让新内容不显得冷清，激励创作者 |
| **评论互动机器人** | 对热门内容自动生成1-2条相关评论（AI生成，标记为“AI互动”） | 带动讨论氛围，引导真实用户参与 |
| **圈子签到机器人** | 在活跃度低的圈子自动发布每日话题帖 | 保持圈子活跃度 |
| **问题提问机器人** | 在付费问答板块自动提出高质量问题 | 引导讲师回答问题，展示平台专业度 |

**重要原则**：
- 所有AI生成的内容和互动**必须标注“AI生成”标签**，让用户清楚知道这是AI行为
- 运营后台可随时开启/关闭各个机器人
- 当真实用户互动量达到一定阈值后，自动降低对应机器人的活跃频率

**（3）AI运营数据简报**

| 功能 | 说明 | 频率 |
|:---|:---|:---|
| **品类健康度报告** | 各品类内容数量、互动率、新增内容趋势 | 每周 |
| **内容质量评估** | AI自动对内容进行质量评分，标记低质内容 | 每日 |
| **用户增长分析** | 各品类吸引的新用户数、留存率 | 每周 |
| **运营建议** | 基于数据分析，AI给出具体运营建议（如“中医品类互动率上升，建议本周增加中医内容曝光权重”） | 每周 |


### 四、初期运营策略：AI先跑，真人逐步进场

**第一阶段（1-2周）：AI全权运营**
- AI自动生产各品类基础内容（知识库+精华库+教程库）
- 虚拟运营机器人开始工作（点赞、评论、话题帖）
- 首页和发现页内容由AI推荐引擎自动配置

**第二阶段（3-4周）：定向邀请创作者**
- 从知乎、B站、小红书等平台邀请各领域创作者入驻
- AI自动生成邀请邮件模板，提供流量扶持和身份认证
- 首批5-10名核心创作者入驻后，AI自动降低对应品类的运营频率

**第三阶段（1-2月）：真人逐步接管**
- 当某个品类真实内容≥20篇、真实日互动≥50次时，自动关闭该品类的虚拟运营机器人
- AI转为辅助角色：内容审核、质量评分、推荐优化
- 运营人员通过AI数据简报了解各品类健康度，做决策


### 五、运营后台新增功能

在现有后台管理系统的基础上，新增以下功能：

| 功能模块 | 具体功能 |
|:---|:---|
| **内容品类管理** | 品类标签增删改查、品类内容数量统计、品类健康度仪表盘 |
| **AI运营引擎控制台** | 内容自动生成任务管理、虚拟运营机器人开关、运营规则配置 |
| **内容推荐配置** | 首页模块化配置、发现页专栏配置、推荐权重调整 |
| **运营数据看板** | 各品类内容量/互动量/用户增长、AI运营效果追踪 |


### 六、给 Claude Code 的具体开发要求

1. **品类标签体系**：在数据库中新增品类字段，设计标签树数据结构，在config_system表中动态维护

2. **AI内容自动生成**：编写定时任务，调用DeepSeek API自动生成各品类基础内容（知识库、精华库、教程库）。生成内容存入草稿箱，待运营审核后发布

3. **自动化运营引擎**：
   - 实现内容轮换推荐逻辑
   - 实现空板块检测和自动提醒
   - 实现关联推荐算法

4. **虚拟运营机器人**：
   - 开发可配置的虚拟机器人系统
   - 每个机器人独立的行为模式和频率控制
   - 所有AI行为全程可追溯、可关闭
   - AI生成内容必须标注“AI生成”标签

5. **运营数据看板**：开发品类健康度仪表盘、AI运营效果追踪报表

6. **功能开关**：所有AI运营功能在后台可独立开启/关闭


### 七、实施优先级

| 优先级 | 任务 | 说明 |
|:---|:---|:---|
| **P0（立即）** | 品类标签体系、数据库字段扩展 | 所有品类扩展的底层基础 |
| **P0（立即）** | AI内容自动生成（基础知识库+经典精华库） | 先让新品类有内容可看 |
| **P1（1-2周后）** | 虚拟运营机器人系统 | 保持平台活跃度 |
| **P1（1-2周后）** | 自动化运营引擎（推荐+空检测+轮换） | 让内容运营自动化 |
| **P2（2-4周后）** | 运营数据看板、品类健康度报告 | 让运营决策有数据支撑 |
| **P2（2-4周后）** | AI内容自动生成（玩法教程库） | 降低用户参与门槛 |
