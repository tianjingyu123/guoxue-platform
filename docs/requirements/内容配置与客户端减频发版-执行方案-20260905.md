## 1. 分类处理，不把所有优化都变成重新安装

| 变化 | 交付方式 | 是否重打原生包 | 必须保留的验收 |
| --- | --- | --- | --- |
| 已有 CMS 支持的文章、商品介绍、封面、活动文案等数据 | 现有后台内容流程 | 通常不需要 | 内容真实性、权限、敏感字段、预览与实际详情、下架效果 |
| 当前协议支持的首页大卡片间隔、学伴分类颜色、已有功能开关 | 受控配置更新 | 新配置运行时首次交付需要；之后相同协议内不需要 | 白名单、版本、账号隔离、灰度、回滚、旧客户端兼容 |
| 管理后台页面变化 | 单独构建和部署后台 | 不默认重打 | 后台角色、真实接口、浏览器交互 |
| 服务端实现修复，保持已有 API 契约 | 服务端构建/滚动部署 | 不默认重打 | 当前与上一受支持客户端契约、错误处理、回滚兼容 |
| 新页面逻辑、分享 SDK、传感器、原生布局、登录支付桥 | 合并为同一个客户端候选 | 需要 | 真实 Android/iOS 等目标端、安装版本、编译产物、审核要求 |
| 公共依赖、共享库、构建配置、未知路径 | 保守纳入全端影响评审 | 未证明无影响前需要 | 依赖门禁、各端构建、配置和产物绑定 |

这不是任意页面的“免发版热更新”。不下发 JavaScript、组件代码、原生模块或可执行模板；不通过开关向审核与普通用户提供不同的隐蔽功能。课程名称和现有学习功能按用户最后确认保留。

## 2. 本轮已实现的配置运行时

复用 `FeatureFlagService` 已有版本历史、灰度与回滚，不新增平行配置数据库。

- `/config/client` 与 `/config/features` 标注 `Cache-Control: private, no-store`，防止个人灰度快照被共享缓存。
- 保持 `schemaVersion=1`；客户端未知字段忽略，未知协议拒收，布尔值/数字边界/样式类按白名单校验。
- 前台每 60 秒检查刷新，仍复用请求合并和缓存 TTL；进入后台停止周期请求。再次前台由既有 `onShow` 拉取。
- 使用当前配置版本参与响应式读取，移除 UI 适配器永久保留旧缓存的独立副本。
- 登录、退出、切换账号时清空旧会话快照；旧请求晚到不能覆盖新账号，不能清除新账号在途请求。
- 只有匿名快照写入环境隔离的 v2 磁盘缓存；不再读取可能含账号灰度的旧 v1 缓存。凭据不写配置缓存。
- 普通样式缓存最多七天；模块、分享类和微信 App 登录等敏感开启值最多信任五分钟，断网持续前台也失效。长 TTL 不能延迟五分钟后的重新核验。
- 客户端开关只是展示和降级，不能代替服务端能力授权、额度及资金门禁；用户已有付费权益与履约不能因此被删除。

边界：当前远程 UI 字段仅有 `home.bigCardInterval`、`agentCard.categoryColors`。分享模板、圈内资格阈值、额度和动态页面编排尚未接入这个协议，不能宣称已经全部后台可配。

## 3. 构建前先分析真实差异

新增只读工具：

```powershell
node scripts/release/classify-change-impact.mjs --base <上一已冻结SHA> --head HEAD --include-working-tree
```

- 同时包含已提交、暂存、未暂存和未跟踪文件；对重命名按删除/新增两端处理。
- 输出各类构建建议、迁移评审、部署评审与兼容性评审要求。
- 未识别路径、共享依赖与构建脚本保守进入全端评审，失败不给“无需发版”的假绿结果。
- `authorizationToPublish` 永远为 false。工具不能替代用户授权，不能提交迁移、推送、上传或上线。
- 文件路径分析只是保守预检。服务端 API 破坏性变化仍可能要求客户端升级，不得因为“只改 server”跳过兼容性判断。

## 4. 从本批开始执行的合包规则

1. 同一批分享、罗盘、底部安全区与圈内能力修复先在独立工作树完成，不为每次文案或菜单调整分别增加云包。
2. 每个缺陷保留复现、根因、行为测试和目标设备证据。自动化通过不关闭真机缺陷。
3. 本地测试、类型检查、目标端构建先通过，再冻结唯一 SHA。客户端源码不再写入后，才申请/执行该候选的云打包。
4. 原生包、H5、服务端配置分别记录源码 SHA、产物 SHA、公开配置指纹与实际安装版本；不拿旧包结果给新候选背书。
5. 内容/配置发布独立记录版本和审批，先预览/受控灰度，再正常发布。危险外发/资金/不可逆动作仍走现有真人审批边界。
6. 原生真实故障优先回退配置或服务端兼容修复；确需代码修复时只补最小候选。不会为减少版本数量压住安全问题。
7. 本次尚未重打包；版本号保持现有 v243。最终冻结前不再递增版本号，不触发多份竞争候选。
