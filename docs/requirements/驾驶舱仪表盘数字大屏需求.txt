## 平台驾驶舱、仪表盘与数字大屏 · 完整需求文档 V3.0


### 一、总体架构：三种形态的定位与边界

| 形态 | 定位 | 给谁看 | 放在哪 | 核心目的 |
|:---|:---|:---|:---|:---|
| **管理驾驶舱** | 老板/高管的战略决策工具 | 老板、CEO、投资人 | **管理后台**首页 | 一眼掌握全平台核心经营状况 |
| **角色仪表盘** | 各岗位的工作台 | 运营、财务、客服、品控、圈主、站长等 | **管理后台/用户端**各角色登录后首页 | 聚焦本职工作的数据与待办 |
| **数字大屏** | 平台实力的可视化名片 | 访客、媒体、投资人、政府 | **独立页面**，须经审核方可访问 | 对外展示平台规模与技术实力 |


### 二、管理驾驶舱（老板/高管专属）

**位置**：管理后台 → 超级管理员登录后的首页

**核心指标卡片（第一行）**：
- 实时交易额(GMV)、付费用户数、活跃用户数、分佣总支出、净利润预估

**趋势图区**：
- 收入构成堆叠图（课程/商品/会员/打赏/咨询 各占比）
- 用户增长与获客成本折线图（双Y轴）
- 近30天各业务线收入趋势

**异常预警区**：
- 支付服务中断、关键API错误率飙升、退款率异常

**排行榜区**：
- 热门课程Top5、活跃圈主Top5、推广达人Top5、用户新增Top5分站


### 三、后台运营角色仪表盘（6种角色各自专属）

**位置**：管理后台 → 各角色登录后的首页

| 角色 | 仪表盘重点模块 |
|:---|:---|
| **运营总监** | 待审核总数（内容/商品/评论）、7日用户留存率、新增用户趋势、各渠道来源分析漏斗、按紧急程度排序的待审队列 |
| **财务总监** | 待审批提现总额、待开票总额、分佣结算倒计时、毛利率趋势图、退款率分布饼图、异常大额提现标红 |
| **客服总监** | 24H工单/举报量、平均首次响应时长、待处理纠纷数、投诉类型分类统计、退款原因高频词云、超时未回复标红 |
| **内容品控** | 待审课程/电子书数、通过率、违规下架数、头部内容流量占比饼图、新课冷启动曝光漏斗 |
| **商品品控** | 待审商品数、48H发货率、平均物流时长、库存预警商品数、快递时效热力图、热卖商品库存消耗趋势 |
| **超级管理员** | 全平台所有核心指标聚合、各业务线健康度仪表盘、系统健康监控（第三方服务状态、数据库连接、Redis状态） |


### 四、用户端角色仪表盘（4种角色各自专属）

**位置**：个人中心 → 切换对应身份 → 管理后台首页

| 角色 | 仪表盘重点模块 |
|:---|:---|
| **分站站长** | 本月预估佣金、昨日推广成交额、推广带来新用户数、推广链接点击数、转化率；每日佣金趋势折线图；推广渠道转化率对比柱状图；推广链接收益排行；最近成交订单列表；沉默用户提醒（7天未活跃）；佣金结算倒计时 |
| **运营商** | 含站长全部指标 + 名下站长总数/活跃数/沉寂数；团队总佣金、管理奖收入；名下站长业绩排行Top10；沉寂站长列表（一键推送提醒）；团队新增站长趋势；异常佣金波动预警；名额使用情况（已用/总量） |
| **线下驿站** | 本月课程收入、本月商品收入、本月开课场次、累计学员数、到课率；收入趋势折线图（课程/商品分色）；到课率趋势；最受欢迎课程排行；热销商品排行；最近学员报名列表；库存预警商品列表；待确认讲师预约；即将开课课程提醒 |
| **圈主** | 圈子成员数、本月新增成员、本月收入（入圈费+课程+商品+问答）、内容互动率；成员增长趋势折线图；收入来源占比饼图；内容互动趋势；圈内活跃成员贡献榜Top10；热门内容Top5；最近加入成员列表；成员流失预警（近期不活跃成员）；待回复付费提问；待确认知识库候选内容 |


### 五、直播间数据大屏（参考抖音直播大屏）

**位置**：独立页面，仅主播/运营/超管可访问，需登录+角色权限

**核心模块**：

**（1）实时概览区（顶部核心指标卡片）**
- 实时在线人数（含峰值）、累计观看人数、新增粉丝数、打赏收入、成交金额(GMV)、成交订单数、平均观看时长、互动率
- 刷新频率：在线人数每5秒，其他每分钟

**（2）实时趋势图区**
- 在线人数波动曲线（标注关键事件节点：发券、秒杀、连麦）
- 成交金额趋势图（每分钟柱状图，标注商品讲解时段）
- 流量来源分析（首页推荐/关注/圈子入口/搜索/分享/同城）
- 观众互动趋势（评论/点赞/分享 三条折线叠加）

**（3）商品讲解与转化区**
- 当前讲解商品（主图、名称、价格、库存）
- 商品点击率、成交转化率、实时销量
- 本场全部讲解商品按成交额排行

**（4）观众画像区**
- 性别分布饼图、年龄分布柱状图、地域分布中国地图热力图、兴趣标签词云

**（5）互动与打赏区**
- 评论词云（实时生成）、打赏用户Top10、各类礼物发送数量统计

**（6）主播表现区**
- 累计讲解时长、语速分析（可选）、商品讲解覆盖（已讲/计划）

**（7）对比与复盘区**
- 本场 vs 上一场同类型直播关键指标对比
- 直播结束后自动生成结构化复盘报告（含关键指标汇总和趋势分析），支持导出PDF/Excel
- 分钟级数据自动保存，形成结构化数据资产


### 六、对外数字大屏（独立页面 + 安全审核机制）

**位置**：独立页面，不依赖登录，但**须经审核方可访问**

**适用场景**：公司展厅大屏、融资路演、政府考察、嵌入官网、行业峰会

**对外大屏类型**：

| 大屏类型 | 展示内容 | 目的 |
|:---|:---|:---|
| **平台综合实力大屏** | 累计用户数、日活、课程数、圈子数、商品数、古籍数、交易额实时滚动 | 对外展示平台规模，提升可信度 |
| **实时交易大屏** | 实时订单地图、支付金额滚动、品类交易占比 | 融资路演、投资人展示 |
| **内容生态大屏** | 全平台内容增长趋势、热门内容词云、创作者排行榜 | 展示平台内容丰富度 |
| **AI能力大屏** | AI调用量、Token消耗、智能体对话量、知识库体量 | 展示平台技术实力，差异化竞争 |
| **线下驿站分布大屏** | 全国驿站地图、线下课场次、到课率、学员评价 | 展示线下覆盖能力 |


### 七、对外大屏安全规则

**7.1 发布审核机制**

任何人（包括运营）创建对外大屏链接后，必须经**超级管理员审批**，方可生效和访问。未经审核的大屏链接一律不可访问。

**7.2 动态Token加密**

每个大屏链接生成时，系统自动附带**动态加密Token**，Token中包含：
- 访问权限
- 生效时间
- 失效时间（最长不超过24小时，可配置为1/6/12/24小时）
- 允许访问的IP白名单（可选）

Token通过**HMAC-SHA256**签名，防止URL被篡改。

**7.3 链接失效机制**

- 超过失效时间后，Token自动失效，链接立即无法访问
- 超级管理员可在后台**随时手动撤销**任何已发布的大屏链接
- 撤销后，即使Token未过期，链接也立即失效

**7.4 数据脱敏**

对外展示的大屏，所有用户个人信息必须脱敏处理：
- 手机号显示为 `138****8888`
- 姓名显示为 `张**`
- 采用字段级脱敏规则，确保低权限用户无法通过任何方式获取敏感信息

**7.5 水印保护**

对外大屏页面叠加**半透明水印**，包含访问者信息和时间戳，防止截图外泄。

**7.6 防嵌入**

对外大屏页面设置 `X-Frame-Options: DENY`，防止被第三方网站iframe嵌入。

**7.7 访问日志与告警**

- 所有对外大屏的访问行为全量记录：访问时间、访问者IP、User-Agent、访问时长、Token信息
- 运营后台可查看访问日志
- 发现异常访问（如同IP高频访问）自动告警


### 八、技术实现要求

| 维度 | 要求 |
|:---|:---|
| **实时性** | 数字大屏通过WebSocket推送实时数据，刷新间隔≤5秒 |
| **可视化** | 使用ECharts实现图表，支持深色/浅色主题切换（数字大屏推荐深色科技风） |
| **响应式** | 数字大屏适配1920×1080、3840×2160等常见大屏分辨率 |
| **数据脱敏** | 对外大屏需对用户个人信息进行字段级脱敏处理 |
| **性能** | 独立部署，不影响主业务API性能 |
| **Token验证** | 对外大屏必须配置Token签名校验，支持手动撤销和自动过期 |
| **直播大屏** | 直播间大屏需登录+角色权限，主播/运营/超管可访问 |
