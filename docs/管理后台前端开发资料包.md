## 一、管理后台 API 接口文档

### 统一规范

```
Base URL：/api/v1
认证方式：Bearer Token（Header: Authorization: Bearer <jwt>）
响应格式：{ code: number, msg: string, data: T }
错误码：  200 成功 / 400 参数错误 / 401 未认证 / 403 无权限 / 404 不存在 / 409 冲突 / 429 限流
```

### 分页参数约定

所有列表接口统一使用：

```typescript
interface PaginationQuery {
  page?: number;      // 默认 1
  pageSize?: number;  // 默认 20，最大 100
  sortBy?: string;    // 排序字段（可选）
  sortOrder?: "asc" | "desc";  // 默认 desc
}

interface PaginatedResponse<T> {
  list: T[];          // 或 items / records / <模块名复数>
  total: number;      // 总条数
  page: number;
  pageSize: number;
}
```

// 权限判断 Hook 示例
function usePermission() {
