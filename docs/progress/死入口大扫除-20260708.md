# 死入口大扫除 — 对账表（2026-07-08 批次）

**背景**：董事长真机点「设置」弹"功能开发中"而设置页早已存在——本批全库清理"目标页在、入口却死"的断层。
**方法**：`grep "toastComingSoon|功能开发中|敬请期待"` 全量审计（apps/mobile/src，共 60+ 命中），逐处三分类：
- **A类** = 目标页已存在且已在 pages.json 注册 → 改接真实路径
- **B类** = 目标功能确实没有（缺页面/缺后端端点/缺资质）→ 保持诚实降级不动
- **C类** = 入口本身无意义（残留占位/死代码）→ 删除

**统计：A类 12 处（已接通）· C类 7 处（已删除）· B类 ~34 处（诚实降级保持）**
