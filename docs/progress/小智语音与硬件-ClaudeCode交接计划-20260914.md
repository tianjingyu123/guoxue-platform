## 已确认产品方向

- 文字与语音是独立入口、页面和会话。文字走热卜自有模型网关；语音由小智负责完整识别、回答和播报，不接 Coze，不要求小智改接我们的模型。
- 知识库统一由热卜维护，语音通过 MCP 按权限查询圈子知识，并保留模型通识。
- 圈主提交角色、提示词和音色，平台审核后发布。腾讯云内容审核作为知识入库环节；不把机器审核通过等同版权授权，也不取消投诉、停用和违规处置。
- 硬件优先现成公版。圈主对应产品/模板，设备对应序列号与使用人。声纹、声音复刻、定制硬件后置。
- 收费优先验证圈主预付技术额度；汇付分账、80/20比例仍须确认成本承担、主体和退款规则，不能当成已完成设计。

## 建议验收标准

- 同一环境至少30轮语音，记录用户说完至首个可听回答的P50/P95，区分普通问答与知识检索。可把P50不高于2秒作为初始体验目标，非供应商保证。
- 记录打断至停止播放耗时；挂断后无继续播放或后台失控任务。
- 两用户、两圈隔离；过期/退出成员不得通过MCP继续查私有知识。
- 至少覆盖正常、权限拒绝、断网、重连、知识无命中、知识撤回和服务失败。
- 商业验收必须用商业环境，不拿社区结果推定性能一致。
