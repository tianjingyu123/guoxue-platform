1. 后台仍保留旧H5地址时，直接打开新域名测试HTTPS、首页及商品深链、微信登录回原页面、支付和退款订单刷新；确认API只有一层/api/v1，确认旧域名继续可用。
2. 两节点健康、静态版本一致及前述真机链路通过后，后台品牌配置仅修改 h5Url 为 https://gx.yrydai.com/h5/。
3. 分别从两节点品牌接口核实新地址，客户端重新进入前台后检查课程、商品、文章、邀请等新分享链接保留路由、推荐参数；历史链接继续工作。客户端新域名的本地登录存储独立，首次访问可能需要重新微信授权。
4. 若入口异常，后台 h5Url 恢复记录的旧值。若涉及代码故障，按本次现场备份逐节点回退镜像和H5静态包，再核实健康及旧域名支付。不要覆盖更新的主线版本。

后台切换仅适用于已完成接入的域名；新增任意域名仍需证书、转发及微信登记，不能通过程序绕过。
