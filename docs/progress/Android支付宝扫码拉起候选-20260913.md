# Android 支付宝扫码拉起候选

基线：360ac6d3b7fd608976335f7f99bed43cc1c63dd1。工作树：`.worktrees/huifu-android-native-20260913`。本轮仅本地候选，没有上线、安装覆盖手机或发起真实支付。

## 官方协议核实

汇付当前[支付宝APP联调攻略](https://paas.huifu.com/help/dev_guide/zf/zfb/app.md)明确给出 A_NATIVE 预下单后，用二维码链接构造支付宝扫码 scheme，通过 Android ACTION_VIEW 打开。前置条件为商户开户审核、支付宝实名及费率配置，没有将托管收银台列为条件。

官方示例前缀为 `alipays://platformapi/startapp?saId=10000007&qrcode=`。本实现只接受 HTTPS、精确主机 qr.alipay.com、无用户信息/端口/控制字符的链接，并对整个二维码URL使用encodeURIComponent，防止内层参数改变外层scheme。

[聚合正扫API](https://paas.huifu.com/partners/api/doc/smzf/api_jhzs.md)的响应表把 `qr_code` 与 `pay_info` 列为独立字段，前者是NATIVE二维码链接，后者是支付返回信息。攻略的泛称“payinfo信息中的qr_code”不构成JSON嵌套契约。本实现只用已验签后端返回的qrCode，不解析raw或把任意payInfo转换成支付串。

支付宝[原生App支付接入](https://aipay.alipay.com/docs/vibe-pay/mobile-app-pay/app-pay-integration-guide-new.html)使用服务端签名的orderStr交给payV2；与本次二维码路径不同。tradeNO属于对应JS/小程序桥接的交易号，不能把二维码URL、汇付流水号、支付宝交易号、orderStr互相替代。

[汇付H5攻略](https://paas.huifu.com/help/dev_guide/zf/zfb/h5.md)实际也给出原生Intent示例，不足以保证所有浏览器都能跨App跳转，尤其不能据此宣称微信内H5可直接拉起支付宝。本次保留原H5行为。

[汇付银联APP攻略](https://paas.huifu.com/help/dev_guide/zf/yl/app.md)要求银联业务/报备完成，取得union_order_no后交支付控件；聚合正扫的U_NATIVE二维码并不等同该接口。本次不改银联。

客户端使用[DCloud openURL](https://www.html5plus.org/doc/zh_cn/runtime.html#plus.runtime.openURL)的失败回调。调用返回或没有报错不代表付款成功。

## 变更范围

- purchase-sheet的Android支付宝入口创建业务订单后转现有paying页；iOS入口不创建新订单。微信路径保持原逻辑。
- paying页仅APP支付宝订单挂载新组件，不增加页面路由；充值和其他支付路径保持原逻辑。
- 新组件展示待支付、打开失败、手动查单及返回订单；页面onShow恢复查单、onHide暂停轮询、卸载停止。自动查询最多70次，每3秒一次。
- 状态机先读取本人订单，只有服务端Order为PAID/SHIPPED/COMPLETED才成功；汇付查询trans_stat=S仍需再读订单。通道查询失败也再读一次，兼容通知已经入账。
- 首次请求前保存按账号和订单隔离的标记，取得凭据后保存原二维码及交易号。重试只打开同一凭据；创建前再读持久化标记，防多个页面重复请求。读取已有其他渠道交易时阻止切换下单。
- 本地缓存凭据在打开前再次校验本人订单及交易号一致；账号变化停止。缓存使用rebu:前缀随既有退出登录流程清理。
- 服务端、数据库、支付渠道配置均无修改；没有新增调试接口。

## 明确限制

缓存丢失而服务端已存在汇付单、网络下单超时而未拿到有效二维码、凭据超过两小时等情况，只能查原单或返回订单处理。本候选不自动重建支付，也没有新增服务端凭据恢复接口，不能称为所有失败均可恢复。

持久化标记不是原子锁。测试覆盖同一JavaScript上下文中的多页面实例及重复进入；跨进程、跨设备或极端并发仍须服务端幂等控制。本候选只能尽力降低客户端重复发起，不宣称解决分布式重复交易问题。

取消支付宝付款后不会收到本方案专属的付款结果回调；用户返回时按原订单重新查询，仍未支付可重新打开原凭据。未安装支付宝等打开错误可重试，但不把成功打开判为到账。

没有实际APK端到端付款验收，未验证当前商户每种设备/场景的实时交易权限；历史A_NATIVE扫码成功与当前商户查询通过只提供接入依据。
