## 7. 计费与额度口径（未拍板项保持保守默认）

- `chargeUsers` 默认 **false**：不向用户扣额度；免费单次上限 180 秒。价格已拍板但链路未通前不打开。
- 预留：收费模式下开始会话原子预留 `min(可用, 单次上限)`；并发同一账户只有一个能预留成功（真实库并发测）。
- 结算：以供应商用量为准；供应商未给时长 → `unknown`，**只释放预留、不扣、不填 0**，进异常清单人工对账；有客户端估算 → `estimated` 待对账。
- 幂等：开始按 `userId+clientRequestId`；签发/结束按会话幂等键；回调按 `(provider, eventId)`；发放按请求号；结算条件更新只生效一次。
- 预算统计不是并发硬上限；硬约束只有额度预留与单次上限。
- 供应商成本、用户收费、圈主分成**分开记账**；分账规则未确认，**未实现自动分账**。
- **上线阻塞（S07）**：报告生成接口没有支付/权益门禁，且每份报告按报告 ID 幂等发放 30 分钟语音。`chargeUsers` 打开前必须先接报告支付门禁，否则免费生成报告即可领取语音时长。本轮按要求只记录，未改收费规则。
- 复用已有 AI 结果（翻译/译文/断句）也扣 AI 次数（决策人 09-21 拍板）。
- 报告赠送时长用完可充值（`VOICE_MINUTES` 订单，2 元/分钟），语音开始计费前不开放下单。

### 16.3 圈内语音时长五五分成（`76145300f`）
- 充值单带 `sourceContentType=CIRCLE_VOICE`、`sourceContentId=圈子`；服务端校验语音充值单 + 该圈有效成员 + 该圈语音助理已上线 + 非圈主本人，否则只剥离归因、照常购买

- 圈子对话扣费顺序：先扣圈子账户（圈主承担），不足开播门槛时改扣成员自己的时长
