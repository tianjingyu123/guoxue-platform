2. `apps/admin/src/views/videos/VideoList.vue`：补 `circleOptions` 定义+`loadCircles`（圈子下拉此前空）；`duration` 提交 `Math.round` 取整（后端 `@IsInt`）。

4. `apps/mobile/src/lib/circle-data.ts`：`my()` 提取嵌套 `.circle`（修"我的圈子不显示名字"）。
5. `apps/mobile/src/pkg-circle/circles/mine.vue`：按 `myRole` 分"我创建/已加入"，删假角标。

## 三、环境坑（务必知晓）

- **工具输出污染严重**：本环境 git/Read 的输出经常错乱（行号跳变、重复行、假成功、假失败）。**关键状态必用 `ls -la`/`wc -l`/`grep -c` 铁验证**，别信单次命令输出。多个"文件已生成/已提交"的假成功都栽在这。
- **SSH 连不上生产**：本执行环境到 `82.157.110.172:22` 超时（疑 IP 白名单），但**能连腾讯云 API**（VOD/COS 直调通）。生产命令靠董事长用 `!` 前缀代跑。
- 本地后端可跑：DB(5433)/Redis(6379) 在跑，仓库根 `pnpm --filter @guoxue/server dev` 起后端（health 因 redis 探测显 503 但业务正常，用登录+签名端点验证）。
- 腾讯云密钥在**仓库根 `.env`**（COS/TENCENT 全套有效，VOD 用 `VOD_SECRET_ID||TENCENT_SECRET_ID` fallback）；`apps/server/.env` 是残缺版（只有 DB/JWT），后端须从仓库根启动才加载全。
- `callVodApi` 是 stub（TC3 未实现，`pullUpload` 是假的）——服务端 VOD 操作（如删媒资）需自己手写 TC3 签名（本次清理测试内容就是本地手写 TC3 调 VOD DeleteMedia）。
