## 落地步骤（按序执行）

### 1. 部署代码（后端 + admin + H5）
按标准流程（git bundle 切码 → install → `prisma generate` → build → pm2 restart）。三端都要发：
- 后端：`apps/server` build 后 `pm2 restart guoxue-server --update-env`（注意 NODE_OPTIONS 内存，见部署记忆）。
- admin：build 后替换 admin 静态资源。
- H5：`pnpm --filter @guoxue/mobile build:h5` → 替换 `/opt/guoxue/apps/mobile/h5/dist/`。

### 2. 应用建表 SQL（新增 MerchantMember 表·幂等）
```bash
cd /opt/guoxue/apps/server
npx prisma db execute --file prisma/sql/2026-07-08-merchant-member.sql --schema prisma/schema.prisma
```
> 幂等（IF NOT EXISTS）。生产 `prisma generate` 已在步骤1随 build 完成，故客户端已含 MerchantMember 类型。
