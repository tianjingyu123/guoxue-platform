# 腾讯 IM 停用过渡方案（2026-09-28）

## 目标

腾讯 IM 暂未开通期间，平台核心交易、内容、通知、直播互动和人工客服可用；后续补齐腾讯 IM 配置后，客户端通过能力接口自动切换回腾讯 IM，不重新改页面。

## 已处理范围

| 场景 | 暂停腾讯 IM 时 | 后期开通后 |
| --- | --- | --- |
| 直播评论、点赞、礼物 | 平台 WebSocket 实时广播；连接失败时轮询合并评论 | 可继续使用平台 WebSocket，保留腾讯 IM 转发能力 |
| 单聊私信、会话列表、未读、已读、置顶、免打扰 | 平台数据库 + WebSocket；短轮询兜底 | `/im/capabilities` 返回 `TENCENT` 后走腾讯 IM |
| 系统/交易/审核通知 | 沿用平台 Notification 数据与通知中心 | 不依赖腾讯 IM |
| 智能客服转人工 | 站内反馈工单为主，企业微信二维码、电话、邮箱为补充 | 可再接入腾讯 IM 客服会话 |
| 群聊、好友关系 | 页面读取能力后明确提示暂未开放 | 腾讯 IM 配置完成后恢复 |
| 音视频通话 | 暂不提供 | 腾讯 IM/TRTC 均配置后开放 |

## 人工客服策略

1. AI 无法解决时显示“需要人工协助”。
2. 首选站内工单：支持问题描述、截图、联系方式、处理状态和官方回复，形成可追踪记录。
3. 后台“系统管理 → 品牌配置”可上传企业微信人工客服二维码，也可配置电话、邮箱；客户端不写死二维码。
4. 建议使用企业微信客服二维码或企业成员活码，避免使用个人微信固定二维码。二维码只作为加急联系入口，不能代替工单记录。

## 上线前操作

1. 执行 Prisma migration `20260928183000_add_im_fallback`。
2. 后台上传企业微信人工客服二维码，并核对客服电话、客服邮箱。
3. 用两个测试账号验收私信发送、接收、已读和会话列表；断开 WebSocket 验证轮询兜底。
4. 验收直播评论、点赞、礼物以及客服工单提交和后台回复。

## 限制

- 过渡私信当前支持文本，不提供图片、语音、撤回和多端同步游标。
- 群聊、好友申请和音视频通话需等待腾讯 IM/TRTC 开通。
- 企业微信二维码的接待分配、工作时间和欢迎语由企业微信后台配置。
