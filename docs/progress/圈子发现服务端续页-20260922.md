# 圈子发现服务端续页（2026-09-22）

发现页原先只请求服务端默认第一页 20 个圈子；“换一批”仅在这批数据中循环。如果前 20 个都已加入，页面会提示“这里的圈子你都已经加入了”，即使后面还有未加入圈子。

本批保留每屏 4 张卡的节奏；当已载入批次浏览完，继续按服务端页码读取后续圈子。首批都已加入但服务端仍有后续页时，展示“继续发现”，不再误判平台已无新圈子。下一页失败保留已加载内容并允许重试；分类切换和刷新会使旧请求失效。登录用户的已加入状态未读取完成时保持加载骨架，避免发现卡先闪现再消失。首页缓存仍只保存第一页公开圈子，成员态不入缓存。

验证：本地浏览器模拟 23 个圈子，其中前 20 个已加入；下一页首次失败后重试成功，剩余 3 个未加入圈子可见。无写请求，320px 无横向溢出。移动端类型检查和微信小程序构建、WXML 与组件校验通过；主包 1.63 MB，保守上传口径 1.92 MB，圈子分包 0.99 MB。真实平台推荐质量、已加入数很大的场景及真机触达仍待核验。未发布小程序。
