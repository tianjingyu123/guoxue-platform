#### 📎 用户提供的专业优化建议（原文照做，权威参考）
**一、画质模糊根治**
1. 推流端编码（90%模糊根源）：码率拉满——1080P 4000~6000kbps / 720P 2000~3000kbps；编码必选 **H.264 High**（不用 Baseline）；GOP=2秒(≤4)；帧率固定25~30不动态变。
2. 腾讯云云端转码必开：开高清转码模板（不用源流直分发）；**关「超低码率极速模板」**（疯狂损画质）；开画质增强/降噪锐化（腾讯云自带AI）；限最低码率≥1500kbps。
3. 采集源：相机分辨率高于输出（播1080P相机≥4K）；关自动曝光/白平衡跳动；补光充足（暗光会自动降码降质）。

**二、延时根治**
1. 播放协议 **HLS→RTMP+FLV**（HLS天生10-30s，FLV压到2-3s）；小程序/APP优先FLV。
2. 推流 GOP 严格锁2秒（越长缓冲越大延时指数涨）。
3. 上行带宽 ≥ 码率×2（4000kbps码率上行需≥10Mbps）。
4. **关云端水印**（增1-2s延时+压画质）。
5. 关大缓冲（视频直播别用音频专属缓存策略）。

**三、一键最优参数套餐**
| 参数 | 1080P | 720P |
|---|---|---|
| 视频码率 | 5000kbps | 2500kbps |
| 编码 | H.264 High | H.264 High |
| GOP | 2秒 | 2秒 |
| 帧率 | 30 | 25 |
| 播放协议 | FLV-RTMP | FLV-RTMP |
| 云端 | 开画质增强/关水印 | 开画质增强/关水印 |

**四、API接入避坑**
1. 别用默认免费源流模板（码率极低天生糊）。2. 拉流别跨地域（华南推流用华南播放节点）。3. 关多次转码嵌套（多次压缩变糊）。4. 排查是否只开标清档、用户默认拉最低清晰度。
