## 首轮实现

| 单元 | 实际变更 |
| --- | --- |
| 广场 | 我的圈子 / 发现圈子 / 圈内动态分区；成员默认回访，游客默认发现；移除冗余宣传大卡和重复入口 |

| 圈内资源 | 课程和橱窗打开本圈接口返回的资源抽屉；选择后进入具体详情；课程卡直达具体课程 |
| 内容卡片 | 清晰作者、正文和操作层级；举报、点赞、阅读全文和评论补键盘/读屏语义；触达区域不低于 44px |
| 我的圈子 | 聚合数据改为中性表面；返回重新加载；顶部避让小程序胶囊；角色筛选与管理按钮增大触达区域 |
| 视觉 | 圈子独立令牌；发现页以封面为重点、回访列表紧凑、阅读区克制；沿用既有底部导航 |
