## 苹果级体验专项（2026-09-22）

### 设计依据

已新增 [对话机器人苹果级体验规范](../design/对话机器人苹果级体验规范-20260922.md)，先定义信息层级、状态反馈、触控尺寸、动效和连续性，再实施页面改造。规范参考苹果产品常见的清晰层级和直接操作原则，保留热卜品牌色，不复制具体界面或素材。

### 本轮已实施

- 增加对话类统一令牌：中性画布、白色表面、主/次文字、边界、语音强调色、圆角、阴影和动效曲线。
- 推荐卡改为白色内容表面、单一动作和 44px 级触控区，保留内容类型色作为小面积提示；补齐键盘和无障碍语义。
- 普通智能体对话页：降低主题色占屏比例，统一消息气泡、推荐承接、额度条、工具栏和输入栏层级；输入区适配安全区。
- 机器人对话页：顶部、场景提示、消息气泡、输入栏和菜单统一为中性玻璃层，减少强色块对阅读的干扰。
- 智能体广场：搜索成为主入口，顶部改为中性玻璃层；最近使用、直接语音和语音筛选保留原路径并补充来源埋点。
- 对话历史：改为按时间分组的白色内容行，搜索、续聊和语音入口保持在同一行内，空状态保留进入广场的下一步。
- 额度弹窗：没有服务端真实价格时显示“价格以支付页为准”，不再显示 0 币；有真实价格时才展示单次换算。
