# 旧排盘微信 H5 接入确认清单

我们正在把旧排盘接入热卜 H5 和 App。旧站账号、推荐关系、支付和佣金继续由旧站管理，不要求提供整套源码。

现有测试：微信顶层打开旧站可以使用；将 p1.php 放在热卜 HTTPS 页的 iframe 中，外框正常、子页持续空白。该入口会跳旧公众号网页授权，尚未定位空白的具体原因。

请确认以下能力，并尽量提供现有文档或测试入口：

1. **微信 H5 内嵌登录**：有没有官方支持的嵌入入口？如果授权必须顶层打开，能否授权后安全回到热卜承载页，再加载旧站已登录内容？普通用户可能没有手机号。请勿要求在 URL 中传热卜登录令牌，也不要通过关闭浏览器安全限制实现。
2. **公开盘面与导航消息**：有没有不含登录凭据、可供其他人打开的具体盘面链接？旧页切换盘面后，能否通过已有 H5 消息接口通知父页最新公开地址，以及首页、返回、分享动作？App 的 webviewJS/webUni 接口是否已有网页嵌入对应版本？
3. **站长开户流程**：历史文档说明 partner.php 对不存在手机号返回失败，微信 addPartner 授权页可以自动开户。请确认现在是否仍如此，以及授权完成后如何回跳、查询已开通的推荐人 userid。已有推荐关系保持由旧站判定。

如果不支持完整内嵌，也请直接说明。可评估只让公开结果页支持嵌入，或在旧站增加返回热卜入口；不能以未经验证的 iframe、登录代理或强制跳转作为上线方案。

验收目标：首次授权、已有登录态、无手机号、站长推荐进入、具体盘面分享、再次分享当前盘面、返回首页、旧站支付取消返回均无白屏或循环；旧站订单和收款主体保持原样。
