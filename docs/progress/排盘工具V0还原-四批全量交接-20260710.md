## 二、🔴 工程决策与教训（后续批次/其他板块通用）

1. **小程序体积**：npm 依赖一律进主包 vendor（optimization.subPackages 只管 src 模块）→ 大依赖源码化进分包：lunar-typescript 415KB→pkg-paipan/lib/lunar/；pinyin-pro 不引入，离线生成拼音表（20856 字 267KB + pinyin-lite 查表）；cnchar 不引入（诸葛改直查康熙字典库更正统）
2. **分包自包含**：小程序分包间不能互相 require——bazi-engine 在两分包各一份副本、shuzi 用 meihua-lite 子集副本（文件头注明真源与同步义务）
3. **X5/小程序渲染红线全程规避**：无 SVG（盘面全 CSS view：极坐标环形/宫格/圆环）、无 writing-mode（逐字 flex column 竖排）、无 aspect-ratio（固定高度）、`<component :is>` 小程序编译报错（rich-message 已改显式分发）
4. **诚实原则**：V0 的假数据 tab（万年历择日/档案/养生/历史今天）、假 AI 区块（13 个 gemini 路由）、¥299 假课程卡、SEED 假历史记录全部砍除；随机起卦「提交时落定入 payload」保证历史/深链可复现
5. **V0 源笔误已修**：ganzhi 注释"2020-07-15=庚子"（实为己未·引擎本身正确）、金钱课签辞 3 处 mojibake、玄空/三合盘两处圈层重叠
