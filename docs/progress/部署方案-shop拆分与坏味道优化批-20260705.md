快进·纯代码·无 schema/数据变更 → 回滚干净：

```bash
# 若冒烟失败：回退代码 + 重建 + reload
ssh rebu-server 'cd /opt/guoxue && git reset --hard a1a6da56'
ssh rebu-server 'cd /opt/guoxue/apps/server && NODE_OPTIONS=--max-old-space-size=6144 nohup npx nest build > /tmp/rollback.log 2>&1 &'

```
> 建议构建前先备份现 dist：`ssh rebu-server 'cp -r /opt/guoxue/apps/server/dist /opt/guoxue/apps/server/dist.bak-20260705'`，冒烟失败可直接换回 dist.bak 再 reload（比重建快）。

## 六、注意事项

- **cluster reload 而非 restart**：cluster×4 用 `pm2 reload` 逐 worker 滚动，真零停机；`restart` 会全停再起有瞬断。先 `pm2 list` 确认进程名与 instances 数。
- **构建内存参数不可省**：`NODE_OPTIONS=--max-old-space-size=6144` + `nohup`，历史踩坑：省参数 OOM 会删掉旧 dist 只留半成品 → 重启即死。
- **shop 拆分是本批最敏感变更**：虽行为零变化设计 + 逐字校验 + 全量 jest 绿，冒烟务必覆盖 shop 商品/下单/支付回调路由，确认 DI 全解析、应用正常 boot。
- **无 env 改动**：ENCRYPTION_KEY 等保持不变，不碰 .env（避免 [[guoxue-cluster-live-env-incident]] 的 env 覆盖坑）。
