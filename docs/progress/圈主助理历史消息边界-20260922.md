# 圈主助理历史消息边界

本批在隔离分支 `codex/integrated-live-gift-paipan-pay-20260920` 上处理圈主助理的客户端历史消息。之前非流式与流式入口都把客户端提交的 `history` 原样交给 RAG；接口类型还允许 `system` 角色。RAG 会在服务端系统提示后直接追加这些历史消息，客户端因而可以伪造系统角色。

现在两条入口均在成员身份校验后、调用 RAG 前清理历史：只接受非空的 `user`、`assistant` 文本，先过滤再保留最近 12 条，每条最多 2000 字；未传历史仍保持原调用语义。接口与移动端类型也只声明这两种角色。该处理只限制历史输入，不声称能消除普通用户文本里的提示注入，也不改变圈子权限、知识检索或额度。

隔离验证：圈主助理服务、控制器与 RAG 定向测试 28/28，通过伪造系统角色、无效内容、超长/超量历史和流式入口用例；服务端构建、移动端类型检查通过。未调用真实模型，线上状态未知。发布时仍需在目标版本上验证问答质量和三端实际行为。
