### 3.2 安全区

以下页面导航栏和目录抽屉头部均采用 `var(--status-bar-height)`：

- 用户协议
- 隐私政策
- 儿童隐私保护规则

最终 APK 分包 CSS 已验证实际编译为 `calc(.75rem + var(--status-bar-height, 0px))`。OnePlus 9R（1080×2400）已完成：

- App 首页：顶部搜索从 `y=102` 起，底部导航位于 `y=2235..2400`，无状态栏/手势区遮挡；
- App 用户协议：标题位于 `y=138..216`，底部按钮位于 `y=2175..2247`；
- App 隐私政策：标题位于 `y=135..222`，底部操作区位于 `y=2169..2244`；
- H5 儿童隐私：顶部标题、目录悬浮按钮、监护人联系方式及底部“我已阅读并理解”均可见且可操作。

解锁后的最终复验曾复现公共 `AppNavBar` 的 Android 特有缺陷：v217“关于我们”页面导航容器为 `[0,0][1080,165]`，标题为 `[159,42][924,120]`，与约 100px 高的系统状态栏重叠。原因是 App WebView 中 `env(safe-area-inset-top)` 返回 0。源码改为同时读取 `uni.getSystemInfoSync()` 的 `statusBarHeight`、`safeAreaInsets.top`、`safeArea.top`，再与 CSS `env()` 取最大值；回归基线已经覆盖。

v218 正式签名预发包在同一台 OnePlus 9R 上复验后，“关于我们”导航容器为 `[0,0][1080,267]`，标题为 `[159,144][924,222]`，相对 v217 整体下移 102px，系统状态栏、返回按钮、标题和正文均无重叠，判定通过。

证据目录：`artifacts/device-audit/oneplus9r-v217-20260825/` 与 `artifacts/device-audit/oneplus9r-v218-20260825/`；v218 以 `r4-*` 和 `evidence-manifest.json` 为权威证据。

### 3.3 隔离 QA 账号工具

新增 `apps/server/scripts/qa-preprod-roles.cjs`，支持：

- `preflight`：只读检查数据库连接及命名冲突；
- `provision`：创建 15 个带批次标记的隔离 QA 账号与业务绑定；
- `verify-api`：逐账号登录并核验 `/auth/me` 返回角色；商家身份按动态 `MERCHANT` 角色单独核验。

脚本安全约束：仅允许 `pre-api.rebugx.cn`，写入必须显式设置二次确认值；遇到同手机号的非本批次用户立即中止；密码只写入已忽略的私有制品目录，终端仅输出脱敏手机号。

账号已经通过腾讯云云助手在预发布主机执行并复验，固定批次 `QA-20260825` 共 15 个账号。圈主同时写入权威 `CircleMember(OWNER)` 关系，商家只加入既有 `merchant_backend` 灰度白名单，不改变全局开关和百分比。完整密码仅保存在 Git 忽略的私有证据目录，未写入报告、命令输出或截图。

### 3.4 VOD 真实就绪度修正

- 所有服务端 VOD 请求统一注入并校验数字型 `SubAppId`，避免查询、处理或删除误落主应用。
- 上传签名启用一次性有效；播放器签名改为官方 HS256 JWT，并要求独立 `VOD_PLAY_KEY`，不再用媒体密钥或 MD5 降级伪造可用状态。
- 批量拉取改为逐 URL 调用真实 `PullUpload`；剪辑改为官方 `EditMedia` 结构；内容审核、水印与转码参数按实际 API 层级修正；不受支持的“按外链直接剪辑”明确拒绝。
- VOD 管理接口增加 JWT 与角色门禁，仅 `SUPER_ADMIN`、`OPERATION_ADMIN`、`CONTENT_AUDITOR` 可访问；云错误对客户端脱敏。
- 健康检查不再只检查配置存在，改为签名调用 `SearchMedia`。缺少权限或播放密钥时返回 `degraded`，不再误报 `ok`。
