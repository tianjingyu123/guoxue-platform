# IM 群聊切片：数据层真连（腾讯 TIM SDK）

- **执行日期**：2026-07-04
- **背景**：单聊已端到端上线（见 `docs/progress/IM联调-20260708.md`，TIM SDK 方案跑通）。群聊页仍全 mock（`mockGroupDetail`/`mockGroupMembers`/`mockGroupChatHistory` 等约 12 处）+ id/groupId 错配。
- **范围**：已存在群的**消息收发闭环** + 群资料/成员/名录真连 SDK；**不做群管理全套**（建群/设管理员/转让/移除/解散 → 诚实降级）。
- **结论**：✅ 群聊数据层全部改为 TIM SDK 为真源，群聊 mock 清零；vue-tsc 0 错误、scan-mock-imports 全绿。E2E 双账号验收待测试群就绪（见"剩余卡点"）。

## 一、改动清单

### 1. `composables/useTim.ts`（复用单聊已建的 SDK 单例 + 登录态）
- 新增类型 `TimGroup`（getGroupProfile 返回）、`TimGroupMember`（getGroupMemberList 返回，role=Owner/Admin/Member）。
- 新增方法并导出：
  - `getGroupProfile(groupId)` → 群资料（名称/头像/公告/成员数/我的角色 selfInfo.role）
  - `getGroupMemberList(groupId, offset, count)` → 群成员列表
  - `getJoinedGroupList()` → 我加入的群名录（SDK `getGroupList`）
  - `setGroupRead(groupId)` → 群会话标记已读（`setMessageRead conversationID=GROUP{gid}`）
  - 群消息收发复用**已存在**的 `sendGroupText` / `getGroupHistory`（原为直播弹幕建，本切片直接复用；社交群不调 `joinGroup`，用户本就是群成员）。

### 2. `lib/im-data.ts`（mock 清零，SDK 为真源）
- **删除**：`mockGroupDetail`、`mockGroupMembers`、`mockGroupChatHistory`、`mockGroupList`、`mockGroupSettings`、`mockGroupDetailMembers`、`getSortedGroupList`、`searchGroupList`、`getGroupOnlineCount`（i%3 假在线数）、`CURRENT_USER_ID`（固定 0）、`GROUP_WITHDRAW_LIMIT_MS`。
- **类型改造**（number → string，对齐腾讯 IM identifier/groupID）：`GroupDetail.id`、`GroupMember.id`、`GroupChatMessage.senderId`、`GroupListItem.id/ownerId`；`GroupChatMessage` 增 `isSelf`（flow==='out'）；`GroupListItem` 多字段改可选。
- **新增适配器**：`timToGroupDetail`、`timToGroupMember`、`timToGroupChatMessage`、`timGroupRole`（Owner/Admin/Member→owner/admin/member）。
- **`searchGroupMembersForAt(members, keyword)`**：改为在已加载成员中过滤（不再依赖 mock）。
- **`imApi` 群方法全部真连 SDK**（错误向上抛走三态，无 mock 回退）：
  - `getGroupDetail` / `getGroupMembers` / `getGroupChatHistory`（返回 `{messages,nextReqMessageID,isCompleted}`）/ `sendGroupMessage`（返回落地消息）
  - `markGroupRead` / `quitGroup` / `setGroupPin` / `setGroupMute`（新增）
  - `getGroupList`：SDK 群名录 + 会话列表**合并**补齐未读/最后一条
  - `getGroupSettings`：群名片=我的群昵称、会话态=免打扰/置顶（`showMemberNickname`/`savedToContacts` SDK 无对应项，默认开启诚实降级）
  - **删除** `imApi.getGroupPermissions`（冗余，页面直接用纯函数 `getGroupPermissions(myRole)`）。

### 3. `pkg-im/im/group-chat/index.vue`（消息收发闭环，对齐单聊范式）
- **id/groupId 错配修复**：`defineProps<{ groupId?; id? }>()` + `gid = groupId || id`，缺参落"未指定群聊"错误态（路由 `/im/group-chat/:id` 传的是 `id`）。
- `onMounted` → `ensureLogin` → 并行拉群资料/成员/历史 → `markGroupRead`；订阅 `tim.onMessage` 过滤 `conversationID===GROUP{gid}` 实时追加（复用单聊已建的 MESSAGE_RECEIVED 回调）。
- `isMine` 改用 `m.isSelf`（不再比 CURRENT_USER_ID）；`roleMap` 从成员列表给消息补齐角色徽标。
- `handleSend` 走 `imApi.sendGroupMessage`（SDK sendMessage 实时下发），失败回填输入框 + submitting 防重复。
- 移除假本地"撤回"（原 `handleWithdraw` 本地置 isWithdrawn）；导航栏"在线数"改为成员数（TIM 无群在线数，诚实降级）。

### 4. `pkg-im/im/group-detail/index.vue`
- 真连 SDK 群资料/成员/设置；`groupId` string；"我"识别改用真实 `getUserInfo().id`（替代 CURRENT_USER_ID）。
- **免打扰/置顶**：真连 `setGroupMute`/`setGroupPin`（乐观更新 + 失败回滚）；**退出群聊**：真连 `quitGroup`。
- **群昵称/设管理员/转让/移除/解散**：属群管理范畴（后端群管理 ADMIN only），本切片 honest 降级为提示，不做假成功。

### 5. `pkg-im/im/group-list/index.vue`
- `getGroupList` 真连 SDK；`goGroupChat(id:string)`；置顶/免打扰真连 SDK（乐观更新+回滚）；退出真连 `quitGroup`，群主解散 honest 降级。

### 6. `pkg-im/im/create-group/index.vue`（诚实降级重写）
- 后端 `POST /im/groups` 为 ADMIN only（SUPER_ADMIN/OPERATION_ADMIN），C 端建群走不通 → 原"选好友+假建群"整页替换为**引导页**（"群聊由圈主/管理员创建"，引导去圈子/看我加入的群），不留假建群按钮。

## 三、剩余卡点 / 未纳入本切片

1. **E2E 双账号验群聊收发**：需先有**测试群**且两账号均为成员。建群需 ADMIN 后端调用（`POST /im/groups` + `POST /im/groups/:id/members`，SUPER_ADMIN/OPERATION_ADMIN 角色），本切片未在生产创建测试群，故 E2E 未跑。
   - 建群步骤（待执行）：以管理员 token 调 `POST /im/groups {groupId,name,type:'Public',ownerId}` → `POST /im/groups/:groupId/members {memberIds:[0099,0098]}` → 复用 `guoxue-e2e` harness 双上下文进 `/im/group-chat/{groupId}` 互发。
2. **群管理全套**（建群/设管理员/转让/移除/解散/改群昵称/群公告编辑）：honest 降级为提示，未实现（需拍板 C 端群管理是否开放 + TIM 权限模型）。
3. **富媒体群消息**（图片/语音/@提及真下发）：本切片仅文本闭环；@ 面板保留但仅插入文本，未做 TIM 群 @ 定向（同单聊富媒体待 `tim-upload-plugin`）。
4. **好友/通讯录/好友请求 mock**（`mockFriendsWithPinyin`/`mockFriendRequests` 等）：属**好友切片**，非群聊范围，未动。
5. **单聊遗留死代码**（`mockChatTarget`/`mockChatHistory` + `imApi.getChatTarget/getChatHistory/sendMessage`）：单聊页已改走 `tim.*` 不再引用，属单聊切片清理项，本次未动（避免触碰单聊已完成文件）。

## 四、关键设计

- **收发走 SDK、群资料/成员走 SDK**：绕开后端 ADMIN-only 群端点，C 端只读/收发不需管理员权限；TIM 服务端对"非群成员发消息/查资料"直接报错 → 前端走错误态。
- **消息 isSelf 判定**：统一用 SDK `flow==='out'`，与单聊一致，不再依赖前端固定当前用户 id。
