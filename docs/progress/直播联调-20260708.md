## 五、发现即修（前端）

### BUG：WAITING 预告房观众页误标「直播已结束」
- 现象：进未开播房 watch 页，占位文案显示「直播已结束」，实际是待开播。
- 根因：后端 play-url 对「未开始 / 已结束」两态返回**同一条** message「直播未开始或已结束」；
  前端 `watch/index.vue` 用 `message.includes('结束')` 区分 → 该串同时含'结束'，WAITING 被误判为已结束。
  且 `getWatchRoom` 适配时丢弃了房间真实 `status`。
- 修复（均在授权文件范围内）：
  1. `lib/live-data.ts · getWatchRoom`：透传房间 `status`（返回类型加 `& { status: string }`）。
  2. `pkg-live/watch/index.vue`：删除按错误串猜测的逻辑，改 `playHint` 为 **computed 按 room.status 精确判定**
     （WAITING→直播即将开始 / ENDED·REPLAY→直播已结束 / BANNED·CANCELLED→直播已停止）。
- vertical/horizontal 页无此问题（拿不到流仅 `playUrl=null` 走通用重试浮层，不显误导文案）。

验收：`npx vue-tsc --noEmit` = **0 错误**；`scripts/scan-mock-imports.sh` = **0 违规**。

> ⚠️ 该前端修复仅落源码，**尚未构建/部署到生产 H5**（生产 H5 当前是 im 分支构建）。
