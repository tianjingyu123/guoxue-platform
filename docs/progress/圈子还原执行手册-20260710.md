## 3. 还原规范（不可违反，来自 CLAUDE.md）

1. **数据流铁律**：页面禁止 import mock；一律走 `@/lib/*-data.ts` 的 `xxxApi`；对接前先读后端 controller 确认真实路径/响应结构。
2. **三态**：loading（骨架）/ error（重试）/ empty，每个数据页必备。V0 已给骨架+空态稿，直接还原。
3. **防重复提交**：写操作 `submitting` 标志。
4. **逻辑层 Vue3 重写**：保留 V0 的 HTML 结构与样式，`<script setup>` + Composition API 按现有页面数据层复用重写，不保留 React 残留。
5. **验证**：每还原一页 → `pnpm --filter @guoxue/mobile exec vue-tsc --noEmit` 绿 + `scan-mock-imports.sh` 净。
