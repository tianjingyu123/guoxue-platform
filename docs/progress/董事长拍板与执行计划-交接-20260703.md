## 二、B1 游戏化成长体系 — 现状重大修正（避免重复造轮子）

> 侦察结论（2026-07-03，Explore agent 深度调研）：**B1 绝大部分已落地并真连**，董事长文档标「待做」为过时判断。

**已存在且真连的**：
- 后端：`GrowthValue`（用户等级+学分）、`GrowthRecord`、`CheckIn`+`DailyTask`（每日签到+任务）、圈子级 `CircleCheckin`+`CircleBadgeRecord`（徽章）。积分在签到/发帖/点赞/购物链路**已自动触发**。
- 端点：`/users/me/growth-profile`（学分/等级/成就/连续天数）、`/users/me/checkin`+status+calendar、`/users/me/tasks/daily`、`/users/me/points/*`。
- 前端（全真连三态齐）：`pkg-mine/achievements/index.vue`（成长中心）、`pkg-mine/points/index.vue`（积分中心）、每日任务/兑换页、`pkg-offline/checkin`。
- 数据层：`apps/mobile/src/lib/growth-data.ts`、`points-data.ts`。

**真正的缺口（仅打磨级，勿重建）**：
1. 平台级「称号/头衔」表缺失（现仅 `GrowthValue.levelName`，无可收集/佩戴的称号）→ 需新建 `UserTitle`。
2. 成就墙成就种类偏少 → 扩充成就定义。
3. streak 追踪的是「签到」而非「学习行为」→ 可选优化。

**结论**：B1 不占大力气，只做上述 3 小块打磨；主力投向真正空白的 T7 内容质量评分、T9 研究院认证、C1 会员、商家开启+入驻协议、赛事。

## 四、关键执行注意事项（踩坑备忘·必读）

- **服务器双库陷阱**：根 `.env`=5432 陈旧快照库；`apps/server/.env`=5433 真库。**查库/迁移必用 5433**。
- **构建**：nest build 需 `NODE_OPTIONS=6144`（否则 OOM）。
- **prisma generate**：必须 `cd apps/server` 用本地 6.19.3；从根 npx 会拉 prisma7 报 datasource 错。
- **新增单表**：用 `prisma db execute --file` 或 migrate diff 安全迁移，**勿 db push --accept-data-loss**（会删数据）。
- **生产部署**：git bundle 传 rebu-server（GitHub 国内不通）；ENCRYPTION_KEY 固定不可变；deploy.sh 危险勿跑。详见 `guoxue-production-deploy` 记忆。
- **H5 部署**：`pnpm --filter @guoxue/mobile build:h5` → tar → scp → 生产路径 `/opt/guoxue/apps/mobile/h5/dist/`（对外 `api.rebugx.cn/h5/`）。
- **验证铁律**：后端 `tsc --noEmit` + `jest` 全绿；前端 `vue-tsc --noEmit` + mock 扫描 0 违规。跨窗口勿信口头 hash，`git log` 核实。
