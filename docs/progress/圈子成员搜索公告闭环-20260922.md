# 圈子成员、搜索与公告闭环（2026-09-22）

## 范围和实际行为

本批在隔离接收工作树完成三条高频浏览链路，不涉及真实订单、余额、审核或公告写入。

| 路径 | 原问题 | 本批处理 |
| --- | --- | --- |
| 圈子详情 → 成员 | 成员接口失败被吞掉，误显示“暂无成员”；只展示首 20 人 | 主请求错误显式呈现并可重试；按 20 人续页，续页失败保留已读成员；显示实际已加载数与总数 |
| 圈子搜索 | 接口失败返回空列表，误导为无结果；快速搜索的旧响应可覆盖新词；仅展示前 20 个 | 搜索页使用显式错误模式；请求序号隔离，清空输入也取消旧响应；结果分页与失败重试；服务端分页排序增加 ID 次序，缓存键纳入分站 ID |
| 圈子公告 | 相关公告点入后仍展示置顶公告；读取失败误显示“暂无公告”；已读上报失败仍提示成功 | 新增限定圈子与公告 ID 的只读详情接口；无置顶时最新公告返回真实 ID；主请求失败可重试；已读上报失败不改变已读状态，可再次点击 |

成员和搜索顶部返回按钮、小屏主要操作区至少 44px；小程序导航栏避开微信胶囊。公告顶部同样避让胶囊。搜索结果和公告仍沿用现有业务规则，没有新增权限、推荐扣费或通知发送。

## 仍须实测与边界

- 微信开发者工具和实际小程序、App 设备的安全区、触控及弱网状态尚未按本批最终产物逐页确认；H5 浏览器验证不能替代真机。
- 公告“已读”接口当前只给圈成员；游客点击会收到失败提示。服务端未返回个人逐条已读状态，重新进入页面可能再次看到“确认已读”。要做到跨设备已读同步需单独设计读状态接口。
- 圈子全链路仍有管理子页、真实支付、审核和外部内容触发等独立验收项目，本批不宣称全面上线。
