## 二、发现并已修（前端 4 文件，已部署生产 H5）

### 1. 🔴 TIM login resolve ≠ SDK ready（阻断级，聊天页必现报错）
- **现象**：聊天页报"用户正在登录中导致 sdk not ready | getMessageList | 接口调用时机不合理"（错误态+重试）。
- **根因**：`chat.login()` resolve 后 SDK 仍在登录中，`useTim.ensureLogin` 立即放行，聊天页马上拉历史消息。
- **修复**：`composables/useTim.ts` 登录后等待 `SDK_READY` 事件（15s 超时给友好错误）；补 `SDK_NOT_READY`/`KICKED_OUT` 时复位 isReady。

### 2. 🔴 路由参数名错配：`/im/chat/:id` 传 `id`，聊天页只收 `targetId`（阻断级）
- **现象**：会话列表/通讯录/用户主页私信按钮三个入口进聊天页 targetId 为 undefined（会话 ID 变 `C2Cundefined`）。
- **修复**：`pkg-im/im/chat/index.vue` props 兼容 `targetId` 与 `id` 双入参（`peerId = targetId || id`），缺参落"未指定聊天对象"错误态；会话列表入口改传完整路径并带 `name`/`avatar` 供导航栏即时展示。

### 3. 🔴 `POST /im/account/import` 空 body 400 + 覆盖昵称为 UUID
- **现象①**：前端空 body `{}` 被 ValidationPipe 400（DTO userId 必填），静默吞掉——好在后端每次登录已自动 importToIm，未阻断。
- **现象②**：修为只传 `{userId}` 后，后端 `Nick: nickname || userId` 把腾讯侧昵称**覆盖成 UUID**（会话列表显示一长串 id，真机实测）。
- **修复**：`useTim.ts` import 携带本地 userInfo 的 `nickname`/`avatar`。

### 4. 🟡 会话列表整页 mock（假会话"张明德/国学研习群"）
- **修复**：`lib/im-data.ts` 删除 mockConversations，`imApi.getConversations()` 真连 SDK `getConversationList`，新增 `timConvToConversationItem` 映射（C2C/GROUP，过滤 @TIM#SYSTEM）；置顶/免打扰/删除会话三个写操作真连 SDK（`pinConversation`/`setMessageRemindType`/`deleteConversation`，乐观更新+失败回滚+submitting 防重复）；会话页订阅 `CONVERSATION_LIST_UPDATED` 实时刷新列表与角标。

**验收**：vue-tsc 0 错误；scan-mock-imports.sh 通过；生产部署后 E2E 复跑全绿（`RESULT: A->B delivered=true B->A delivered=true`；`badge=true chatFromList=true`）。

## 三、只记录不动的问题（后端/范围外）

1. **后端 `ImportAccountDto.userId` 必填是冗余设计**：controller 实际用 `req.user.id`，dto.userId 被忽略却参与校验 → 建议改 optional（`apps/server/src/modules/im/im.dto.ts:11`）。同时 `im.service.importAccount` 的 `Nick: nickname || userId` 兜底会覆盖已有昵称，建议不传 Nick 或先查 profile。
2. **群聊页同样有参数错配**：`/im/group-chat/:id` 路由传 `id`，`group-chat/index.vue` props 收 `groupId`——群聊本轮不在范围（数据层仍全 mock，im-data 剩余 if(true)：群聊/好友/通讯录/好友请求等 12 处），留待群聊切片。
3. **TIM 富媒体上传插件未注册**：SDK 警告"未检测到上传插件，无法发送图片/音频/视频"——发图需集成 `tim-upload-plugin`，本轮文本闭环未做。
4. **`pkg-common/scan` 跳转 `/im/chat?targetId=`**：`/im/chat`（无尾段）不在 ROUTE_MAP，跳转会失败（扫码加好友入口，边缘）。
5. **在线状态**：聊天页头部"在线/离线"来自 query/消息补齐，未接 `/im/account/state`（该端点仅允许查好友）。
