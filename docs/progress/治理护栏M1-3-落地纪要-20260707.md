## 一、三档自主分级（§2.1）— `common/autonomy.ts`
| 级 | 枚举 | 谁动手 | 人是否在环 |
|---|---|---|---|
| L1 只建议 | `AutonomyLevel.L1_SUGGEST` | AI建议·人执行（默认级别） | 是 |
| L2 一键执行 | `AutonomyLevel.L2_ONE_CLICK` | 人点·AI执行（带回滚） | 是 |
| L3 带回滚自动 | `AutonomyLevel.L3_AUTO_ROLLBACK` | AI自动（白名单+限半径），全程台账 | 事后可查/可回滚 |

- **逐级晋升**：`canPromote`/`assertPromote` 强制只能 L1→L2→L3，跳级抛 `AUTONOMY_ILLEGAL_PROMOTION`；降级（收权）始终允许。
- **标级装饰器** `@Autonomy(level)`：给自动能力端点标级，审计与治理盘点可读取。

## 二、四红线 + 合规红线（§2.2）— `common/red-lines.ts`
五类**永久人工闸**（无论进化到 L4/L5 都不得自动执行）：

| 红线 | 枚举 | 覆盖 |
|---|---|---|
| 钱 | `RedLine.MONEY` | 退款/分佣/提现/改价 |
| 用户数据 | `RedLine.USER_DATA` | 删/改/导出 |
| 对外发布 | `RedLine.EXTERNAL_PUBLISH` | 内容/推送/公告 |
| 不可逆 | `RedLine.IRREVERSIBLE` | 删库/删用户/DROP |
| 合规 | `RedLine.COMPLIANCE` | 传销两级/杀熟/命理数据聚合/占卜类目 |

- **HTTP 硬闸**：`@RedLineGate(...RedLine[])` + 全局 `RedLineGuard`（main.ts `useGlobalGuards`）。标了红线的端点，执行者判定为自动化（头 `x-executor-type: CLAUDE/AUTOMATION` 或数字员工身份）→ **永久 403**（不受一键接管开关影响，红线是硬编码闸）。未标端点全部放行。
- **服务/任务层兜底**：`assertHumanForRedLine(executor, lines)`，供 cron/ops 自动执行路径（不经 HTTP 守卫）兜底。

## 三、一键回滚（§2.3 · 验收标准三）— `system.service`
- `setConfigWithRollback(key, value, desc, executor, autonomyLevel?)`：自动化改配置的标准入口，写含快照的审计（`rollbackData={kind:"config",key,previousValue,previousExists}`）。
- `POST /system/automation/rollback/:auditId`（SUPER_ADMIN·真人纠错）：按快照一键还原；有原值→还原，原本不存在→删除；不支持的动作类型抛 `ROLLBACK_NOT_AVAILABLE`。
- `GET /system/automation/rollbackable`：可回滚操作列表（供后台一键回滚面板）。

## 四、能力分级登记册（验收① · 随能力增长维护）
| 自动能力 | 端点 | 档位 | 红线 |
|---|---|---|---|
| 每日巡检+分级自动处置 | `POST /ops/inspect` | **L3** | 无（白名单可逆动作） |
| 完成运营任务 | `PUT /ops/tasks/:id/complete` | **L2** | 无（受一键接管约束） |
| 自动改配置（示范/推荐调权等） | `SystemService.setConfigWithRollback` | L2/L3 | 无（可回滚） |
| 一键接管开关 | `POST /system/automation/toggle` | 人工（SUPER_ADMIN） | — |
| 一键回滚 | `POST /system/automation/rollback/:auditId` | 人工（SUPER_ADMIN） | — |

> 新增任何自动能力：① 代码标 `@Autonomy(level)`；② 触碰红线的标 `@RedLineGate(...)`；③ 在此表登记。

### 4.4 未铺开 / 设计级约束
- **COMPLIANCE**（命理数据聚合 R3 / 占卜类目 R4）：无干净单一端点可标，属**设计级红线**（"别建这类功能"），由现有 `audit/compliance-scan` 合规扫描兜底；强标 fortune 端点会误锁正常排盘，故不做端点锁。
