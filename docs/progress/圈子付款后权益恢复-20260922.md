# 圈子付款后权益恢复

基线 `a7a456654630d0dd4119bd4ed106150c456e4922`，在隔离分支继续。代码与本记录同提交。本批未部署，未发起真实付款，也未修改生产订单或成员权益。

## 用户断点

付费页检测订单已支付后会调用入圈或续费确认，但确认失败仅写本地日志，仍跳到圈子页。原详情页没有订单编号，只能刷新成员状态；确认未完成时刷新无法补做兑现，用户容易误以为还要付款。续费时用户本身已经入圈，单凭“已加入”也不足以证明本次续费已生效。

## 本批实现

- 付费页成功回到圈子时附上当前订单编号。它只是定位本次付款的线索，不是权益凭据。
- 圈子页读取服务端“本人订单最新状态”，要求订单已付、类型为入圈或续费、目标圈子与当前页一致，再调用对应确认接口。确认成功后重新读取成员状态；不乐观开放权益。
- 续费已加入成员仍需确认本次订单，避免进入页面时提前清掉回跳状态。
- 查询或确认失败时保留原订单重试入口和“勿重复付款”提示；目标不一致则拒绝确认。已完结订单只刷新成员状态，不重复执行续费确认。
- 旧链接无订单编号仍只允许刷新状态，不猜测或创建订单。
