## 暂待外部条件

- 商业语音授权 API：取得供应商正式文档、测试凭据、调用额度与费用规则后，才实现并验收真实 ASR/模型/TTS、中继失败行为与扣费边界。
- 余额不足/充值提醒：在隔离账号与可回滚额度条件下安排一次真机触发，核对屏显、播报、待命和服务日志；不动当前正常用户余额。
- 容量：在独立预发布环境按连接突发、持续会话、供应商延迟分别压测，采集 TCP 队列/拒绝、OTA 与 WS 阶段、进程和数据库指标后再给出容量数值。
- 上线：完成上述主线接收、部署评审和真实通道验收后另行执行；当前本地 Mock 测试没有生产上线结论。
