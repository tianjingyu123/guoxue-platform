# 圈子付费问答列表权限与完整浏览（2026-09-22）

审计发现：公开 `/question` 列表原先接受任意 `askerId`、`answererId`、`participantId`，且直接读取完整 PaidQuestion，存在未公开问题和付费答案字段被列表绕过详情付费墙的风险。`/question/:id` 与围观入口也没有拒绝外部用户访问未公开问题。

现将公开列表强制限定为 `isPublic=true`，查询字段明确不含回答正文和语音 URL，并以创建时间、ID 稳定排序。本人记录改走带 JWT 的 `/question/my`，服务端只从登录态确定用户；传入的用户 ID 仅作视图模式选择，不作为授权身份。未公开问题的详情和围观仅允许提问者与回答者访问，外部用户返回不存在，围观操作不扣币。`/question/my` 在 `/:id` 前注册。

“我的问答”页面改为每页 20 条，可继续浏览与重试；状态筛选只匹配已加载记录时，明确说明还有后续页，避免把首批没有已回答记录写成真实空态。咨询订单图文来源同步改用本人入口。

验证：问答、通话服务及问答控制器定向测试共 58/58 通过；移动端类型检查和服务端构建通过。本地浏览器模拟 23 条问答，验证翻页、分组暂空和加载失败重试，未产生写请求。微信小程序构建及 WXML、组件、体积校验通过：主包 1.63 MB，保守上传口径 1.91 MB，圈子分包 0.98 MB。真实线上历史数据和小程序真机仍待发布后核验。本批未部署、未迁移、未发起真实围观扣费。

发布依赖：服务端 `/question/my` 与使用它的移动端必须同批部署；单独先发移动端会造成本人记录不可用。公开列表的权限收紧属于必要安全修复，需随同发布。
