## 三、useList.ts 用法（供后续接入）

```ts
import { useList } from '@/composables/useList'
import { onLoad, onReachBottom } from '@dcloudio/uni-app'

const { list, total, loading, error, isEmpty, loadStatus, refresh, loadMore } = useList<Item>({
  fetcher: ({ page, pageSize }) => api.list({ page, pageSize }).then(items => ({ items })),
  getParams: () => ({ tag: activeTag.value }),   // 可选:随筛选变化的查询参数(交后端)
})
onLoad(() => refresh())                 // 首屏/切筛选
onReachBottom(() => loadMore())         // 页面级滚动
// 内部 scroll-view 滚动时改用 <scroll-view @scrolltolower="loadMore">
// 模板:<app-load-more :status="loadStatus" />
```
- `hasMore` 判定靠 `items.length >= pageSize`，不依赖 total（total 仅展示）。
- fetcher 可带 side-effect 设置头部信息（见 store 页：page===1 时设 merchant）。

### 范式（已沉淀为可复制样板 `src/lib/order-data.ts`，commit `e817fbf8`）
data 层是「后端响应 → 前端视图模型」适配层，any 集中在 adapter 入参 / `apiGet<any>` 泛型 / 内联回调。收敛规则：
1. 为后端响应定义**非 export 的 `Raw*` 接口**（字段全 optional + 宽松类型 `string`/`number|string`/嵌套 `| null`，**仅声明 adapter 实际访问字段**，不复刻完整 DTO）。
2. adapter 入参 `(o:any)`→`(o:RawXxx)`；内联 `.map/.sort/.find((x:any))`→元素 Raw 类型；`apiGet<any>`→`apiGet<RawXxx>` 或 `<{items:RawXxx[];total?}>`。
3. 纯转换工具 `(v:any)`→`(v:unknown)`；容错函数入参可空 `(id?:string)`。
4. **收敛会暴露隐患**：adapter 假设必存在、实则 optional 的字段——赋给必填 `string` 补 `|| ''`，Record 索引 `MAP[x.status||'']`。这是收敛的真正价值（暴露并修正潜在 undefined）。
