# 圈主助理对话层级与额度提示

基线 `02e302206582f6ef7f29be2bdd102e2a4ff30953`。本批是客户端展示与错误引导收口，不调整智能体收费、圈子权限或问答接口。

## 实现

- 本地 390px 窗口截图显示欢迎语和一句话短答都被渲染成大幅图文答卷，首屏阅读空间被装饰占用。现在欢迎语与短回答用紧凑气泡，长回答仍保留结构化答卷；检索摘要和推荐继续跟随该轮回答展示。
- 对话顶部的“在线”改为“AI 对话”，避免把 AI 状态误读成人工客服在线。
- 圈主助理当前后端有成员门控及每分钟请求限流，但没有已接通的用户付费问答额度。该场景不再把包含“额度”等字样的服务错误引导到会员购买；通用聊天组件保留可选额度恢复能力，供确有真实购买额度的场景使用。

## 验证及边界

本地 H5 交互 12 组通过，新增长短回答层级、失败后不展示错误检索摘要、圈主助理不出现虚假购买引导；无真实业务写入。移动端类型检查和微信小程序构建通过：主包 1.63 MB，保守上传口径 1.91 MB，最大分包 `pkg-paipan2` 1.94 MB、`pkg-circle` 0.96 MB；615 个 WXML 与 2683 个文本产物检查通过。截图只用于本地视觉复核，不代表三端真机验收。

实时语音通话仍依赖客户端音频运行时；仓库现有 `voice-agent-runtime.ts` 仅定义桥接契约，未发现已装载的供应商运行时。圈主助理这批仍为图文对话，不能宣称可进行实时语音通话。发布前需由受控环境验证 SDK、麦克风授权、断流恢复与费用规则，本批不增加假通话入口。
