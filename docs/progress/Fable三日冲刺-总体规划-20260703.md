## 北极星：1 亿的含义

1 亿/年 ≈ 27.4 万/天。以国学赛道的现实结构，这不可能靠 C 端会员单线撑起（19 元月卡需要百万级付费会员），**必然是 B 端供给侧收入为主、C 端交易为辅的复合结构**。D1 第一件事就是把这笔账算清楚、算诚实——每条收入线需要多少供给量/转化率/客单价，与现有产品能力的差距是什么。这份测算是后面一切优先级的裁判。
