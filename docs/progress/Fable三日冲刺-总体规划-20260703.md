# Fable 三日冲刺 · 总体规划 V2（板块精磨版·2026-07-03 深夜定稿）

> 用户核心诉求定稿：**怎么优化现有平台功能 + 怎么把生态建立起来 + 商业模式最优化 —— 精细打磨每一个板块**。
> Fable 只做梳理/诊断/设计/计划，产出全部是「普通模型可照做的任务包」。目标锚：上线后年收入 1 亿。

---

## 零、诊断定稿（基于用户亲述数据·三天工作的前提共识）

| 事实 | 结论 |
|---|---|
| 570 万注册 / 10 万日活，用户=易学爱好者+老师+从业者 | 用户池不是消费者，是**渠道与供给侧**。平台的本质=从业者的生意操作系统 |
| 工具付费率 <1%，课堂/商城历史销售≈0 | **C 端零售模式已被 570 万用户投票证伪**。工具=流量与信任入口，不是收入线；变现必须走 B 端 |
| 商品是"用户的客户"需要的 | 商城正确形态=B2B2C 供应链（供应商→从业者→其客户），从业者是进货方不是消费者 |
| 货源=网上找的 | **供应链空心**——供应商生态是真·从0到1。没有差异化货源（开光/文创/独家），从业者没理由从平台进货 |
| 老工具站保留，新平台部分引导 | 双站结构：老站=纯工具流量池，新站=生态。引导动线要在"用完工具"的瞬间给出"生意机会"的钩子 |

**生态飞轮（三天所有板块打磨的总纲）**：
```
工具引流(排盘·免费好用) → 内容留人(古籍/课程/AI·建立信任) → 身份升级(爱好者→学员→认证从业者)
   ↑                                                              ↓
老站+官网SEO 持续供血      ←——  收入分享绑定  ——←   生意系统(站长/驿站/研究院/供应商·四角色阶梯)
```
每个板块的打磨都要回答：**它把用户往飞轮的下一环推了吗？**
