# 圈子续费并发确认收口

基线 `d82b6a6be78c4e3f7d2bd4afdf2c1ab816b7ab9f`，隔离分支接续。只修改续费确认的服务端事务与定向测试；未部署、未执行真实续费或生产迁移。

## 修正

原路径在事务外读取已付订单和成员到期时间，事务内直接更新成员并完结订单。两个并发确认都可能读到 PAID，并各自执行顺延。

现在事务先以订单ID、付款用户、圈子ID、类型及状态 PAID 条件认领订单；只有命中一行的请求继续。随后在同一事务读取最新成员到期时间，按订单数量顺延一年或两年；成员更新失败则事务失败，不返回续费成功。既有折扣及金额计算保持原样。
