# 圈主助理场景推荐接线与验证

隔离分支 `codex/integrated-live-gift-paipan-pay-20260920`。圈主助理原有对话页能显示结构化推荐，但服务端从未给该场景生成推荐：用户问“推荐入门内容”只能看到文字回答。本批复用平台既有 `RecommendationService`，不另造推荐池或收费规则。

非流式在回答成功后附上与本轮问题相关的已上架资源；流式在正文结束后通过 SSE 元信息追加推荐，再发送完成事件。推荐失败只省略卡片，不截断或回滚问答。当前圈子从候选中剔除，避免给已在圈内的成员推荐“再加入本圈”；剔除后若只剩内容资源，同步去掉不适用的商业提示。低置信商业推荐仍沿用现有先征求用户同意的展示规则，卡片保留价格及商业属性说明。无知识命中的页面文案改为提醒核实原文，不将模型回答说成已获资料验证。

隔离验证：圈主助理、控制器和推荐服务定向测试 34/34，覆盖先回答后推荐、同圈过滤、流式元信息及推荐失败不中断；本地 H5 场景测试 13 组，全部业务接口拦截，真实业务写入 0。服务端构建、移动端类型检查及小程序构建通过；615 个 WXML、2683 个文本产物通过校验，主包 1.63 MB、保守上传口径 1.91 MB、圈子分包 0.97 MB、最大分包 `pkg-paipan2` 1.94 MB。构建沿用隔离树公开配置：`formal`，API `https://api.rebugx.cn`，H5 `https://api.rebugx.cn/h5/`，资源 `https://static.rebugx.cn`。

尚未覆盖：真实模型回答与真实资源匹配质量、目标环境数据权限、微信和 APP 真机点击跳转、线上两节点版本。代码候选未部署，不代表该推荐已在线对用户开放。
