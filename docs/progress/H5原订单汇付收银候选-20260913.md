## 防重复和边界

按账号与订单 ID 在本端持久记录提交标记，发送前保存；保存失败不发送。已知流水或已提交标记只查询，不跨渠道重新初始化。网络失败、缺失付款码、返回结果保存失败时保留待核对状态，重开页面不会自动重发。

订单详情存在 Redis 缓存，没显示流水不能证明跨端未提交。本次仅实现本端界面防重复和已知流水不重发，没有实现服务端并发锁；首次实测必须使用明确新建的测试订单或已确认未受理的订单。不得把旧微信报错订单直接换渠道重试。

二维码展示、通道返回成功均不直接当作订单成功，以服务端订单状态确认。轮询有次数上限，页面隐藏停止，离开销毁；账号变化停止支付请求。没有承诺外部浏览器微信支付、支付宝自动拉起或云闪付产品已开通。
