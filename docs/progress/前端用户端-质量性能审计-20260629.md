# 前端用户端 质量与性能审计报告

> 日期：2026-06-29
> 范围：`apps/mobile/src`（uni-app + Vue3，40 个分包 / 492 .vue / 93 .ts / lib 数据层 / utils）
> 方法：4 组只读 agent 并行审计（性能 / 代码质量 / 健壮性·多端 / 安全·脱敏），交叉去重后整合
> 性质：纯只读审计，未改动任何代码。证据均带 `文件:行号`，可逐条复核

## 一、总体评价

**架构底子扎实，债集中在四处。** 这不是"重写级"的烂摊子，而是一个工程意识良好、但在性能细节与系统性兜底上有欠账的成熟项目。

**值得保留的优点（复核确认）：**
- 主包仅 6 页、40 分包拆分到位、**无 echarts/富文本/地图等重型依赖**误入主包
- 数据层 `Promise.all` 并发广泛（106 处/87 文件）、首页走聚合接口、古籍按章加载
- 健壮性基础好：几乎无静默吞错（空 catch 仅 3 处）、防重复锁覆盖广（71 文件 + `use-submit-lock`）、三态基建齐全
- 安全无硬伤：**0 处硬编码密钥、0 处 v-html、前端不签发 IM user-sig、日志不含 token/手机号**

**四大欠账方向：**
1. **资源加载**——图片几乎不懒加载、静态资源未压缩、无分包预下载
2. **类型安全**——969 处 `any`，data 层类型契约集体失守
3. **全局兜底缺失**——无 401 统一跳转、无全局 errorHandler、无请求超时
4. **已知坑未清**——`type=number` 用于手机号/银行卡（精度坑）大面积存在

## 二、P0 — 最该先做（影响核心链路 / 资金，且改动面小）

### P0-1 手机号、银行卡号大量用 `type="number"`（精度坑·已知坑仍在）
- **证据**：登录/注册/找回 `pkg-auth/login/index.vue:42,58`、`pkg-auth/register/index.vue:50,73`、`pkg-auth/forgot-password/index.vue:39,52`；改手机 `pkg-mine/change-phone/index.vue:176,202`；支付密码 `pkg-mine/payment-password/index.vue:201,209`；**银行卡号 `pkg-wallet/bank-cards/index.vue:67`（16–19 位必丢精度）**。`type=number` 共 42 文件，约 12 处用于手机号/卡号
- **影响**：银行卡号超 2^53 直接丢精度 → 卡号错误；手机号在部分端吞前导零、`maxlength` 失效 → 登录注册输入异常。资金 + 鉴权双重风险
- **建议**：手机号/验证码/卡号统一改 `type="text"` + `@input` 过滤非数字 + `:maxlength`

### P0-2 全局兜底三件套缺失（401 / errorHandler / 超时）
- **证据**：`utils/request.ts:38-42,69-73,103-107` 三处 401 分支只 `clearToken()` 不跳登录；`main.ts:8-13` 无 `app.config.errorHandler`，`App.vue` 无 `onError`；`uni.request` 未传 `timeout`、无重试
- **影响**：token 过期后用户卡在错误态需手动重进；未捕获异常线上无感知；弱网长时间空等
- **建议**：集中在 `request.ts` + `main.ts`/`App.vue` 少数文件即可补齐——401 统一 `reLaunch` 登录页（带回跳 + 去重）、加 `errorHandler` 统一 toast+上报、`timeout: 15000` + 幂等 GET 重试 1 次

### P0-3 图片几乎全量未懒加载（覆盖率约 3%）
- **证据**：`<image>` 全库 377 处/192 文件，带 `lazy-load` 仅 13 处/8 文件。重灾区 `pkg-circle/circles/detail.vue`、`pkg-shop/product/index.vue`、`pkg-video/detail/index.vue`、`pkg-mall/product/detail.vue`
- **影响**：长列表进入即并发请求全部图片，首屏带宽/解码压力大、滚动掉帧
- **建议**：列表项 `<image>` 统一加 `lazy-load` + 占位背景防抖动（机械批量改，收益高）

### P0-4 清理 29 个散落备份文件（零风险，立即可做）
- **证据**：`lib/` 及业务目录散落 37 个 `*.bak*`/`*.claude-bak`（约 800KB），如 `lib/shop-data.ts.bak-20260624`、`lib/icons-registry.ts.claude-bak`、`pages.json.claude-bak`、`pkg-circle/circles/detail.vue.bak-20260624`
- **影响**：含陈旧 `if(true)`/`Math.random`/明文 mock，污染全局搜索与后续审计、有误 import 风险
- **建议**：全部移出源码树（git 已留历史），`.claude-bak` 立即清除
