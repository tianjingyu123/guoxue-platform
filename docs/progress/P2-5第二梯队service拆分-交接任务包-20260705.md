## 一、范式（照做即可·同 shop）
1. **facade 委托模式**：原 XxxService 保留为薄 facade，controller/marketing/外部消费者**零改动**、公共 API 逐字节不变 → **行为零变化**（风险最低）。
2. **纯搬家逐字复制**：抽取的方法**逐字**从原 service 复制到子 service（勿手写重构，防偏差）；跨域调用改 `this.xxx` → `this.xxxSvc.xxx`。
3. **叶子优先·破环**：先抽不被其他域依赖的叶子域；有循环依赖时把「被双方依赖的方法」独立成一个叶子 service（如 shop 的 refundExpiredGroupBuys 归退款域）。
4. **每域验收**：tsc0 + 抽取方法**逐字 diff 校验**（`awk` 提方法体 vs .backup）+ **全量 jest 回归**（当前基线 422 套 5536）+ 子 service 加入 module providers + spec 的 TestingModule providers。
5. **<600 行/文件**；response 结构/any 保持原样。
