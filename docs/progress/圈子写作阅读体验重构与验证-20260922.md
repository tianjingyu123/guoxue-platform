# 圈子写作与阅读体验重构

日期：2026-09-22。起点 `5d61fb0a27c64d3164b0225d95c434019e65ddcd`，隔离分支 `codex/integrated-live-gift-paipan-pay-20260920`，开始时工作树干净。

## 本批设计与实现

沿用圈子中性表面、系统字体和内容优先原则：编辑器顶部保留返回/草稿/发布，下方明确当前圈子和保存状态；正文是主区域，附件和创作助手维持按需工具。阅读页把评论输入改成用户触发后展开，避免常驻底栏占用阅读空间。

本批不变更发布权限、收费、内容可见范围、服务端审核规则；不改根工作区未提交文件。

- 本机兜底草稿按账号、入口圈子、云端草稿 ID 隔离。不自动恢复原有无归属公共草稿，避免串圈串号；旧键不自动清理。
- 编辑后 600ms 自动保存，离页/进入后台再次保存。正文、标题、摘要、附件、图片、封面、可见范围、标签和关联商品一并保留；不再只有卸载时才保存。
- 普通动态“保存草稿”明确为本机保存，不创建一个无法续编的后端帖子草稿。文章继续沿用云端草稿接口，并有本地兜底；不声称两种草稿都同步云端。
- 本机存储失败时给出说明；通过页面返回按钮离开会提示继续编辑或放弃。系统强杀/浏览器强退仍不能保证最后一次写入。
- 正文显式取消输入框默认 140 字限制。上传/保存/发布/AI 处理期间拦截重复提交，发布失败保留内容；成功清草稿并返回，直接打开编辑页也可回到原圈子。
- 创作权限严格查询，不因网络失败把文章模式误切为动态；圈子切换时旧权限响应不覆盖新请求。
- 编辑器和帖子顶部预留微信胶囊区，主要导航/发布/草稿触控区至少 44px。
- 帖子评论按需展开。共享评论组件收起只隐藏，保留文字和回复对象；切换目标内容时清空，发送失败继续回填。
