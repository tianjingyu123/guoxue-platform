# 服务器、数据库、域名迁移准备进度（2026-07-28）

## 已完成

- API、H5、静态资源、Cookie、CORS、WebSocket 和分享链接均支持环境变量切换。
- 生产镜像统一构建服务端、管理端与 H5，Nginx 同一入口提供 H5 SPA、管理端、API、上传资源和 WebSocket。
- API 容器不再暴露公网端口，只允许 Nginx 通过 Docker 内网访问。
- 生产模板集中为 `docker/.env.production.example`，包含真实控制器对应的支付、退款、物流、直播、VOD 和 IM 回调路径。
- `check-env.mjs --full` 会检查必填密钥、HTTPS、公网域名、回调同源和精确路径，且不会输出敏感值。
- 部署入口会先执行环境检查、Compose 配置检查、镜像内全量发布门禁和健康检查。
- `DATABASE_MODE=prepare|restored|empty` 明确区分准备、恢复和空库初始化，默认绝不初始化数据库。
- 旧版 `scripts/server-setup.sh`、`scripts/deploy-h5.sh` 已改为拒绝执行的兼容入口；写死旧域名和绕过门禁的 Nginx 文件已删除。
- 数据库导出、恢复、逐表计数、API/H5/CORS 冒烟与 SSL 脚本已具备。

## 新资源到位后执行

1. 填写服务器、PostgreSQL、Redis、对象存储/CDN、域名和 DNS 信息。
2. 在新服务器以 `DATABASE_MODE=prepare` 准备环境。
3. 填写 `docker/.env.production`，通过 `check-env --full` 和 Compose `config -q`。
4. 恢复旧数据库到隔离空库，逐表核对并完成关键业务抽样。
5. 配置 Nginx、SSL、WAF、对象存储 CORS、防盗链和全部第三方回调。
6. 通过 hosts/预览域名完成 H5、小程序、App、手机、平板和 PC 验收。
7. 安排短暂停写、最终快照、DNS 切换和至少 72 小时双环境观察。
