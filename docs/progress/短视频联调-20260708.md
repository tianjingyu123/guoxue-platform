## 二、关键发现与修复

### 🔴 发现 1（已修）：全屏视频流页 `detail/index.vue` 根本没有播放器
消费端全屏流页此前**只渲染 `coverUrl` 封面图**，模板中无任何 `<video>` 元素，后端下发的 `videoUrl` 被 adapter 取到却从未使用——即使库里有真实视频也永远只显示封面、不会播放。`isPlaying` 仅切换一个暂停图标遮罩，是纯视觉假象。这正是"单测绿但真人崩"类问题：无真实媒资时页面看起来正常，一旦有视频就暴露"不能播"。

**修复**（仅 `pkg-video/detail/index.vue`）：
- 当前视频层新增 uni `<video id="vp-player">`，`:src="currentVideo.videoUrl"`，`autoplay`+`:loop`+`:muted="isMuted"`+`object-fit="cover"`，隐藏原生控件（controls/center-play/fullscreen/progress 全关），封面图保留为 poster/兜底。
- `v-if="currentVideo.videoUrl && !playError"`：**无 videoUrl（如当前 seed 商品视频 videoUrl 为空）或加载失败时不挂载 player，自动回退到封面**（优雅降级）。
- 播放控制走 `uni.createVideoContext('vp-player')`：单击 `togglePlay()` 播放/暂停；`@play/@pause` 事件回写 `isPlaying`（H5 autoplay 被浏览器策略拦截时暂停态与 UI 保持一致，暂停遮罩正常显示可点播放）；`@error` → `playError` 回退封面。
- 上下滑切换视频时 `watch(id)` 重置 `playError=false / isPlaying=true`，新 `videoUrl` 触发 autoplay。
- CSS：`.vp__video` 覆盖封面之上（z-index:1）且 `pointer-events:none`，让单击/滑动手势穿透到父层由脚本统一控制；相应把暂停遮罩/渐变/飘心 z-index 提到 2~3 保证盖在 video 之上。

### 发现 2（记录，非本次范围）：VOD 签名端点前端未接入
后端 `videos/vod/upload-signature`（客户端直传 VOD）与 `play-signature`（psign 防盗链）均 200 可用，但 **mobile 前端未调用任何 VOD 签名接口**——发布页 `publish/index.vue` 走的是 `POST /upload/video`（后端 COS 代传），播放走 `videoUrl` 直链。二者是两套上传/播放方案：
- 当前生效方案 = COS 直传 + videoUrl 直链播放（与任务背景"复用 /upload/video COS 直传"一致，链路完整）。
- VOD SDK 直传 + psign 播放 = 后端已就绪但前端未启用（属于后续增强：客户端直传 VOD 可省后端带宽、psign 可做防盗链/多码率自适应）。本次不改（涉及新增前端 VOD SDK 与播放器改造，非"发现即修"小范围）。

### 发现 3（记录）：play-signature 无媒资时降级 md5
`vod.service.genPlayerSignature` 先查媒资 `ContentKey`，取到才用 HMAC-SHA1 生成标准 psign；查不到（如本次 fakefileid 或无转码媒资）降级为 `md5(fileId+time+expire+secretKey)`。真实媒资上传+转码后才会走标准 psign。当前 psign 未被消费端使用（见发现 2），不影响。
