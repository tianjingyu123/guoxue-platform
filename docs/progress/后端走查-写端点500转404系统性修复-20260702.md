## 本轮修复主题

**一类系统性 bug**：service 对**按 id 执行 `update`/`delete`** 时缺少存在性检查 → 操作不存在记录时 Prisma 抛 `P2025` → HTTP **500**（正确应为 **404**）。
**另一类**：用 `updateMany`/`deleteMany` 删改单条记录 → 记录不存在时静默返回 200（**假成功**）。

修复模式（统一）：
```ts
const existing = await this.prisma.<model>.findUnique({ where: { <键> } });
if (!existing) throw new BusinessException(ErrorCode.NOT_FOUND, "<资源>不存在");
```
`BusinessException(ErrorCode.NOT_FOUND)` 全局映射为 HTTP 404（已由 e2e 验证）。
