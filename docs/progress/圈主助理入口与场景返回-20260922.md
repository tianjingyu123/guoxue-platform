# 圈主助理入口与场景返回

基线：`f23beac4edb86cc74baf3571b378b2f6e17f7af0`。本批只改圈子客户端的进入和返回行为，不变更 AI 权限、额度、价格或服务端接口。

## 已修复

- 服务端仅允许有效圈成员调用圈主助理。详情页入口此前向游客和未加入者直接打开对话页，发送问题后才被拒绝。现在入口依照已查得的成员状态显示可用条件：未加入走现有入圈流程，审核中查看进度，已过期走续费，付款待确认沿用订单恢复，成员状态查询失败先重试；只有有效成员进入对话。
- 从圈内打开助理仍按页面栈返回原位置。直接打开带 `circleId` 的助理页面、没有上一页时，返回相同圈子的详情，不落到通用首页。通用聊天组件仅增加可选返回目标，其他场景行为不变。
- 圈名参数异常时使用默认标题，避免解码错误使对话页白屏。

## 本地验证

- `tests/release/circle-assistant-entry-browser.mjs`：6 组本地 H5 交互通过，覆盖未入圈、有效成员、过期、独立入口返回、成员查询失败，以及对话返回后数据刷新时保留圈内阅读滚动位置；接口由夹具拦截，无真实业务写入。
- `pnpm --filter @guoxue/mobile type-check` 通过。
- `pnpm --filter @guoxue/mobile build:mp-weixin` 通过：主包 1.63 MB，保守上传口径 1.91 MB；33 个分包，最大 `pkg-paipan2` 1.94 MB，`pkg-circle` 0.96 MB；615 个 WXML 和 2683 个文本产物检查通过。

## 未覆盖与发布边界

圈子助理真实问答、知识来源与推荐、语音能力、微信/App 真机返回栈、真实续费后返回对话仍待有权限的受控环境验收。此次构建是隔离候选，不代表线上已更新；未部署或提交小程序审核。
