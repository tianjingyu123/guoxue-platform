## 可执行试点及覆盖边界

新增 `pilots/managed-tenancy`，不注册到正式 `AppModule`，不改变现有 schema/迁移、商城、课程、佣金、站点、认证或客户端。用 Node 内置 SQLite 与 HTTP 适配器运行，两客户独立数据库、两个品牌站共享平台文件但私有数据逐 scope 过滤；同客户第二进程竞争圈子配额。无需共享依赖或 Prisma 生成。代码和报告绑定同一候选与公共协议摘要。

已经实现的最小闭环：

1. 独立控制面开通 API：单独维护身份、应用与空间唯一映射、PREPARING/READY、相同请求重试、冲突拒绝及审计。合成客户管理员/客服不能开通；本地测试控制面单写入者，不冒充多运维节点开通竞争实测。
2. 客户与应用身份：固定实例只连接指定数据空间；令牌绑定应用/客户/用户/认证修订；角色读主库；内部上下文不可由普通对象伪造，续费后旧上下文/令牌失效。
3. 模块/资源/数量：白名单商品、课程及智能体；单条和批量写入过滤与事务回滚；圈子数量在事务内检查，跨进程并发不超额；知识检索与本人会话闭环。
4. 品牌/模板/页面：community 与 single-agent 合成模板元数据；品牌色/文案限制；直接消费公共解析器，按后端授权收窄入口。未知组件/脚本拒绝，legacy 客户端不消费新版组件。没有复刻草稿、发布、回退引擎或装修后台。
5. 年合同与退出：maintenanceCycle=ANNUAL，maintenancePrice 未知用 null；提醒/结束/导出截止/下载TTL均显式输入。合成验收用加速时间窗口，不当作真实一年或业务默认天数。状态 ACTIVE→REMINDER→EXPIRED_RESTRICTED→ARCHIVED_RETAINED；到期不删库，既有订单/售后可按原权限处理。
6. 续费：维护适配器更新期限和认证修订，恢复经营；已暂停和旧修订任务不自动重跑；没有扣年费或自动扣款实现。
7. 导出：本客户管理员申请，用户/商品/课程/圈子/订单/会话/合成附件的显式字段范围，手机号脱敏，不含控制面、签名密钥、源码及其他客户；带额外临时授权、原申请人认证、截止检查和下载审计的 JSON 附件。密码和供应商凭据不能作为资源 body 种子进入此闭环。
8. 合成交易：客户商户、金额及规则快照检查，付款/权益/退款/重复事件契约；品牌站共享平台商品，固定平台交易主体、商户与既有规则引用，不开放站长上传/独立收款。付款事件仅合成运维方法，没有真实支付或公开回调路由。
9. 迁出/恢复：一致 SQLite 备份，同版本独立目录恢复，身份误接拒绝；订单/附件/审计读回与原实例比较，并启动恢复进程经 HTTP 验证，原实例仍可作为回退读路径。

本地所有实例以同一个 Windows 用户运行，不验证操作系统隔离或最小权限数据库账号；进程被攻破后能否读其他文件尚未验证。SQLite、内存缓存和合成任务只是规则与适配试验，不能代替 PostgreSQL、Redis ACL、BullMQ、COS、pgvector 或实际模型/渠道的隔离证据。现有 NestJS 全业务控制器没有接入本试点，不能宣称全业务租户交付完成。

品牌站的合成 contract 仅验证不替换平台主体、商户和规则引用；没有计算实际现有佣金比例、对账账单或真实收益。本候选未修改既有商城/佣金/权益源码，旧业务本身仍按主线自己的验收门槛，不因合成测试通过而免验。

## 迁出与回滚边界

标准迁出：核源实例身份与版本 → 获维护授权并备份 → 同版本目标实例/数据库/账号 → 复制数据与私有媒体，校验行数/内容摘要/订单权益/归属 → 协调冻结或暂停写入/支付回调/任务消费 → 增量与对账 → 切换应用入口/回调/任务所有者 → 受控验收 → 保留原只读回退窗口。

本轮只演练同版本本地副本与读验证；没有切 DNS、迁移真实客户、实际外部回调切换、任务主控选举或写入增量同步，不承诺零停机/RPO/RTO。原实例和迁出实例不能同时成为业务写入者。

新 SQLite 迁移文件只用于试点，不修改已执行迁移。正式迁移要新建 Prisma migration：先新增可空/显式状态结构，逐应用启用后验收，最后再增加必要约束；回滚时先停止新入口/新业务，保留订单、售后、审计与导出数据。不自动 DROP 数据库、删除对象或恢复会重复扣款的任务。试点回滚仅停止本任务进程并撤销本目录候选，不需修改主线数据。
