# 苹果支付资金安全候选

基线360ac6d3。未发布，未启用Apple配置，未调用真实支付。

## 修复

- 首次验票必须匹配Apple签名appAccountToken和当前账号；缺失、不符不发币。已入账交易仍通过既有账本幂等返回，不能跨账号领取。
- 退款及撤销退款使用状态条件更新，再修改余额，处于同一数据库事务。状态已被其他通知改变时不重复增减余额。
- REFUND_REVERSED只允许从REFUNDED恢复，不把REVOKED恢复成有效交易。
- 正式NODE_ENV=production服务只验证Production交易和通知，不回退沙盒，以免免费测试交易进入真实国学币账本。TestFlight必须使用隔离测试账本，不可直接改正式服务开关放行。
- 客户端在拉起购买前检查账号UUID格式；更新注释，禁止将尚未经真机验证的原生透传能力写成既定事实。

## 验证及限制

Apple服务/配置共14项测试通过，其中新增5项覆盖账号标记缺失、不匹配、并发状态争抢失败、退款撤销和撤销资格保护。数据库真实并发和通知乱序仍未验收；本次CAS并非完整事件时间排序方案。

Apple官方appAccountToken为UUID，签名交易会返回该绑定；DCloud现有username字段存在，但现有安装包到签名载荷的映射尚须苹果真机沙盒确认。若字段丢失，应升级原生接入，不放宽服务端归属校验。未匹配交易不得finishTransaction；保留恢复处理机会。

现有产品为消耗型国学币，不声称支持自动续订。全量数字商品路由、配置、退款通知到达、消耗型未完成交易恢复、Sandbox与Production资金隔离尚需继续验收；不得因单测通过对用户开放IAP。
