## 本轮已实现并本地验收的候选

控制面新增六张 Managed 表，合同配置与 API 配额 Tenant 分开；绑定应用主体、交易主体、数据库空间、最低权限角色、凭据引用和认证摘要。开通用数据库事务、唯一约束及请求摘要处理幂等，续期和授权使用乐观修订；所有维护入口必须既有 JWT + SUPER_ADMIN，并留下审计。管理后台提供配置、期限、模块/资源/数量、成员、实例核验、启用和暂停，保存配置本身不会部署或收费。

独立 `lease-main` 只加载租赁最小路由，不加载平台 AppModule、运维或支付控制器。业务连接固定到一个客户库；控制面账号只读。实际核对数据库、账号、端口、角色能力、schema CREATE、密钥摘要和已挂载业务允许的表/字段权限，不能只凭连接成功宣称隔离。运行账号与合成数据准备账号分开，拒绝改用户/商品价格、读平台角色或内部提示词、删除审计及跨库连接。

租赁会话由已验证的平台登录身份换取，绑定客户、空间、应用、选择器、合同与成员修订，15分钟有效。业务每次复核原令牌、成员状态、合同和应用状态；平台改密/封号同步推进成员修订。客户角色放在独立成员表，不添加平台 UserRole。**客户完全独立的注册/登录链路还没接好**；当前方式仍依赖平台用户状态与授权对应，不能宣称独立用户体系已商业交付。

最小业务覆盖授权资源元数据读取、商品标题更新、数据库事务锁下的圈子数量创建、本人历史订单、本库授权圈子知识检索。圈子创建后仍是待审状态；不是完整圈子运营功能。到期停止新经营，历史本人订单及售后受理保留。售后仅 PENDING_REVIEW，不自动退款。

导出采用真实 RepeatableRead 快照、明确字段、手机号脱敏、原申请人和额外短期令牌，仅令牌摘要落库；每类超过5000条拒绝同步导出，不静默截断。保存和下载都有审计。新增三张退出表；仍是 JSON 业务快照，未包含实际媒体附件、完整知识/会话、分页异步导出或真实迁出交付格式。

品牌入口新增来源表，复用既有 ShopOrder/Pricing/Attribution/Commission 服务及 JWT；平台资源白名单、应用和本人订单来源单独核对。同一重试键只建一个订单、扣一次库存，不同应用独立命名域。自购立减与防自推荐沿用既有规则，不设置新佣金率。站长/关联有效运营商只拿本应用数量汇总，不获得客户手机号、地址或跨站订单。新增订单与来源分两段持久化，重试能补登记；生产仍需故障窗口与补偿验收。

页面配置消费公共草稿/发布/能力登记裁决，再按合同、模板和公共运营开关收窄。保持协议要求的内容流声明；独立入口没有通用推荐搜索路由。它不是已经接入真实品牌 H5/小程序页面的证明。
