# 第五部分：单模块标准闭环（可复制的核心流程）

每个模块按这5步走，全绿才"锁定🔒"：

1. **接口对账**：该模块前端调用 vs 后端openapi。命名漂移→改前端名对齐后端；后端缺→补后端接口。（依据：术语表）
2. **真实运行**：本地起前后端，登录态下走该模块所有页面，开浏览器Network看每个请求真实状态码（200/404/500），看页面真实渲染。← 这步定位"走不通"
3. **修复打磨**：修运行时bug、补三态(用现成app-skeleton/error/empty)、加写操作防重复锁、修交互细节、对比V0原型(Desktop/V0-6.24)校验还原度。
4. **验证**：该模块涉及文件 vue-tsc 0错 + 构建不回归。
5. **锁定**：写契约快照测试+关键流程e2e，标记🔒，更新模块台账。永不回退。

# 第六部分：贯穿全程的机制

1. **一致性机制**：后端是接口事实来源；前端从openapi用orval生成api层、不手写url；每次改动跑check:contract红绿灯。
2. **回归测试网**：每锁定一个模块沉淀测试，只增不减，全量一键跑，改A坏B立即暴露。
3. **进度台账**：`进度跟踪-实时更新.md` + 模块状态表，每步更新，跨会话可接。
4. **协作规则**：只读直接做+汇报；改动/动数据/选方案先说+等同意；不碰后端贵数据。
