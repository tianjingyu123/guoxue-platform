## 第一期（P0）：高频刚需 · 流量入口 · 7个工具

> 竞品标配，缺了用户会觉得平台不完整。

### 1. 八字合婚 `bazi-hehun`
- **场景**：情侣/夫妻八字匹配度分析
- **输入**：男命（年月日时）+ 女命（年月日时）
- **输出**：年柱合（生肖）、日柱合（配偶宫）、五行互补度、十神配对、用神协调、综合评分
- **核心**：复用 bazi.calculator 双人排盘，新增合婚分析层
- **竞品**：问真有 `/hehun.php`，热卜有合婚板块
- **排期**：P0-1

### 2. 称骨算命 `chenggu`
- **场景**：极简输入，用户只需年月日时
- **输入**：出生年月日时
- **输出**：年骨重+月骨重+日骨重+时骨重=总骨重，对应袁天罡称骨歌
- **核心**：纯查表算法，60甲子骨重表 + 12月骨重表 + 30日骨重表 + 12时辰骨重表
- **竞品**：热卜/灵机均有，全行业标配
- **排期**：P0-2（实现最快，1小时内可完成）

### 3. 灵签/抽签 `lingqian`
- **场景**：用户祈福、求签、心理决策辅助
- **输入**：签种选择 + 摇签动作
- **输出**：签号 + 签文（诗/解）+ 上中下签
- **签种**：观音灵签(100签)、关帝灵签(100签)、吕祖灵签(100签)、妈祖灵签(60签)、黄大仙灵签(100签)、月老灵签(100签)
- **核心**：各签种签文数据库 + 随机摇签 + 签文解读
- **竞品**：寺庙类小程序标配，热卜有观音签
- **排期**：P0-3

### 4. 生肖运势 `shengxiao-yunshi`
- **场景**：12生肖每日/每周/年度运势速查
- **输入**：生肖（可自动从出生年推导）+ 查询类型
- **输出**：今日运势（总分+事业/财运/感情/健康分项）+ 幸运色/数字/方位 + 宜忌
- **核心**：基于生肖流年太岁关系（值/冲/害/刑/破）+ 月份五行旺衰
- **竞品**：全行业标配
- **排期**：P0-4

### 5. 星座运势 `xingzuo-yunshi`
- **场景**：吸引年轻用户，中西结合差异化
- **输入**：星座 + 查询日期
- **输出**：今日运势 + 事业/爱情/财运 + 幸运物 + 星座配对
- **核心**：12星座 + 基于行星位置的运程模板
- **特色**：可接入 sweph 星历做真实星象驱动（七政四余已集成）
- **竞品**：测测/热卜有
- **排期**：P0-5

### 6. 周公解梦 `zhougong-jiemeng`
- **场景**：巨大搜索流量入口，SEO/ASO贡献
- **输入**：梦境关键词/描述
- **输出**：梦境分类 + 传统解梦 + 心理学解读
- **核心**：梦境关键词数据库（千级条目）+ 全文检索
- **竞品**：全行业标配
- **排期**：P0-6

### 7. 每日黄历推送 `huangli-push`
- **场景**：轻量级每日宜忌，适合微信/APP推送
- **输入**：日期
- **输出**：宜忌摘要、吉神、凶神、冲煞、吉时、财神方位
- **核心**：复用万年历择吉引擎数据，轻量输出
- **竞品**：全行业标配
- **排期**：P0-7
