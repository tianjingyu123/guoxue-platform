# 首页商城与课堂卡片优化候选（2026-09-22）

状态：隔离候选，待主线评审；未部署。工作树 `.worktrees/home-feed-card-refresh-20260922`，分支 `codex/home-feed-card-refresh-20260922`。

## 规划与审计

目标是让首页双列内容更充分利用屏宽，同时让商城与课堂卡在窄列里保持协调比例。当前 `.flow` 两侧各留 24rpx，列间 18rpx、列内 18rpx；商城 1:1 图片下叠多层标签、简介、销量和按钮；课堂把 16:9 素材放进 3:4 高容器，图片、填充带和标题又分三层，窄屏上信息割裂。

设计约束：保留热卜朱红与暖白识别度；参考苹果界面的清晰信息顺序、轻量反馈、稳定圆角和留白，不复制系统界面。整张卡片作为点击目标，先读图和标题，再读辅助信息，最后看价格/讲师。无真实数据时不编造价格、人数或标签。

## 设计方案

| 项目 | 原状态 | 候选 |
|---|---|---|
| 首页双列 | 两侧 24rpx，列间/列内 18rpx | 两侧 16rpx，列间/列内 12rpx |
| 商城图 | 1:1，窄列中偏高 | 4:3，给标题与价格留宽 |
| 商城信息 | 标签、两行简介、销量、价格、按钮均堆叠 | 简介限一行，去掉重复按钮和“到手价”说明，保留真实销量与价格 |
| 课堂图文 | 3:4 图文填充容器 + 另一个标题区 | 16:9 图片直接接同一张白色内容面，标题、简介、讲师/人数、价格依次排列 |
| 装饰 | 书脊、光晕、渐变色带 | 只保留封面理由浮签和细分隔线 |
| 交互 | 卡片按压反馈 | 保留按压反馈，增加键盘焦点与减少动态效果支持 |

课堂卡在紧凑列中优先显示课程题目；讲师名和价格在同一底行，超长讲师名省略，价格不被挤出。商城价格为空时不再显示误导性的“¥0”。

## 实施与验证

改动限于首页双列布局、商品卡、课程卡及共用卡点击外壳。课程与商品仍复用原有 `FeedEnvelope` 数据与路由映射，未改接口或后台。隔离工作树内离线恢复依赖，构建 `@guoxue/shared`；H5 使用 `example.invalid` 占位公开配置完成构建；ESLint 对改动文件无错误，现有格式规则仍有警告。真实设备、微信小程序和线上内容图比例尚待视觉验收。

接收时先审查这四个前端文件，在小屏 H5、微信和 App 真机分别核对长标题、无图、无价格、免费课、有讲师/无讲师、长理由与屏幕阅读器焦点。若与其他首页改动冲突，只移植本候选四文件的相关差异；撤回可对本候选提交执行 `git revert`。
