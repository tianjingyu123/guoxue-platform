## 校验与限制

`verify-final-audit.py` 对 6500 字及 31 条决定通过；`verify-hand-poems.py` 与 `verify-reviewed.py` 对展示引文通过。相关 Jest 单测 62 项通过；姓名详批 5 组 32,552 调用回归指纹已重算。全服务端类型检查受当前工作树复用的旧 Prisma Client 影响，报错集中在 classic/shop/voice 等未修改模块；不得据此视为本轮代码全部类型通过。移动端类型检查报错在金口诀、罗盘、梅花等未修改模块及旧 shared 声明中，本轮起名改动无报错。正式合并前需在目标分支生成匹配的 Prisma Client 和 shared 声明并跑完整构建。

公开姓名库含采样、年代与性别偏差，不能推出全国重名率、某年新生儿频率或姓名优劣。`low` 意味样本少于 10 次或没有可比样本；不是全国少见。6500 字的结构和参考读音完成校验，含义和「宜/可」属于逐字规则加重点人工审查，不能声称每一字都已由独立语言学专家审定。诗词全集未批量进入产品，未解决的异文和作者冲突继续留在上一轮报告。当前仅为本地代码与数据交付，未上线。

## 后续提升顺序

1. **排盘可信度**：为各排盘引擎建立可追溯的古籍页码、流派、算法版本与人工复核样例；优先补齐节气跨日、时区、真太阳时、闰月和历法边界。把“传统流派结论”和确定的历算结果分开呈现，用户可切换流派并看到依据。
2. **外部对照与独立校验**：选择可合法使用的权威历算数据和多家排盘结果，形成差异台账；对重大差异回到原典与计算链路裁定，而非用多数票替代考证。将黄金样例覆盖各法关键边界和罕见输入。
3. **起名质量**：建立双人复核的字义、禁忌、谐音、异体字和出处工作台；每条修改记录来源、审核人、理由、版本。若要提供真正重名风险，先取得有代表性且许可明确的人口统计，再按地区、出生年段和性别给置信区间。当前公开样本只保留为辅助参考。
4. **用户体验与可用性**：真机复验推荐、详批、字典联动，覆盖长姓、复姓、多音、少数民族名、无字典字及输入错误；让每项判断可点击查看计算依据和适用边界，收集经同意的纠错反馈并以匿名方式回流。
5. **交付门槛**：目标分支生成匹配 Prisma Client 后跑全量构建与关键回归；完成移动端真机验收、许可署名检查和发布前数据版本冻结，再考虑上线。以准确率、可追溯率、边界样例覆盖率、用户纠错闭环时长衡量领先程度，不预设行业第一的结论。
