# Android 全角色真机审计与优化（2026-08-30）

## 1. 目标与结论边界

本轮不再以「页面能打开」作为验收，而以真实角色完成一条业务任务为最小单元。当前仍处于审计与修复阶段，未获得同版本服务端、数据库迁移、客户端和真机证据前，不宣称「全部通过」或「已达上线水平」。

## 2. 新的验收方法

每条证据必须同时绑定：

- 唯一完整 `sourceCommit`；
- 唯一 `releaseId`、服务端双节点版本与数据库迁移状态；
- 客户端版本号、APK SHA-256、包签名和运行域名；
- 设备型号、Android 版本、分辨率和验收时间；
- 账号角色、入口、操作序列、截图/XML/日志和最终状态。

审计按五层递进，任一层失败就不能以下一层的「静态测试通过」代替：

1. **导航与生命周期**：冷启动、热启动、前后台、左缘返回、系统返回、重复进入、异常恢复；
2. **真实任务链**：从入口到结果页，不仅点第一个按钮；
3. **交互完整性**：点击、竖滑、横滑、输入、弹层、键盘、焦点、空态、错误态、加载态；
4. **角色与权限**：普通用户不多权，业务角色能完成工作，未配置能力诚实禁用；
5. **弱网与失败恢复**：超时、401/403/404/5xx、重试、幂等、重复点击和进程重建。

本轮同时新增“版本边界”规则：若手机 `versionCode/sourceCommit`、公网 `releaseId` 与数据库迁移不属于同一冻结候选，测试结果只用于定位问题，不得记为上线通过。这样可以避免新客户端连旧服务端时出现套餐缺失、旧排盘回滚等伪缺陷或伪通过。

## 3. 全角色任务矩阵

| 视角 | 必过核心任务 | 关键交互/异常 | 最终证据 |
| --- | --- | --- | --- |
| 游客 | 首页、文章、古籍、课程、直播、短视频浏览 | 需登录操作精确拦截且可返回 | 公开路径不白屏、不死按钮 |
| 普通用户 | 登录、内容、收藏、评论、订单、地址 | 键盘/弹层/返回/前后台 | 普通用户端到结果页 |
| 会员/买家 | 套餐、下单、支付前确认、订单、售后 | 空套餐、库存、重复提交、支付取消 | 不扣款预发布链 + 既有小额证据 |
| 创作者 | 创作中心、作品、发布页、数据 | 权限、空作品、上传中断 | 发布前不产生真实内容 |
| 圈主 | 圈子详情、成员、待办、帖子、收入 | 空圈、审批、治理权限 | 圈主管理后台闭环 |
| 讲师 | 讲师工作台、课程、直播、收益 | 资质、上传、推流、下播恢复 | 讲师与学员双视角 |
| 直播主播 | 创建/编辑、OBS 预检、开播、评论、带货、下播 | 过期推流地址、断流、回调、前后台 | 媒体在线+回调+Redis+DB |
| 商家 | 商品、库存、订单、发货、退款 | 越权、伪库存、重复发货 | 商家与买家同单据闭环 |
| 站长/运营商/线下驿站 | 业务看板、归因、履约、分润 | 旧排盘映射失败不影响主业务 | 三种角色各自独立证据 |
| 研究院成员/院长 | 成员端、管理端、内容与课程 | 双角色切换与越权 | 成员/院长各一条闭环 |
| 内容/商品审核 | 待审、详情、通过/拒绝前确认 | 空队列、并发审核、审计日志 | 不执行真实审批的预发布路径 |
| 财务 | 对账、退款审核、流水 | 金额与币种、重复回调、权限 | 历史小额证据+无真扣款路径 |
| 客服 | 用户、工单、会话、售后协同 | 敏感信息脱敏、不越权处置 | 客服工作台闭环 |
| 超管/运营管理员 | 运行看板、开关、内容、用户、风险 | 变更前确认、审计记录、回滚 | 只读预发布证据，不擅自改配置 |

## 4. 当前 v230 重审计已得结论

| 项目 | 真机结果 | 归因/处理 |
| --- | --- | --- |
| 短视频打开、上下滑、评论面板 | 通过 | 旧排盘不是短视频数据层根因 |
| 旧排盘具体工具点击 | 失败 | 当前手机被旧服务端导入第三方 WebView；旧页工具无响应 |
| 排盘运行模式 | 已修源码，待同版 APK/服务端真机复测 | 网络异常不再永久写入 legacy；删除 App 全局 reLaunch 劫持 |
| 商城商品→SKU→确认订单 | 通过，未提交订单 | 发现详情与 SKU 库存不一致，已统一使用实时 `currentStock` |
| 会员购买 | 被「套餐未配置」诚实阻断 | 新迁移已含会员套餐初始化；当前预发布尚未同版部署/迁移 |
| 文章/帖子评论按钮 | 真机复现「看似无响应」 | 旧实现只滚到评论区；已改为定位并聚焦真输入框 |
| 标准左缘返回/系统 Back | 商城结算页通过 | 之前跨全屏过长模拟滑动是测试输入伪差，不计产品缺陷 |
| 课程列表→详情→文字课 | 通过 | 同版候选需再复测 |
| 古籍列表→详情→阅读器→滚动 | 通过 | 内容与工具栏正常 |
| 听书播放/暂停/后台继续/前台恢复 | 通过 | 进度从第 2 句前进到第 5 句，路由保持 |
| 智能体广场→助手详情→输入框/键盘/返回 | 通过，未发送消息 | 无真实对话副作用 |
| 圈子→圈子详情→圈主管理后台 | 通过 | 成员/收入/待办/起步任务正常展示 |
| 创作中心、我的直播、编辑直播、帮助中心、设置 | 通过 | 未发布、未开播、未改配置 |

## 5. 进入上线候选的硬条件

- 客户端、服务端、数据库迁移和公网 `releaseId` 必须对齐到同一冻结提交；
- 普通用户核心链与 15 类 QA 角色各至少一条核心任务真机通过；
- 所有高频可点元素均有可见反馈，不存在死按钮、假成功或无返回路径；
- 五个主导航连续切换、排盘工具连续切换、短视频竖滑、支付前确认、评论输入、前后台恢复均通过；
- 无白屏、无状态栏/挖孔遮挡、无未处理 JavaScript 异常；
- 支付、评论、开播、发布、审批等外部副作操作仅在明确的动作级授权下执行，不用伪数据代替结果。
