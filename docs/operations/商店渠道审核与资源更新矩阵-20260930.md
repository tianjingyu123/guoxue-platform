# 商店渠道审核与资源更新矩阵

核验日期：2026-09-30。目录覆盖 16 个商店/品牌渠道，另有官方直发和历史兼容槽。目录、构建能力、上架身份、具体应用许可是四件不同的事；本轮没有商店账户鉴权、上传、审核或发布。

所有渠道实际默认 DENIED。下表“方案禁用”还由服务端、原生配置构建器和 Android 扩展共同拒绝；其余渠道也必须有正式匹配包实测、应用身份和策略根签名证据，经人工审批后才能启用，不能只填写说明文字。

运营开关用于实际运营和故障收窄，不能用于审核时隐藏违规内容、审核后再开启，也不能切换应用主营业务来规避复审。关闭新购买/开播/入驻入口，不等于取消原有订单、退款、客服、已购阅读或正在履行的权益。

公开文档控制记录：优先读取官方页面和页面支持的匿名只读结果。vivo 页面为 SPA；本轮从其公开脚本定位 `/webapi/doc/tree` 和 `/webapi/doc/info?id=12/240`，返回 HTTP 200、code 0 与对应文档标题/正文。它们是官网页面使用的匿名文档接口，不是账户开放 API/SDK，不证明任何开发者身份、权限或稳定接口契约。仅适用于公开文档读取；没有读取 Cookie 或取得账户鉴权。华为/应用宝正文不可读的部分如实保留未核验状态。
