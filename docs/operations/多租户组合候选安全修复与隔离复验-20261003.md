## 修复的安全缺陷

原客户修订操作发生在平台令牌撤销之前。一旦客户数据库更新失败，改密入口可能已经更新密码，却跳过平台旧令牌撤销。修复将平台撤销放入 finally：客户修订失败也撤销原平台令牌，同时保留失败语义；平台 Redis 自身故障仍抛错。

这不提供 PostgreSQL 与 Redis 的跨系统原子事务，也不回滚此前已写入的新密码。真实合成入口验证客户修订失败时返回 500，新密码已写入，旧平台访问与刷新令牌已拒绝。未声称客户修订本身完成，真实 Redis 故障与重试恢复仍需补验。
