# 客户模型响应边界与继续推进

本批仍在本地隔离候选推进，没有扩展主线接收、远端推送、云部署、生产迁移、真实收费、供应商付费或渠道登记授权。前批停机及客户端证据保持原样，见[停机交接](多租户独立入口停机顺序与继续推进-20261003.md)。

## 发现与修复

客户模型原适配器先用Response.json完整读取响应，再由会话服务检查8000字符正文；错误响应也先完整读取文本。合成复现源码为491e6e2755c7d90858e749157062ae43c045b37b：成功与503两种响应各读取1,048,670字节，均未取消读取；成功路径仍接受其中很短的助手答案。正文字符检查不能替代读取前的资源约束。

固定客户非流式调用现在逐块计量实际解码后的响应正文，候选技术上限64KiB；超限块不保存，已声明超限则在正文读取前拒绝。无长度、虚报小长度或gzip压缩不能绕过实际字节检查。完整正文才解析JSON；无效UTF8、截断JSON、非对象、断流或取消不会返回部分助手答案。错误状态直接取消正文，日志和错误仅保留状态及泛化说明。

读取失败会取消流并中止该次fetch；不等待不受控的底层取消回调，不新增供应商重试或降级。调用方取消和30秒原超时继续有效。该上限是客户端实际保存的正文预算，不是整个进程或网络内部缓冲的硬内存限制；Linux资源配额与并发、模型费用额度仍需独立验收。

官方只读模型清单继续使用1MiB上限，改为同一边界读取器；只对完整有效原字节计算响应摘要并签名。只读失败不生成核验记录；默认不授权生成调用。固定客户通道保持客户、空间、密钥摘要与签名校验，未继承平台环境变量。原平台未指定固定客户配置的路径及平台流式路径不属于本次改动范围。

实现依据为[Node Web Streams读取与取消](https://nodejs.org/download/release/latest-v24.x/docs/api/webstreams.html)和[AbortController](https://nodejs.org/download/release/latest-v24.x/docs/api/globals.html#class-abortcontroller)。本机实际验证版本为Node v24.17.0；官方24.x页面不是本机安装或运行版本证明。

## 实际验证

合成字节流专项9组通过：精确64KiB与跨块中文、声明超限零读取、分块及虚报长度、错误正文零读取且不进入日志、无效编码/JSON、头成功而正文停滞、永不完成的取消回调、调用方取消、清单摘要/签名与1MiB约束，以及原平台非固定路径兼容行为。

真实loopback HTTP、固定Qwen适配器、三个独立Nest进程与合成PostgreSQL专项8组通过：普通与gzip完整答案提交；压缩超限、503正文、截断正文和无效编码保留一条UNKNOWN，无助手正文；跨进程同键只查询，换键也不能盲重发。实际gzip线上长度小于64KiB、解压后超过1MiB，仍拒绝。另一客户保持访问，跨客户令牌拒绝。

供应商失败或超限不能推断未收费，UNKNOWN不自动退费、补发或改为成功；真实结果和费用对账仍待实际授权及供应商查询权限。合成Qwen配置只存在于pilots包装器，正式lease-main没有这个loopback配置入口，也没有访问真实模型账号。

服务端完整候选编译和本批相关文件lint通过，受测源码 `1abb07d75b4598d9f2b89270ff3a0a5a03f0a71a` 的28套完整串行验证零失败：22套真实本地数据库/服务183组，另列字节流9组、只读核验模拟3组、商业100项、认证47项、SQLite18组和隔离11条。126个源码磁盘字节/Git对象及1364个编译文件摘要一致，原始报告和逐文件核验见[本批冻结证据](tenant-pilot-evidence/real-provider-boundary-20261003/README.md)。统一清单新增固定Qwen适配器、其协议类型与边界读取器的源码/Git对象摘要，不再仅依赖专项报告里的适配器磁盘摘要。没有改schema、迁移、客户端或公共编排引擎。
