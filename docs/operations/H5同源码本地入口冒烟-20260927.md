## 数据限制

- 本地测试源是 `http://127.0.0.1:8769`，正式 API 为 `https://api.rebugx.cn`。浏览器发往正式 API 的请求报 `net::ERR_FAILED`；对 `config/client` 带本地 Origin 的只读探针得到 HTTP 200，但未返回允许该本地 Origin 的 `Access-Control-Allow-Origin`。因此除首页部分静态元素外，其余页面显示网络失败、排盘显示“服务暂时不可用”。这是本地跨域条件下的结果，**不能据此判断正式同域 H5 服务也失败，也不能判定正式数据通过**。
- 本次没有登录、下单、支付、退款、分享、写入数据或触达用户。正式 H5 需在备案/域名与最终后端一致后，用真实入口复验内容、权限、排盘分享及付款回跳。

结论：当前源码 H5 构建和八页本地路由冒烟通过；真实数据与业务闭环仍未覆盖，完整版本尚不具备发布条件。
