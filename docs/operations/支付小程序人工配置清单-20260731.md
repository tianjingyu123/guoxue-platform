## 三、微信支付商户平台（必须由商户超级管理员操作）

1. 登录 `https://pay.weixin.qq.com/`。
2. 「产品中心」确认开通实际使用的产品：小程序支付、JSAPI 支付、APP 支付；不用的产品不要开通。
3. 「产品中心 → APPID账号管理」发起或检查绑定：
   - 小程序 AppID；
   - 公众号 AppID（微信内 H5/JSAPI 支付使用）；
   - 移动应用 AppID（旧 APP 升级后的 APP 支付使用）。
4. 到小程序/公众号/开放平台分别确认绑定申请。该确认通常要求管理员扫码或安全验证，不能由服务器代替。
5. 「账户中心 → API安全」准备并妥善保管：
   - 商户号；
   - APIv3 密钥（32字符）；
   - 商户 API 证书序列号；
   - `apiclient_key.pem` 商户私钥；
   - 微信支付公钥及公钥 ID，或仍在使用的平台证书。
6. 若启用公众号内 H5/JSAPI 支付，在「产品中心 → 开发配置 → JSAPI支付授权目录」添加实际拉起支付页面所在目录。当前 H5 在 `/h5/` 下时，预发布填写 `https://pre-api.rebugx.cn/h5/`；正式上线再增加 `https://api.rebugx.cn/h5/`。如果最终支付页面迁到其他目录，应以真实页面目录为准，且目录必须以 `/` 结尾。
7. 将上述凭据填写到新系统后台「系统 → 第三方配置 → 支付 → 微信支付」。回调地址使用本文第一节的推荐值。
8. 完成 0.01 元闭环：支付成功、订单入账、退款、退款回调、账单核对。

## 四、汇付斗拱（必须由汇付商户管理员操作）

1. 登录汇付开发者站点/合作伙伴控台，确认主体认证、合作协议、结算账户和管理员实名认证均已完成。
2. 向汇付商务确认本项目正式开通的产品线及正式参数，至少覆盖实际需要的聚合支付、退款、延迟分账/订单分账、下级商户进件和对账；未使用的代付能力不要默认开通。
3. 打开「开发设置 → 开发者信息」，取得正式环境的收款 `huifu_id`、下级商户进件使用的 `upper_huifu_id`、`sys_id`、`product_id`、商户 RSA 私钥、汇付平台 RSA 公钥。必须让汇付商务明确收款号和上级渠道号是否相同，不能自行推定；联调/沙箱密钥不得用于生产。
4. 如果汇付启用了服务器 IP 白名单，加入新环境实际出口 IP；当前两台 CVM 公网地址为 `62.234.115.193`、`49.232.184.7`。如后续增加 NAT 网关，应改为 NAT 的固定出口 IP。
5. 在合作伙伴控台「商户 → 商户信息 → 查看 → 一体化收款产品 → 基础支付 → 微信支付 → 详情 → 微信配置」中配置实际使用的 AppID：
   - 热卜星火小程序：`wx06397e8ab26bed9e`；
   - `T_MINIAPP` 必须绑定小程序 AppID；
   - `T_JSAPI` 必须填写真实支付页面的授权目录，当前 H5 位于 `/h5/` 时使用 `https://pre-api.rebugx.cn/h5/`；
   - 不重置现有小程序 AppSecret；若汇付控台确实要求 AppSecret，只使用当前有效值并由管理员直接在汇付控台填写。
6. 异步通知地址使用：`https://pre-api.rebugx.cn/api/v1/huifu/notify`。同步下单成功不等于支付成功，最终必须以验签后的异步通知或主动查单结果为准。
7. 在新系统后台「系统 → 第三方配置 → 支付 → 汇付天下」填写收款 `huifu_id`、进件 `upper_huifu_id`、`sys_id`、`product_id`、商户私钥、汇付平台公钥；暂不开展下级商户进件时 `upper_huifu_id` 可留空；旧版对称密钥保持为空；回调地址使用页面推荐值。
8. 点击「保存并生效」，随后点击「测试连通」。必须返回正式商户名称且 `ok=true`；如果只返回网络可达或联调商户名称，不算通过。
9. 上线前依次完成 0.01 元支付、支付通知、主动查单、全额退款、退款通知、延迟分账、分账查询和账单核对。任何一步都不得仅凭同步返回判定资金成功。
10. 小程序商品交易还需完成微信订单发货管理接入，否则可能触发资金冻结；以汇付控台对应 AppID 的风险提示和微信平台要求为准。

## 五、Grafana 与企业微信

1. Grafana 管理员默认用户名为 `admin`，`GF_ADMIN_PASSWORD` 是监控后台强密码，不是业务后台账号。
2. 密码应由密码管理器生成并保存，不提交到 Git。
3. 企业微信上线前创建自建应用，并提供 `CorpID`、`AgentID`、应用 Secret、告警接收人的企业微信 UserID。
4. 填入后启用 `MONITORING_ENABLED=true`，做一次故障告警和恢复告警演练。

1. 两台 API 实例滚动重启，确认健康检查均为 `ready`。
2. 管理后台逐个执行微信支付/汇付连通性检查。

4. 核对支付回调验签、订单入账幂等、退款回调、财务对账。
5. 确认旧域名不再出现在客户端构建产物和第三方后台配置中。
