# 圈子知识宇宙 3D 选型与隔离样例（2026-09-23）

## 结论与边界

上一版平面关系图不是最终效果。本轮选择 `3d-force-graph@1.80.0` 制作独立 H5 体验样例：真实 WebGL 三维力导向布局、动态关系粒子、光晕、缓慢环绕、拖拽缩放、点选具体知识点的卡片。样例入口：`prototypes/knowledge-universe-3d/index.html`，本地用静态服务访问。数据是 24 个演示概念和人工演示连线，不对应真实圈子、课程或知识库事实；没有部署、没有改动现有加入页。

这不是可上线成品。当前点击节点虽可正常显示详情卡，但浏览器控制台出现 `3d-force-graph@1.80.0` 的 `Cannot read properties of undefined (reading 'x')`，尚未定位；镜头聚焦因此暂不启用。光晕模块还会提示多实例 Three.js，正式工程应统一 Three.js 版本并打包，不能沿用演示的双 CDN 引入方式。

## 选型（只比较三项）

| 方案 | 适配情况 | 判断 |
| --- | --- | --- |
| [3d-force-graph](https://github.com/vasturiano/3d-force-graph) | 原生 JS、Three.js/WebGL，H5 可独立使用；官方有粒子、镜头、bloom 样例 | 本轮视觉样例采用；现存点击异常须解决 |
| [three-forcegraph](https://github.com/vasturiano/three-forcegraph) | 更底层的 Three.js 对象，需自行搭建相机、控制器、渲染及后处理 | 灵活但实现和维护成本较高，作为点击异常的备选 |
| [ECharts GL](https://github.com/ecomfe/echarts-gl) | 图表生态较成熟，但三维知识宇宙的定制表现与官方示例不如上述方案直接 | 不用于本轮样例 |

选型依据是当前 Vue/uni-app H5 技术栈、官方效果能力和集成成本，不把 GitHub 星数等同于性能或稳定性。`3d-force-graph` 与 Three.js 代码均为 MIT 许可，正式打包须保留许可声明；MIT **不授权任何课程、插画、字体或知识素材**。样例只用了系统字体、CSS 效果与手写演示文字，没有第三方商业视觉素材。正式数据要单独核对内容公开许可及来源。

## 接入建议

1. 先修复点击异常，统一 Three.js 依赖并测 FPS、内存、首屏和切后台销毁；大型知识库不能把全部节点一次绘出，需限量精选、按关系展开与聚合。
2. 数据层以**具体知识点**为节点，边记录关系类型、证据来源和审核状态。圈外加入页只读取标记为公开展示且取得授权的摘要，绝不直接暴露会员课程全文、私密问答或未审核推断。
3. 加入页只给一段自动演示和轻量点选，真正检索仍走文本/列表入口；动效减少、WebGL 不支持、低端设备、nvue 和小程序走可访问的静态卡片降级。
4. H5 性能和真实内容接口完成后，再由主线决定是否集成。当前不建议直接接入正式加入页，更不代表发布验收通过。

## 撤回

本轮只有独立 `prototypes/knowledge-universe-3d/` 文件和本说明。主线不引用它即无线上影响；删除这两个新增文件即可撤回视觉样例，不涉及数据库或服务端协议。
