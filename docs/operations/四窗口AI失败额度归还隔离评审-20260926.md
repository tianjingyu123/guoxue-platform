# AI 对话失败额度归还隔离评审（2026-09-26）

## 已实现

- 非流式模型报错或空回答时，按本请求刚消耗的试用/已购类型归还一次；推荐检索或审计异常发生在已取得回答之后，不归还已交付内容的额度。
- 流式首字前上游报错、空完成、客户端主动断开时归还一次；已有回复文字后中断不归还，以免用户获取部分内容后反复断线规避计费。
- SSE 连接断开取消上游订阅。额度归还异常记录服务端错误，不覆盖原始模型异常；免费智能体和会员无额度写入。
