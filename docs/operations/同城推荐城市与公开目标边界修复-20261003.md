源码提交：`c358a147b6d8902ec087be0f3e0fab648ce926a3`。本批是 F3 后台缺陷修复，不代表完整同城频道已经开放；没有改前端、没有部署、没有精确位置采集、没有资金操作或迁移。

## 问题与结果

此前实际 Prisma 查询使用不存在的 `StationOffline.cityCode`，已在本机专用合成 PostgreSQL 复现校验异常。公开控制器没有传入城市；无驿站或无关联内容时会兜底全国推荐，标题含城市名也被当作同城动态。线下课程及驿站商品的关联行 ID 被当成平台详情 ID，可能跳到不存在或不相符的内容。

现在公开参数 `city` 是现有驿站的城市名称，修剪前后空白，限制 1～64 字及合法字符；不猜测行政编码映射。查询精确匹配 ACTIVE 驿站。缺少城市、旧编码或无有效资源时返回真实空态，不兜底全国内容、不通过标题关键词认定地点。

线下课程要求 PUBLISHED、审核 APPROVED、未结束且所属驿站仍 ACTIVE；关联的平台课程还要审核通过、PLATFORM 可见且未删除。驿站商品及关联平台商品分别检查有效状态、库存、软删除。返回平台实际 Course/Product ID、标题和当前价格，保持现有详情路由契约，不将驿站关联价格冒作平台商品价格。

同城公开控制器不信客户端 `x-station-id` 或 Query stationId 切换资源范围，只聚合平台公开内容。内部已有分站上下文的召回类型保留，公开入口没有因此开放私有分站。缓存加入城市与分站维度，版本 v3 不复用旧全国兜底；同城场景不混入冷启动全国内容、运营强插或站长精选。其他推荐场景保持原流程与 v2 缓存。
