# 自动圈主冲正收益边界补齐

本批接续 `f6c7b4258836e85b14d14ed3cfd7ac82ec4c2d54`，仅修正自动退款的收益金额判定，不改退款审批规则、不放开历史推断、不执行真实冲正。

## 已复现与修正

旧源码在订单、圈子、成员和收益总额均匹配时直接接受 `ownerShare`。合成收益100、分成600、部分退款40的案例会记分成冲正240，超过正常分成边界。另有合法零圈主分成会触发零金额保护，导致用户退款事务失败。

精确匹配现要求收益与退款实付均为有限正数、收益金额匹配、圈主分成为有限非负数且不超过收益。异常分成记 `revenue_share_invalid`，只留金额为零的待核对台账，用户退款和成员失效继续完成。合法零分成不阻断退款，收益仍按实际退款比例冲正。历史 `single` / `amount` 推断开关仍关闭。
