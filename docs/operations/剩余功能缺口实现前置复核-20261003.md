# 剩余功能缺口实现前置复核（2026-10-03）

核对源码 `1e1ff0b8c`。本记录是后续实施的具体依据，**不代表这些功能已实现或批准延期**。七类上线门槛、其他窗口已接候选、真实渠道和正式迁移清单继续保留；不能只把下面五组当全部剩余工作。

## 先后顺序与验收边界

1. 先收口微信绑定与解绑的当前完整 CI，保持独立源码提交、测试来源和 staging 接收点。实际微信授权和 QQ/Apple 新绑定继续独立推进，不用登录接口替代绑定。
2. 八字四柱输入先完成同源反查接口、候选选择和页面/报告事实校验，再接 UI。没有政策决策依赖，可以独立实施。
3. 首页同城先修正地域契约与真实内容查询，再接城市手选、空态、详情跳转。先使用城市级信息，不静默申请精确位置。
4. 普通邀请先做本人可审计来源/记录与分享，不自行承诺奖励。已有站长归属和佣金规则独立保留。
5. 赛事先补详情事实、报名/资格/有效状态/返程闭包，直播 PK 与现场核销各设受控测试入口；邀请资金奖励待已有真实规则对应后处理。新资金政策待决策，不阻止其他技术工作。

## F1：四柱直接录入

已核：`components/bazi/date-picker-modal.vue` 的四柱确认仍只提示开发中；其“1801~2099”文字不是已实现范围。`Solar.fromBaZi` 在 server vendor 中确有实现，但上限实际是运行时当前年，不能直接据此承诺 2099 年，更不能把候选代表时刻当真实出生分钟。

实际预览与保存均由 `paipan.service.ts` 调用 `@guoxue/bazi-engine` 的 `calcBazi`。结果页经 `lib/bazi-result-data.ts` 正确把 earlyZi 转成 ziShiMode，已经透传真太阳时、夏令时与出生地；这部分不是缺失，不重复改造。另一个工具注册引擎不是这个入口的唯一真源，不能混用其结果证明页面一致。

实施要求：

- 只接受六十甲子中的有效干支组合，明确查询年限与子时口径；年干/月干和日干/时干组合必须可由既有引擎复核。
- 多日期返回可解释候选，用户选择后再确认时间；取消、无匹配、断网、旧请求覆盖新输入均不得退回默认日期出盘。
- 反查产生的候选以最终预览/保存引擎逐一验证，节气边界前后一分钟、23/0 时、跨年、60 年重复必须有实测证据。
- 真太阳时、夏令时或时间修改可能改变四柱，必须重新验证；选项变化不能继续显示旧查询“已匹配”。
- 反查来源、所选四柱、时间精度和用户确认要进入报告事实，不能凭四柱还原不存在的精确生辰；AI 解读只消费后端同一事实，不编造生日。
- 保留正常公历/农历入口；不扩主包引入前端反查算法。最终页面测试、四移动目标和小程序体积重新对应最终源码。

## F3：首页同城

已核：首页 local 分支 toast 后返回，没有拉取同城。虽有 `RecommendScene.SAME_CITY`，控制器/DTO 未接 cityCode；`sceneSameCity` 中使用的 StationOffline.cityCode **不在实际 schema 中**。在专用合成库的只读调用已证实该条件会被 Prisma 参数校验拒绝，记录 `same-city-schema-probe.json`。这不是已经发生在线上的 500，当前首页入口仍未接通。

此外，该场景没有城市条件时会查全国驿站，驿站为空时退回普通推荐；标题含城市名的文章不等于归属该城市。不能把此方法直接接入首页并标成“同城已完成”。

实施要求：统一城市数据契约后，仅查真实 ACTIVE 驿站关联且公开/通过审核的课程、商品及活动；无同城内容显示真实空态，另设清楚标注的全国推荐入口。详情必须使用真实线上/线下内容 ID 对应正确路由，结束/下架/私有内容不能因推荐缓存绕过校验。手选城市与当前城市可见，切换清缓存和分页，取消定位保留可操作的手选，不让旧城市响应覆盖新城市。

## F4/F5：赛事与邀请

已核：普通邀请页/历史页目前是预告或不可用操作。`AuthService.bindReferral` 解析 ACTIVE Station 的 code/userId，创建 STATION_MASTER 来源；不能据此说普通用户邀请关系已落库。按人数乘 7 的界面表达也不是会员赠送流水，已有推荐关系不代表奖励发放。

实施先补可追溯普通邀请来源、本人只读聚合和真实分享路径，拒绝跨用户读取，展示掩码及必要状态；不自动改写既有站长关系或合并新旧平台佣金。不自行增加“每人七天”、重复奖励或新资金写接口。

赛事四个预告页与既有赛事列表/报名/排名/考试入口分别接收。详情状态、本人资格、报名截止、未登录回原页、取消/失败/成功返程先验证；线下核销需实名义之外的可验证凭证、防重、权限和审计，直播 PK 需真正受控会话和断流/结束释放，不用模拟 UI 冒充链路完成。

本次前置核对已完成，**F1/F3/F4/F5 实现及最终验收仍未完成**；没有删除范围，没有据预告文案认定已上线。
