## 独立客户账号

`lease/auth/register`、`login`、`refresh` 在固定客户实例内运行，要求已登记、启用的 `x-app-client`。注册不要求手机号，不创建平台账号或 UserRole，只授普通用户；账号大小写归一，同名账号在不同客户库相互独立。密码至少12个Unicode字符、不超过72个UTF-8字节，拒绝控制字符，bcrypt成本12。账号和凭据只在客户业务库中保存。

访问令牌绑定客户、空间、应用、选择器、合同修订、身份来源、本地凭据修订及维护成员修订，有效15分钟。30天刷新凭据仅存SHA-256摘要，按应用和选择器绑定，数据库事务单次消费并轮换。改密及退出原子推进本地凭据修订、撤销刷新凭据、保存审计；其他进程已持有的令牌立即失效。

维护成员授权显式选择 `LOCAL` 或 `PLATFORM`，既有来源不能改换。LOCAL须先通过数据库身份与权限核验，再只读核对这个客户的实际账号；管理员和客服由维护超管明确授予。未授权普通注册无需建立维护成员表行。平台改密/封号仅撤销PLATFORM成员，不接管或撤销碰巧同标识的LOCAL账号。平台来源会话还检查客户库与平台账号的软删除状态。

登录限流用PostgreSQL持久计数和原连接socket地址，跨进程有效，不信任客户端转发IP。10分钟窗口：注册每连接5次、登录每连接30次且每账号10次、刷新每连接60次、改密每连接30次且每账号10次。生产反向代理的可信源IP配置、账号恢复和实际运营支持流程仍须验收；当前限流配置不是容量承诺。

## 客户课程学习

独立入口仅提供已审核、合同白名单课程的章节目录、内容、本人进度读取和写入。免费课程、课程本地作者及本人的有效已付COURSE订单允许学习；试看仅授该章节内容。已付状态和有效期读取本客户库，不继承平台会员身份，没有客户端指定已付状态或建支付单的路由。

进度只能写本人、当前课程实际章节，拒绝未知身份/完成字段和越界值。数据库唯一键下的原子更新取较高进度，两个进程的乱序重放不会回退完成状态。退款、到期、下架后内容和进度写入被拒绝，已有进度保留。验收中的已付和退款状态由合成数据准备账号设置，**没有真实付款或退款**；真实视频授权、购买、会员权益、证书、作业及退款并发仍未交付。

## 分页退出

保留原同步导出；超过每类5000条时明确拒绝。新增 `POST lease/exports/paged`，请求体必须为空，不收SQL、路径、表名或字段清单。服务端用RepeatableRead建立固定快照，游标每页500条，分成用户、商品、课程、章节、进度、圈子、订单、本圈知识和售后九类。手机号脱敏，不含认证表、刷新摘要、平台角色或global知识。

快照页不可由运行账号更新或删除，下载必须是原申请人，持有额外短期凭据，并通过实时令牌、成员、应用和导出期限检查。每页有按键递归排序的UTF-8 JSON SHA-256；manifest记录行数、页数、摘要和遗漏项。源库在建立后新增、修改不会改变已保存快照。体积或权限超限时整组回滚，不遗留半份导出，不静默截断。

本轮固定上限为总10万行、单页2MiB、总128MiB、建立事务60秒；超过上限须安排维护迁出。它是受控分页快照，**不是异步队列导出、全部媒体搬迁或正式迁出SLA**。媒体二进制、真实供应商会话和向量索引尚未包含。
