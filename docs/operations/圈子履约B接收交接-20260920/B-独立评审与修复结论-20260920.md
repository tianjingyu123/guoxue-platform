## 2. B 修复后的资金边界

`no_change` 与 `adjust` 是两种独立结论：

- `no_change`：只写结案人、结案时间和核对依据，不写收益冲正行，不改退款金额。
- `adjust`：仅允许对有真实原订单的待办操作；订单必须属于退款成员和圈子，类型必须为入圈或续费；指定收益行必须同时匹配订单、圈子、成员、类型并为正金额；收益主体必须是该圈圈主。

写入在同一数据库事务中完成，并锁定待办行和收益行。同一待办重复提交、并发提交以及同一订单累计重复冲正都会被拒绝。事务后段失败时，已尝试的收益冲正和退款回填会全部回滚。

历史无订单、订单归属不一致或缺少成员来源的待办不允许在线冲正，只能走线下财务流程。
