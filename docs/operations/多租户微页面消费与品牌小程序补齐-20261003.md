# 微页面消费与品牌小程序补齐

用户继续推进后，对照原工作计划发现上一批完成范围遗漏了独立入口的已发布微页面消费及品牌小程序构建。此前“本地独立事项全部完成”仅能描述已冻结经营批次，不能覆盖这两个原计划项目。本批修正范围，不覆盖或改写旧证据。

独立入口复用共享 `ClientPresentation` 解析和公共草稿、预览、版本、发布、回退、能力登记引擎。新增H5 `web` 与微信 `weixin` 目录；目录项不代表真实渠道授权。能力仍须对已启用应用/平台/渠道、源码、完整资源摘要和明确版本范围登记，合成登记仅test环境允许。独立能力档案为 `managed-presentation-v1`，随包仅提供公告、纯文字和入口组件；未交付图片模块不下发，不声称已消费通用导航、推荐流或任意HTML。

客户端每次登录及刷新记录时读取本应用已发布配置，按当前模块、模板和入口可见性收窄组件及目录顺序。入口只映射包内商品、课程、圈子和智能体，不接任意URL。无配置、旧包、能力未登记、版本不匹配或解析失败时保留默认界面；401仍撤销当前会话。配置失败不复用陈旧布局。订单、已有学习记录、会话、经营及数据退出固定入口保留，装修不新增或撤销服务端业务权益。服务端再逐次核合同、应用、成员和运营状态；隐藏入口也从组件中移除，不在宫格重新出现。

`managed-brand-client-build.mjs h5|mp-weixin` 复制当前任务源码到隔离输入副本，只在副本替换合成UniAppID和游客微信AppID。原平台manifest不改；完整原外壳只编译，没有运行SDK。微信构建必须在产物中核游客AppID、分包品牌路径及JS/WXML/JSON，防止空壳构建被当成入口验收。记录移动端全src、共享包全src、构建脚本、依赖锁及输出摘要，构建前后源码不变才产出记录。正式登记、跨主体登录/支付、通知、审核和真机仍未验收。

本地验证与归档正在进行，当前新增首轮真实PG/Nest接口6组通过，服务端候选编译、共享包编译和两个移动入口专项类型检查通过。品牌微信候选已实际编译出入口，后续按冻结源码重新构建并记录正式结果；该合成构建不是渠道发布。新证据单独归档，不用此前24套清单覆盖新增实现。

执行仍限定本地候选。未合主线、推远端、云部署、生产迁移、切DNS、真实商户收费或正式渠道登记。原一期仍有真实客户映射、交易链路、基础设施、真机和两北京节点验收待关闭，不能据本批补齐宣称一期商业交付完成。
