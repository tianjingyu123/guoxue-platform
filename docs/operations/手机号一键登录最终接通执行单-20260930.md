本单用于后续获准的发布窗口；本轮不部署函数、不配置生产密钥、不调用计费取号、不启用客户端入口。购入取号资源包、服务空间正常及资源导出成功，均不代表一键登录已接通。

## 按顺序执行

1. 由唯一云端写入任务确认候选、目标两节点、可回退镜像和维护备份。两节点必须运行包含 `auth/internal/univerify` 的同版后端，连接同一可用 Redis；不能用旧健康接口或仅 PING 成功代替此项。当前只读证据显示两节点共享签名键都缺失。
2. 在受限环境生成同一份至少 32 字符的随机共享密钥，配置到两节点服务端和指定云函数；不在聊天、源码、客户端、命令行参数或日志中输出值。函数公开配置为 `REBU_DCLOUD_APPID=__UNI__277B108`、`REBU_API_URL=https://api.rebugx.cn`，私密配置为 `REBU_UNIVERIFY_SHARED_SECRET`。不得复用账号密码或其它业务密钥。
3. 上传上述同版函数，配置环境变量及扩展；读回函数名称、空间、版本和配置键的存在性，以布尔值核配置匹配，不归档原始配置值。共享密钥匹配应在受限进程中核验，只输出匹配结论。确认没有公开 URL 触发器、手机号或运营商凭据日志。
4. 在隔离验证进程和受控测试命名空间先做合成签名、nonce 重放、时窗、错签名与共享 Redis 失联验证，确保失败不创建会话、不改余额；禁止将合成手机号送入生产登录写入口。现有隔离测试可复用，但两节点实际 ACL、同一 Redis 身份和跨节点防重放仍须由唯一云端任务实测；本人真实登录仅在下一步的受控账号验收中执行。
5. 取得同源码、同证书且绑定上述空间的正式原生测试包，在受控账号和蜂窝网络验证本人授权、存量复用、新账号、取消、双卡、弱网及登录后回原受阻页。只在必要的成功测试消耗取号次数，记录实际扣次和耗时，不购买套餐。腾讯云入门版 3 秒上限仍须实测；本函数后端交换最多 1.8 秒，剩余时间不足会回验证码，不能仅凭模拟判断套餐足够。
6. 完成接线及受控验收后，才以 `VITE_UNIVERIFY_ENABLED=true` 构建最终默认手机号入口，重新冻结公开配置和包摘要，再验拒绝授权/无蜂窝/服务异常时验证码入口、协议主动勾选、回原页。验证版不能冒充最终启用版。iOS 与鸿蒙 SDK、签名和真机能力分别验收。

## 停止和撤回

任何空间/应用身份不符、共享密钥不匹配、Redis 不可用、函数超时或取号无法核验时，停止启用入口，保留验证码登录。撤回客户端先回已验证的关闭开关版本；再由唯一云端写入任务停用指定函数/共享签名接线并核读回，保留审计记录，不撤销用户既有权益。不得拿旧 APK 换资源冒充新原生包，也不得在未接通服务时发布默认的一键登录按钮。
