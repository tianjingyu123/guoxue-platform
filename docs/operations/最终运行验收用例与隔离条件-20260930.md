## 报告、对话与续费用例

当前支持范围为八字、紫微、六爻、梅花、奇门、大六壬、金口诀、玄空、八宅、阴盘奇门、小六壬、阳盘。旧 `排盘结果页报告入口静态矩阵-20260926.csv` 保留作历史，不能代替本次最终矩阵。合盘、七政等工作台入口不计作消费者 AI 报告已经实现。

每个盘式依次核：合成输入 → 展示盘 → 本人记录保存 → 服务端报告图形/关键事实一致 → 现有权益查询 → 无权益的真实购买入口 → 有权益生成 → 重试/重复请求不重复扣权益 → 正文/出处 → 报告解读对话 → 返回原盘与历史记录。紫微重点核十二宫/四化与同源引擎；阴盘重点核数理定局、手选局、真太阳时、九宫和报告一致；小六壬保留同页结果。

共同异常用例：未登录回原页面、他人记录拒绝、结果尚未保存不进入无效报告、模型不可用不返回伪造报告、生成中退出后可恢复、错误消息可重试、历史报告可继续阅读。真实模型调用可能计费，执行前明确测试次数及预算；静态入口可见不等于模型完成。

AI 场景覆盖排盘报告、圈主助理、智能体广场、古籍伴读及工作台：文字与语音入口易找；开始语音经主动操作并说明麦克风；中断/后台恢复/结束释放；上下文与跨用户权限；推荐卡片相关且可回原对话；额度不足可找到续费入口，付款最终确认后回到当前服务；不得自行改价格、额度或新增扣减。

## 三端支付与导航用例

电脑 H5 点付款直接呈二维码；微信内直接调起已有 JSAPI 支付；App 默认支付宝，选择微信后进入匹配版支付专用小程序的具体付款页，不能停在小程序首页。支付渠道自己的验证步骤不被承诺可取消；不在热卜增加二次确认或再次选渠道。

核取消、失败、网络中断、重复点击、重复回调、后台恢复、结果未确定时查询，不能以客户端“成功”替代后端最终状态。圈子最终付款成功且权益到账后直达圈子；商城订单结果页能直接回商城，返回栈不反复进入收银台/订单；课程、报告及会员回对应权益。退款后核权限、圈主收益、余额与通知审计。执行真实交易前集中明确测试订单、金额、退款和清理安排，禁止借用真实用户订单。

小程序首发排盘仍显示升级提示；允许独立验证未来打开能力，不把测试入口放入正式用户版本。旧排盘分享以当前可用的回退策略为准，完整 iframe 嵌入不能因为用户已登录而直接判定成功。H5 备案已由用户确认通过，待留官方与同版链路证据，不再列为“等待备案审核”。
