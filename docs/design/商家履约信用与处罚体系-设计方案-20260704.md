## 一、体系总览

```
每日指标聚合(MerchantMetric) ──▶ 信用评分模型(0-100) ──▶ 信用等级(A/B/C/D)
      ▲                                                    │
  订单/物流/退款/评价/投诉/抽检                                ├─▶ 权益：流量位/严选标/结算周期/保证金系数
      │                                                    └─▶ 处罚：五级递进(自动触发+人工确认)
  异常实时预警(阈值+AI) ──▶ 工作台告警 + admin 风控台            │
                                                     申诉通道(时效+举证+复核)
```

## 二、履约监控（每日聚合 + 实时预警）

### 2.1 指标聚合表 MerchantMetric（日粒度·cron）
merchantId/date/ordersCount/shipOnTimeRate(48h内发货率)/avgShipHours/refundRate/returnRate/avgRating/complaintCount/qcPassRate(抽检)

### 2.2 实时预警（阈值·先规则后 AI）
| 预警 | 默认阈值（可配） | 动作 |
|---|---|---|
| 发货超时 | 付款后 48h 未发货 | 提醒商家；72h 升级 admin 预警；96h 自动向买家致歉券 |
| 退款率异常 | 7 日退款率 >15% 或环比翻倍 | admin 风控台工单 |
| 差评聚集 | 24h 内 ≥3 条 ≤2 星 | 工单+商品临时降权 |
| 投诉 | 单条即工单 | 平台介入流程（已有基础·补 SLA：24h 首响） |

### 2.3 品质抽查
- admin「抽检任务」：按类目/信用等级抽样（低信用高频抽）→ 记录 QcRecord(merchantId/productId/result/photos/notes) → 不合格：商品下架+计入信用+触发处罚流
- 自营供应商同标准（对内更严·树标杆）

## 三、信用评级（分数→等级→权益/处罚 全自动挂钩）

**信用分（0-100·周更）** = 发货时效 25 + 退款退货 20 + 评价均分 20 + 投诉率 15 + 抽检 10 + 经营时长/稳定 10
（新商家 60 分起评·观察期 30 天不参与流量加权）

| 等级 | 分数 | 权益 | 约束 |
|---|---|---|---|
| A 严选 | ≥85 | **严选标**·流量加权·结算 T+7→T+3·保证金系数 0.8 | 抽检季度 1 次 |
| B 良好 | 70-84 | 正常流量·标准结算 | 抽检双月 1 次 |
| C 观察 | 55-69 | 流量降权·新品限量上架 | 月检·限期整改 |
| D 高危 | <55 | 商品全线降权·暂停上新·结算延长 | 触发清退评估 |

信用变动全部写 MerchantCreditLog（旧分/新分/因子明细）——商家后台可见明细，**透明是公平的前提**。

## 四、处罚体系（五级递进·自动触发+人工确认）

| 级 | 处罚 | 触发示例 | 执行 |
|---|---|---|---|
| 1 警告 | 站内警告信+限期整改 | 首次超时聚集/单次抽检不合格 | 自动 |
| 2 扣保证金 | 按违规单赔付/定额扣罚 | 假货嫌疑/严重超时致投诉 | 自动生成→**FundApproval 人工确认**（资金动作必人审） |
| 3 商品下架 | 涉事商品/类目下架 | 抽检不合格/违禁表述(R4词库) | 自动下架+通知 |
| 4 暂停经营 | 店铺冻结 7-30 天 | 30 天内 2 次三级/信用连续 D | admin 确认 |
| 5 永久清退 | 清退+保证金按协议处置+黑名单(身份证/执照指纹) | 售假实锤/刷单实锤/暂停期再犯 | admin 双人确认+审计 |

## 五、申诉通道

- 处罚通知附「申诉」入口：72h 内提交举证（文字+图片）→ admin 复核队列（48h SLA）→ 维持/减轻/撤销（撤销自动回滚信用与资金·审计留痕）
- 申诉结果计入 MerchantAppeal；滥用申诉（月 ≥3 次驳回）冷却 30 天

## 六、AI 化建议（后置增强·不阻塞主体）

资质审核 OCR 预校验 → 商品审核违禁词+图片审核（三层漏斗已有·接商品域）→ 刷单模式识别（同收货人聚集/时段异常）→ 信用趋势预测预警

## 七、待拍板项

## 八、普通模型任务包（3 批）

| 批 | 内容 | 验收 |
|---|---|---|
| P1 指标+预警 | MerchantMetric 表+日聚合 cron(runExclusive)+四类阈值预警(工单进 admin 风控台/复用 risk 模块)+商家后台指标卡 | 造数验证聚合正确·超时预警触发 |
| P2 信用评级 | 信用分周更 cron+CreditLog+等级权益挂钩(流量加权接推荐排序·结算周期接引擎·严选标进商品卡)+商家后台信用明细页 | 分数可复算·A级严选标端到端展示 |
| P3 处罚申诉 | 五级处罚状态机(2级接FundApproval/3级自动下架)+MerchantPenalty/MerchantAppeal 表+admin 处罚台+申诉复核队列+商家端申诉页 | 全级别流转+撤销回滚+审计完整 |

依赖：P1→P2→P3 串行；与供应链 P1-P3 无文件冲突可并行推进。
