# 分站运营商板块 · V0 设计委托书（重构优化·修正版 v2）

> 2026-07-12 · 热卜国学平台（面向易学/国学爱好者的知识付费平台）· 委托 V0 出移动端 H5 视觉与交互设计稿，我方负责 1:1 还原为生产代码。
> 本委托书**自包含**。**v2 为修正版**：上一版把站长做成了"能装修自己的分站页面"，方向错误，本版彻底纠正——**站长不装修、无独立分站页面、无独立账号，只在「主推位」里选品**。
> 流程：**阶段一先交信息架构线框稿 → 确认结构 → 阶段二视觉稿**。

## 〇、三个「没有」（先读·上一版最大误解）

1. **没有分站装修**：站长动不了任何风格、布局、配色、主题色、模板。平台长什么样，站长的用户看到的就是什么样。
2. **没有独立分站页面**：不存在"某某分站"的落地页/首页，也没有"站长编辑自己页面布局"的功能。站长选的主推内容**分散注入到平台各板块的主推位**，不集中在一个分站页里。
3. **没有独立账号体系**：运营商/站长**不单独登录、不单独设密码、没有独立后台**，身份与注册信息完全沿用总平台统一用户体系。

**站长做的唯一事**：在各板块的主推位里，从平台内容库挑内容锁定展示。仅此而已。

## 一、背景与定位

平台前身是排盘工具（570 万注册用户），核心战略是把**存量用户向 B 端身份转化**——运营商/站长是这个分销生态的骨架。**分站运营商板块 = 平台商业化的分销与生态底盘**。

现状是多轮原型迭代的补丁产物（28 个页面、角色混淆、工作台重合、空壳死页）。**本次推翻重做前端**，狠做减法，并落地核心功能：**站长「主推位」选品自服务**（第二节·本委托灵魂）。

### 三个角色（必须区分清楚）
| 角色 | 定位 | 一句话 |
|---|---|---|
| **一级运营商** | 对外销售的团队管理者 | 4999 元购入，得 1+5 个分站，带站长团队，拿团队管理奖 10% |
| **二级运营商** | 不对外销售 | 随**线下驿站赠送**开通，不走 4999 对外销售通道 |
| **站长 StationMaster** | 分站推广者 | 开一个分站、在主推位里选品、推广拉客、拿分销佣金 |

> 用户（访客）扫站长的推广码 → 与站长建立**归属关系** → 该用户在平台各板块看到的**主推位内容 = 该站长锁定的内容**；其消费为站长带来佣金。**归属关系是纽带，不是一个独立分站页面。**

## 二、核心命题：站长「主推位」选品自服务（本委托灵魂）

### 2.1 是什么
平台每个内容板块**保留 6 个「主推位」**，由站长从平台内容库里挑内容锁定。归属于该站长的用户浏览平台该板块时，这 6 个主推位优先显示站长锁定的内容，其余位置照常走平台千人千面推荐。

- **6 个主推位不参与千人千面**，是站长锁定的固定展示。
- 主推内容**分散注入平台各板块**，**没有一个集中的分站页面**。
- **发现页自动同步**：站长把各板块主推位配好后，发现页作为聚合出口自动汇总展示，**不需要单独配置发现页**。

### 2.2 站长的操作界面（重点重做）
站长进入一个**「主推位管理面板」**（在个人中心 → 站长工作台内），面板是一个**竖列排序的板块列表**，从上到下依次：

**首页 → 商城 → 课堂 → 圈子 → 智能体 → 古籍 → 文章 → 短视频 → 直播**（共 9 个板块）

- 每个板块名称后挂 **6 个「＋」加号主推位**。
- 点任意「＋」→ 拉起**平台选品库半屏面板**（搜索 + 分类）→ 选一个内容 → 锁定到该位（加号变内容缩略卡）。
- 每板块 0-6 个自由锁定，可替换、可移除、可调顺序。保存即生效。

> ⚠️ 不是"在某个分站页面上进入编辑模式"，而是一个**统一的选品管理面板**。不要画分站页面、不要画编辑态/浏览态切换。

### 2.3 选品分类口径（上一版搞错的地方）
| 板块「＋」 | 可选范围 | 选品弹窗的分类 Tab |
|---|---|---|
| **首页** | **所有类别**内容 | **按板块分**：课堂 / 商城 / 圈子 / 智能体 / 古籍 / 文章 / 短视频 / 直播。**绝不是**按"八字/六爻/奇门"这种排盘工具分类！ |
| 商城 | 只能选商品 | 商品分类 |
| 课堂 | 只能选课程 | 课程分类 |
| 圈子 | 只能选圈子 | 圈子分类 |
| 智能体 | 只能选智能体 | 智能体分类 |
| 古籍 | 只能选古籍 | 古籍分类 |
| 文章 | 只能选文章 | 文章分类 |
| 短视频 | 只能选短视频 | 短视频分类 |
| **直播** | 只能选**已有的**直播（正在直播/预约直播） | 直播结束自动取消该位（渲染校验状态，过期自动剔除） |

**所有选品弹窗都支持搜索选品**（搜标题定位内容）。

### 2.4 要 V0 出的主推位界面
1. **主推位管理面板**：竖列 9 板块，每板块一行标题 + 6 个「＋」/已锁内容卡（带移除、替换、拖动排序）。已锁数量角标（如 课堂 3/6）。
2. **选品库半屏面板**：顶部搜索框 + 分类 Tab + 内容列表（可选中）+ 底部「确认锁定（已选 N）」。**首页面板**的分类 Tab 按板块分、可选任意类型；**直播面板**只列正在直播/预约直播（带状态标 + 开播时间，注明"结束自动下架"）。

## 四、开通规则与费用（C1/C2 文案按此写·重点·关系后期分佣）

### 运营商（两级）
- **一级运营商（对外销售·唯一对外档位）**：**4999 元**，获得 **1+5 个分站**——1 个自用，5 个可对外销售。**团队管理奖 = 名下站长收入的 10%**。
- **二级运营商（不对外销售）**：随**线下驿站赠送**开通，不走 4999 通道。C1 页只对外呈现一级档；二级为内部/线下赠送开通，不做对外销售卖点。

### 分站（站长）
- **加入无门槛**（谁都能开）。
- **系统租赁费：999 元 / 年**。
- 减免/退还规则（原样呈现，勿改动措辞）：
  - 若分站收入累计**小于 5 倍**系统租赁费，则**不用再交**租赁费；
  - 若分站收入**一年内累计达到 10 倍**平台系统租赁费，则**退还**租赁费，**仅限第一年有效**。

### C1/C2 页文案纪律（重要）
- **删除**所有承诺式/收益诱导宣传：不写"已有 XX 家分站加入""XX 人已赚 XX 元""月入过万""躺赚"等。
- **改为风险与资源提示**，例如：
  - 「请先评估你是否具备**推广渠道与资源**；**若无推广能力，请勿加入**。」
  - 「这是投资行为，**存在亏损风险**，请理性决策。」

## 五、数据能力边界（画的每个元素要能对上后端）

- **运营商**：团队概览（团队数/收益/成员）、成员列表、业绩排行、沉寂列表+提醒、名额管理（自用/可售/已赠）、邀请链接、业绩分析（CTR/CVR 漏斗）。
- **站长**：身份信息（名/推广码/月度统计 lockedUsers/monthOrders/monthEarning）、归属客户列表+行为时间线、收益明细（分页）、推广素材、海报模板。
- **🔴主推位（本次新增·需后端补·V0 只管画）**：
  - 新表 `StationPinnedContent`（stationId / board(home·mall·course·circle·agent·classic·article·video·live) / position(0-5) / contentType / contentId）。
  - 端点：GET 某站某板块主推位、PUT 锁定/替换、DELETE 移除；选品库复用各板块现有 list+搜索+分类接口。
  - 直播主推位渲染校验状态，结束自动剔除。
  - 归属用户浏览平台各板块时读其站长的主推位覆盖前 6 位；发现页聚合所有板块主推位。
- **没有的能力（禁止画）**：分站装修/分站页面/主题色、师资邀约、分站独立开播、AI 助手、独立登录后台。

## 六、视觉规范
全站统一 token：宣纸白 #FAF8F5 页底、卡片白 #FFFFFF、朱红 #C41E3A（主按钮/激活/价格）、金 #C9A96E（价值强调/收益/等级）、文字 #2C2C2C/#6E6E73/#999、圆角 18px·胶囊 999px、页边距 20px。
- **不做站长主题色/品牌定制**（本模型无装修）。
- **主推位「＋」占位**：虚线描边 + 居中加号 + "主推位"小字，克制；已锁卡右上角移除/替换角标。
- 工作台：数据数字大、标签小、卡片化；国学雅致、克制留白、禁荧光渐变与娱乐贴纸感。
- ⚠️ 禁同色系底字；封面图上文字必须有渐变衬底。

## 七、技术兼容（安卓微信 X5 内核）
1. 封面/比例用 padding-top（不用 aspect-ratio，稿内标注比例）。
2. 不用 writing-mode 竖排。
3. 半屏选品面板用实色+透明度（毛玻璃不承载关键信息）。
4. 主推位选品交互由我方实现，V0 只出视觉与态。
