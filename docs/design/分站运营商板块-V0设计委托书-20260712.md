## 一、背景与定位（先读这段）

我们平台的前身是排盘工具（570 万注册用户），核心战略是把**存量用户向 B 端身份转化**——站长/运营商是这个生态的骨架。**分站运营商板块 = 平台商业化的分销与生态底盘**。

现状是多轮原型迭代的补丁产物：现有 **28 个页面**功能散落、角色混淆（站长/运营商混用）、多个工作台职责重合、4 个空壳死页、多处诚实降级。**本次推翻重做前端**（后端能力大体完整，只重 UI 与交互，狠做减法），同时落地一个**核心新功能：站长「主推位」前端自服务**（见第四节·本委托灵魂）。

### 两个角色（必须区分清楚）
| 角色 | 定位 | 一句话 | 核心诉求 |
|---|---|---|---|
| **运营商 Operator** | 团队管理者 | 带一支站长团队、管名额、看业绩、发任务、拿团队管理奖 | 管好团队、提升团队业绩 |
| **站长 StationMaster** | 分站推广者 | 开一个自己的分站、装修品牌、**主推内容**、推广拉客、拿分销佣金 | 让自己的分站好看、主推自己想推的内容、拉客变现 |

> 用户（访客）扫站长的推广码进入**分站首页**，与站长建立"归属"关系，其消费为站长带来佣金。

## 二、核心命题：站长「主推位」前端自服务（本委托灵魂·重点设计）

### 2.1 是什么
平台各内容板块（首页 / 课程 / 商城 / 古籍 / 短视频 / 直播 / 圈子 / 智能体）的展示，**默认走平台千人千面推荐**。但每个板块**保留 6 个「主推位」**，由**站长在前端自由锁定显示什么内容**。

- **6 个主推位不参与千人千面**，是**站长锁定的固定展示**；其余位置照常平台个性化。
- 这样**既保平台调性一致，又给站长主推空间**。这批主推位是**站长×平台×内容方三方合作的资源与筹码**（谁的内容上主推、如何分成）。
- **发现页不单独配置**：发现页是各板块内容的聚合出口，站长把各板块主推位配好后，**发现页自动同步聚合展示**（无需单独装修发现页）。

### 2.2 站长怎么操作（前端所见即所得·不进后台）
> 让站长上后台操作不现实、也不人性化。主推位配置**全在前端、在站长自己的分站页面上完成**。

**动线**：
1. 站长开通分站 → 填分站名称 → 引导进入**个人中心 → 站长工作台**。
2. 站长在自己的分站的某个板块页面（如分站课程页），进入**「编辑模式」**，该板块的 6 个主推位显示为 **6 个「+」加号占位**。
3. 点某个「+」→ 拉起**平台选品库半屏面板**（支持**搜索 + 分类**）→ 从该板块内容库里选一个内容 → 该内容**锁定**到这个位置（加号变成内容卡）。
4. 站长选几个就锁几个位（0-6 个，未锁的位不占）。可替换、可移除、可调顺序。
5. 保存后，用户访问该站长分站的这个板块时，前 6 位优先显示站长锁定的内容，其余走平台流；发现页对应板块自动同步这些主推内容。

### 2.3 各板块选品库口径
| 板块 | 选品库来源 | 特殊规则 |
|---|---|---|
| 课程 | 平台课程库（搜索+分类） | — |
| 商城 | 平台商品库 | — |
| 智能体 | 平台智能体库 | — |
| 圈子 | 平台圈子库 | — |
| 古籍 | 平台古籍库 | — |
| 短视频 | 平台短视频库 | — |
| **直播** | **只能选「已有的」直播** | 只能选**正在直播 / 预约直播**；**直播结束后自动取消该位**（渲染时校验状态，过期自动剔除） |
| 首页 | 跨板块混合（可从任意库选） | 首页 6 主推位可放任意类型内容卡 |

### 2.4 要 V0 设计的主推位相关界面（重点出稿）
1. **主推位编辑态**：某板块页面进入编辑模式，6 个位置的「+」加号占位排布（如首页/课程页顶部 6 位，或分区首排 6 位）。已锁定的位显示内容卡 + 移除/替换角标。
2. **选品库半屏面板**：顶部搜索框 + 分类 Tab（该板块的内容分类）+ 内容列表（可选中）+ 底部「确认锁定」。直播面板只列正在直播/预约直播（带直播状态标）。
3. **编辑态与浏览态切换**：站长看自己分站有「编辑」入口；普通用户看到的是浏览态（锁定内容 + 平台流）。

## 四、每页设计简章

### O1 运营商工作台（合并 dashboard+operator-panel）
1. 头部：运营商身份 + 本月团队总收益/团队规模/活跃站长数（关键数字大）。
2. 团队健康分（Team Health Score）+ 一句诊断。
3. 快捷功能格：邀请站长 / 我的团队 / 业绩分析 / 沉寂预警 / 名额管理 / 设置。
4. 名额概览条：自用 1 + 可推荐 N（点进 O6）。
5. 团队业绩 Top5 榜 + 成功案例横滑。
**状态**：未开通运营商 → 引导态（跳 C1）。

### O2 我的站长团队
名下站长列表（头像/分站名/本月业绩/状态标：活跃/沉寂）+ 业绩排行 + 成功案例。筛选/排序。

### O3 邀请站长 / O4 沉寂预警 / O5 业绩分析 / O6 名额管理 / O7 设置
沿用现有真连能力，视觉按新规范重塑（列表/卡片/表单标准化）。O4 沉寂预警支持批量提醒。O6 名额：总览（自用/已售/已赠/可用）+ 分配/赠送。

### S1 站长工作台（合并 station-manage+station-master-panel·站长唯一主控台）
1. **品牌卡**：分站 Logo/名称/主题色/推广码（点击分享）。
2. **数据条**：本月收益/订单/新增客户（点进各详情）。
3. **主推位管理入口**（新·重点）：「我的主推内容」入口 → 进入各板块选择编辑（或直接在分站首页 S3 编辑态操作）。展示各板块已锁主推位数（如 课程 3/6·商城 2/6）。
4. 快捷入口格：分站装修 S2 / 主推位 S4 / 客户洞察 S5 / 收益 S6 / 素材 S7 / 海报 S8。
5. 运营商下发的团队任务卡（如有）。
**状态**：未开通分站 → 引导态（跳 C2）。

### S2 分站装修
品牌信息（Logo/名称/简介上传编辑）+ 首页模板选择（预设模板卡）+ 主题色（预设色系/自定义 Hex）。实时预览分站首页。

### S3 分站首页（品牌定制·含主推位·统一 station-home/detail）
**用户浏览态**：品牌头（Logo/名称/站长信息卡）→ 各板块主推位（站长锁定内容优先）→ 平台推荐流（千人千面）。整体套用站长主题色做品牌化。
**站长编辑态**（站长看自己分站时右上角「编辑」切换）：各板块主推位显示 6 个「+」加号/已锁卡（见 2.4），点位编辑。
**状态**：正常/加载骨架/无主推（全平台流兜底）。

### S4 主推位选品库面板（新·取代 station-promote）
半屏面板：顶部搜索框 + 分类 Tab（该板块分类）+ 内容列表（该板块内容卡·可单选/多选到剩余空位）+ 底部「确认锁定（已选 N）」。**直播面板**：只列正在直播/预约直播（带 LIVE/预约状态标 + 开播时间），选中后锁位，注明"直播结束自动下架"。

### S5 客户洞察 / S6 收益明细 / S7 推广素材库 / S8 海报生成
沿用现有真连能力（customers 客户智能名片+行为时间线设计精妙，保留；earnings 收益明细；materials 素材库；poster 海报模板生成）。视觉按新规范重塑。

### C1 成为运营商 / C2 成为站长
转化漏斗页：价值主张 + 定价套餐（真实 /operator·/station 定价 API）+ 权益对比 + FAQ + 底部「立即开通/申请」（付费或邀请码）。

### C3 协议页
运营商协议 / 站长协议（一稿两态，纯展示 + 底部同意）。

## 五、数据能力边界（都是现成后端，画的每个元素要能对上）

- **运营商**：概览（团队数/收益/成员）、团队成员列表、业绩排行、成功案例、沉寂列表+提醒、名额管理（自用/已售/已赠/可用）+ 赠送、邀请链接、业绩分析（含 CTR/CVR 漏斗）。
- **站长**：分站信息（名/logo/intro/主题色/推广码/月度统计 lockedUsers/monthOrders/monthEarning）、归属客户列表+行为时间线、收益明细（分页）、推广素材（海报/文案+使用统计）、海报模板、分站模板列表+选择、分站微页面（复用 MarketingPage 引擎·分站级隔离）。
- **分站首页渲染**：GET /station/brand/:code（品牌配置）+ 模板/微页面 + 平台 Feed。
- **🔴主推位（本次新增·需后端补·V0 只管画，我方补接口）**：
  - 新表 `StationPinnedContent`（stationId / board(home·course·mall·classic·video·live·circle·agent) / position(0-5) / contentType / contentId / createdAt）。
  - 端点：GET 某分站某板块主推位、PUT 锁定/替换某位、DELETE 移除某位、选品库复用各板块现有列表接口（课程/商品/古籍/短视频/圈子/智能体/直播 list + 搜索 + 分类）。
  - 直播主推位渲染时校验直播状态，结束/回放自动剔除。
  - 发现页聚合：读所有板块主推位汇总展示。
- **没有的能力（禁止画）**：师资邀约、分站独立直播开播、AI 运营助手对话（后端无模型，本次不做）。

## 六、视觉规范

全站统一 token：宣纸白 #FAF8F5 页底、卡片白 #FFFFFF、朱红 #C41E3A（主按钮/激活/价格）、金 #C9A96E（价值强调/收益/等级）、文字 #2C2C2C/#6E6E73/#999、浅红底 rgba(196,30,58,0.08)、圆角卡 18px·胶囊 999px、页边距 20px。
- **分站首页 S3 支持站长主题色定制**：品牌头与主推区用站长配置的主题色做品牌化叠加（其余保持平台调性）。
- **主推位「+」加号占位**：虚线描边 + 居中加号 + "主推位"小字，克制不花哨；已锁卡右上角移除/替换角标。
- 运营商/站长工作台：数据数字大、标签小、卡片化；国学雅致、克制留白、禁荧光渐变与娱乐化贴纸感。
- ⚠️ 禁止同色系底字；封面图上文字必须有渐变衬底。

## 七、技术兼容要求（安卓微信 X5 内核）
1. 封面/比例用 padding-top 方案（不用 aspect-ratio，稿内标注比例）。
2. 不用 writing-mode 竖排。
3. 毛玻璃不承载关键信息（半屏选品面板用实色+透明度）。
4. 关键按钮单层实底+文字，无复杂层叠。
5. 主推位编辑态/浏览态切换、选品库半屏面板由我方实现交互，V0 只出视觉与态。

   - **通用编辑态模板**：平台各板块页面「主推位编辑态 + 选品库面板」一稿（各板块复用）。
