# 发布架构统一：官方身份 + 创作工作台（设计文档）

> 2026-07-08 · 董事长口述愿景整理 · 状态：待评审后分阶段实施

## 一、背景与设计原则

董事长在排查"后台传视频/duration 报错"时，逐步提出了一套**统一的平台发布架构**理念，核心是纠正当前"脱离场景"的发布设计（独立游离的内容实体、让人手填机器该自算的字段、官方内容在后台搞独立一套）。

**五条统一原则**：
1. **内容/商品都归属真实容器**：短视频/文章/课程 → 圈子；商品 → 店铺(商家)。不做游离实体。
2. **官方内容用"官方身份"**：官方内容归「热卜官方」圈子；平台自营商品归「官方旗舰店」商家。与真实用户/商家走**同一套发布流程**，不另起炉灶。
3. **人工发布走前端**（C 端 / 商家端 / 讲师工作室）；**后台(admin)发布接口留给 AI 数字员工自动发种子内容**（API 优先，人工 UI 只兜底/测试）。
4. **编辑器一律**：友好 · 高效 · 便捷 · 傻瓜式 · 所见即所得 · 场景适合。
5. **电脑端专属页面只在"得天独厚"时才做**：短视频/文章/帖子手机随手发即可；只有课程（大文件传输、多章节组织、长篇富文本、拖拽排序）值得电脑端专属工作室。

## 三、编辑器选型：wangEditor（替换 Quill）

**现状**：admin 课程章节 / 文章 / 商品详情用 Quill 1.3.7（轻量，无图片上传按钮，排版能力弱，"作品感"不足）。

**推荐 wangEditor v5**：
- 国产、中文文档与社区、创作场景友好；开箱即用的图片/视频插入、标题/引用/代码/表格/对齐/字号字色等**作品级排版**。
- 图片/视频上传可直接对接现有 COS/VOD（customUpload 钩子）。
- Vue3 有官方封装 `@wangeditor/editor-for-vue`，接入成本低。
- 一次替换，同时满足：文章作品感、课程章节图文、商品详情，并清掉 memory 里"后台编辑器换 wangEditor"的历史待办。

对比：Quill(现状·轻)｜**wangEditor(推荐·中文创作友好·作品级)**｜TipTap(最强可定制·但集成重)。

> 决策点①：确认 wangEditor 作为统一富文本编辑器。

## 四、课程电脑端「创作工作室」详细设计（重点）

**技术路线（已拍板）**：复用 admin 的 Vue3 + Element Plus + VodUpload + CosImageUpload 桌面栈，做面向讲师的独立「课程创作工作室」，讲师用 C 端手机号账号登录（同一套 JWT；后端 `CourseCreatorGuard` 已支持讲师认证/管理员放行）。

**数据结构（现状·扁平章节，够用）**：课程 → 章节(CourseChapter)一层。章节含 title / mediaUrl(音视频) / content(富文本图文) / duration / sortOrder / freeTrial。一个章节可同时含音视频+图文。

**页面布局（三栏）**：
```
┌────────────────────────────────────────────────────────┐
│ 课程创作工作室        [保存草稿][提交发布]  状态:草稿    │
├──────────────────┬─────────────────────────────────────┤
│ 课程信息(左30%)   │  章节编辑区(右70%)                    │
│ [封面拖拽上传]    │  第2章 · 八字排盘实操                 │
│ 标题/简介         │  内容类型 ●视频 ○音频 ○图文          │
│ 类型/价格/分类    │  ┌─────────────────────────────┐    │
│ 圈子:热卜官方▾    │  │ 拖拽视频到此/点击上传        │    │
│ ── 章节列表 ──    │  │ (自动读时长·自动截首帧封面)  │    │
│ ⠿1 导论  ✎🗑     │  └─────────────────────────────┘    │
│ ⠿2 实操 ◀(编辑中)│  图文正文:[wangEditor 富文本+插图]   │
│ ⠿3 ...           │  ☑免费试看     [保存本章]           │
│ [+ 添加章节]      │                                      │
└──────────────────┴─────────────────────────────────────┘
```

**"得天独厚"的电脑端交互**：①章节**拖拽排序**(自动写 sortOrder)②视频**拖拽到区域直传**+进度条+自动时长/封面(VodUpload 已具备)③**边编辑边存**(每章独立 POST/PUT chapters，草稿态)④连续加章节不打断⑤大文件电脑上传更快更稳。

**范围**：只做"创作"(课程信息+章节音视频/图文)；教学管理(学员/作业/评价)留在 admin，不进工作室。

**关键前置——讲师登录权限**：需确认 admin 应用登录是否限角色、路由守卫如何控。方案：工作室作为 admin 应用内独立路由区(如 `/studio/*`)，登录放行讲师角色但 RBAC 仅允许其访问工作室路由；或独立品牌入口。（实施前需读 `apps/admin/src/router/index.ts` 守卫 + 后端登录角色策略确认。）

> 决策点②：讲师登录形态——admin 内独立 `/studio` 路由(省，复用一切) vs 独立部署 studio 前端(隔离好，成本高)。推荐前者。

## 五、各模块后端改造要点

- **课程**：`course.service.create` 加 `resolveCircleId(dto.circleId)` 兜底官方圈(沿用 video.service 模式)。
- **文章**：现走 `POST /articles/circles/:circleId`(路径参数强制)。后台/AI 发官方文章 → 传 official_circle_id；或加一个 `POST /articles`(无 circleId)走兜底官方圈。C 端作品发布同理(圈子内发→该圈；否则官方圈)。
- **商品/官方旗舰店**：建官方 Merchant(ACTIVE·跳过入驻)；商家端 `POST /merchant-backend/products` 现硬编码 `supplierType=CERTIFIED_MERCHANT`+`status=PENDING`，官方账号需支持免审自动上架(按 isOfficial 或官方 merchant id 判定)。商家端 `product-edit` 图片上传当前是"功能即将开放"占位——需接 CosImageUpload 真实上传（傻瓜式所见即所得）。

## 六、分阶段实施路线图（建议每阶段独立窗口，保上下文质量）

- **Phase 0 · 地基**(后端·低风险)：课程/文章 circleId 兜底官方圈；建官方旗舰店 Merchant + config。
- **Phase 1 · 编辑器统一**：接入 wangEditor，先替换文章/课程章节/商品详情的 Quill（含图片传 COS/视频传 VOD 钩子）。
- **Phase 2 · 文章作品发布**：C 端文章创作页(wangEditor·作品感·区别于帖子)+圈子化。
- **Phase 3 · 课程电脑端工作室**(重点)：Element Plus 讲师工作室(三栏·章节拖拽·边传边存)+讲师登录权限。
- **Phase 4 · 课程手机简版**：C 端轻量课程发布(建课程+加章节)。
- **Phase 5 · 商品官方旗舰店**：建官方商家+商家端发布完善(真实图片上传·傻瓜式)+免审逻辑。
