# D1 附录·商业化国学平台古籍数字化文本来源调研报告（原文存档）

> 调研日期：2026-07-02（联网调研）· 主文档见 [D1-古籍内容质量治理与来源策略-20260702.md](./D1-古籍内容质量治理与来源策略-20260702.md)

## 一、执行摘要

1. **法律底线**：古籍**原文**属公有领域，但**现代点校本（分段/标点/校勘/注释/白话译文）在中国司法实践中被认定为受著作权保护的作品**（中华书局诉国学时代案已判）。商用平台**不能直接采集他人整理本**，这是比"选哪个源"更优先的红线。
2. **现用的殆知阁是"量大质低+来源不清"的典型**：简繁转换丢字、双行夹注错乱、OCR/转录错误率高、无底本标注，且其语料疑似混入他人整理本（标点文本），既有质量问题也有合规隐患。
3. **最佳免费增量源：识典古籍（北大-字节跳动）**——权威底本（四部丛刊/百衲本二十四史等）、粗校/精校分级、免费不限复制；但"免费开放"≠"明示商业再分发授权"，批量商用前建议函询确认。
4. **要达到"权威底本+精校标点"的商业级质量，核心经典最终绕不开付费授权**：首选中华书局古联（籍合网），其已有对外数据合作先例（"荀子"古籍大模型语料合作），是唯一明确走"正版整理本数据授权"路线的厂商。
5. **推荐三层策略**：核心经典（几十部）= 自建精修（公有领域白文 + 自研标点/译注）；扩展书目 = kanripo（CC BY-SA，9000+ 部，底本明确）+ 维基文库 dump（CC BY-SA）；权威整理本/独家内容 = 与古联商务接洽。

## 二、法律问题：古籍点校本的著作权

### 判例事实
- **中华书局诉国学时代案**（2011 起诉，北京海淀法院一审、北京一中院二审）：法院认定**"以分段、加注标点和文字修订的方式完成的二十五史点校作品具有独创性，应当受《著作权法》保护"**，国学时代版与中华书局版构成实质性近似，终审判赔 17 万余元并停止侵权。细节：法院同时认定中华书局版《史记》《三国志》**已过保护期**（法人作品发表满 50 年）——点校本保护有期限，但逐书核期成本高、边界模糊。
  - 出处：[古籍点校第一案终审宣判](https://www.ciplawyer.cn/articles/118929.html) · [中华书局整理古籍获著作权](https://www.ciplawyer.cn/articles/118906.html) · [案件评析](https://www.ciplawyer.cn/articles/118835.html) · [公司宝案例整理](https://m.gongsibao.com/article-6336.html)
- 学界有分歧（邻接权保护论/复原事实不具独创性论），但**司法主流倾向保护**，赔偿+下架风险真实存在。
  - 出处：[南理工·古籍点校版权争点](https://ciipr.njust.edu.cn/20/25/c11083a270373/page.htm) · [邻接权保护可行性论文](https://hanspub.org/journal/paperinformation?paperid=92576)

### 商用风险矩阵

| 内容类型 | 商用风险 |
|---|---|
| 古籍白文（无标点原文，据古本自行录入/OCR） | ✅ 公有领域，安全 |
| 自己做的标点/分段/白话译文（含 AI 生成+人工审校） | ✅ 安全，且形成自有资产 |
| 采集他人现代点校本（出版社整理本、商业库导出文本） | 🔴 高风险，有直接判例，禁止 |
| 开源社区标点文本（MIT/CC 授权） | 🟡 许可可商用，但警惕"实际抄自出版社点校本"的上游污染 |
| 爬取聚合站（国学大师等） | 🔴 双重风险：上游盗采+爬取行为涉反不正当竞争 |

## 三、来源逐项评估

### A. 开源/公开来源

1. **ctext.org 中国哲学书电子化计划**：质量★★★★（先秦两汉配原书扫描页对照）。⚠️ 对商用不友好：API 分层限流，官方**明确禁止自动批量下载**，商用未授权 → 只作校对参考基准。出处：[API 页](https://ctext.org/tools/api) · [简介](https://ctext.org/introduction)
2. **维基文库**：质量★★★（有 ProofreadPage 扫描校对的部分较高，大量转贴条目未校）。✅ CC BY-SA 可商用（注意 SA 传染）。dump：[dumps.wikimedia.org/zhwikisource/latest/](https://dumps.wikimedia.org/zhwikisource/latest/)。出处：[下载帮助](https://zh.wikisource.org/wiki/Help:%E4%B8%8B%E8%BD%BD%E7%BB%B4%E5%9F%BA%E6%96%87%E5%BA%93)
3. **殆知阁（现用）**：质量★★（繁转简丢字/夹注错乱/无底本/校对差，有评测实锤）。🟡 上游污染风险。只可托底，付费/主打场景逐步替换。出处：[殆知阁2.0文本质量评测(CSDN)](https://blog.csdn.net/iCloudEnd/article/details/99250877) · [github daizhigev20](https://github.com/garychowcmu/daizhigev20)
4. **chinese-poetry**（MIT ✅）：唐诗5.5万+宋诗26万+宋词2.1万，但**宋词约 4,278 处待校（约1/5 有疑点）、新版全唐诗简转繁讹误多**——引用锁旧版+抽检。出处：[Issue #261](https://github.com/chinese-poetry/chinese-poetry/issues/261) · [Issue #280](https://github.com/chinese-poetry/chinese-poetry/issues/280)
5. **kanripo 漢籍リポジトリ**（京都大学 Christian Wittern）：**9000+ 部按四部分类、每书一 GitHub repo、底本明确（多为四部丛刊等善本转录）、git 可溯源可 PR 纠错、CC BY-SA 4.0 可商用** → 本次调研重点推荐。出处：[github.com/kanripo](https://github.com/kanripo) · [KR-Catalog](https://github.com/kanripo/KR-Catalog)
6. **CBETA**（佛典）：质量★★★★★学术级。🔴 条款限非营利，**营利用途须事先取得协会与底本版权者同意**（再传播附版权声明+版本信息）。出处：[版权页](https://cbetaonline.cn/doc/zh/06-copyright.php)
7. **书格 shuge.org**：影印 PDF 为主**无文本层**，CC BY 4.0 → 作底本书影/校对参照素材。出处：[shuge.org](https://www.shuge.org/)
8. **国学大师/国学网等聚合站**：🔴 禁用（文本普遍源自商业库盗采；国学时代即点校侵权案败诉方）。
9. **🌟 识典古籍 shidianguji.com**（北大-字节）：质量★★★★☆——底本四部丛刊/四库/百衲本二十四史/永乐大典；粗校（OCR 96-97%+自动标点）/精校（全人工）分级；2025 已 19,000+ 部。🟡 官方"免费、不限复制"，但未见明示商业再分发许可 → 批量商用先函询北大-字节数字人文开放实验室（谈成可能性较高）。出处：[北大 DH 中心项目页](https://pkudh.org/project/shidianguji/) · [北京日报报道](https://www.bplisn.net.cn/news/3007.html) · [字节公益页](https://gongyi.bytedance.com/detail/7161003434291775518)

### B. 商业授权库

10. **中华书局「中华经典古籍库」（籍合网/古联数字）**：★★★★★正版整理本（中华书局+凤凰/巴蜀/齐鲁等十余家，13 期 1 万余种）。✅ 有数据授权先例（向"荀子"古籍大模型提供 20 亿字整理本语料）→ **最值得谈**。报价需商务接洽。出处：[籍合网](https://www.ancientbooks.cn/) · [荀子大模型（南农+古联）](https://info.njau.edu.cn/info/1032/3207.htm) · [新华网报道](http://www.news.cn/politics/2023-12/13/c_1130023543.htm)
11. **爱如生「中国基本古籍库」**：★★★★（1 万种/19 亿字录文+1300 万页影像对照；录文校对精度一般）。个人版 300 元/月、3600 元/年；机构版 10 年付费永久+3600 元/年服务费；**数据级授权无公开渠道，管控极严谈判难度高**。出处：[产品页](http://er07.com/home/pro_3.html)
12. **雕龙/鼎秀**：机构订阅检索平台，无公开数据授权产品，文本多为 OCR 全文，精校不及籍合网 → 备选比价。出处：[北大图书馆·雕龙](https://www.lib.pku.edu.cn/portal/cn/news/0000001904) · [鼎秀](https://www.lib.pku.edu.cn/portal/cn/news/0000001617)

## 五、分层推荐方案

1. **核心经典（50-100 部主打）= 自建精修**：kanripo 白文为基（底本标注明确）+ ctext 扫描页/书格/识典影像三方核校 + 自研标点译注（AI 生成+人工审校）→ 整理层成为**自有受保护作品**（竞争壁垒）；每书登记"底本+校对轮次"元数据前端展示。
2. **扩展书目（数百至数千部）= kanripo 整体引入 + 维基文库有校对标记条目**（均保留 CC BY-SA 署名脚注；SA 传染只及文本层，自加译注/AI 功能层不受影响）。
3. **佛典 = CBETA + 授权函**（先函询后取数，附版权声明+版本号）。
4. **权威整理本/付费差异化 = 古联商务接洽**（按书目打包数据授权或 API；爱如生/雕龙/鼎秀备选比价）；并行函询识典古籍批量合作（低成本高可能）。

### 立即执行项（不花钱）
1. 停止扩大殆知阁书目；现有精修书目逐一核对来源，含现代标点且非自校的文本优先替换（法律红线）
2. 诗词模块引用 chinese-poetry 锁旧版+抽检
3. 阅读器为每书增加"底本/校对状态"元数据字段——把质量优先变成用户可感知卖点
