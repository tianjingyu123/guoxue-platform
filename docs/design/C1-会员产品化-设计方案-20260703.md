## 二、现状侦察结论（2026-07-03）

**可复用（不动或微调）**：
- 模型：`User.memberLevel/memberExpire`、`MemberConfig`（level 为 String @unique，档位行free）、`MemberPurchase`
- 购买链路：`POST /shop/orders(type=MEMBER, targetId=MemberConfig.id)` → 在线支付 → `processMemberPaid`（复购叠加不吞天数、只升不降）
- 权益判定：`bot.service.consumeQuota`（会员智能体不限量已通）、`ebook.checkAccess`、`course.checkAccess`
- 基建：`redis.incrWithTtl`（每日计数）、`redis.runExclusive`（cron 分布式锁）、`points.service.earnPoints`（积分发放）、marketing 优惠券发放

**缺口（本轮做）**：
1. 档位/定价是旧版（199/999/3949）→ 改书院会员四档
2. 古籍伴读/白话对照/查词/AI问答**完全无门控**（免费用户无限用）→ 补每日限次
3. 电子书会员权益是「单本 memberFree」→ 改「会员全场畅读」；**存量 bug**：`ebook.service.ts` canRead 中 `price<=0 || memberFree` 短路导致 memberFree 书对所有人免费，一并修复
4. 每月赠积分+优惠券无发放机制 → 月度 cron + 购买即发首月
5. MEMBER_PURCHASE 分佣当前 enabled=true → 关
6. 前端：/vip 档位权益文案旧版；records/renew 两页 mock；伴读无额度提示与会员引导；无会员标识组件

## 三、档位设计

| 档位 | MemberConfig.level | 价格 | 时长 | user.memberLevel | 说明 |
|---|---|---|---|---|---|
| 月卡 | MONTHLY | ¥19 | +1 个月 | MONTHLY | |
| 季卡 | QUARTERLY | ¥49 | +3 个月 | QUARTERLY（**枚举新增**） | |
| 年卡 | YEARLY | ¥168 | +12 个月 | YEARLY | **主推**（前端 popular） |
| 连续包年 | YEARLY_AUTO | ¥148 | +12 个月 | YEARLY | 开通置 `User.memberAutoRenew=true` |
| 终身（旧） | LIFETIME | — | — | LIFETIME | **停售**（isActive=false）；存量终身会员权益不变（只升不降逻辑保留） |

**连续包年的诚实降级**：微信委托代扣（papay）资质未接，真自动扣费暂不可行。本期实现=首年 ¥148 开通 + `memberAutoRenew` 标记 + 到期前 7 天/当天站内通知提醒按 ¥148 续费价续费（续费时 autoRenew 用户下 YEARLY_AUTO 单仍按 148）。前端明示「自动扣费能力开通前，到期我们会提醒你以 ¥148 续费」。papay 就绪后升级为真代扣。

**schema 变更（全部增量·安全）**：
```sql
ALTER TYPE "MemberLevel" ADD VALUE IF NOT EXISTS 'QUARTERLY';
ALTER TABLE "User" ADD COLUMN IF NOT EXISTS "memberAutoRenew" BOOLEAN NOT NULL DEFAULT false;
ALTER TABLE "MemberConfig" ADD COLUMN IF NOT EXISTS "monthlyPoints" INTEGER NOT NULL DEFAULT 0;
ALTER TABLE "MemberConfig" ADD COLUMN IF NOT EXISTS "monthlyCouponId" TEXT;
ALTER TABLE "MemberConfig" ADD COLUMN IF NOT EXISTS "sort" INTEGER NOT NULL DEFAULT 0;
```
（ALTER TYPE ADD VALUE 单独文件先跑，避免与用新值的语句同事务）

**代码适配**：
- `calcMemberExpiry`：QUARTERLY → +3 月；YEARLY_AUTO → +12 月
- `processMemberPaid`：plan.level `YEARLY_AUTO` → memberLevel=YEARLY + `memberAutoRenew=true`；memberType 记 YEARLY
- `resolveMemberLevel`（仅历史无 targetId 订单兜底）：≥3000 LIFETIME / ≥900 YEARLY（旧价）/ ≥148 YEARLY / ≥49 QUARTERLY / 其余 MONTHLY
- `getStatus` 响应加 `autoRenew`

## 四、五项权益落地

### 权益① AI 伴读/白话对照不限量（免费用户每日限次）
- 新建 `MemberBenefitService`（member 模块，全局可注入）：
  - `isActiveMember(userId)`：统一会员判定（收口现有三处散装实现，逐步替换）
  - `consumeAiQuota(userId)`：会员直接放行；免费用户 `redis.incrWithTtl("aiq:{userId}:{yyyyMMdd}", 26h)`，超限抛 `BusinessException`（message 引导开通会员，前端识别 code）
  - `getAiQuota(userId)`：`{ isMember, dailyLimit, usedToday, remaining }`
- 限次数值：**每日 10 次**（伴读对话/白话翻译/查词/AI 问答合并计数），`AI_DAILY_FREE_LIMIT` env 可调
- 门控接入点（一次调用记一次）：
  - classic：`companion/chat`、`translate`、`dictionary/lookup`、`ask`
  - ebook：`translate` 等 AI 端点
- 新端点：`GET /member/ai-quota`（JWT）供前端额度提示
- **多实例安全**：redis 计数天然安全；redis 不可用时降级内存计数（RedisService 已有 fallback，单实例语义可接受）

### 权益② 付费精品电子书畅读
- `ebook.checkAccess/canRead`：`价格≤0 → 放行`；**有效会员 → 全场放行**；否则查购买记录
- 同步修存量 bug：`memberFree` 不再对非会员短路放行
- `purchase()`：有效会员购买任意书 → 0 元 upsert EbookPurchase（领取式，保留阅读记录语义）
- 前端 checkout：会员显示「书院会员·畅读免费」一键领取；非会员显示「开通书院会员畅读全场」引导（无痕触点）

### 权益③ 每月赠积分+优惠券
- 配置：`MemberConfig.monthlyPoints`（月卡 100 / 季卡 120 / 年卡 & 连续包年 150）+ `monthlyCouponId`（可空·运营后台配券模板后启用）
- 发放：member 模块月度 cron（每月 1 日 09:00）`runExclusive("member-monthly-grant")`：
  - 遍历有效会员 → `earnPoints(userId, points, "member_monthly_{yyyyMM}")`
  - **幂等**：发放前查 PointsRecord 同 source 是否已存在
  - 配了 monthlyCouponId 则同步发券
- 购买开通当场发首月（processMemberPaid 事务后异步发，失败仅告警不回滚支付）

### 权益④ 会员专属标识
- 后端：users/me、profile 响应已含 memberLevel（沿用）
- 前端：新建 `app-member-badge` 组件（「书院」印章式小标·区分月/季/年/终身色阶），接入个人中心头部 + 个人主页昵称旁

### 权益⑤ 专属客服
- 轻实现：会员中心「专属客服」入口（复用客服 FAB 链路）+ 客服会话透传会员身份；权益文案落地。不建独立系统。
