# V1 学习成就卡裂变 · 设计方案

> 2026-07-03 · 战略总纲 3.5 裂变方案库 P0 项 · 前置 B1 称号体系已上线（0b5fddc8）· 自主拍板（纯功能无资金/定价）

## 一、裂变机制（总纲原案）

连续学习 N 天 / 晋级新称号 / 达成成就 → 生成雅致成就卡分享；好友点开见「TA 的成就 + 连续天数」→ 一键同学。
公式 = 值得炫耀的产出物（成就卡）+ 好友点开有即时价值（看到具体成就与路径）+ ref 归因闭环（已有全平台单一 ref 基建）。

## 二、实现

### 后端（已完成）
- `GET /growth-card/:userId?code=&type=achievement|title` — **公开端点**（ThrottleGuard 防刷）：
  仅当该用户真实获得过该成就/称号才返回（否则 404 不泄漏）；只回展示字段
  `{ nickname, avatar, type, code, name, desc, earnedAt, currentStreak, maxStreak, level, levelName, totalExp }`。
  连续天数口径与 getMyGrowth 一致（断签超 1 天按 0）。
- 复用 B1 的 ACHIEVEMENTS（17 枚）与 TITLES（12 枚）目录做 code 校验。

### 前端
1. **成长中心成就卡弹层**（pkg-mine/achievements）：点已获成就/称号分享入口 → canvas 手绘成就卡
   （范式=V8 节气卡：createCanvasContext + roundRect + drawWrapped + canvasToTempFilePath 保存相册）。
   卡面：品牌头「热卜国学 · 学习成就」+ 成就/称号名 + desc + 连续 X 天 + 功名等级 + 邀请语。
2. **分享链路**：小程序 `open-type="share"`（toAppMessage/withRef 自动带 ref）；H5 复制分享链接。
   落地 path = `/pkg-common/growth-card/index?uid=&code=&type=`。
3. **公开落地页**（新建 pkg-common/growth-card）：captureRefFromQuery 归因 → 拉公开端点 → 展示 TA 的成就卡
   → CTA「我也要每天学一点」（已登录→成长中心；未登录→登录）→ 支持二次转发。三态齐全。

## 三、边界与合规

- 分享完全自愿；公开数据仅昵称/头像/成就（平台内本就公开维度），未获得即 404。
- 纯荣誉无资金，不触 R1；埋点走 useShare 内置 track（曝光→点击→注册归因漏斗已有）。
