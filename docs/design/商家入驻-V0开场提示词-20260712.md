# 商家入驻板块 · 给 V0 的开场提示词（2026-07-12）

> 用途：连同《商家入驻板块-V0设计委托书-20260712.md》一起发给 V0，先定调再让她按委托书出稿。

你好，帮我设计一个**移动端 H5**（390px 宽，纯静态 HTML 稿，稿内用 HTML 注释标数据来源与交互）的**商家后台**板块。完整规格见附件《商家入驻板块-V0设计委托书》，这里先讲清最关键的几点，请务必先理解再动手：

**一、定位（别做偏）**
这是平台电商的「**供货端**」——商家只管**供货、上架商品、管订单、看结算**。**不做店铺装修、不做流量投放、不做内容运营**。气质是"高效的商家工作台"，国学雅致、克制，不要娱乐化贴纸感。

**二、核心是商品编辑器（这是重点，请重点设计）**
现在的商品编辑器有硬伤要一次性解决：**顺序乱、详情图加不了、轮播分不清主图、价格和 SKU 打架**。请按「**全屏分区块编辑页 + 右侧手机实时预览**」重做，左侧从上到下：
主图(1:1) → 基本信息 → 轮播图(1:1·首张标"主图") → 详情图(宽750·多图拖拽拼长图·**没有富文本编辑器**) → 价格与规格 → 库存 → 上架控制。

**价格/SKU 口径（务必按此，别搞混）**：
- 划线价（原价）= 商品级一个值，只用来划线展示，不参与结算；
- **无 SKU**：填一个商品级售价结算；
- **有 SKU**：售价由每个 SKU 各自定，商品级不填售价、改为自动显示"¥最低~最高"区间。
- 出**两态稿**：无 SKU 态 / 有 SKU 矩阵态。

**三、要砍要合（别照搬旧的 22 页）**
按委托书把 22 页收敛成 13 页：入驻链路 7→4，后台 15→9（数据分析并进工作台、通知/咨询/违规合并成"消息中心"三态、资料与预览合并、新增"操作员管理"）。

**四、图片比例**
主图/轮播 1:1（800×800）、详情图宽 750、店招 16:9；所有未上传位统一"虚线框 + 灰图标 + 点击上传 + 推荐尺寸小字"。

**五、流程**
**分两阶段**：先出**线框级信息架构稿**（重点让我确认砍并结构 + 商品编辑器交互 + 价格/SKU 口径）→ 我确认后 → 再出视觉稿。

具体每页简章、数据能力边界、视觉 token 全在委托书里。**商品编辑器是灵魂，请重点打磨。**
