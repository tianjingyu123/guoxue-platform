# 聚合三页重构设计方案：首页 / 发现页 / 个人中心

> 2026-07-10 · 智能体体验批窗口收尾产出 · 供下一窗口实施引用
> 背景：各板块（课程/商城/智能体/古籍/短视频/直播/文章/圈子/排盘…）已各自规范化，
> 现在重构三大聚合页。核心命题：**异构内容如何在聚合页上融为一体，同时各板块魅力不损**。

---

## 〇、总纲：三页一句话定位

| 页面 | 定位 | 用户动词 | 融合策略 |
|---|---|---|---|
| **首页** | 千人千面的内容消费流（留客主场） | **刷** | 强统一：所有内容压进同一张"卡骨架"，类型只是角标差异 |
| **发现页** | 平台能力全景图 + 主动探索中枢 | **找 / 逛** | 强差异：各板块以原生形态开"橱窗"，各展其貌 |
| **个人中心** | 资产账户 + 学习档案 + 身份成长 | **管 / 续** | 资产化：各板块以"我的 xx"资产形态出现，不是内容卡 |

**一融一异一资产**——首页求融（刷得下去），发现页求异（逛得出彩），个人中心求续（回得来）。
三页各司其职后，任何板块都有三个曝光面：首页流内被动分发、发现页橱窗主动陈列、个人中心资产复访。

---

## 一、首页：双列瀑布流（小红书式·已拍板）

### 1.1 为什么异构内容能"融为一体"——小红书的答案

小红书流里视频/图文/商品看起来是一体的，因为**所有卡片共享同一张骨架**，
内容类型只通过「封面内角标 + 底部指标」表达。我们照此立规：

### 1.2 统一卡骨架（铁律）

```
┌─────────────┐
│   封面区     │  ← 高度自适应（宽固定，高在 3:4 ~ 4:3 间浮动 = 瀑布流错落感）
│  (角标层)    │  ← 类型角标只出现在封面区四角，最多 2 个
├─────────────┤
│ 标题（≤2行）  │  ← 28rpx，--text-ink，超出截断
│ 头像 昵称    指标 │  ← 作者行：24rpx 头像+昵称（左）· 单一关键指标（右）
└─────────────┘
```

统一 token：圆角 24rpx、卡间距 16rpx、白卡 --card、阴影 0 2rpx 12rpx rgba(0,0,0,0.04)、
作者行字号 22rpx --text-soft。**任何类型不得改骨架，只能改封面内容与角标。**

### 1.3 各类型卡片样式（骨架内的差异化）

| 类型 | 封面 | 角标 | 底部右侧指标 | 点击去向 |
|---|---|---|---|---|
| 短视频 | 首帧竖图 3:4 | 右上时长胶囊 | ▶ 播放量 | 沉浸播放页 |
| 图文/文章 | 首图；**无图降级为"文摘卡"**：宣纸底+serif 摘句大字（国学差异化，小红书没有） | 无 | ♥ 点赞 | 文章详情 |
| 圈子帖 | 同文章 | 左下圈子名胶囊 | ♥ 点赞 | 帖详情 |
| 课程 | 课程封面 4:3 | 左上「课程」金标 | ¥价格/免费·xx人学 | 课程详情 |
| 商品 | 白底商品图 1:1 | 左上「好物」 | ¥价格（朱红加粗） | 商品详情 |
| 古籍 | 书封竖版 3:4 + 底部书名衬线条 | 左上「古籍」 | 共读 xx 人 | 阅读器/书详情 |
| 直播 | 直播封面 4:3 | 左上呼吸红点「直播中」 | 👁 观看数 | 直播间 |
| 排盘钩子卡 | 特制运营图（今日干支/宜忌） | 「工具」 | 测一测 › | 排盘首页 |
| 智能体引导卡 | 智玄形象+热门问题一句 | 「AI」 | 问一问 › | 智玄对话 |

### 1.4 混排与插卡策略（避免广告感）

- 主流 = 短视频/文章/圈子帖/古籍/直播/课程（内容位）
- **每屏（约 4~6 卡）至多 1 张交易/工具卡**（商品/排盘/智能体），固定间隔注入，可运营配置频率
- 排盘钩子卡是战略卡：570 万老平台用户的熟悉入口，冷启动用户前三屏必出 1 张
- 直播中的内容加权置顶前两屏（时效性最高）

### 1.5 交互逻辑

1. 顶部保留现有轻 tab（推荐/关注/直播/古籍/课程/商城），滚动后吸顶为胶囊条
2. 双列瀑布流无限滚动（复用 useList 分页基建）+ 下拉刷新换一批
3. 卡片长按 →「不感兴趣/减少此类」负反馈浮层（喂给推荐系统）
4. 点赞在卡上直接可点（乐观更新），其余互动进详情
5. 图片全部 lazy-load + 占位骨架屏（首屏 LCP 优先）
6. 【X5 红线】不用 aspect-ratio 控封面比例——用 padding-top 百分比撑高

### 1.6 后端配套

- 新增/扩展 `/feed/recommend` 混排聚合端点（recommend 模块已有底子）：
  返回统一信封 `{ type, id, cover, coverRatio, title, author{avatar,name}, metric{kind,value}, payload }`
- 前端 `components/feed/cards/` 组件库 + 注册表分发（**照搬本批富消息 rich-message 注册表模式**：
  新类型 = 新卡组件 + 注册一行，不动流主体）

## 二、发现页：全景导航 + 主题策展（定位论证）

### 2.1 定位思考

首页解决"没想好看什么"（算法喂），发现页解决两件首页做不了的事：
1. **"我想找某类东西"**——全景导航：一屏看清平台有什么，直达各板块正门
2. **"跟着平台逛主题"**——运营策展：跨板块打包的主题内容，这是发现页独有价值
   （例：「零基础学八字」= 入门课程 + 精选文章 + 智玄引导 + 推荐圈子，一个专题横跨四个板块）

一句话：**首页是算法的地盘，发现页是运营的地盘。**

### 2.2 页面结构（自上而下）

```
① 大搜索框（全局搜索主场·热词轮播跑马灯）
② 金刚区 2×5（板块正门：课程/商城/古籍/短视频/直播/圈子/智能体/排盘/听书/赛事）
③ 主题策展带（发现页灵魂）：横滑大专题卡，运营后台可配
   专题卡 = 主题大图 + 标题 + "含 3 门课·5 篇文章·1 个圈子" 摘要 → 专题落地页
④ 分板块橱窗（每板块一节，可配顺序）：
   节头 = 板块名 + 一句运营文案 + 「更多 ›」
   节体 = 横滑 3~5 张【该板块原生小卡】（各板块规范卡的缩小版，不强求统一——各展其貌）
   例：本周新课（课程卡）｜直播预告（直播卡）｜新书上架（书封卡）｜掌柜好物（商品卡）｜热门圈子（圈子卡）
⑤ 榜单角（二期可选）：热学课程榜 / 热读古籍榜 / 智能体热度榜
```

### 2.3 交互与配套

- 橱窗顺序、专题内容 = admin 运营位配置（新增 DiscoverSection 配置表或复用现有运营位机制）
- 专题落地页 = 通用"混合内容列表页"（一个页面模板吃所有专题）
- 与首页的边界纪律：发现页**不做无限瀑布流**（那是首页的事），到⑤为止，逛完有底

## 三、个人中心：资产 + 续接 + 身份

### 3.1 定位思考

个人中心的留客逻辑不是"展示内容"而是"**我的东西在这、我没做完的事在这**"。
各板块在此的发挥方式 = 沉淀为用户资产：我的课程表、我的书架、我的盘、我的会话、我的圈子。

### 3.2 页面结构（自上而下）

```
① 头部身份区：头像/昵称/等级 + 关注·粉丝·获赞 + 【书院会员金卡条】
   （会员显示权益/到期；非会员显示开通引导——会员是变现主线，位置要金贵）
② 「继续」区（最重要的复访钩子·横滑）：
   继续学习（课程进度条）｜继续阅读（古籍/电子书上次章节）｜
   继续对话（智能体最近会话）｜我的圈子新动态
   → 谁有进行中就出谁，按最近活跃动态排序；全无则显示推荐引导卡
③ 资产四宫格：钱包余额 ｜ 国学币 ｜ 优惠券 ｜ 积分
④ 订单条：全部订单 + 待付款/待发货/待收货/售后（角标数字）
⑤ 我的内容矩阵（2×4 宫格）：
   收藏 ｜ 足迹 ｜ 我的发布 ｜ 【我的排盘记录】（老工具用户最重的资产，必须一级露出）
   我的课程 ｜ 我的书架 ｜ 我的圈子 ｜ 我的会话
⑥ 身份成长区（按角色条件渲染·B 端化战略入口）：
   已是 → 讲师工作台 / 商家中心 / 站长分站 / 驿站后台 直达卡
   不是 → 「成为讲师」「我要开店」引导卡（存量用户 B 端转化漏斗的 C 端入口）
⑦ 服务与设置：客服 / 帮助 / 设置
```

### 3.3 交互要点

- ②「继续」区数据聚合一个 `/users/me/continue` 端点（课程进度/阅读进度/最近会话/圈子红点各取 top1-2）
- ⑥ 身份区按 `roles` 条件渲染，一个用户多身份则多卡横滑
- 整页宣纸白底 + 白卡分组，克制留白，与三页统一 token

## 四、落地路径建议（下一窗口）

| 阶段 | 内容 | 依赖 |
|---|---|---|
| P1 | 首页瀑布流：`/feed/recommend` 聚合端点 + `components/feed/cards/` 卡组件库（8 类卡）+ 注册表分发 + 负反馈 | recommend 模块扩展 |
| P2 | 发现页橱窗化：金刚区规范化 + 分板块橱窗（先静态配置后运营位）+ 专题卡与通用专题落地页 | admin 运营位 |
| P3 | 个人中心：「继续」聚合端点 + 头部会员金卡条 + 身份成长区 | 无硬依赖 |

- 三页共用的先做：统一卡 token 常量（styles/ 或 feed 组件内），杜绝各写各的
- 走查方式：沿用 V0 协作工作流（截图打包 → V0 出视觉稿 → 还原 uni-app）出高保真视觉稿再动手
- 【X5 红线备忘】禁 writing-mode / aspect-ratio / backdrop-filter 承载关键信息
