你好，帮我设计一个**移动端 H5**（390px 宽，纯静态 HTML 稿，稿内用 HTML 注释标数据来源与交互）的「**赛事**」板块参赛端。完整规格见附件《赛事板块-V0设计委托书 v2》，这里先讲清最关键的，请务必先理解再动手：

**一、定位（重大升级）**
赛事 = 平台的「**国学知识竞技场 + 易学分析师荣誉体系 + 自传播获客引擎**」。四个理念贯穿每一页：**自运转**（全流程系统驱动、定时赛自动开跑）、**高透明**（赛制/题目/评分/排名/奖励发放全公示）、**低维护**（自动组卷判分排名）、**高传播**（荣誉海报+邀请奖励+分析师身份三引擎）。
- 它是**知识与易学分析能力的比拼**，**不是占卜、不是赌博、不预测吉凶**。文案一律「知识竞技、学识荣誉」，严禁「预测中奖/赌运气/算命服务」式包装。

**二、三大新增机制（本委托灵魂）**
1. **三赛制晋级链**：线上答题赛（海选）→ 直播赛（复赛/决赛）→ 线下赛（顶级决赛）。赛事详情用**赛程时间轴**呈现当前阶段。
   - **直播赛是混合玩法**：① 实战 PK（选手对**赛事标准案例/命例样本**解卦断盘论断，评委打分+观众投票）② 直播答题（主持人出题，限时答，实时成绩）。⚠️实战PK对象是标准案例不是给真人算命（合规）。
   - **线下赛**：App 只做报名+签到核销（选手二维码↔工作人员扫码）+成绩公示+证书，线下比试本身在线下。
2. **易学分析师等级认证**：人才榜**不是讲师榜、是易学分析师榜**。等级见习→初级→中级→高级→资深，**战绩自动晋级**+认证标识，打通达人咨询接单变现。要「我的分析师档案」（等级+晋级进度+战绩+认证徽章）。
3. **邀请人奖励（🔴合规单级）**：被邀请人参赛**获奖得实物**时，**直接邀请人（仅一级）得对应实物**。挂钩**真实获奖**（非拉人头计酬）、**仅一级**（不多级）、协议明示。要「邀请机制说明」+「我的邀请奖励（含发放公示）」。

**三、双灵魂（沿用·做到位）**
- **答题体验**：三档倒计时（正常→≤5分金→≤1分朱红呼吸）+ 答题卡抽屉三态 + 交卷仪式 + 专注提示。
- **荣誉呈现**：金银铜领奖台 + 红金证书 + 9:16 荣誉海报（带邀请归因）+ 名次/等级徽章统一体系全板块复用。

**四、高透明（专门界面）**
赛制规则公示 + 赛后题目公示 + 排名实时 + **奖励发放公示**（含邀请奖励），防暗箱、建公信力。

**五、图片比例**
赛事封面/直播预告 16:9；荣誉海报 9:16；证书竖版 3:4；徽章/头像/等级徽章/签到码 1:1。

**六、视觉基调**
宣纸白 #FAF8F5、**朱红 #C41E3A（进行/倒计时/CTA）× 金 #C9A96E（荣誉/名次/等级/证书）** 双主色。直播赛要现场感+实时（LIVE标/投票条/PK分屏）、分析师等级要进阶感（青铜→鎏金）。**国学雅致、竞技庄重**——禁荧光渐变、禁娱乐贴纸、禁赌博抽奖浮夸。

**七、流程**
**分两阶段**：先出**线框级信息架构稿**（重点确认三赛制晋级链 / 分析师等级 / 邀请奖励 / 高透明四条主线）→ 我确认后 → 视觉稿。

共 16 页（A1-A16），灵魂页 = A4 答题 / A6 直播赛间（多态）/ A9-A11 荣誉 / A12-A13 分析师 / A14-A15 邀请裂变。具体每页要点、数据边界、合规红线、视觉 token 全在委托书里。**做出「自运转、高透明、低维护、高传播」的荣誉生态气质。**
