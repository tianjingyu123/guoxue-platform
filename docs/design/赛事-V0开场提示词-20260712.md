# 赛事板块 · 给 V0 的开场提示词（2026-07-12）

> 用途：连同《赛事板块-V0设计委托书-20260712.md》一起发给 V0，先定调再让她按委托书出稿。

---

你好，帮我设计一个**移动端 H5**（390px 宽，纯静态 HTML 稿，稿内用 HTML 注释标数据来源与交互）的「**赛事（线上国学答题赛）**」板块参赛端。完整规格见附件《赛事板块-V0设计委托书》，这里先讲清最关键的几点，请务必先理解再动手：

**一、定位**
这是平台的「**国学知识竞技场 + 荣誉体系 + 获客裂变入口**」（参赛用户一侧）。流程：**发现赛事 → 报名 → 限时答题 → 出成绩排名 → 领证书 / 生成海报分享**。
- 它是**国学知识水平的比拼**（八字/风水/紫微/六爻/奇门等知识点答题），**不是占卜、不是赌博、不预测吉凶**。文案一律以「知识竞技、学识荣誉」立意，**严禁**任何「预测中奖/赌运气/占卜结果」式包装。
- 只做参赛者 C 端；出题/评审/赛程编排在管理后台，不用画。

**二、这次是"整体重构打磨"，不是砍并**
参赛侧 **10 个页面**功能都已能跑（首页 / 详情 / 答题 / 报名 / 成绩详情 / 排行榜 / 证书 / 海报 / 人才榜 / 往届），**页面一个不砍、逐页对应升级**。当前短板是视觉平淡、缺乏竞技与荣誉气质——请把它做成有「**竞技张力 + 荣誉殿堂**」质感的精品。

**三、灵魂一：答题页（重点设计·A3）**
这是选手唯一"实时较量"的时刻，要**沉浸、专注、有压力而不慌乱**：
- 顶部**倒计时**常驻醒目，**三档变色**：正常 → ≤5 分钟（转金/橙）→ ≤1 分钟（转朱红 + 轻微呼吸感）。
- 题干大字克制专注；题型标（单选/多选/填空/论述）+ 分值清晰；**单选点选高亮、多选可勾多项且明确标"多选"**。
- 底部：上一题 / 题号进度（7/20）/ 下一题 / **标记本题**。
- **答题卡抽屉**（半屏上推）：宫格题号三态——已答（朱红实心）/ 标记（金）/ 未答（灰描边），点击秒跳。
- **交卷**二次确认（列总题/已答/未答/标记数），有**收官仪式感**。
- **专注提示**：切屏回来温和提示"已离开 N 次，请专注"（提示为主不惩罚）。

**四、灵魂二：荣誉呈现（排行榜 A6 / 证书 A7 / 海报 A8）**
竞技的回报是荣誉，要**看得见、值得炫**：
- **排行榜**：顶部金银铜**领奖台**（冠军最高最亮·金），完整榜单里**"我的排名"醒目高亮** + 晋级/淘汰态。
- **证书**：红金纸质、双线框、朱红钤印、防伪编号，**值得截图收藏**的仪式感。
- **荣誉海报 9:16**：名次成绩荣誉卡 + 赛事二维码 + Slogan，**自带炫耀 + 拉新钩子**；未获奖态文案转"邀请你来同台竞技"。
- **名次徽章**（冠/亚/季/晋级/参与）做**一套统一视觉**，在排行榜、成绩、人才榜、证书、海报间复用。

**五、图片比例**
赛事封面/Hero **16:9**；荣誉海报 **9:16（1080×1920）**；证书 **竖版 3:4**（前端绘制）；徽章/头像/领奖台头像 **1:1**。

**六、视觉基调**
全站统一：宣纸白 #FAF8F5、卡片白 #FFFFFF、**朱红 #C41E3A（进行中/倒计时/主 CTA）× 金 #C9A96E（荣誉/名次/证书/徽章）** 双主色、文字 #2C2C2C/#6E6E73/#999、圆角 18px。**国学雅致、竞技庄重**——禁荧光渐变、禁娱乐贴纸、禁赌博抽奖式浮夸。

**七、流程**
**分两阶段**：先出**线框级信息架构稿**（重点确认参赛状态流"报名中/进行中/已结束" + 答题页交互 + 荣誉呈现）→ 我确认后 → 再出视觉稿。

具体每页要点、数据能力边界、视觉 token 全在委托书里。**答题体验（灵魂一）+ 荣誉呈现（灵魂二）是重点，请做出竞技张力与荣誉仪式感；名次/证书/徽章多用金色。**
