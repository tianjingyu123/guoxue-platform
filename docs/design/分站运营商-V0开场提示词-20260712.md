# 分站运营商板块 · 给 V0 的开场提示词（2026-07-12）

> 用途：连同《分站运营商板块-V0设计委托书-20260712.md》一起发给 V0，先定调再让她按委托书出稿。
> 注：若 V0 已按上一版出过稿（做成"站长装修分站页面"），请改用《分站运营商-V0修正提示词》纠正；本开场词用于全新开场。

你好，帮我设计一个**移动端 H5**（390px 宽，纯静态 HTML 稿，稿内用 HTML 注释标数据来源与交互）的「**分站运营商**」板块。完整规格见附件《分站运营商板块-V0设计委托书》，这里先讲清最关键的几点，请务必先理解再动手：

**一、三个「没有」（最容易做偏，先记住）**
1. **没有分站装修**：站长动不了任何风格、布局、配色、主题色、模板。平台长什么样，站长的用户看到的就是什么样。
2. **没有独立分站页面**：不存在"某某分站"的落地页，也没有"站长编辑自己页面布局"的功能。
3. **没有独立账号**：运营商/站长不单独登录、不单独设密码、没有独立后台，沿用总平台用户体系。

**二、站长唯一做的事 = 在主推位选品**
站长进一个「**主推位管理面板**」，竖列 9 个板块（**首页 / 商城 / 课堂 / 圈子 / 智能体 / 古籍 / 文章 / 短视频 / 直播**），每个板块挂 **6 个「＋」主推位**。点＋拉起选品半屏面板（搜索+分类）→ 选内容锁定。这些主推内容**分散注入平台各板块的主推位**，展示给该站长引流来的归属用户；发现页自动聚合。**不是**在某个分站页面上编辑。

**选品分类口径（别搞错）**：首页的＋可选所有类别，分类 Tab **按板块分**（课堂/商城/圈子…），**绝不是**按八字/六爻/奇门；其余板块只能选本板块内容；直播只能选正在/预约直播（结束自动下架）。

**三、两级运营商 + 费用（转化页文案按此）**
- **一级运营商**（对外销售）：4999 元得 1+5 个分站（1 自用 + 5 可售），团队管理奖 = 名下站长收入 10%。
- **二级运营商**（不对外销售）：随线下驿站赠送开通。
- **分站**：无门槛加入，系统租赁费 999 元/年（收入累计<5倍免续交；首年累计≥10倍退还，仅第一年）。
- **开通页禁承诺式宣传**（不写已加入家数/收益），改**风险提示**（无推广渠道勿加入、有投资亏损风险）。

**四、要产出的页面**
运营商侧（工作台/团队/邀请/沉寂/分析/名额/设置）+ 站长侧（工作台 / **主推位管理面板** / 选品库半屏面板 / 客户/收益/素材/海报）+ 转化协议（成为运营商/成为站长/协议）。**不要**做：分站落地页、装修编辑器、布局工具、独立登录后台。

**五、流程**
**分两阶段**：先出**线框级信息架构稿**（重点让我确认三个"没有"、主推位选品交互、砍并结构）→ 我确认后 → 再出视觉稿。

具体每页简章、数据能力边界、视觉 token 全在委托书里。**站长主推位选品自服务是灵魂，请重点打磨；千万别做成"站长装修分站页"。**
