## 一、定位拍板

### 1.1 一句话定位（内部总纲）

> **用 AI 和线下网络，让国学变成现代人用得上的学问、过得上的生活、做得成的事业。**

三个"用得上"对应三类人，也对应三台收入引擎：

| 面向 | 对外表达 | 收入引擎 |
|---|---|---|
| **学习者（大众C）** | 「学国学，有 AI 相伴、有名师在侧」 | 课程/会员/电子书/打赏 |
| **生活者（付费C）** | 「过有讲究的生活」——择日、起名、咨询、雅集 | 咨询/工具/商城/线下活动 |
| **从业者与渠道（B）** | 「你的国学事业，交给数字化」 | SaaS 服务费/交易佣金/驿站/研究院认证 |

### 1.2 增长飞轮（平台的发动机）

```
从业者入驻（工具+客源） → 供给变厚（课程/咨询/直播/驿站）
      ↑                                ↓
认证与数据沉淀（研究院/洞察）    学习者进来（内容+AI 体验）
      ↑                                ↓
分销与驿站网络放大交易 ← 交易发生（课程/咨询/商城）
```
AI 是飞轮的润滑剂：学习者侧降低门槛（伴读/白话对照），从业者侧提高效率（经营顾问/客户洞察），平台侧守住信任（内容审核/风控）。

### 1.3 差异化三支柱（对手抄不走的）

1. **AI 原生**：老牌国学站没有 AI 基因，新 AI 产品没有国学纵深。我们两者都有。
2. **OMO 线下网络**：驿站让平台长在真实世界里，纯线上对手无法复制。
3. **从业者全链路**：获客→转化→交付→服务→复购的 SaaS 闭环 + 研究院认证 = 从业者离开成本极高。

### 1.4 不做什么（定位的另一半）

- 不做效果承诺型算命（合规红线 R4，也是品牌自杀）；
- 不做无出处的内容堆砌（CLAUDE.md 五维质量标准是铁律）；
- 不做廉价红包裂变（文化产品的增长要有文化的样子）；
- 短期不做泛心理/泛健康扩品类——先把国学做成标杆再说。

### 1.5 品牌人格

**「有学问的朋友」**——温和、可信、讲出处、不神叨。全平台文案统一校准到这个声音（对照：不是神秘大师，不是冰冷工具，不是营销号）。

### 1.6 经营哲学：无痕商业化（用户钦定·2026-07-03）

> 「这是内容平台、工具平台、工作平台——看上去没有主推销售，但处处是销售。
>   从主动推荐到创造需求，引导付费。」

**三条铁律**：
1. **台前永远是价值**：内容、工具、工作是用户看到的一切；商品/课程/圈子作为「此刻正好需要」的答案出现，不作为货架强推。
2. **销售发生在场景里**：每个高价值时刻埋一个自然的付费引子——

| 场景（价值时刻） | 自然引子（创造需求→引导付费） | 状态 |
|---|---|---|
| 古籍读到精彩处 | 「这一篇有名师精讲」→ 课程 | 🔲 |
| 排盘/运势结果页 | 「想听更深的解读」→ 达人咨询 | 🔲 |
| 诗词赏析页 | 应景雅物（字帖/香品/茶器）→ 商城 | 🔲 |
| 节气/民俗内容 | 节气限定礼盒/活动 → 商城/驿站 | 🔲 |
| AI 伴读用到额度上限 | 会员畅享 → 会员 | 🔲（待会员定价） |
| 圈子优质讨论 | 「圈主的系统课」→ 课程/入圈 | 🔲 |
| 今日学一点卡片 | 内容卡本身即课程/古籍/诗词入口 | ✅ 已上线 |
| 学习成就/晋级时刻 | 「进阶之路」推荐下一门课 | 🔲（随游戏化） |

3. **克制即品味**：每页至多一个商业触点；推荐必须与当前内容强相关；永不打断阅读/工具流程弹窗卖货。营销感视觉元素（爆款角标/倒计时轰炸）从 C 端心智区清除。

**落地机制**：场景触点统一走推荐引擎（recommend 模块）+ 埋点归因（触点曝光→点击→成交漏斗），每个触点用数据说话，转化差的触点撤掉——无痕的前提是有效。

## 二、通往标杆的三大战役

### 战役一「第一印象」（当前·T4 主战场）
一个新用户 30 秒内应该经历：**看懂我们是谁 → 被一件事打动 → 留下来**。
1. **首页信息架构重构**：20+ 模块按定位重排——学习（课程/古籍/诗词）、生活（工具/咨询/商城）、社区（圈子/直播）三大心智区；从业者/渠道入口收进「事业」入口。
2. **新手首launch旅程**：兴趣选择（3 秒）→ 千人千面首页 → 啊哈时刻（免费 AI 体验：今日一签/古籍白话对照/AI 伴读一段《论语》）。
3. **游戏化成长体系**：学分/等级/称号（书童→秀才→举人→进士…）+ 连续学习 streak + 成就；激励对准内容创作与付费转化（发布优质内容的积分 >> 签到）。

### 战役二「增长飞轮」
4. 社交裂变（T5）：双人合盘、师徒邀请、以文会友——文化原生玩法。
5. 客户洞察复制到驿站/圈主；推送召回（密钥解冻后）。
6. 数据看板（admin）：DAU/留存/漏斗/模块热度——数据驱动运营。
7. **SEO 战线（新识别的大杠杆）**：46 万章公版古籍是天然的搜索流量金矿，但 uni-app hash 路由搜索引擎不可见。建独立的内容 SSR 站（古籍/诗词详情页）反哺 App，免费自然流量长期复利。

### 战役三「护城河铸深」
8. 内容规模化（C 线）：古籍 62→千部、诗词 60→万级，后台批量注入。
9. AI 三件套（T7）：内容质量评分+流量倾斜、活首页、创作辅助。
10. 研究院认证体系（T9）：从业者的「金字招牌」，供给质量的守门员。
11. 多租户/国际化蓝图（T11）：为道商世界等品牌扩张和出海做地基。

### 3.5 病毒式裂变方案库（学习·交流·分享驱动，非红包驱动）

> 用户指令：分销之外，要更多「让大家一起学习、交流、分享、受益」的文化原生裂变。
> 共同地基已就绪：全平台单一 ref 分享链接 + 归因 + 漏斗统计。每个方案 = 一个「值得分享的时刻」。

| # | 方案 | 裂变机制 | 成本 | 优先级 |
|---|---|---|---|---|
| V1 **学习成就卡** | 连续学习 N 天/晋级新称号 → 生成雅致成就卡（金句+称号+天数）分享；好友点开见「TA 在热卜读到第 X 天」+ 一键同读 | 低（游戏化②的自然延伸） | P0 |
| V2 **每日一签分享** | 今日一签结果卡（签文+古籍出处）天然社交货币；好友点开可抽自己的签 | 低 | P0 |
| V3 **共读拼团** | 「7 天共读《论语》」组队（3-5 人成团），全员完成各得学分加成+结业卡；缺人 → 主动邀请 | 中 | P1 |
| V4 **双人合盘** | 合婚/合作盘需双方生辰 → 必须邀请对方注册授权，深度报告双方可见（任务五原案） | 中（依赖排盘线） | P1 |
| V5 **师徒传承** | 老用户收徒（新用户拜师）：徒弟学习进度给师父加「传道值」（荣誉榜非现金，避开传销红线），出师仪式双方成就卡 | 中 | P1 |
| V6 **以文会友·飞花令** | 诗词接龙/飞花令对战，战报卡分享应战；输家看赢家战绩必点 | 中 | P1 |
| V7 **提问悬赏外溢** | 圈内好问题生成「悬赏帖」分享站外，答题需注册；答案精华回流圈子 | 低 | P2 |
| V8 **节气仪式** | 24 节气限定内容+限定成就卡（错过即无），节气日全平台推送分享 | 低（D5 联动） | P2 |
| V9 **家庭书房** | 家人共享学习空间（父母子女共读），儿童启蒙内容拉动家庭多账号 | 高 | P3 |
| V10 **结业证书** | 课程结业证书带编号与讲师签章，分享即为课程背书（讲师也愿转发） | 低 | P2 |

**执行原则**：每个裂变时刻 = 「值得炫耀的产出物 + 好友点开有即时价值 + ref 归因闭环」。V1/V2 随游戏化落地（当前批次），V3-V6 逐批推进。
