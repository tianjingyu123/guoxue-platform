# 平台上传图片尺寸规范（董事长下发·2026-07-12·权威标准）

> 本文件为**用户上传素材统一规范的唯一真源**。各上传入口的比例/校验/引导/占位/处理均以此为准。
> 首页/发现页等容器页的卡片封面比例，最终取决于各素材的上传比例（本表）。

## 一、各场景上传尺寸

| 场景 | 推荐尺寸 | 宽高比 | 最大 | 格式 | 用途 |
|---|---|---|---|---|---|

| 用户头像 | 200×200 | 1:1 | 1MB | 同上 | 主页/评论 |
| 文章配图 | 960×1280 | **3:4** | 2MB | 同上 | 首页卡片 |
| 帖子图片 | 宽1080·高不限 | 不限 | 5MB | 同上 | 多图最多9张 |
| 短视频封面 | 960×1280 | **3:4** | 2MB | 同上 | 首页卡片 + 播放页 |

## 二、上传前端引导（每个上传入口）
1. **尺寸提示**：上传按钮旁灰色小字「推荐尺寸 1280×720px · 支持 JPG/PNG/WebP · 最大 2MB」
2. **裁剪引导**：比例不符时弹裁剪工具，提示「你的图片 4:3，推荐 16:9，请调整裁剪区域」
3. **上传后预览**：展示实际展示效果供确认
4. **未上传占位**：浅色虚线边框 + 灰色图标 + 「点击上传」

## 三、存储与处理
- 格式：上传支持 JPG/PNG/WebP，存储统一转 WebP
- 压缩：自动压缩留原图备份；缩略图(宽400·列表卡)/中图(宽750·详情)/原图(点击放大)
- CDN 分发；列表懒加载·首屏优先

## 四、开发落地清单（系统性任务·分期）
1. **上传校验**：文件大小超限提示 / 格式不支持提示 / 最小宽度≥400px 校验
2. **上传引导**：每入口推荐尺寸+格式提示文字 / 比例不符弹裁剪 / 上传后效果预览
3. **图片处理**：自动压缩留原图 / 生成缩略图(400)+中图(750) / CDN 分发
4. **占位图**：统一「浅色虚线边框+灰色图标+点击上传」·各场景尺寸文字适配

## 五、首页/容器页卡片比例对照（据本规范·实现执行）
- 课程/直播 → 16:9 源图（首页统一 3:4 容器 cover 裁剪填满 / 或按容器规范）
- 商品/头像/智能体 → 1:1
- 圈子/文章/短视频 → **3:4**（首页卡与板块列表均 3:4）
- 电子书 → 2:3
- 帖子/商品详情 → 宽度定·高不限
