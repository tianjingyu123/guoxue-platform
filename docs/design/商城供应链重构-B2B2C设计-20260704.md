# 商城/供应链重构 · B2B2C 设计（Day 1）

> 2026-07-04 · 现状：货源=网上采、零售≈0、供应链空心。生态定位（引总设计）：商城=交易线的「货」，北极星=可分销 SPU 数 × 分销者人均 GMV——1 亿主力线的一半。

## 一、第一性问题：从业者凭什么从平台进货？

拼多多更便宜、1688 更全。平台商城的存在理由必须是**拼多多给不了的五件事**：

| # | 差异化 | 说明 |
|---|---|---|
| 1 | **一件代发到"他的客户"** | 从业者不压货、不打包、不发货——推荐给客户，供应商直发，物流状态自动同步给从业者 |
| 2 | **白标贺卡（获客回流器）** | 包裹内附从业者署名贺卡+名片二维码（"XX 老师为您甄选"）——客户收货=从业者的品牌触达，扫码=归因回流平台 |
| 3 | **分佣自动化** | 客户按零售价购买（全员同价·R2 合规），从业者佣金自动结算进钱包（引擎已有），无需买低卖高、无资金风险 |
| 4 | **场景化选品** | 类目按"客户人生场景"组织（乔迁/合婚/开业/本命年/学业），与排盘咨询场景直接咬合——从业者服务到哪个场景，顺手就有对应的货 |
| 5 | **平台严选信任背书** | 保证金+抽检+严选标（Day 2 履约信用体系承接），从业者敢推荐给自己的客户（他赌的是自己的口碑） |

**模式定稿：分销+代发**（客户按零售价买、从业者拿佣金），不做"批发进货自加价"（平台外交易失控、税务与售后黑洞）。从业者自用可享内部价（分销者本人下单立减——复用站长自购立减机制）。

## 二、货从哪来：三步走冷启动（自营先行）

**关键决策（待拍板）：自营先行**——先由平台自营做出首批 100-200 SPU 的样板与销量数据，再拿数据招商。没有销量数据，好供应商不会来；先开放入驻只会招来一批 1688 二道贩子，砸掉"严选"招牌。

| 阶段 | 动作 | 目标 |
|---|---|---|
| S1 自营严选（M1-2） | 平台注册自营供应商主体；从产业带直采：香品（厦门/永春）、瓷器茶器（景德镇/德化）、文房（宣城/湖州）、木器手串（福建仙游）、字画（现有书画资源）；每类目 20-30 SPU；统一质检与拍摄 | 100-200 SPU·树立价格与品质基准 |
| S2 定向招商（M3-4） | 拿自营销量数据定向邀请产地厂商入驻（商家系统已建·开 flag）；供应商政策：保证金+首批寄样质检+严选审核；**从业者反向推荐供应商**（他们最知道什么好卖·推荐成功给推荐奖励） | 供应商 30-50 家·SPU≥500（军令状） |
| S3 生态开放（M5+） | 入驻常态化+履约信用体系（Day 2 设计）自动优胜劣汰；类目扩展跟着咨询热点走（行业洞察中心选品建议） | SPU 千级·爆款迭代 |

## 三、类目体系：按"客户人生场景"组织（非普通电商类目）

```
主类目（供给视角）：香品香器 / 文创摆件 / 文房字画 / 茶器雅物 / 服饰配饰 / 典籍图书 / 定制服务(印章/手串/名字画)
场景标签（销售视角·可多挂）：乔迁新居 / 合婚嫁娶 / 开业大吉 / 本命年 / 学业考试 / 长辈寿诞 / 节气时令
```
- 场景标签是无痕商业化的接线口：排盘结果页/咨询结束页/节气日 → 按场景标签取货推荐
- **合规定性（R4 红线）**：全部商品定性为"民俗工艺品/文化礼品"，详情页与营销物料**禁止功效承诺**（开运/化解/辟邪字样进违禁词库），用"寓意"表述（"寓意平安"），已有三层审核漏斗把关

## 四、价格与分佣结构（示例·比例待拍板）

零售价 ¥100（全员同价）拆分：
```
供应商结算价 55-65（含货+发货）
平台毛利   10-15（质检/流量/售后兜底）
分销佣金池  25-30 ——按 SettlementRule 两级：直推者(从业者/圈主/驿站) 20-25 + 上级(站长/运营商) 5
```
- 从业者自用：本人下单按"零售价-佣金池"立减（复用自购立减·不产生佣金·防套利已焊死）
- 定制类（印章/名字画）佣金池可到 35-40%（高毛利高激励）

## 五、代发与白标链路（核心新能力）

1. **代客推荐**：从业者在 CRM 客户档案里点"推荐商品"→ 生成带 ref 的商品卡发给客户 → 客户自己下单支付（资金合规·平台担责售后）
2. **代客下单**（可选二期）：从业者替客户下单填客户地址，客户微信确认支付——先不做，链路复杂且资金关系模糊
3. **白标贺卡**：下单归因到从业者时，订单自动附贺卡任务给供应商（打印模板：从业者名号+祝语+名片二维码）；供应商发货时放入——**每个包裹都是从业者的获客物料，也是平台的归因入口**
4. 物流状态同步：客户和归因从业者都可见（从业者工作台"我推荐的订单"卡）
