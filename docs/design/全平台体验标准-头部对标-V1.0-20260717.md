# 全平台体验标准 V1.0（头部对标 · 2026-07-17）

> 董事长要求：对标头部平台（小红书 / 抖音 / 今日头条 / 微信公众号），达不到就是不合格。
> 本文档是全平台 UI 与交互的**唯一验收标准**。后续所有前端改动，出厂前逐条过第十节红线。
> 立标依据：多轮优化后平台仍"随便点几下就感觉低端、不严谨"——根源不是单点功能坏，
> 而是全局质感失守。本标准把"质感"拆成可量化、可验收的硬指标。

---

## 一、低端感的五大来源（诊断框架）

修任何页面前先对照自查，命中一条就是不合格：

1. **不一致**：同类元素在不同页面长得不一样（返回键五花八门、字号随手写、间距随缘）。
2. **字号偏小 + 层级不清**：正文 24/26rpx 挤成一团，标题和正文差 2rpx 分不出主次。
3. **触控热区小**：图标 32rpx 裸奔无 padding，手指点不中；返回箭头"细到看不见"。
4. **默认样式裸奔**：原生 button 边框、默认蓝链接、无兜底的裂图、无 loading 的白屏。
5. **密度失衡**：要么信息挤到贴边，要么大片空白无内容层级。

## 二、字体规范（750rpx 设计宽 · 全平台唯一阶梯）

**只允许以下字号**（写在全局 CSS variables，禁止再手写魔法数字）：

| Token | 字号 | 字重 | 行高 | 用途 |
|---|---|---|---|---|
| `--fs-display` | 44rpx | 700 | 1.3 | 页面大标题、金额强调 |
| `--fs-title-lg` | 36rpx | 600 | 1.4 | 详情页标题、区块大标题 |
| `--fs-title` | 32rpx | 600 | 1.4 | 卡片标题、导航栏标题、区块标题 |
| `--fs-body` | 30rpx | 400 | 1.6 | **正文**：评论内容、帖子内容、简介 |
| `--fs-body-sm` | 26rpx | 400 | 1.6 | 次要说明、昵称、标签文字 |
| `--fs-caption` | 22rpx | 400 | 1.5 | 时间、计数、辅助信息（**全平台最小字号，禁止更小**） |
| 文章正文特例 | 34rpx | 400 | 1.85 | 文章详情页正文（对标公众号 17px） |

- 字重只用 400 / 500 / 600 / 700 四档。
- 文字颜色三层（浅色模式）：主文字 `#1f1f1f`、次要 `#666`、辅助 `#999`；**禁止纯黑 #000**。
- 现状正文普遍 26/28rpx → 统一提到 30rpx，这是"字体偏小"的直接解法。

## 三、触控热区规范

1. **任何可点击元素热区 ≥ 88×88rpx**（44pt，iOS HIG 标准）。图标本体可以小（32~44rpx），热区用 padding 撑够。
2. **返回按钮全平台统一**：图标 40rpx、线宽不细于 3rpx、热区 88×88rpx，收敛为公共导航组件，禁止各页自写。
3. 列表可点行高 ≥ 96rpx；底部主操作按钮高 88~96rpx。
4. 相邻可点元素间距 ≥ 16rpx，防误触。

## 四、间距 / 圆角 / 阴影 Token

- **间距只用 8 / 16 / 24 / 32 / 48rpx** 五档；页面左右安全边距统一 **32rpx**。
- 圆角：卡片 16rpx、图片 12rpx、按钮 12rpx（胶囊 999rpx）、半屏弹窗顶部 24rpx。
- 阴影只允许一档：`0 4rpx 16rpx rgba(0,0,0,0.06)`；禁止黑重阴影。
- 分割线 `1rpx solid rgba(0,0,0,0.06)`，能用留白分隔就不画线。

## 五、卡片容器规范（沿用三层模型：容器≠素材≠适配）

- 容器比例只有三种：**竖卡封面 3:4、大卡 2:1、方图 1:1**。课程、商品、直播、短视频、圈子、文章卡一律归入其一。
- 封面图 `aspectFill` + smart-cover 兜底，**任何裂图/拉伸/白块都是不合格**。
- 标题最多 2 行 ellipsis；信息层级严格三层：标题(32rpx/600) > 价格或作者(26~30rpx) > 数据计数(22rpx/#999)。
- 价格统一样式：`¥` 22rpx + 整数 32rpx/600 红 `#e63e31`，免费/会员免费用绿色标签。
- 卡片内边距 24rpx，卡片间距 16~24rpx。

## 五·附、素材上传规范（董事长 2026-07-17 增补：发布处必须给用户尺寸指导）

**所有上传入口（图片/视频）必须展示建议尺寸文案**，并尽可能提供对应比例的裁剪框。
目标：用户按标准传 → 卡片/详情页展示协调统一，从源头消灭裂图与构图失衡。

| 素材 | 比例 | 建议分辨率 | 用于 |
|---|---|---|---|
| 竖版封面 | 3:4 | 900×1200（最低 750×1000） | 课程/商品/古籍/圈子竖卡封面 |
| 横版封面 | 16:9 | 1280×720（最低 960×540） | 文章封面/直播封面/课程详情头图 |
| 大卡横幅 | 2:1 | 1500×750 | 运营 banner / 大卡位 |
| 方图 | 1:1 | 800×800 | 头像/店铺 logo/商品方图 |
| 短视频 | 9:16 竖屏 | 1080×1920 | 短视频内容 |
| 文章内图 | 宽 ≥1080px | 横图 4:3 或 16:9 | 文章正文配图 |

- 上传组件（CosImageUpload / VodUpload）统一支持 `hint` 展示建议尺寸，各发布页按上表配置。
- **文章配图必选**：发布文章必须有封面图（无图文章在信息流与详情页效果不达标）。

## 六、交互路径上限（对标头部平台的"最短路径"）

| 场景 | 上限 | 标准形态 |
|---|---|---|
| 评论 | **1 步开始输入** | 详情页底部**常驻输入条**，点击即弹键盘；禁止"点评论→进列表页→再点输入框" |
| 发帖 | **≤2 次点击到编辑页** | 入口(+号)→编辑页→发布，**禁止中间选择弹窗**；类型在编辑页内 tab 切换 |
| 分享 | 1 步出面板 | 点分享直接弹（海报/微信/链接） |
| 点赞/收藏 | 0 中间步骤 | 点击即生效 + 微动效反馈，失败再回滚 |
| 操作成功 | toast + 自动返回 | 禁止"操作成功【确定】"弹窗（破坏性操作、资金操作除外） |

## 七、评论区标准（内容社交平台的核心 · 对标小红书）

**统一为一个公共评论组件**，全平台（帖子/文章/短视频/课程评价）复用：

```
[头像64rpx圆] 昵称26rpx#666 [作者标签]          [♡ 点赞列]
              评论内容 30rpx #1f1f1f 行高1.6      (心形+计数
              时间·回复 22rpx #999                竖排右对齐)
              └ 子回复缩进(左移头像宽) >2条折叠"展开N条回复>"
```

- 热评在前、作者评论带"作者"金色小标签；长评论 6 行折叠"展开"。
- 点赞心形微动效：点击 scale 弹跳 + 变红 `#e63e31`；已赞态持久。
- **底部常驻输入条**：灰底圆角胶囊 + 占位"说点什么…" + 表情入口；点击弹键盘，发送后乐观插入列表顶部。
- 空态文案有温度："还没有评论，来抢沙发～"，不用"暂无数据"。

## 八、文章详情页标准（对标今日头条 / 微信公众号）

列表卡片**保持现有通用卡片不动**（董事长拍板）；详情页重做为：

```
标题 44rpx/700/1.4（可两行）
作者栏：头像72rpx + 昵称30rpx/500 + 时间22rpx#999 + [关注]胶囊按钮
正文 34rpx / #333 / 行高1.85 / 段间距32rpx（统一 article-content 富文本样式）
  - 图片通栏、圆角12rpx、点击可预览
  - blockquote：左 6rpx 竖线 + 浅灰底
  - h2/h3 递减字号、加粗；有序/无序列表正常缩进
底部固定互动栏：点赞 / 评论 / 收藏 / 分享（评论走第七节组件）
文末：相关推荐（3~5 条通用文章卡）
```

## 九、带货组件标准（对标抖音）

统一半屏商品面板组件 `GoodsSheet`（商品图+名称+价格+"去购买"），三处复用：

1. **短视频**：播放页左下角**商品浮卡**（图 60rpx + 名称单行 + 价格红字），点击弹 GoodsSheet 或直达商品详情。
2. **直播**：底部**购物袋图标**（带商品数角标）+ 讲解中商品浮卡，点开半屏商品列表。
3. **文章**：正文中插入商品卡片（图 + 名 + 价 + "去看看"按钮）。

跳转一律带归因参数（分佣归因 V2 已有后端），转化路径 ≤2 步到收银台。

## 十、验收红线（每页出厂检查清单）

1. 字号全部命中第二节阶梯，无魔法数字；正文 ≥30rpx、最小字号 ≥22rpx。
2. 无任何 <88×88rpx 的可点击热区；返回键用公共组件。
3. 卡片过第五节容器规范，无裂图/拉伸/白块。
4. 三态齐全（loading 骨架 / 空态有温度文案 / 错误可重试），无白屏。
5. 交互路径不超第六节上限。
6. 深色/浅色两种模式无花屏、无不可读文字。
7. `vue-tsc --noEmit` EXIT 0。
