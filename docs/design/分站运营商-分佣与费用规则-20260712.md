# 分站运营商 · 分佣与费用规则（后端权威口径 · 2026-07-12 董事长拍板）

> 本文是分站运营商板块「钱」的唯一口径。分三层：**① 已在生产生效** / **② 已落后台配置(参数)** / **③ 待建计费引擎(红线·真人实现)**。

## 角色与两级
- **一级运营商**：对外销售（渠道 ONLINE）。**4999 元** 得 **1+5 个分站**（1 自用 + 5 可对外销售）。团队管理奖 = 名下站长收入的 **10%**。
- **二级运营商**：**不对外销售**，随**线下驿站赠送**开通（渠道 OFFLINE）。团队管理奖沿用现存 OFFLINE 默认 **20%**（本次未改）。
- **站长（分站）**：无门槛加入；**系统租赁费 999 元/年**。
- **无独立账号体系**：运营商/站长不单独登录、不单独设密码，沿用总平台用户体系。

## 一、已在生产生效（无需改动）
- **团队管理奖**：`commission.service` 已实现——管理奖 = 名下站长实得佣金 × `operator.mgmtRate ?? channelType 默认`（**ONLINE 0.10 / OFFLINE 0.20**·佣-V2-P1·2026-07-04 拍板）。→ 一级 10%、二级 20% 已自动生效。
- **退款冲正**：`commission.service.reverseCommission` 已逆向 station 收益 + operator 管理奖 + 平台抽成（同事务·幂等）。
- **站长分销佣金**：CommissionConfig 各 configKey 费率已播种（课程 20% 等）。

## 三、待建计费引擎（🔴 MONEY 红线·后期·真人实现）
以下涉及真实收款/退款，属红线，需真人执行、单独谨慎实现，本次**只定规则不落代码**：
1. **一级运营商 4999 付费开通流**：下单→支付→建 Operator(channelType=ONLINE, containQuota=6[1自用+5可售])。当前 `createOperator` 仅 admin 手建，无付费流。
2. **分站 999/年 系统租赁费**：年度计费、到期提醒、缴费流水。
3. **减免逻辑**：分站累计收入 < 5×999 时不触发续交。
4. **退还逻辑**：分站首年累计收入 ≥ 10×999 时退还租赁费（仅第一年）。需要"分站累计收入"口径与结算周期定义。
5. 开通页(C1/C2)按 `promo_disabled` 呈现风险提示文案，不写收益承诺。
