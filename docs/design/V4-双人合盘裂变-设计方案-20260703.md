# V4 双人合盘裂变 — 设计方案

> 2026-07-03 · 裂变库 V4（合婚/合作盘需双方生辰→邀请对方→报告双方可见）· 自主拍板
> 侦察结论：POST /paipan/hehun 已实现但只能合自己两个盘（跨用户查不到）；analyzeHehun AI 完整；前端合婚页零；useShare+referral 可复用；PaipanRecord 单用户 IDOR 防护严。

## 一、裂变机理与合规边界（拍板）

裂变核心：合婚必须两个人的盘 → **发起人只有自己的盘，必须拉对方进来授权** → 强制邀请一个真实用户。这是排盘线最强的裂变钩子。

**R3 合规红线（生辰=敏感个人信息·必须最小授权）**：
- 被邀请方授权的是「用自己的盘参与这次合盘」，**不等于把生辰/完整命盘暴露给发起方**
- 双方可见的只有**合婚结果报告**（关系分析文本），**不互相暴露对方的原始生辰、四柱、完整排盘详情**
- 授权可拒绝；报告生成后关系锁定，任一方可删除自己侧（删除即报告失效）

## 二、数据模型

新表 `CoupleChart`（manual-sql）：
- id / initiatorId / partnerId? (授权后填) / status(PENDING_INVITE|AUTHORIZED|REJECTED|EXPIRED)
- initiatorRecordId (发起方自己的盘) / partnerRecordId? (对方授权时提供自己的盘)
- inviteToken (邀请链接令牌·唯一) / analysisId? (关联 AiAnalysisRecord) / expiresAt / createdAt / updatedAt
- @@index([initiatorId]) @@index([partnerId]) @@unique([inviteToken])

## 三、端点契约

1. `POST /paipan/couple/invite` body { myRecordId } → 校验 myRecordId 归属本人 → 建 CoupleChart(PENDING_INVITE·inviteToken·7天过期) → 返回 { id, inviteToken, shareUrl }
2. `GET /paipan/couple/invite/:token` （公开·被邀请方点链接看邀请详情）→ { initiatorNickname, status, expired } （**不透露发起方生辰**）
3. `POST /paipan/couple/:token/accept` （登录·被邀请方）body { myRecordId } → 校验令牌有效未过期未接受+myRecordId 归属本人+partnerId≠initiatorId → 填 partnerId/partnerRecordId·status=AUTHORIZED → **服务端取双方盘调 analyzeHehun**（此处是唯一同时读两个盘的地方·仅用于生成报告不返回原始盘）→ 存 analysisId → 返回 { chartId }
4. `POST /paipan/couple/:token/reject` （登录·被邀请方拒绝）→ status=REJECTED
5. `GET /paipan/couple/:id` （登录·仅 initiatorId||partnerId 可见）→ { status, initiatorNickname, partnerNickname, analysisContent(AUTHORIZED 才有), createdAt } —— **只返回报告文本+双方昵称·绝不返回对方 recordId/生辰/四柱**
6. `GET /paipan/couple/mine` → 我发起的+我参与的合盘列表
7. `DELETE /paipan/couple/:id` （任一方）→ 软删该方可见性（双方都删或发起方删=记录失效）

**跨用户读盘的唯一豁口**：仅 accept 端点内、服务端、为生成报告，同时读 initiatorRecordId+partnerRecordId 调 AI。绝不经任何端点把对方原始盘返回给另一方。修复现有 hehun 端点的自查缺陷不在本范围（couple 走独立链路）。

## 四、前端

- pkg-paipan/couple/invite（发起页：选我的盘→生成邀请→useShare 分享带 ref+inviteToken）
- pkg-paipan/couple/accept（被邀请落地页：见发起人昵称邀请→登录→选/建我的盘→授权或拒绝）
- pkg-paipan/couple/result（结果页：合婚报告+双方昵称+分享·再裂变）
- pkg-paipan/couple/mine（我的合盘列表）
- 合婚入口接入 paipan 首页
