## #37 AI 搜索推荐

- 端点：`POST /circles/search/ai {query}`（OptionalAuthGuard·可匿名）。
- 实现：`circle-insight.service.ts` `aiSearchRecommend`——组合「用户已加入圈子偏好（名称/分类/tags，未登录为空）+ 平台 ACTIVE 圈子清单 top50（名称/简介/分类/成员数）」→ AiGateway `chat(scene='circle_search_recommend')`（走既有 deepseek 路由/降级链）→ 宽容解析 JSON → 返回 `{recommendCircleIds(≤3·仅清单内 id), circles(摘要), reason, followUps(≤3)}`。
- **fail-open**：空 query / AI 抛错 / 输出不可解析 / 无有效内容 → 返回 `{}`，前端不渲染。
- 前端 `search.vue`：搜索时**并行**请求 AI（seq 防错序），有内容才渲染 AI 卡（V0 ai-card 金描边+呼吸点）：推荐圈子组+追问 chips（点击=以该词重新搜索）+ "仅供参考"注脚；失败完全不渲染，保持既有热门推荐降级。
