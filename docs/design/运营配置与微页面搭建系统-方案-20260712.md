# 运营配置与微页面搭建系统 · 方案（2026-07-12）

> 董事长多次拍板方向：**前端的展示，后端要全面支持配置**。本方案把散点需求收敛为一套「运营配置中台 + 微页面搭建器」，分期落地。

## 一、需求归并（董事长陆续提出）
1. 每个板块后台有**微页面编辑**，自由组合布局：哪里放大卡片、哪里放双列瀑布流、哪里放促销组件、哪里放轮播图。
2. **智能体卡**的类型/配色（4 色系）后台可配。
3. 首页**大卡出现频率**后端可配。
4. 微页面位置后端**支持预览**。
5. 首页/发现页/各板块首页的分区、橱窗顺序、运营位均可配。

## 二、系统架构（三层）
### 1. 数据层：页面配置表 `PageLayout`
```
PageLayout { id, pageKey('home'|'discover'|'course_home'|'circle_home'|...),
  status(DRAFT|PUBLISHED), version, blocks: Json[], updatedAt, updatedBy }
```
`blocks` = 有序区块数组，每块：`{ type, props, dataSource }`
- type 枚举：`banner`(轮播) / `kingkong`(金刚区) / `feed`(双列瀑布流) / `bigCard`(2:1大卡) / `rail`(横滑专栏) / `rank`(榜单) / `flashSale`(促销/秒杀) / `showcase`(板块橱窗) / `notice`(公告)
- props：区块参数（如 feed 的 `bigCardInterval`、rail 的标题/更多链接、bigCard 的选品来源）
- dataSource：数据来源（接口 key + 筛选参数 / 运营手选内容 id 列表）

### 2. 组件配置：`ComponentConfig`（如智能体卡色系）
```
ComponentConfig { key('agent_card_category'), value: Json }
// agent 分类→色系映射：{ 文案生成:'g-copy', 分析报告:'g-analyze', 古籍查询:'g-classic', 办公效率:'g-office' }
```

### 3. 端点
- `GET /operation/page-layout?pageKey=&preview=0|1`：前端拉取已发布(默认)或草稿(preview=1·带鉴权)布局 → 前端按 blocks 顺序渲染
- `PUT /operation/page-layout`（admin）：保存草稿 / 发布
- `GET /operation/component-config?key=`：组件级配置（智能体色系等）

## 三、前端：区块注册表渲染（照搬 feed-card 注册表模式）
- `components/layout/block-renderer.vue`：按 block.type 显式 v-if 分发到区块组件（banner/kingkong/feed/bigCard/rail/rank/flashSale/showcase）
- 页面（home/discover/course_home…）= 拉 PageLayout → v-for blocks → block-renderer
- **预览**：admin 编辑器 iframe 加载 `H5?pageKey=&preview=1&token=`，前端读 preview 参数拉草稿布局 → 所见即所得

## 四、后台：微页面编辑器（admin·Vue3+Element Plus）
- 左侧组件库（可拖入的区块类型）→ 中间画布（拖拽排序区块·每块可配 props/dataSource）→ 右侧属性面板
- 顶部：草稿保存 / 预览(开 H5 preview) / 发布
- MVP 可先做「区块增删排序 + 参数表单」，拖拽二期

## 五、分期落地
| 期 | 内容 | 说明 |
|---|---|---|
| **P0（已就绪雏形）** | 首页大卡频率 `bigCardInterval` 前端 ref 预留 | 待接 config 端点 |
| **P1** | PageLayout 表 + GET 端点 + 前端 block-renderer（首页先接）+ 智能体色系 ComponentConfig | 让首页布局后端可配 |
| **P2** | admin 微页面编辑器（区块增删排序+参数表单+发布）+ 预览 | 运营可视化编辑 |
| **P3** | 铺开到发现页/各板块首页（course/circle/...）+ 拖拽画布 | 全板块可配 |

## 六、与现状衔接
- 现有首页/发现页/课程首页均为**硬编码区块**，P1 把首页区块改为「读 PageLayout 渲染」，无布局配置时回落当前硬编码默认（平滑迁移，不留白）。
- feed-card / 九类卡 / big-card / SectionHeader / 金刚区等**区块组件已就绪**，P1 主要是「配置驱动 + 注册表渲染」的接线，不重写组件。
