# V8 节气仪式裂变 — 设计方案

> 2026-07-03 · 裂变库 V8 · 自主拍板 · 纯内容+荣誉·无资金·零需用户拍板
> 侦察结论：节气计算引擎 jieqi.ts 完备（可判今日/下一节气·精确到分）；notification 站内通知可用（无需密钥）；成就体系 ACHIEVEMENTS 常量需扩展。

## 一、玩法

24 节气每个节气日推出**节气限定内容 + 限定成就卡**（错过即无·稀缺=传播动力）：节气日当天在首页/万年历展示节气主题（三候/习俗/养生/应景诗词），用户参与（阅读/打卡/分享）得**节气限定成就**（如"立春·咬春"·带年份·限当期可得），成就卡分享带 ref。节气日推送提醒（站内）。

## 二、合规
纯文化内容+荣誉成就·无资金·无抽奖。节气成就是荣誉徽章不可兑现。

## 三、数据/实现（轻·不建重表）

- 节气判定：复用 jieqi.ts `calcAllJieQi(year)`+当日匹配（今天是否某节气·距下一节气天数）——纯计算无表
- 节气限定成就：ACHIEVEMENTS 常量新增节气成就族（solar_term_{term}_{year} 动态·或统一 solar_term_participant 带 meta 记录哪个节气）。**选统一成就 `solar_term_ritual`**（首次参与任意节气仪式得·避免 24×N 年成就爆炸）+ 计数里程碑（参与 4/12/24 个节气→"应时·四时/十二气/廿四节"进阶成就）
- 参与记录：新轻表 `SolarTermParticipation`（userId/termName/year/participatedAt·@@unique([userId,termName,year])·防重）→ 记录参与→颁发成就+计数
- 节气内容：24 节气静态内容库（三候/习俗/养生/应景诗词·代码常量 SOLAR_TERMS 或 seed·公版知识无版权问题）

## 四、端点契约（solar-term 模块·或挂 wannianli）

1. `GET /solar-term/today`（公开）→ { isSolarTermDay, current?:{ term, date, sanHou, custom, health, poem }, next:{ term, daysUntil }, myParticipated(登录·今日是否已参与) }
2. `POST /solar-term/participate`（登录·仅节气日当天可参与）→ 记录 SolarTermParticipation（当日节气·防重）→ 颁发/更新节气成就+计数里程碑 → { term, achievement?, totalTerms }
3. `GET /solar-term/my`（登录）→ 我参与过的节气列表+计数（集齐进度 x/24）
4. 节气日推送 cron（每日 8AM·runExclusive 多实例锁）：检测今日是否节气→是则给活跃用户发站内通知「今日{节气}·{一句应景}」（notification 站内·无密钥·限活跃用户防打扰·可配）

## 五、前端

- 首页/万年历节气日横幅（isSolarTermDay 时显示当期节气卡·入口）
- pkg 节气页（或复用万年历）：节气主题内容（三候/习俗/养生/诗词）+「参与今日节气」按钮→participate→成就卡+分享（带 ref）
- 节气成就集齐进度（我的·x/24 环）+ 里程碑成就展示
- 成就卡 canvas 分享（复用 V10/V3 范式）

## 六、裂变闭环
节气日推送唤醒→参与得限定成就(稀缺·错过即无)→成就卡分享(应景+炫耀)→好友被节气氛围+成就吸引来参与。文化仪式感驱动·零资金。
