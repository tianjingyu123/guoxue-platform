# 小程序过审功能面清单（R4 合规 · MP-WEIXIN 差异化）

> 2026-07-07 · 合-P2 · 依据 docs/design/运营底座三件套-…-20260704.md §三.2
> 背景：微信小程序无「占卜」类目，排盘/算命/占卜/运势直白表述入口与标题在 MP 端改「民俗文化研究/传统历法参考」类表述；纯占卜功能页 MP 隐藏入口（页面保留）；内容/课程/商城/圈子等不动。
> 手段：`#ifdef MP-WEIXIN` / `#ifndef MP-WEIXIN` 条件编译，**只改展示层文案与入口可见性，不动路由与逻辑**。全部页面 `navigationStyle: custom`（标题为页内渲染，无需 setNavigationBarTitle）。

## 判定规则
- ①排盘/算命/占卜/运势直白入口与标题 → **MP改名**（民俗文化研究/传统历法参考类表述）
- ②纯占卜性功能（六爻起卦/称骨/神数/风水测算类）→ **MP隐藏**入口（页面保留）
- ③八字排盘类工具 → **MP改名**保留
- ④内容/课程/商城/圈子等 → **保留原样**

## 六、说明与边界
- 结果页/表单内正文话术（如「排盘时间」「开始排盘」表单标签）属 F2 全站话术批（合-P1 违禁词库 B 级替换）范围，本批不动。
- 工具网格数据来自 `toolsApi.getTools()`（后端目录），MP 过滤/改名在**展示层**做（id 匹配·未知 id 默认放行），不动数据层与后端。
- H5/App 端构建不受任何影响（条件编译只在 MP-WEIXIN 生效）。
- 验收：`npx vue-tsc --noEmit` + `scan-mock-imports.sh` 全绿；小程序构建包人工按本清单过一遍（需用户微信开发者工具）。
