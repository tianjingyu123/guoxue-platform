# 赛事板块 · V0 设计委托书（重构优化）

> 2026-07-12 · 热卜国学平台（面向易学/国学爱好者的知识付费平台）· 委托 V0 出移动端 H5 视觉与交互设计稿，我方负责 1:1 还原为生产代码。
> 本委托书**自包含**。**本板块与分站不同：不是推翻重做、不砍页**，而是对已有 10 个参赛页做**视觉与交互的整体重构打磨**——把一套功能已通、但视觉平淡、仪式感与荣誉感不足的赛事流程，升级成有「竞技张力 + 荣誉殿堂」气质的精品。
> 流程：**阶段一先交信息架构线框稿 → 确认结构 → 阶段二视觉稿**。

## 〇、一句话定调（先读）

赛事板块 = 平台的**国学知识竞技场 + 荣誉体系 + 获客裂变入口**（面向**参赛用户**一侧）。

- 它不是占卜、不是赌博、不预测吉凶——是**国学知识水平的比拼**（八字/风水/紫微/六爻/奇门等知识点答题竞赛）。文案一律以「知识竞技、学识荣誉」立意，**严禁**任何「预测中奖/赌运气/占卜结果」式包装。
- 两件事做到位，这个板块就成了：**① 答题时的专注与竞技张力；② 赛后的荣誉呈现与炫耀分享。** 这两条是本委托的灵魂（第二节）。

## 一、背景与定位

平台前身是排盘工具（570 万注册用户）。赛事板块承担三重价值：

1. **激活与粘性**：给易学爱好者一个「证明自己学识」的舞台，办赛即拉活跃。
2. **荣誉与身份**：名次、徽章、证书、人才榜——沉淀用户的「国学身份资产」，与讲师认证打通。
3. **获客裂变**：荣誉海报（9:16）自带赛事二维码，选手炫耀式分享 = 平台低成本获客。

**现状**：参赛侧 10 个页面功能已从零建成、端到端闭环打通（报名→答题→判分→排名→证书→海报），后端能力完备（3 个 controller、完整赛程状态机、判分引擎、人才库）。**短板在前端**：视觉平淡缺乏竞技/荣誉气质、答题页仪式感不足、证书与海报的「炫耀价值」没做透。**本次委托 = 对这 10 页做整体视觉重构与交互打磨，不砍不并。**

### 门控与边界
- 本板块由后端环境开关 `COMPETITION_ENABLED` 门控；关闭时全平台无赛事入口（设计不受影响，仅入口显隐）。
- **只做参赛用户端**。评委评分端、赛事组织/运营后台在 admin 管理端（独立、本委托不涉及）。
- **本期范围 = 线上答题赛闭环**。直播连麦 PK、观众投票、赛后 UGC 文章沉淀属二期，不画。
- **无独立账号体系**：参赛者沿用总平台用户身份，不单独登录/设密码。

## 二、核心命题：双灵魂（本委托的重点）

### 灵魂一 · 答题体验（A3 在线答题页 quiz）
这是选手与赛事唯一「实时较量」的时刻，要的是**沉浸、专注、有压力而不慌乱**。

必须做出张力的元素：
- **顶部倒计时**：常驻醒目，三档视觉升级——正常（中性）→ 警戒（≤5 分钟转金/橙）→ 危急（≤1 分钟转朱红 + 轻微呼吸/闪动）。时间是竞技的核心压迫感。
- **题干区**：大字、留白、克制，让人专注读题；题型标（单选/多选/填空/论述）清晰；分值角标。
- **选项**：大点击区、选中态明确（朱红填充/描边）；多选与单选视觉可区分。
- **底部操作条**：上一题 / 题号进度（如 7/20） / 下一题 / 标记本题（星标）。
- **答题卡抽屉**（半屏上推）：宫格题号，三态一眼分清——已答（朱红实心）/ 已标记（金色）/ 未答（灰描边）；点击秒跳。
- **交卷**：底部「交卷」→ 二次确认弹层，列出**总题数 / 已答 / 未答 / 已标记**，给一次「回去检查」的机会；交卷有**收官仪式感**（非冷冰冰 toast）。
- **专注提示（防作弊感知）**：切屏离开时记次数，回来后温和提示「已离开 N 次，请保持专注」（提示为主，不惩罚性弹窗轰炸）。

> ⚠️ 答题页的目标不是花哨，是**让人心无旁骛地比拼**。删掉一切与答题无关的干扰元素。

### 灵魂二 · 荣誉呈现（A6 排行榜 / A7 证书 / A8 海报）
竞技的回报是荣誉，荣誉要**看得见、值得炫**。

- **领奖台（A6 排行榜顶部）**：冠/亚/季三席，金银铜阶梯式领奖台，头像 + 名次冠冕 + 分数；第一名最高最亮（金）。往下是完整榜单，**「我的排名」行要高亮吸顶或醒目卡片**，含晋级/淘汰状态。
- **荣誉证书（A7）**：红金纸质、双线描边、朱红钤印、落款颁发日期 + 防伪证书编号——要有**「值得截图收藏」的仪式感**。支持保存为图片 / 分享。
- **荣誉海报（A8·9:16 竖版）**：顶部赛事名 + 中部名次/成绩荣誉卡 + 底部赛事二维码 + 品牌 Slogan，**自带炫耀属性 + 拉新钩子**。未获奖/未参赛者分享时文案转为「邀请你来同台竞技」（不误导为「我正在参赛」）。

> 名次徽章体系（冠军/亚军/季军/晋级/参与）统一一套视觉语言，在排行榜、成绩单、人才榜、证书、海报间复用。

## 四、关键交互规格（注释即规格·稿内标注数据来源）

- **倒计时**：`GET /competitions/rounds/:roundId/paper` 返回时限；前端每秒递减，三档阈值切换视觉；到时自动交卷。
- **试卷**：题目 + 选项**乱序下发**（不含答案），防查重按 key 比对；单题可 `submit`，整卷 `batch-submit`。判分契约：**SINGLE 单选 / MULTI 多选，选 key**。
- **交卷**：二次确认列已答/未答/标记数；提交后客观题自动判分，主观题进评委队列（成绩页显「评委评分中」）。
- **专注检测**：切屏 `onHide` 记次，回来提示，仅感知不惩罚。
- **排名/晋级**：`GET /competitions/:id/rankings`；状态含 淘汰/晋级/冠军/亚军/季军。
- **证书**：`GET /competitions/certificates/:rankingId/view` 返回可打印证书；仅获奖/晋级者有。
- **海报**：前端 canvas 绘制，9:16，含赛事二维码（带归因参数）；保存相册 / 分享。
- **人才榜**：`GET /competitions/talents`（脱敏公开）+ `/talents/me`（我的战绩）。

## 七、视觉规范

全站统一 token：宣纸白 `#FAF8F5`（页底）、卡片白 `#FFFFFF`、朱红 `#C41E3A`（进行中/倒计时/主 CTA/激活）、金 `#C9A96E`（荣誉/名次/徽章/证书/等级）、文字 `#2C2C2C`/`#6E6E73`/`#999`、圆角 18px·胶囊 999px、页边距 20px、暖调描边 `#ECE7DF`。

赛事板块**特有视觉语言**：
- **竞技红 × 荣誉金**双主色：进行中/倒计时/紧迫感用朱红；名次/领奖台/证书/徽章用金。
- **领奖台**：金（冠·最高最亮）/ 银 / 铜三阶，冠冕或桂冠点缀，克制不俗气。
- **名次徽章**：冠亚季 + 晋级 + 参与，一套统一视觉，全板块复用（排行/成绩/人才榜/证书/海报）。
- **证书**：红金纸质、双线框、朱红钤印、衬线大字标题（Songti/Noto Serif），古雅庄重。
- **倒计时**：等宽数字，三档色阶（中性→金→朱红），危急态可轻微呼吸动效。
- 整体**国学雅致、竞技庄重**：禁荧光渐变、禁娱乐贴纸感、禁赌博/抽奖式浮夸。
- ⚠️ 封面/证书/海报上的文字必须有渐变或实色衬底，禁同色系底字。

## 八、技术兼容（安卓微信 X5 内核）

1. 封面/比例用 padding-top 方案（不用 aspect-ratio），稿内标注比例。
2. 不用 writing-mode 竖排；答题卡半屏用实色 + 透明度（毛玻璃不承载关键信息）。
3. 倒计时、canvas 海报、切屏检测、交卷等交互由我方实现，V0 只出视觉与各状态态样。

## 九、交付格式

1. 纯 HTML 静态稿，390px 宽，稿内 HTML 注释标数据来源与交互规格。
2. 交付清单（10 页 · 关键页多态）：
   - A1 赛事首页（报名中/进行中/已结束三态）
   - A2 赛事详情（未报名 / 已报名待赛 / 进行中 / 已结束 四态 CTA）
   - **A3 在线答题（单选/多选/填空/论述题型 + 答题卡抽屉 + 交卷确认 + 倒计时三档）★灵魂**
   - A4 报名（确认态 / 报名成功态）
   - A5 成绩详情（含逐题展开 + 主观题评分中态）
   - **A6 排行榜（领奖台 + 我的排名 + 晋级/淘汰）★荣誉**
   - **A7 荣誉证书 ★荣誉**
   - **A8 荣誉海报 9:16（获奖态 / 未获奖邀请态）★荣誉/裂变**
   - A9 人才榜
   - A10 往届赛事
   - 附一套**名次徽章 / 领奖台**视觉规范（全板块复用）
3. **两阶段**：先线框级信息架构稿（确认双灵魂交互：答题体验 + 荣誉呈现）→ 确认 → 视觉稿。**答题体验（灵魂一）与荣誉呈现（灵魂二）是本委托的重点，务必做出竞技张力与荣誉仪式感。**
