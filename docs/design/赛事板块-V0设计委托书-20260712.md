## 〇、定调（先读·四个理念 + 三大机制）

赛事板块 = 平台的**国学知识竞技场 + 易学分析师荣誉体系 + 自传播获客引擎**（面向**参赛用户**一侧）。

**四个运营理念（贯穿每一页的设计取向）**：
1. **自运转**：全流程系统驱动——自动开赛 → 自动组卷 → 客观题自动判分 → 自动排名 → 自动发证 → 自动结算奖励。人工只碰题库与线下环节。可做「定时赛」（每周/每月自动开赛）。
2. **高透明**：赛制规则公开、题目赛后公示、评分标准可见、排名实时、**奖励发放公示**。透明 = 公信力，是荣誉体系立身之本。
3. **低维护**：题库复用 + 自动组卷 + 赛程状态机自动流转，仅主观题/线下需人工。
4. **高传播**：荣誉海报裂变 + **邀请奖励机制** + **易学分析师身份** 三个引擎驱动自增长。

**三大机制（本委托新增灵魂）**：
- **三赛制晋级链**：线上答题赛（海选）→ 直播赛（复赛/决赛·实战PK+直播答题）→ 线下赛（顶级决赛）。
- **易学分析师等级认证**：赛事战绩自动晋级分析师等级（见习→资深），带认证标识，打通达人咨询变现。
- **邀请人一级奖励**：被邀请人获奖得实物时，直接邀请人得对应实物奖励（单级·挂钩真实获奖·合规）。

> ⚠️ 立意红线：这是**国学知识水平 + 易学分析能力的比拼**，**不是占卜、不是赌博、不预测吉凶**。文案一律「知识竞技、学识荣誉」，严禁「预测中奖/赌运气/算命服务」式包装（详见第七节合规）。

## 一、背景与定位

平台前身是排盘工具（570 万注册用户）。赛事板块承担三重战略价值：

1. **激活与自运转**：定时赛自动开跑，给易学爱好者持续的「证明学识」舞台，低人工成本高活跃。
2. **易学分析师荣誉体系**：名次→等级→认证→接单，把用户的实战能力沉淀为可变现的「国学身份资产」。
3. **自传播获客**：荣誉海报 + 邀请奖励，选手炫耀式分享 + 拉新有回报 = 低成本裂变。

**现状**：线上答题赛闭环功能已通、后端能力较完备（赛事/赛程状态机/判分引擎/人才库/排名/证书）。**本次委托 = 在此之上做整体视觉重构 + 三赛制/分析师/邀请奖励三大机制的界面落地。**

### 门控与边界
- 本板块由 `COMPETITION_ENABLED` 门控；关闭时全平台无赛事入口。
- **只做参赛用户端**。评委评分端、赛事组织/运营后台在 admin 管理端（独立、本委托不涉及）。
- **线下赛**：App 只做**报名 + 签到核销 + 成绩公示 + 证书**，线下比试本身在线下（不在 App 内直播/答题）。

## 二、三赛制晋级链（新增灵魂 · 重点）

一条赛事可由多阶段晋级组成，App 用**赛程时间轴**呈现当前阶段：

| 赛制 | 定位 | App 承载 | 传播点 |
|------|------|----------|--------|
| **线上答题赛** | 海选 / 初赛（大规模自动化） | 限时答题 + 自动判分 + 自动排名（见第三节·灵魂一） | 门槛低、覆盖广 |
| **直播赛** | 复赛 / 决赛（实战较量） | 直播赛间·**混合两玩法**：① 实战 PK（选手现场对案例解卦/断盘/论断，评委打分 + 观众投票）② 直播答题（主持人出题，选手/观众限时答，实时出成绩） | 直播引流、现场感强 |
| **线下赛** | 顶级 / 区域决赛 | 报名 + 签到核销（选手凭证 ↔ 工作人员扫码）+ 线下成绩公示 + 证书 | 高端、权威、沉淀线下关系 |

**晋级逻辑**：线上答题海选 top N 晋级直播赛 → 直播赛胜出者晋级线下决赛。赛事详情页的**赛程时间轴**高亮当前阶段，未晋级/已晋级状态清晰。

> ⚠️ 直播赛「实战 PK」的分析对象是**赛事提供的标准案例/历史命例样本**（有专家评判维度），**不是给真实用户算命**——这是合规关键（见第七节）。

## 三、双灵魂 · 竞技体验 + 荣誉呈现

### 灵魂一 · 答题体验（在线答题页）
线上答题赛的核心时刻，要**沉浸、专注、有压力而不慌乱**：
- **顶部倒计时**三档视觉：正常 → ≤5 分钟（金/橙）→ ≤1 分钟（朱红 + 轻微呼吸）。
- 题干大字克制；题型标（单选/多选/填空/论述）+ 分值；选项大点击区、选中态明确。
- 底部：上一题 / 题号进度 / 下一题 / **标记本题**。
- **答题卡抽屉**（半屏）：宫格题号三态——已答（朱红实心）/ 标记（金）/ 未答（灰描边），点击秒跳。
- **交卷**二次确认（列总题/已答/未答/标记数），收官仪式感；**专注提示**（切屏回来温和提示，不惩罚）。

### 灵魂二 · 荣誉呈现（排行榜 / 证书 / 海报）
- **排行榜**：金银铜**领奖台**（冠军最高最亮·金）+ 完整榜单，「我的排名」醒目高亮 + 晋级/淘汰态；晋级链名次（线上→直播→线下逐级）。
- **荣誉证书**：红金纸质、双线框、朱红钤印、防伪编号，值得截图收藏。
- **荣誉海报（9:16）**：名次成绩荣誉卡 + 赛事二维码 + 邀请钩子（**与邀请奖励打通**：分享海报即带邀请归因）。未获奖态文案转「邀请你来同台竞技」。

> 名次徽章体系（冠/亚/季/晋级/参与）统一一套视觉，全板块复用。

## 四、易学分析师等级认证（人才榜升级 · 新增灵魂）

人才榜**不是「讲师」榜，是「易学分析师」榜**——沉淀赛事实战断验能力。

- **等级体系**：见习分析师 → 初级 → 中级 → 高级 → 资深分析师。**赛事战绩自动晋级**（积分/名次/获奖累计驱动），带**认证标识**。
- **分析师榜**：按等级 + talentScore 排行；等级徽章、战绩（参赛/晋级/夺冠数）、认证标。
- **我的分析师档案**：当前等级 + 晋级进度条（距下一级还差多少）+ 战绩时间线 + 认证徽章墙。
- **变现打通**：已认证分析师可与 C 端「达人咨询」打通（挂牌接单）——荣誉转收入，强化「高传播 + 自运转」。
- 与讲师区分：讲师是**教学**，分析师是**实战断验能力**（对案例/命例的分析论断水平）。

## 五、邀请人奖励机制（裂变 · 新增 · 🔴合规单级）

**规则（协议须明示、页面须透明）**：
- 用户通过**邀请**带来的新人参赛并**获奖得实物奖励**时，**直接邀请人（仅一级）得对应实物奖励**。
- **挂钩真实获奖**：只有被邀请人真实获奖、平台发放实物时才触发邀请奖励——**不是按邀请人头数计酬**（防传销）。
- **仅一级**：只奖励直接邀请人，不向上追溯多级（合规底线，见第七节 R1）。
- **对应实物**：邀请人获得与被邀请人所获实物**对应/等值**的奖励（具体对应关系由赛事奖品配置定义）。

**页面承载**：
- **邀请机制说明页**：一句话讲清「邀朋友来比赛，他获奖你也有奖」+ 规则细则 + 我的专属邀请码/链接/海报。
- **我的邀请奖励页**：我邀请的人列表（参赛/获奖状态）+ 我因此获得的奖励 + **发放状态公示**（待发放/已发放·高透明）。

> 邀请归因复用平台既有邀请/推广码链路；奖励发放走后端结算 + 公示。

## 六、高透明公示（贯穿 · 新增）

透明是荣誉生态的公信力基石，需专门界面承载：
- **赛制规则公示**：赛制、晋级规则、评分标准、奖品设置，赛前公开可查。
- **题目公示**：赛后公示题目 + 标准答案 + 解析（客观题）。
- **排名实时**：排行榜实时可查、可追溯。
- **奖励发放公示**：获奖名单 + 奖励发放状态公开（含邀请奖励），防暗箱。

## 七、合规红线（务必遵守 · 文案与机制都要）

- **R1 传销两级红线**：邀请奖励**仅一级**、挂钩**真实获奖实物**（非拉人头计酬）、协议明示。绝不做多级分销/团队计酬。
- **R4 占卜类目红线**：赛事立意是**知识与分析能力竞技**。直播赛实战 PK 的对象是**赛事标准案例/历史命例样本**（专家评判），**不得**包装成「给真实用户算命/预测吉凶」。文案禁「预测中奖/赌运气/占卜结果」。
- **无承诺式营销**：不写「已有 XX 人获奖」「参赛必赚」等诱导；奖励以真实赛事产出为准。
- **实物奖励与资金**：奖励发放、邀请奖励结算属**资金/实物**动作，前端只展示后端结算结果与公示状态，不在前端复算金额。

## 十一、视觉规范

全站统一 token：宣纸白 `#FAF8F5`、卡片白 `#FFFFFF`、朱红 `#C41E3A`（进行中/倒计时/主 CTA/激活）、金 `#C9A96E`（荣誉/名次/等级/证书/徽章）、文字 `#2C2C2C`/`#6E6E73`/`#999`、圆角 18px·胶囊 999px、页边距 20px、暖调描边 `#ECE7DF`。

赛事**特有视觉语言**：
- **竞技红 × 荣誉金**双主色；**领奖台**金银铜三阶；**名次/等级徽章**统一一套复用；**证书**红金纸质衬线庄重；**倒计时**等宽数字三档色阶。
- **直播赛**：现场感 + 实时性（LIVE 标、投票条动态、PK 对阵分屏），但不娱乐化。
- **分析师等级**：等级徽章体系有进阶感（青铜→鎏金递进），庄重不浮夸。
- 整体国学雅致、竞技庄重：禁荧光渐变、禁娱乐贴纸、禁赌博抽奖式浮夸。
- ⚠️ 封面/证书/海报文字必须有渐变或实色衬底，禁同色系底字。

## 十三、交付格式
