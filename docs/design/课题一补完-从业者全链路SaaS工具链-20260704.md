> 生态定位（引总设计）：工作台+SaaS 工具=「从业者留在平台的日常理由」·北极星=周活从业者数·支撑收入线6（交易佣金·工具带来的客户经营能力→人均GMV）与线8（SaaS订阅）

## 一、设计总纲：三环补完后的从业者一天

> 早上打开工作台：「今日内容日历」推荐今天该发的获客内容（今日小暑，AI 已生成 3 条节气文案+配图建议，一键带我的名片码发朋友圈）→ 中午收到「客户提醒」：老客王姐生日后天，AI 草拟了问候+流年提示（一键发送）→ 下午新客扫名片码填了生辰和诉求，AI 预分析已放在待办里 → 晚上看「本月咨询热点：流年运势占 38%」，决定周末直播讲这个主题。

**灵魂设计（区别于普通工具集）**：所有获客内容自动携带从业者的 **ref 归因链接/名片二维码** → 客户点开即绑定归因 → 后续在平台的消费（课程/商品/咨询）自动给从业者分佣。**获客工具不只是"帮他发内容"，是"帮他把客户资产沉淀到平台上"**——这是从业者离不开平台的真正原因，也是平台交易线的水源。

## 二、获客环：AI 营销内容套件 + 内容日历

### 2.1 功能清单
| 工具 | 输入 | 输出 | 备注 |
|---|---|---|---|
| 短视频脚本 | 主题(可从热点日历选)/流派/人设/时长 | 口播稿+分镜表+封面标题3选 | 抖音/快手/视频号/小红书四模板 |
| 朋友圈文案 | 场景(节气/流年/案例复盘/日常) | 3条备选+配图建议(平台图库) | 接 jieqi 引擎——节气日自动生成应景内容 |
| 小红书图文 | 主题/关键词 | 标题(爆款结构)+正文+tag组 | |
| 海报名片 | 自动 | 个人品牌海报(认证等级+服务+二维码) | 复用 V1 canvas 范式·补 poster teacher 类型(核验批坐实的缺口) |

### 2.2 内容日历（获客环的调度器）
- 工作台新增「今日发什么」卡：节气/传统节日/黄历宜忌/平台热点(行业洞察输出) 驱动的每日选题，点选题→直达对应生成器
- 生成记录表 MarketingContent（复用审核漏斗过审后才可复制/下载）

### 2.3 合规内嵌（不是事后审）
- 生成 prompt 内置 R4 定性话术（文化解读/民俗参考，禁"预测/化解/改运"承诺）；产出过三层审核漏斗；违规词直接不生成
- 所有内容尾部自动拼接从业者 ref 短链或名片码（可关，默认开）

## 三、转化环：智能名片 + 需求预分析

### 3.1 从业者智能名片（升级现有 teacher-profile 为通用版）
- 通用「从业者名片页」：头像/认证徽章(F1)/服务清单(咨询/课程/商品)/客户评价/预约按钮/驿站归属；讲师、达人、站长复用同一名片引擎，角色差异用板块开关
- 名片二维码进全部获客产出物；名片页本身即归因落地页（captureRef）
- **一键转发到微信** = 从业者最高频动作，放名片页首屏

### 3.2 AI 需求预分析
- 客户从名片页发起咨询/预约时填轻表单（诉求类型+可选生辰）→ AI 生成《客户预分析摘要》推给从业者（诉求归类/建议切入点/相似案例主题）——从业者"提前备课"，成交率↑
- 生辰走 M4 加密；摘要不落个体数据到平台聚合层（R3）

### 3.3 跟进提醒
- 新客咨询后 48h 未成交 → 工作台待办 + AI 草拟跟进话术（挽回率抓手）

## 四、服务环：客户经营 CRM（本课题最重的新建）

### 4.1 数据模型（新表·全部增量）
```
ClientBook  客户档案（归属从业者·平台不跨从业者聚合个体）
  id/ownerId(从业者)/name/phone?(加密)/birthEnc?(M4加密)/gender/tags[]/source(名片/手工/订单归因)
  /lastServeAt/totalSpend/serveCount/notes/createdAt   @@index(ownerId)
ClientServeLog  服务记录：clientId/type(咨询|课程|商品|排盘)/amount?/summary/servedAt
ClientReminder  提醒：clientId/kind(生日|立春流年|大运切换|复购)/dueAt/status/aiDraft(AI草拟话术)
```
- 客户来源自动化：经从业者 ref 成交的订单/咨询 → 询问从业者"是否归档该客户"（一键入库·尊重双方）
- **大运/流年提醒是命理行业独有的钩子**：立春全量客户提醒"流年已换"；按客户生辰算大运切换年（排盘引擎已有算法）→ 这是竞品没有的复购发动机

### 4.2 客户分层与精准营销
- RFM 自动分层（活跃/沉睡/高价值/流失预警）→ 每层给 AI 营销建议（接经营顾问 AdvisorEngine 规则库，扩从业者维度规则）
- 分层→群发工具不做（微信生态风险），做"逐客户一键复制话术"

### 4.3 隐私与合规红线（设计即合规）
- 客户生辰/手机号 M4 加密存储；客户数据**归从业者私有**，平台层只允许统计级聚合（进洞察中心）；导出功能不做（防数据贩卖）；客户可要求从业者删除（记录删除审计）

## 五、行业洞察中心（R3 合规版·数据护城河）

- **只做统计聚合，禁个体案例**：盘型分布/咨询主题热度/节气咨询波动/课程主题趋势/地域热度（地级市粒度以上）
- 双向价值：①从业者侧——工作台「本月行业热点」卡（接内容日历选题）②平台侧——季度《行业洞察报告》= 研究院白皮书素材（课题四A的学术权威建设弹药）+ 官网 SEO 内容
- 数据源：排盘参数聚合、咨询分类统计、TrackEvent、课程销售分类——建 InsightAggregate 天级汇总表（cron），查询永不触原始个体记录
- 明确禁止：个体案例库、生辰+地域等可再识别组合、按用户维度输出

## 六、商业化（✅已拍板 2026-07-04：工具不收钱·完整版全量赠送 B 端角色）

> 用户拍板原话：这些角色是给平台创造收入的，不能再收钱了，全都赠送。

| 档 | 对象 | 内容 |
|---|---|---|
| 体验档 | 无角色的普通用户 | 客户档案≤20 / 内容生成 10次/月 / 基础名片——**当"入角色"的钩子**：想不限量？成为站长（¥999）即全解锁 |
| 完整版（角色权益·免费） | 站长/运营商/驿站/研究院成员/供应商/认证从业者 | 客户无限+生成不限+大运流年提醒+需求预分析+品牌海报 全含 |

**设计含义**：SaaS 工具不再是收入线（原线8取消），而是 **L3→L4 跃迁的核心诱因**与角色权益的价值填充——让 ¥999/¥9800 的会费"值回票价"，把钱赚在角色转化与交易抽成（线1/5/6）上。
