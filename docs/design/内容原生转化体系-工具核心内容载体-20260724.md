# 内容原生转化体系：工具为核心，内容为载体

> 版本：2026-07-24  
> 目标：减少课程、商品、圈子的直接货架式曝光，让交易自然发生在用户已经获得价值之后。

## 一、定位

平台首页与公共流量场不再以“卖什么”为主线，而以三层结构组织：

1. **工具解决问题**：排盘、历法、查询、记录、对照。
2. **内容解释问题**：文章、古籍、短视频、直播、智能体。
3. **服务承接下一步**：课程、圈子、商品、会员。

交易内容不是独立插队，而是用户完成一个动作后的可选下一步。任何推荐都必须能回答：

- 为什么此刻出现？
- 与当前内容有什么直接关系？
- 用户不点击是否仍能完整使用当前功能？

无法回答就不展示。

## 二、推荐优先级

| 用户意图 | 第一推荐 | 第二推荐 | 商业内容条件 |
|---|---|---|---|
| 查资料、了解概念 | 文章 / 古籍 | 视频 / 智能体 | 不主动出现 |
| 想看演示或讲解 | 短视频 / 直播 | 文章 | 不主动出现 |
| 想操作、生成、核对 | 工具 | 智能体 / 文章 | 不主动出现 |
| 明确说“系统学习、报名” | 文章 / 免费内容 | 课程 | 明示价格 |
| 明确说“交流、同好、加入” | 相关内容 | 圈子 | 明示免费或收费 |
| 明确说“买、价格、商品” | 使用说明 / 评测内容 | 商品 | 明示价格与推荐理由 |

默认兜底必须是内容，不能因为内容匹配失败就自动降级成商品或课程。

## 三、五类内容载体

### 1. 文章：正式、完整、可引用

- 列表要求必须有首图；文章专区采用单图、三图等资讯式版型。
- 正文保持公众号式阅读秩序：标题、来源、时间、正文、引用、注释清晰。
- 商业内容只允许出现在语义段落之后，以“延伸阅读 / 文中所用 / 继续学习”形式出现。
- 每篇最多一个强触点；读完后可以出现来源圈子，但不得遮挡正文。

### 2. 古籍：阅读优先、章节末承接

- 正文中不插入浮层和连续广告。
- 在章节末、卷末或用户主动打开“伴读”时出现一张“延伸精讲”策展签。
- 推荐必须与书名或古籍分类直接相关；无匹配宁可不显示。
- 同一本书、同一用户 24 小时最多展示一次。

### 3. 短视频：先看懂，再承接

- 播放中不弹商品卡；用户暂停、看完或主动点“相关”后才展示。
- 相关内容排序：同主题文章 → 工具 → 直播预告 → 明确关联商品。
- 商品必须由创作者明确挂载，且标注“视频同款 / 文中所用”，不能由弱关键词强行匹配。

### 4. 直播：实时价值优先

- 直播画面、主题、开播时间是主信息。
- 商品、课程放在可收起的“本场资料”内；默认不盖住画面。
- 在主播讲到具体主题或用户主动打开清单时再定位对应内容。
- 回放按章节挂载资料，用户跳到相关章节时才出现。

### 5. 智能体与客服：向导，不是推销员

- 先完整回答本职问题，再给最多两个下一步。
- 默认优先工具、文章、古籍、视频、直播和其他智能体。
- 课程、圈子、商品只响应用户明确意图；展示前征求同意。
- 推荐理由必须具体，商业内容明确价格，不使用恐吓、夸大、制造焦虑和“假装懂你”的话术。
- 相关性不足时明确不推荐，不用热门商品填空。

## 四、统一视觉语言

统一触点不使用商城卡片，而使用“策展签 / 阅读旁注”：

- 一条书签式竖线代表内容脉络；
- 小标签明确内容属性，例如“延伸精讲”“相关商品”；
- 主标题说明推荐对象；
- 一句话解释“为什么此刻出现”；
- 价格只在商业类型中出现；
- 单一轻动效只用于行动箭头或直播状态，不做大面积闪烁。

用户应先看到关联理由，再看到行动入口。

## 五、频控与退出机制

- 单页最多一个内容原生触点。
- 同触点、同用户 24 小时最多曝光一次。
- 用户点“不用了”后，本轮对话不再出现。
- 连续两次忽略同类推荐，降低该类型权重。
- 推荐失败、开关关闭或没有强相关内容时静默隐藏。
- 全局和分场景均保留运营开关。

## 六、搜索与猜你喜欢

### 搜索

搜索结果按“工具 → 内容 → 服务”分组，不把商品置顶：

1. 直接可用工具；
2. 文章、古籍、视频、直播；
3. 智能体；
4. 用户明确搜索交易词时才出现课程、圈子、商品。

### 猜你喜欢

“猜你喜欢”只基于用户实际行为生成，并提供弱解释：

- 因为读过《周易》
- 因为常看诗词内容
- 来自你关注的老师

不使用“为你算出”“你最近需要”等不可验证或敏感表述。

## 七、效果指标

首要指标不是点击率，而是：

- 推荐后当前内容完成率是否下降；
- 推荐卡关闭/忽略率；
- 进入下一内容后的停留与完成；
- 商业卡从曝光到支付的完整漏斗；
- 用户投诉、误触和退款率；
- 各场景“无匹配不展示”的比例。

只有在内容完成率不下降、投诉不增加的前提下，才允许扩大商业触点曝光。

## 八、本轮落地

- 智能体推荐扩展为文章、古籍、视频、直播、智能体、工具、课程、圈子、商品九类。
- 平台兜底改为内容优先；没有明确商业意图时会过滤模型给出的课程、圈子、商品。
- 文章召回强制要求：审核通过、全平台可见、有首图。
- 古籍阅读章节末的 `classic_course` 已接通，书名优先、分类兜底、无相关课程不展示。
- 统一触点卡改为“策展签”；智能体推荐卡改为“向导卡”，商业类型明确价格。
- 智能客服提示词加入同一套内容优先、克制、透明规则。
