## 一、定位

研究院是平台师资供给的源头与学术权威的载体：**筛选（付费准入+任务考核）→ 培养（五级认证）→ 输出（签约讲师进驿站网络+内容资产沉淀）→ 权威（榜单/白皮书反哺品牌）**。T8 驿站网络铺开后，师资供给能力就是驿站网络的天花板——T9 是 T8 的水源工程。

## 三、研究院制度设计 V2（2026-07-03·用户核心理念细化）

> 用户定纲：研究院=强制分享考核制度（发现好老师→输送驿站）+高密度知识聚集组织（各怀绝技互相分享·不限国学）+资源整合社交平台；门槛远高于圈子/课程（付费+须为圈主/嘉宾+圈子经营考核）；**故意容纳"只学不讲"的成员，其年费=研究院收入来源**；管理层选举产生年度轮岗；要求=中上强度考核+自运转体系+共赢。

### 3.1 双轨席位制（"只学不讲"的制度化）

| | **讲席（分享席）** | **研修席（学习席）** |
|---|---|---|
| 义务 | 年度分享积分考核（3.3） | 无分享考核 |
| 年费 | 同研修席，**考核达标返 50%、优秀返 70%**（分享抵费） | 全额（研究院收入池主来源） |
| 权益 | 讲师五级培养通道→签约→驿站授课+榜单+带教资格 | 全部分享内容+活动+社交网络+优先咨询/约课权 |
| 转换 | 考核不达标→**自动转研修席**（不驱逐·全额年费）——制度自动分层不伤和气 | 可申请转讲席（补准入校验） |
- 比例控制：研修席:讲席 ≈ 2:1~3:1（后台可配）——保证收入池充足与内容供给平衡
- 年费建议值 **9,800 元/年**（后台可配·与驿站服务费同量级形成体系感）；现有"押金 1 万退费制"演化为讲席的"考核返还制"（返还口径=已达标考核期，防突击）

### 3.2 准入门槛（远高于圈子/课程·与圈子生态正向联动）

**讲席五维硬门槛**（平台数据自动校验——全部有现成数据源）：
1. 身份：任一圈子 OWNER 或 GUEST（CircleMember.role 自动校验）
2. 圈子规模：成员 ≥50 人（可配）
3. 作品：圈内容/文章 ≥20 篇且质量评分 B 级以上占比 ≥50%（**复用 E2 ContentQualityScore**）
4. 活跃：近 90 天圈子发帖/互动达标（TrackEvent/circle 数据）
5. 经营：圈子/课程累计创收 ≥5,000 元（可配·市场认可证明）
**研修席门槛**：实名+平台注册满 90 天+任一圈子成员+现有成员推荐 1 名（每人每年限荐 2 名·控规模保质量）
**特邀席位（V6·用户拍板：后台席位设置·名师破格引入·平台灵活掌控）**：管理员后台可直接引入成员——**跳过全部准入门槛+可设永久免会费**（feeExempt）；免会费成员自然豁免返还与转席逻辑（无年费可返·名师转席不体面），分享积分照记（进榜单·名师站台本身就是分享供给）；操作留痕（invitedBy+remark）。用途=冷启动名师站台/战略人物引入/生态灵活调节——**平台的"名师牌"**。
**生态效应**：门槛=圈主的晋升目标——研究院不是圈子的竞品，是圈子生态的塔尖与拉力（想进院→先做好圈子）

### 3.3 分享考核（中上强度·积分制替代次数制）

**年度 100 分达标线 + 季度 15 分最低线**（防年底突击·数值后台可配）：

| 分享行为 | 积分 | 数据源（自动采集） |
|---|---|---|
| **驿站线下授课 1 场** | **25**（最高·定向引导向驿站输送） | StationTeacher 排课/签到 |
| 院内沙龙主讲 1 场 | 20（×质量系数：到场率+评分） | InstituteEvent |
| 直播公开课 1 场 | 15 | live 模块 |
| 深度文章/案例 1 篇 | 10（**须质量评分 ≥B 级才计分**——数量不能换质量） | ContentQualityScore |
| 带教研修席成员 | 10/人/季（师徒·联动 V5 裂变） | 带教关系（P1 建） |
| 回答院内提问 | 2/次（封顶 20 分/年） | 圈内互动 |

**考核分层与处理（V5 定稿·用户拍板：必须有 100% 全返名额——心理底线与尊严·"只要努力都能拿回去"）**——**绝对指标制+线下硬指标，调节阀=坑位供给与阶段性指标调整**（取代 V4 相对排名制——排名制是零和游戏伤尊严伤续费，废弃）：

| 档位 | 条件 | 返还 |
|---|---|---|
| **全返** | 年度积分 ≥100 **且** 线下分享达标（当期指标三选一：旗舰驿站线下分享 ≥1 场 / 平台月度线下沙龙主讲 ≥2 场 / 季度高规格分享会主讲 ≥1 场） | **100%** |
| 半返 | 积分 ≥100 但线下未达标（纯线上分享型） | 50% |
| 保籍 | 积分 ≥60 且季度 ≥15 | 0（籍在） |
| 转席 | 连续两季 <15 或年度 <60 | 自动转研修席 |

- **调节阀（平台之手·用户核心洞察）**：全返率不靠比例卡，靠**线下坑位供给**调——旗舰驿站讲座档期、月度沙龙场次、季度高规格会讲席名额全部由平台排期；供给放多少，全返通道就多宽。章程写明「考核细则由平台于每年度初公布，阶段性调整」——指标调整权在平台
- **一石三鸟**：线下硬指标同时=旗舰驿站的内容供给（讲座落地）+讲师线下授课实战筛选（向驿站输送的真考核）+高规格分享会即研究院品牌活动
- **财务弹性化（用户拍板）**：研究院无固定开支承诺——奖励与津贴从收入池**弹性分红（多得多分、少得少分）**；极端情况全员达标全返可接受：讲席年费本就不指望留存，**研修席年费才是收入池主体**（双轨制闭环），全员全返意味着大量线下分享发生=平台收获内容资产+人气+驿站讲座供给
- 预警：advisor 探针按季度提醒积分与线下指标缺口（「距全返还差 1 场旗舰分享，本季旗舰档期开放报名中」——预警即引导）
**90% 考核数据自动采集**（分享行为都发生在平台上），管理层只做质量验证——这是自运转的地基。

### 3.4 财务自运转（收入池规则化分配）

收入池=研修席年费+讲席实付年费+知识库分成 → **固定比例分配（后台可配）**：运营 30% / 分享奖励与管理津贴 40% / 风险储备 20% / 平台服务费 10%。
- InstituteRevenue/InstituteDividend 模型已有·分红走 FundApproval 审批（防自审自批已修）
- 奖励规则化：季度分享之星（积分 TOP3）/年度榜单奖金/带教奖——**按规则自动触发候选名单，管理层确认发放**

### 3.5 治理（选举+强制轮岗）

- 管理层三职（PRESIDENT/VICE_PRESIDENT/SECRETARY_GENERAL·role 已有）**年度全员选举**：候选资格=讲席+上年考核优秀+入院满 1 年；一人一票线上投票（P1 建投票功能）
- **同职连任最多 1 届**（强制轮岗防固化·卸任后隔届可再选）
- 平台保留合规一票否决权（写入章程·防治理被劫持）；管理津贴从收入池 40% 档支出（有偿服务合规定性）
- 管理层职责：入会终审（数据校验通过后的人工面审）/分享质量验证/活动组织/奖励确认

### 3.6 自运转六飞轮

①考核自动化（数据自动采集+advisor 预警探针）②分层自动化（积分线触发转席/返还）③**供给飞轮**：考核逼出分享→好老师浮现（榜单）→签约进驿站（25 分引导）→讲师有收入有名→更多圈主想进院 ④**收入飞轮**：分享质量高→研修席慕名付费→池子奖励分享者→质量更高 ⑤治理飞轮：选举+轮岗+数据考核→管理层向成员负责 ⑥**生态拉力**：高门槛不冲击圈子反而拉动圈子经营（进院资格=圈子 KPI）

### 3.6.5 五位一体功能架构（V3·用户定纲：培训基地+私董会+学校+创业发展+圈层社交）

| 功能面 | 内涵 | 平台承接（最大化复用·用户提示"借助圈子功能"） | 状态 |
|---|---|---|---|
| **培训基地** | 讲师培养+学员研修+驿站实训 | 五级认证（已有）+带教制（3.3 积分）+T8 旗舰驿站区域实训中心联动 | 大部就绪 |
| **私董会** | 6-12 人闭门小组·轮流出题·众人拆解事业课题 | **私密子圈**（免费圈+needApproval·每小组一圈）+圈公告排期+闭门直播（live 圈内可见）+CircleKnowledge 沉淀案例 | 圈子全套现成·P1 建小组管理 |
| **学校** | 体系化课程·学制·毕业 | course 模块（研究院精品课程系列·会员免费闸门已有）+GRADUATED 状态（已有）+结业证书（V10 裂变联动） | 复用为主 |
| **创业发展** | 成员事业孵化与资源对接 | **平台本身即创业路径**：开驿站（T8 认证合作）/做圈主/做讲师/城市服务商——研究院=从业者创业的人才池与推荐通道；成员资源对接走圈层社交 | 制度衔接 |
| **圈层社交** | 高净值成员社交网络·不限国学的分享交流 | **Institute.circleId 专属大圈**（字段已存在！入会即入圈）：公告/知识库/圈主助理全套现成；成员名录（已有 members 页）+资源发布（圈内帖） | 字段就绪·P1 接通 |

**架构结论**：研究院不重建社交基础设施——**研究院=圈子体系之上的「制度层+身份层」**（准入/考核/席位/选举是制度，圈子承载日常交互）。P1 实施量因此大幅下降。

### 3.6.6 总院-分院体系（V4·用户拍板：可设多个分院·同机制运营·关系恰到好处）

**分院=专业维度的网络节点**（八字研究院/书法研究院/××商学院……），与城市服务商（地理维度节点）构成平台的两张网。

**总院-分院关系设计（"恰到好处"的分权）**：

| 维度 | 总院（平台直管） | 分院（自治运营） |
|---|---|---|
| 定位 | **标准制定+认证机构**，不直接收个人成员 | 成员归属地·按同一机制运营（双轨席位/积分考核/选举轮岗） |
| 认证权 | **讲师五级认证与签约=总院统一颁发**（跨分院通用·保证含金量不稀释） | 分院可推荐，无认证权 |
| 财务 | 收分院上缴（建议：分院收入池的 15%=平台 10%+总院公共基金 5%·后台可配） | 收入池独立核算·按 3.4 比例自治分配（比例中"平台 10%"改为"上缴 15%"） |
| 治理 | 章程/考核框架/准入标准/合规否决权/分院授牌与摘牌 | 自选管理层（年度选举+轮岗）·自办活动 |
| 榜单 | 总榜（跨分院·统一计分口径） | 分院榜 |
| 品牌 | 命名规范（「××研究院·平台认证」）+授牌体系 | 分院 IP 自建（院长个人品牌+领域号召力） |

**分院创设机制（又一把"事业椅子"）**：分院院长发起制——申请条件建议：讲席成员考核优秀 or 领域公认大咖（平台邀请）+首批成员承诺（≥20 人意向）+院长资质审核 → 平台授牌试运营（6 个月内成员达标转正，同服务商筹备期逻辑）。**分院院长与城市服务商、旗舰驿站主构成平台三大事业位置**——晋升叙事互通（研究院优秀成员是三个位置共同的人才池）。

**技术影响（P1 架构项）**：现有 `InstituteMember.userId @unique` 是全局一人一院约束——分院制下须改为 `@@unique([instituteId, userId])`（一人可入多个分院·多份年费商业上成立·分享精力自摊薄由考核自然调节）；现有代码单院假设（intro/my 等端点）需多院化改造——**P1 批次一并做，工作量中等**。
