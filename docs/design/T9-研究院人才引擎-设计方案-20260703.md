# T9 研究院人才引擎 — 设计方案 V1

> 创建：2026-07-03 · 课题=作战计划 T9（学术权威建设+命理师等级认证+内容资产沉淀）· 设计自主拍板
> 侦察结论：五级培养链路（NONE→PREPARATORY→JUNIOR→SENIOR→SIGNED·管理层推荐制）与签约→驿站供给（StationTeacher.sourceUserId）后端全通；**InstituteContent 付费知识库后端完备前端 0 页**；榜单无模型但数据源齐（任务/活动/驿站覆盖/资历）；缺真实会费支付（mock·等支付门控）与活动报名

## 一、定位

研究院是平台师资供给的源头与学术权威的载体：**筛选（付费准入+任务考核）→ 培养（五级认证）→ 输出（签约讲师进驿站网络+内容资产沉淀）→ 权威（榜单/白皮书反哺品牌）**。T8 驿站网络铺开后，师资供给能力就是驿站网络的天花板——T9 是 T8 的水源工程。

## 二、分期

### P0-a 讲师影响力榜单（学术权威的数据化起点·本窗口）
- `GET /institute/rankings?period=`（公开）：实时聚合+Redis 缓存 1h（成员规模小·YAGNI 不建表）
- **维度与权重**：年度任务完成 40% + 授课活动场次 30% + 驿站覆盖数 20% + 资历年限 10%——**收入数据不进公开榜单**（合规与体面：学术榜单不谈钱）
- 前端：pkg-institute 榜单页（前三名突出+完整榜单+各维度分值透明展示）+ 研究院首页入口
- 讲师公开主页补「研究院签约讲师」金标徽章（SIGNED 时显示·信任资产联动）

### P0-b 大师讲座付费知识库前端（做了不展·本窗口）
- 核实并补 C 端端点：GET 内容列表/详情（PUBLISHED）+ POST 购买（**国学币支付·复用 coin.spend 原子模式**·已购永久可看）
- 前端：内容列表页（ARTICLE/VIDEO/DOCUMENT 类型标签+价格）+ 详情页（未购看简介与试读/已购全文或播放）+ 我的已购
- 定价：纯币价起步；**会员折扣/豁免待用户拍板**（会员权益三项清单里没有讲座，不擅自扩权益）

### P1（后续批次）
