# 线下驿站板块 · 给 V0 的开场提示词（2026-07-12）

> 用途：连同《线下驿站板块-V0设计委托书-20260712.md》一起发给 V0，先定调再让她按委托书出稿。

你好，帮我设计一个**移动端 H5**（390px 宽，纯静态 HTML 稿，稿内用 HTML 注释标数据来源与交互）的「**线下驿站**」板块。完整规格见附件《线下驿站板块-V0设计委托书》，这里先讲清最关键的几点，请务必先理解再动手：

**一、定位（B 端是重点）**
线下驿站 = 平台的「**线下服务终端**」：线上引流、线下交付（线下课/面授/沙龙/师承）。**重点在 B 端——驿站运营者后台**：一个驿站主在这里经营实体教学点，主动线是 **排课 → 招生 → 到店核销 → 选用讲师 → 卖驿站商品 → 结算**。C 端只是学员"找驿站、报名线下课、到店签到"的轻链路。

**二、把 C 端 / B 端切干净（现状混杂）**
- C 端 4 页：发现驿站 / 驿站详情（含师资、商品、地址导航）/ 线下课报名 / **我的报名·到店签到凭证**。
- B 端 7 页：驿站工作台 / 品牌资料 / 课程排期管理 / **招生与核销** / **师资管理** / 驿站商品 / 订单与结算。

**三、核心（重点设计）**
1. **B 端线下经营闭环**：把 B1→B7 串成一个顺手的经营工作台，不是零散页面堆砌；B1 工作台聚合"待办+数据"。
2. **到店核销双向**：C 端学员报名后生成**核销凭证**（二维码 + 6 位核销码 + 场次/地址）；B 端运营者**扫码/输码核销**，名单实时标"已到店"。两态都要出。
3. **从签约讲师库选用讲师**：B 端师资管理里有个入口，拉起平台**签约讲师库**列表 → 选中 → 该讲师入驻本驿站、可排期被预约。（这是"书院研究院签约讲师 → 驿站授课"闭环的驿站侧落地。）

**四、要砍要合（别照搬旧的 10 页）**
按委托书重构为 11 页并 C/B 切分：驿站对外主页并入详情；语义冲突的"师资预约"拆成 C 端师资展示 + B 端师资管理；别做成独立的"师资需求大厅/人才库"页（那就是 B 端师资管理）。

**五、图片比例**
驿站环境图/课程封面 16:9（1280×720），驿站商品 1:1（800×800）；未上传位统一虚线占位。

**六、流程**
**分两阶段**：先出**线框级信息架构稿**（重点让我确认 C/B 切分 + B 端经营闭环 + 到店核销双向）→ 我确认后 → 再出视觉稿。

具体每页简章、数据能力边界、视觉 token 全在委托书里。**B 端线下经营闭环 + 到店核销是灵魂，请重点打磨。**
