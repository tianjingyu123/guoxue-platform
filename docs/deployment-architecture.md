## 五、数据流

### 5.1 用户请求路径

```
小程序/H5/管理后台
    │
    ├─ 静态资源请求 (图片/CSS/JS)
    │   → CDN (腾讯云 COS) → 命中缓存直接返回
    │   → CDN Miss → COS 源站 → 缓存到 CDN
    │
    ├─ API 请求
    │   → Nginx 反向代理 → guoxue-server:3000
    │       │
    │       ├─ 读操作 → Redis (缓存命中) → 返回
    │       │         → Redis Miss → PostgreSQL → 写入 Redis → 返回
    │       │
    │       ├─ 写操作 → PostgreSQL (主库)
    │       │         → 清除/更新 Redis 相关缓存
    │       │
    │       └─ 文件上传 → 腾讯云 COS → 返回 CDN URL
    │
    └─ WebSocket 连接
        → Nginx (Upgrade: websocket) → guoxue-server:3000
        → Socket.IO 长连接 (IM 消息推送)
```

### 5.2 支付回调路径

```
微信支付/支付宝平台
    │
    └─ POST {notify_url}
        → Nginx → guoxue-server:3000
            → shop/wechat-pay.service 或 shop/alipay.service
            → 验签 → 更新订单状态
            → 发放权益 (课程/虚拟币/商品)
            → 发送通知 (小程序订阅消息/站内信)
            → 返回成功应答
```

### 5.3 定时任务

```
@nestjs/schedule (内置在 server 进程)
    │
    ├─ 每小时: 推荐 CTR 计算
    ├─ 每日 02:00: 用户兴趣挖掘
    ├─ 每日 03:00: 协同过滤矩阵更新
    ├─ 每日 04:00: 趋势计算
    ├─ 每日 05:00: 收入统计结算
    └─ 每 5 分钟: 刷单检测扫描
```

## 七、推荐的生产环境规格

### 7.1 服务器配置

| 环境 | 规格 | 说明 |
|------|------|------|
| **最低配置** | 2C4G + 40GB SSD | 适合日均 PV < 1万 的小规模 |
| **推荐配置** | 4C8G + 80GB SSD | 适合日均 PV 1-10万 的中等规模 |
| **高配** | 8C16G + 200GB SSD | 适合日均 PV > 10万 |

### 7.2 资源分配

| 服务 | CPU | 内存 | 磁盘 |
|------|-----|------|------|
| NestJS Server | 1-2 核 | 256-512MB | 5GB (日志+上传) |
| PostgreSQL | 1-2 核 | 512MB-1GB | 20-50GB (数据) |
| Redis | 0.5 核 | 128-256MB | 2GB (持久化) |
| Nginx/Caddy | 0.5 核 | 128MB | 1GB (日志) |

### 7.3 扩容路径

```
当前: 单机 Docker Compose (2C4G)
  │
  ├─ Phase 1: 升级服务器规格 (4C8G)
  │
  ├─ Phase 2: 数据库分离
  │   · 迁移到腾讯云 CDB PostgreSQL (托管数据库)
  │   · 迁移到腾讯云 Redis (托管缓存)
  │
  ├─ Phase 3: 多实例 + 负载均衡
  │   · 2× NestJS 实例 (CLB 负载均衡)
  │   · 1× 任务调度实例 (定时任务专用，避免重复执行)
  │
  └─ Phase 4: 容器编排
      · TKE (Kubernetes) 管理多服务
      · HPA 自动扩缩容
      · 滚动更新 + 自动回滚
```

