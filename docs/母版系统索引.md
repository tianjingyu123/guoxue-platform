# 热卜国学 · 母版系统索引

本文件汇总原型中沉淀的「母版」（可复用的视觉/交互范式）。迁移到 Vue3 + uniapp 时，
按此索引逐个对照实现，避免面对分散的半成品。所有母版统一国风视觉语言：
**故宫红 #c41e3a · 鎏金 #c9a96e · 宣纸米色 · 思源宋体**，全程使用设计令牌（深色/小程序友好）。

- `/common/achievement-demo` 成就时刻

## 迁移要点

1. canvas 渲染引擎（海报、成就卡片）是纯函数，迁移到 uniapp 时把 `CanvasRenderingContext2D`
   换成 uniapp 的 `CanvasContext` API，绘制逻辑可直接移植。
2. 母版组件全部使用设计令牌，切换主题/深色模式无需改组件。
3. 接入新场景时，参考各母版"已接入"页面的数据映射写法。
