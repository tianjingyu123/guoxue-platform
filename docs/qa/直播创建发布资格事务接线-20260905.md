# 直播创建发布资格事务接线

## 已实现

- `LiveService.createRoom` 经 `LivePublicationService` 使用新 LIVE 资格，不再只对 PLATFORM 检查旧审批，也不再按 OWNER/ADMIN/PARTNER 静态头衔挡住平台直授成员。
- 非管理员只能用本人资格创建本人主持的直播。当前圈主按圈级授权核验；其他成员按个人直授核验。角色、主体、配置、撤权校验复用真实能力服务。
- 授权锁、房间创建、审核记录在同一数据库事务内。审核失败不留房间，也不调度后置机审。
- 真人平台管理员沿用后台权限，不依赖圈子申请；内部 AUTOMATION 也被外发红线拦截，控制器显式传递执行者类型。
- 预告创建不占开播并发额度。未改变列表、详情、观看、私密和付费规则。
