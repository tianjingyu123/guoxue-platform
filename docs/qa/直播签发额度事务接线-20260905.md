# 直播签发与额度事务接线

本轮仅本地修改，未发布、未连接云端数据库、未调用供应商停流。

## 已接入

- 房间 stream-urls 在同一数据库事务中读取发布资格、锁定房间并预留/激活媒体资源；凭据在提交后返回。
- 重复领取及正式开播复用 LIVE_SESSION 的 ACTIVE 记录，不重复计数；授权版本/绑定变化时拒绝刷新。
- 签名失败回滚；结束 WAITING 预告后不再签发。结束业务仍不冒充媒体停止，ACTIVE 保留至可信收尾。
- 签发、开播、结束按圈子锁→房间行锁顺序串行化。TRTC 回调映射在提交后写缓存。
