# 直播停流前提与供应商适配

仅本地开发与模拟网络测试；未部署、未真实禁推、未读取腾讯云密钥、未更改云端配置。

## 核对的官方语义

- [ForbidLiveStream](https://cloud.tencent.com/document/api/267/20468)：默认仅按流名匹配；域名+路径+流名强匹配须联系腾讯云开通；默认禁推7天，最长90天。
- [DescribeLiveStreamState](https://cloud.tencent.com/document/api/267/20470)：active、inactive、forbid 三种结果。官方建议结合回调和其他在线信号判断，不能把查询超时当作已停止。

## 已完成的本地改动

- 房间推流地址入口要求明确领取者；只允许 WAITING/LIVING 且未被下架，结束/回放/封禁/取消状态连管理员也不能重签。
- CSS 生成器验证流名字符与长度，签发有效期必须为1至86400秒整数。该约束是后续有限禁推覆盖历史凭据的前提之一，不单独等于安全收尾。
- 内部 `LiveCssStopClient` 每次只发一条禁推请求，不自动重试。强匹配未核验、目标无效或禁推时间超范围时不发送。
- 请求成功仅 `ACKNOWLEDGED`；HTTP/网络/解析/API失败均 `UNKNOWN`，不返回供应商原始错误或秘密字段。只读查询保留 active/inactive/forbid，不把 inactive 当作禁止重连。
- 所有网络测试均替换 fetch 和凭据解析；固定请求目的地是 `live.tencentcloudapi.com`，拒绝重定向。
