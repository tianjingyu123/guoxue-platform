# 发布申请冷却期与个人启用接线

## 本地实现

- 短视频/直播共享申请面板改用服务端 application-context 的 canApply，不再仅凭经营资格 eligible 判断能否重申请。冷却期明确提示；过期批准是否能重申请以服务端计划器为准。
- 先读本人 current 授权，再区分圈级申请与个人直授。个人获批未启用时不调用仅限圈主的申请预检，不要求出现在旧圈主列表中，启用仍绑定 grant ID 与 revision。
- 管理员暂停、撤销或已过期的个人资格不可在前台自行恢复；本人启用不等于平台解封。服务端写入仍重复核验。
- 申请和启用写动作绑定已核对圈子、能力及主体，关闭面板或切圈后的旧数据不允许写入。未改阅读权限，未申请真实授权。

## 验证与边界

- 共享面板和权限适配器运行测试 14/14；包含冷却期、过期批准重新预检、个人直授、管理员暂停、错人和切圈案例。
- 与咨询可用性和圈主嘉宾申请联合回归 41/41 通过；指定文件 diff-check 通过。
