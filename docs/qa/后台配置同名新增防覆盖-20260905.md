# 后台配置同名新增防覆盖

## 发现与修复

当前 POST 新增原先复用 upsert，持有同名记录的最新预览指纹也能覆盖已有配置，不符合新增操作语义。
新增接口现传递仅创建模式，在 Serializable 事务内发现同名立即返回 409，不写配置、历史或缓存。并发唯一键冲突转换为重新加载提示，不自动重试旧意图。PUT 原有创建或更新兼容性保持。
