# 发布授权后台合成浏览器验收

## 范围

真实加载 `CircleCapabilityList.vue` 和 `CircleDirectGrantDialog.vue`，在独立无头 Chromium 中操作 Element Plus 表单。Vite 仅监听 `127.0.0.1`，Axios adapter 全部使用内存合成数据；浏览器拦截非 `127.0.0.1` 请求。未登录真实账号、未写数据库、未创建真实授权、未操作云端。

本地夹具与可复跑脚本：`D:\gx-deploy-91\artifacts\local-qa\capability-ui-20260905`，执行 `node artifacts/local-qa/capability-ui-20260905/check.cjs`。需先启动该目录的 `serve.mjs`，测试目标为 `http://127.0.0.1:5173/`。夹具故障注入接口不进入产品构建。

## 本轮结果：6 组通过

1. 选择圈子、成员、确认对象后，缺期限/额度/原因不能提交，合成写入为 0。
2. 从个人范围切换为圈子整体范围，旧确认快照立即失效，提交按钮禁用。
3. 确认后注入接口故障，提交不显示成功，清除确认快照，不自动重试；合成写入仍为 0。
4. 恢复接口、重新确认、填写有效内容，双击直授只产生一次合成请求并关闭弹窗。
5. 驳回必须填写原因；双击仅一次请求，携带 `expectedRevision=7`、`action=REJECT` 及填写原因。
6. 列表重新加载失败时明确报错，旧记录操作按钮被清除，不能对陈旧列表继续审核。

全程浏览器 `pageerror` 为 0，脚本 ExitCode=0。两次合成成功请求分别为直授和驳回，不代表任何真实授权状态。

## 测试准备问题与边界

- 沙箱启动无头浏览器遇到 `spawn EPERM`，经批准在沙箱外运行同一本地受限测试；并非业务错误，也不是 Windows 1344。
- Element Plus 的点击目标采用可见选择器外层，并等待成员加载完成；不强制点击禁用控件。
- 此验收不覆盖真实后端事务、令牌失效、生产角色、真实分页、多用户竞争、客户端开播或问答。
- 当前新控制器未注册到 CircleModule，新后台页面未挂正式路由/菜单。直播与问答接线、存量授权兼容及完整验收结束前，不可将此报告作为正式上线通过证据。
- 发布资格与普通阅读/观看权限分离；本轮未扩大阅读限制。
