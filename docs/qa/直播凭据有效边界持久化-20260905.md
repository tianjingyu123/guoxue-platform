# 直播凭据有效边界持久化

## 用途与实现

停流必须使用本场实际签发的供应商范围，并覆盖所有已签凭据的最长有效期，不能仅依赖当前环境配置或最近一次回调。

- 新 LiveMediaCredentialBoundary，复合主键 roomId/provider；记录 CSS 域名/应用/流名或 TRTC 应用/房间，以及 expiresAt、revision。
- 不保存完整 URL、txSecret、txTime、UserSig、privateMapKey。
- 仓储持 LiveRoom 行锁，只允许未结束、未下架房间；刷新只延长期限，重复/较短期限不缩短。已有范围变化拒绝，CSS/TRTC 分别保留。
- 写入须与签名事务共同提交；已在本地接入 LiveService 的开播、OBS 刷新和 RTC 签发，并注册模块。尚未部署，不可作为线上已经生效的证据。
