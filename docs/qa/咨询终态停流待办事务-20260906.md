# 咨询终态停流待办事务

## 当前实现

- `ConsultCallMediaBoundary.stopIntent` 以 JSONB 持久化待办，新增独立迁移 `manual_add_consult_call_stop_intent`。尚未在远端执行。
- 结束、取消及超时扫描先按圈子锁→订单锁取锁，再认领终态、写入待办和退款，处于同一数据库事务。
- 待办只包含操作编号、原因、发起者、时间、原 SDKAppId/房间、凭据版本和保护截止时间，不包含 UserSig、PrivateMapKey 或密钥。
- 保护截止时间为原票据到期时间与当前时间的较晚者加五分钟。该时间不是媒体停止证明，也不触发额度释放。
- 历史订单没有可信签发边界时不伪造待办，仍允许原有取消/退款；已有待办不覆盖或重新编号。存在待办的边界不再接受续签。
- ACTIVE 资源保持占用，未新增云端调用、自动重试或管理后台强制释放入口。
