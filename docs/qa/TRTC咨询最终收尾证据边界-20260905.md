## 当前源码与剩余缺口

咨询 `buildTrtcConfig` 已签发用户/字符串房间绑定的 UserSig 和 privateMapKey；直播 `live-trtc.util.ts` 也包含房间权限票据。两者均读取 TRTC_SDK_APP_ID，但尚未核对当前云端应用、在用客户端、混流入房参数及旧票据范围，不能据此声称同应用全部兼容。

咨询当前移出用户 ACK、离线回调和票据过期分别只是部分证据；尚未实现可验证的最终关闭证明及同事务账本完成记录。不得用历史监控 API 替代实时完整证明，不得引入任意布尔值或手工改库作为完成凭证。

下一阶段必须取得：

1. 当前目标应用和高级权限控制状态的只读证据，以及各在用入房路径兼容情况。
2. 合成测试中缺失、错误房间、到期权限票据均被云端拒绝的证据；不使用真实用户票据。
3. 原票据有效窗口结束后的最终媒体结束证据，并明确异步回调、重投、乱序、重入的处理与数据缺失时的补偿方案。
4. 在同一主库事务锁定圈子/订单/边界/账本、校验凭据版本和完结回执，实现并发幂等收尾后再开放能力审批控制器。
