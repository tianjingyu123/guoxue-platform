# 发布页异步准入收口

- 短视频原入口只在 PLATFORM 范围预检资格，CIRCLE_ONLY 会跳过前台预检。现所有发布范围均先核验 SHORT_VIDEO；不改普通阅读。
- 查询忙状态防重复点击；选圈变化或页面离开使迟到结果失效，不弹申请、不继续上传。视频上传后及封面上传后再次核对页面代次和圈子，写入圈子绑定核验时的值。
- 直播创建页增加离开/返回代次边界，迟到 LIVE 资格不会触发建房或申请弹窗。
- 正在上传的文件不主动删除；已发出的服务端写请求不宣称可以撤回，最终写权限仍由服务端核验。
- 实际页面函数回归 10/10 通过，覆盖本圈无资格、获准发布、重复点击、切圈、离开及上传期间失效；指定 diff-check 通过。未上传真实视频、未建房、未部署或付款。
