# 排盘整套切换后台浏览器验收

环境：本机127.0.0.1:4188，真实 NativePaipanPreview.vue、Vue与Element Plus；内存合成API及身份替身，无线上连接。不是正式后台登录/权限验收。

实际浏览器操作结果：

- 初始第三方模式、预览关闭；无修改时保存禁用。
- 选择自研后保存可用；确认弹窗明确普通用户入口、预览、MP维护与不迁移历史/不改变收款体系。
- 取消后已确认写入仍为0。
- 再次确认后写入为1，权威状态显示native，自研单选选中，预览仍关闭。
- 模拟下次冲突，选择第三方并确认：写入仍为1，显示保存未获确认、要求重新加载；旧状态清空，保存禁用。
- 重新加载显示权威native状态，未把失败的第三方选择当成已保存。
- 当前桌面视口截图检查：表单文字、单选、预览开关和底部按钮均完整可见，无重叠。尚未完成窄屏与键盘无障碍验收。

配套真实PostgreSQL的切换往返/审计/并发证据见需求进度文档；本次浏览器API不替代真实HTTP与数据库整链路测试。客户端路由、第三方共用罗盘、正式签名包真机仍未据此判绿。

启动方式：`node apps/admin/node_modules/vite/bin/vite.js --config scripts/qa/paipan-suite-browser/vite.config.mts`。只监听localhost，不配置生产代理。
