# 达人预约授权事务接线

## 本地变更

- 时段查询不再按 OWNER/PARTNER/GUEST 头衔决定音视频服务资格；分批扫描当前有效成员，按独立音视频批准投影选取可用服务。未获批的第一个圈子不再遮住其他圈子的授权。
- 时段与占用查询采用同一 REPEATABLE READ 事务，不从共享缓存复用旧授权结果。
- 创建预约在同一事务内串行锁定达人/日期，重新核验服务能力、实际预约者主库身份、圈子成员有效期及配置时段，再检查交叠并创建。不存在批准、撤权、账号/成员失效时拒绝新增；不删除已有预约。
- 控制器透传执行者类型，自动化不能直接占用预约时段。
- 真实并发测试发现既有冲突默认映射 HTTP400，现精确改为 HTTP409，不改变冲突判断或放宽测试。
