# 圈内能力持久化第五批：本地验收

基线：`f25b7471f5063a612a17a422a64900a29b5f8cd3` / v243 的独立工作树未提交增量。本批只处理服务端授权工作流，不代表该 SHA 已含全部改动，也不生成新的云端候选。

## 本批实现

- 四项能力分开申请，不继承旧平台授权或用价格代替批准。
- `CircleCapabilityGrant` 保存按圈/能力/主体区分的历史申请和授权；`CircleCapabilityAudit` 保存每次版本变更快照、操作者与原因，外键限制级联删除。
- 达标只生成待审记录，人工批准仍禁用；圈主或服务者本人再启用。嘉宾的音频/视频问答必须同时有对应圈级和个人授权。
- 同事务重读资格、当前圈主、账号及平台角色；版本/状态条件更新失败不返回成功；审计写入失败使申请/审批回滚。
- HTTP 控制器已实现参数验证、身份/角色、人工红线、禁止资格和状态缓存；仅独立测试模块注册，正式 CircleModule 继续不注册该控制器。
- 新迁移 `manual_add_circle_capability_workflow` 只新增 2 枚举、2 表、6 索引和 2 个 RESTRICT 外键，不删除/回填历史数据；完整空库基线已更新。
