# 咨询媒体后台只读核查

## 面向运营的入口

现有通话账单申诉页增加媒体与资源核查区。可直接输入通话 UUID，也可点击任意申诉记录的“媒体状态”并定位到核查区。不要求创建申诉才能按 ID 查询。

沿用后台 Element 主题、字体和颜色变量；左对齐查询，单列状态详情，窄屏查询按钮换行。风险状态用中文解释，不将 ACK 或退房涂成“全部完成”。未新增支付、停流、重发或释放按钮。

- GET `/api/v1/consult-calls/admin/media-status/:id`：仅超级管理员、运营管理员。
- 单条参数化 SELECT 联查订单、媒体边界和资源账本，无网络请求、事务写入或供应商动作。
- 显示订单状态、凭据修订及到期时间、停流待办记录、回调观察及事件时间、资源账本状态。
- 不返回账号 ID、映射用户 ID、SDK 应用号、房间鉴权范围、票据、回调原文、签名或原始供应商错误。
- 异常、跨范围、重复记录不冒充成功；无历史证据明确显示未跟踪/未知。
- 查询失败清除旧成功；切换记录、账号、权限或离开页面时丢弃迟到响应。
- 明确：记录状态不是供应商停流完成证明；`canRelease=false`，额度没有因该页面改变。
