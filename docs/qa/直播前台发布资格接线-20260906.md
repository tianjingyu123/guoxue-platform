# 直播前台发布资格接线

## 本地修改

- 将短视频授权面板复用为显式 SHORT_VIDEO/LIVE 两种发布能力；请求、进度、当前授权、申请及本人启用均精确传递该能力，不能以短视频授权代替直播授权。
- 直播创建页增加“核对开播资格 / 申请开通”入口；核对成功只提示用户继续确认，不自动建房或开播。
- 圈子选择不再仅按 owner/admin 角色过滤，允许已加入圈子的个人直授成员选择。选择圈子并不获得授权，实际创建仍由后端事务再次核验。
- 新建预约、OBS和手机直播在调用createRoom前核验LIVE资格；仅本圈也不能绕过。查询中阻止重复提交，切换圈子后丢弃旧查询结果。
- 编辑已有房间和已创建房间的重试沿用既有服务端校验，没有强行新建替代房间。未改变普通观看、连麦申请或付款逻辑。

## 证据

- 共享面板与请求适配器11/11：包含LIVE精确查询和申请、拒绝短视频能力替代。
- 真实创建页函数脚本4/4：拒绝时零建房、授权后单次OBS建房、查询重复点击/圈子切换保护、仅核对不触发建房。
- 直播安全区既有门禁25/25，合并29/29；mobile Vue类型检查通过。
- 以上均本地合成测试，不是实际腾讯云房间或同包真机。未部署、未签发真实票据、未创建真实直播、未付款。

## 剩余

实时问答提供者申请及本人启停入口仍需对齐；随后需在冻结候选同包上验证直播创建、审批直授与媒体接通，不能以脚本测试代替实际通话。
