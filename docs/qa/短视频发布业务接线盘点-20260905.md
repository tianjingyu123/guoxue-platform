# 短视频发布接线盘点

实际 VideoService.create 当前：解析圈子→仅 PLATFORM 可见性核旧 CirclePublishGrant→解析可见性→video.create→事务外创建审核记录→异步机审。新 CircleCapabilityQuota 未调用。作者 update 可直接改状态、标题、封面；audit 单独更改发布状态。

因此不能直接塞入一个额度检查便宣称同事务接入完成：需明确业务实例/幂等标识、圈主与平台个人直授主体选择、审核与业务记录原子性及可靠机审调度。不得用现有 isAdmin 布尔当作新平台直授证据，不以普通新 MEMBER 头衔限制覆盖真实直授。

本轮确认并修复 POST /videos 与 PUT /videos/:id 缺少 EXTERNAL_PUBLISH 红线。新增真实 HTTP 用例证明带 AUTOMATION 的作者调用在业务前403；真人作者仍按 isAdmin=false 进入业务。视频控制器与新增 HTTP 共26/26，server tsc通过。

身份和业务服务为合成替身，未创建实际视频、未调供应商或线上。此修复不等于新能力/额度业务接入完成。现有红线基于显式标记或已识别数字员工，不能防止未识别的自动化伪装真人。
