# 平台直授后台交互保护（第九批）

本批仅完成后台交互会话模型，未完成页面、预览接口或业务接线，不构成上线验收。

## 完成范围

- 对象变更使旧查询失效；异步结果必须匹配对象及查询代次。
- 预览有效期最多 60 秒；时钟倒退要求重查。该限制是交互保护，不代替服务端鉴权。
- 理由、有限期限和正整数额度必须明确填写，不提供商业默认值。
- 提交携带最新授权 ID/修订；仅发送字段白名单。
- 单次提交期间禁止再次提交及切换对象；结束后不保留可再次提交的旧预览。
- 网络失败与结果不明均应由页面调用 settle，随后重新查询，不自动重发 POST。
