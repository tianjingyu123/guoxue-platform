# 后台功能开关分页与恢复闭环

## 发现与修复

- 服务端列表返回全量数组，前端原先没有分页切片。现按20项分页，删除末页后收敛到有效页；仍兼容带明确total的分页响应。
- 慢列表响应不再覆盖新请求；异常响应作为加载错误，不伪装成零条配置。
- 编辑结果不明后的“重新加载”改为按精确key读取，校验返回对象；错误或不存在时保持发布锁。服务端管理详情直接读主库并加private/no-store，不复用运行时缓存。
- 历史查询用请求序号隔离，切换对象后旧响应不能覆盖新历史；加载失败有明确重试入口，禁止回滚。
- 页面说明未配置表示沿用业务默认值，不等同停用；错误态与真实空态分开。
