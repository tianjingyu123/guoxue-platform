# 咨询终态资金红线补齐

## 缺口与改动

咨询结束会结算及退还多扣预付，取消会退还预扣；原 HTTP 端点没有 RedLineGate，服务层也未接收执行者类型。带 AUTOMATION 的身份可能继续进入资金业务。

- `ConsultCallController` 的 end、cancel 均声明 MONEY、EXTERNAL_PUBLISH，并向服务层传递解析后的执行者类型。
- `ConsultCallService` 对这两个入口在任何查询、事务或资金动作前再次断言；避免仅靠控制器元数据。
- 真人默认调用和既有内部超时补偿语义保留，不重新要求已撤销的发布资格才能取消。
- 无新增迁移，没有真实资金、云端配置、部署、DNS 或设备操作。

## 证据

- 服务单测、关键红线元数据、真实 Nest HTTP 红线 E2E：3 suites / 80 tests，Exit 0。
- AUTOMATION 两端点为 403；服务层直接调用在任何查询、事务、退款、分账前拒绝。
- HUMAN 两端点针对不存在记录进入业务并返回 404，不被错误阻断。
- 隔离本地 PostgreSQL 专项：4/4，另外 135 项未在此轮执行。包括取消仅结束订单、退款失败回滚、两连接同时结束仅一次结算、历史无边界等待单可取消。
- 服务端 TypeScript：Exit 0；精确修改文件 diff-check：Exit 0。
- 服务端 Nest production build：Exit 0。
