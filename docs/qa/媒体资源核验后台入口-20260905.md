# 媒体资源核验后台入口验收

## 本轮实现

- 在直播列表的已结束/回放房间提供「资源核验」入口，显示结论、下一步、额度状态、媒体证据、供应商查询时间及当前响应节点的任务状态。
- GET `/api/v1/live/admin/media-closure/:id` 为只读接口；真实角色守卫先拦截，服务再次读取主库用户状态及无圈子绑定的平台管理员角色。响应 `Cache-Control: private, no-store`。
- 不返回推流范围、原始签名、供应商原文、密钥或凭据；不提供强制释放、重复停流等写入口。
- 关闭、换房、重复刷新和失败不会残留上一房间的成功状态。
- 已结束且有结束时间的房间发布回放后，可继续按原停流意图查询收尾；没有结束时间的回放状态不能冒充媒体已结束。
