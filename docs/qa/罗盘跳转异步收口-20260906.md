# 罗盘跳转异步收口

## 复现与修改

直接抽取承接页真实 `openNativeCompass` 函数运行，四项回归修复前全部失败：重复桥消息会创建两次导航；隐藏页面或换文档后迟到的 `canBack` 仍后退；隐藏后的失败仍弹提示。

最小修改仅在承接页增加打开中状态，并将后退限定为同一可见子窗口、同一文档版本和 URL；导航失败可重试，回到承接页重置打开中状态。没有更改排盘整体权限、第三方商户、支付或云端配置。

新增 `legacy-compass-navigation-runtime.test.mjs`，并将其及既有布局、读数来源测试纳入 `release:test-paipan-suite`，避免只手工跑专项而常规门禁遗漏。
