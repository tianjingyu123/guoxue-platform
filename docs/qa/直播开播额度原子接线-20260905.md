# 直播开播额度原子接线

## 当前本地实现

`LiveService.startLive` 调用 `LivePublicationService.startInTransaction`，开播时重新读取房间及新 LIVE 授权。非管理员的额度 RESERVE、ACTIVATE、房间 WAITING→LIVING 在同一主库事务提交。CircleCapabilityService 负责当前账号、圈子、成员、配置、授权和个人直授校验，不使用创建时的旧快照。

房间不允许结束后重新回到 WAITING，因此其 ID 作为一次直播业务实例。重复开播返回 HTTP409，不重新创建额度。原子更新同时核对状态、主播、圈子、审核及方向；并发失败回滚已产生的额度和回执。手机/OBS 控制器均传入执行者类型，自动化不因管理员身份绕过红线。OBS 仍要求媒体预检。

外部通知、IM 建群及 Redis TRTC 映射在数据库事务提交之后。普通列表与观看权限未改变。
