# 达人本人服务配置闭环（本地验收）

## 本轮完成范围

- 在既有公开咨询授权投影基础上，将音频/视频的批准状态与正价格启用状态分离。平台直接授权的普通成员可以从零价格开始配置已批准服务，不再被固定头衔排除。
- 本人配置使用独立 JWT 接口，身份仅取服务端认证用户；响应禁止共享缓存。本人可以读取历史价格并关闭失效服务，公开接口仍隐藏未获准的旧通话价格。
- 写入在同一主库事务内锁定圈子、相关成员、实际操作者及角色，重新检查当前批准。管理员代配置必须有主库当前有效的全局管理角色，不信任旧令牌中的管理声明；自动化资金配置入口拒绝。
- 文字提问维持原准入规则，不因音视频批准扩大权限。不改变普通阅读/观看权限。
- 客户端允许圈子成员进入服务状态页；未批准的服务只能关闭，不能开价。保存/加载时禁止切换修改，迟到的其他圈子配置响应不能覆盖当前圈子。
