# 圈内能力事务组合服务本地验证

## 本批范围

新增内部 CircleCapabilityDispatchService，将既有额度预留与派发登记交给同一个调用方事务；领取时先持圈锁、核对业务绑定，再激活额度并条件更新派发状态。供应商幂等键使用已持久化值。

- 重复预留只回读；派发账本缺失抛错，不静默补建。
- 已领取、结果未知或终态重复请求返回 NONE，不再激活或发送。
- 领取条件更新零行抛错，由外层事务回滚额度及回执。
- 自动化调用不能绕过外发红线。
- CLAIMED 只有在外层事务提交成功后才可用于发送。事务内不得调用供应商。
