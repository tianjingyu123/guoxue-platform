# 排盘整套站内跳转核验

## 实现范围

- App站内navigateTo、redirectTo、reLaunch、switchTab共用一次整套资格核验，三个自研分包没有独立工具开关。
- 第三方承接页与共用罗盘不做自研核验，其他板块正常跳转且使旧排盘在途跳转失效。
- 返回与应用隐藏使在途请求失效；单次内存凭据只用于恢复原请求，消费即删除，不写URL或存储。
- 保留请求原回调。被新操作取代时完成取消回调，不在迟到结果后改变页面栈；恢复抛错时报告失败而不自动重试。

## 本地证据

- 7项Node/VM测试通过，覆盖不同分包、共用入口豁免、失败关闭、账号切换、快速切页、返回/隐藏取消、单次凭据。
- 第7项直接提取已安装uni-H5运行时的queue/wrapperOptions/invokeApi实现，验证同步暂停及恢复一次，成功/完成回调各一次。底层页面API为替身，不能视为浏览器或App实测。
- mobile类型检查及diff-check通过。已纳入release:test-paipan-suite。
