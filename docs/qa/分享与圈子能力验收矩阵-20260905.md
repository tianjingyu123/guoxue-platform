# 分享与圈子能力验收矩阵

对应需求：`docs/requirements/分享与圈子能力治理-执行基线-20260905.md`。

## 证据规则

- 本矩阵创建时所有用例均为 `NOT_RUN`，不是 PASS，也不复用旧候选的通过结果。
- 后续逐项记录 sourceCommit、客户端包 SHA256/版本、服务端 releaseId、渠道、设备/系统、测试时间、脱敏证据路径、实际结果。
- 所有不适用项必须注明理由；P0/P1 未完成或无证据时不能给出“全面通过”。
- 卡片需独立接收方点击，海报需独立接收方扫码。分享面板打开、原生 success 回调、截图和本机预览都不足以证明落地通过。
- 不在报告记录手机号、Token、支付参数、第三方私密 URL 或排盘隐私资料。
- 付费问答优先隔离测试数据与沙箱；未获准的真实扣费不执行。第三方支付只验到确认页。
