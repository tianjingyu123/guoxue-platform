# 短视频列表状态筛选隔离

本地核实：公开视频列表虽剥离非管理员scope=all，但原服务仍接受任意status；圈内列表还未排除isPrivate与auditStatus=REJECTED。因此筛选参数可读到本应不在普通列表出现的记录。

修复：非管理范围固定PUBLISHED；圈内列表同时排除SELF_ONLY、私密、审核驳回；管理scope=all仍保留审核筛选。缓存key升为video:list:v3，不复用旧规则结果。

视频相关8 suites/164测试通过，TypeScript通过；随后补充控制器角色测试，检查访客/普通账号/圈主scope被剥离，三类审核管理员保留scope。服务层测试为模拟Prisma的实际where断言，不是线上查询。
