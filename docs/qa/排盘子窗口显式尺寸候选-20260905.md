# 排盘子窗口显式尺寸候选（待真机验证）

## 依据与边界

v242 实装 Android 会员页仍裁切购买按钮；原位无障碍树外层底边 2298、内部虚拟底边 2400。该差值只提示容器/内容基准不一致，不能当作所有设备固定补偿值。

官方规则：<https://www.html5plus.org/doc/zh_cn/webview.html> 的 WebviewStyles 支持显式 height，未设置时才使用 top/bottom 推导；<https://uniapp.dcloud.net.cn/api/system/info.html> 定义 windowHeight 为可使用窗口高度，windowTop 为窗口顶部位置，安全区为逻辑像素。

本次将旧 top/bottom 隐式推导替换为逻辑像素的显式 top/height，按当前窗口原点只补尚未避让的顶部；不按 102 物理像素硬编码，不再次扣除底部安全区。挂载后重申同一尺寸，onResize 使用新窗口尺寸。无效初始尺寸拒绝创建并显示既有重试入口；后续异常保留最后有效尺寸。既有底栏安全区桥、支付/分享导航、第三方域名约束不变。

## 不得省略的终验

- 用当前候选签名包在 Android/iOS 打开同一会员活动页，确认购买按钮文字和点击区域完整可见；只进入支付确认前边界，不实际付款。
- 核对旋转、软键盘弹出/收回、返回重进、刘海屏与系统手势模式，顶部不重叠、底部不裁切、不多扣空白。
- 记录真实窗口尺寸与网页视口；若候选仍有差异继续定位，不得用这 21 项本地测试宣称真机问题解决。
