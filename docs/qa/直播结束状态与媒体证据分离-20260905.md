# 直播结束状态与媒体证据分离

## 修复

- `endRoom` 使用主事务中的 `endInTransaction`，明确要求操作者并校验主播/管理员。无身份的内部调用不再默认放行。
- 已撤销发布资格不妨碍本人结束现有直播；结束时不重新要求可发布资格。
- 重复结束返回既有结束时间，不重复修改业务状态或发送 LIVE_ENDED。清理连麦、混流和缓存仍可幂等重试。
