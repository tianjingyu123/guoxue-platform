# 国学传统文化平台 — 移动端 UI 统一设计规范 & 需求文档

## 项目概述

UniApp (Vue3) H5 移动端，国学传统文化综合平台。需要补建和优化核心页面的 UI，**所有页面必须整体统一，风格一致，不可各板块割裂**。

## 1. 设计系统（严格遵循）

### 1.1 色彩体系

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景 | `#f5f0e6` | 暖色仿古纸底色，全局统一 |
| 主色调 | `#8b4513` | 鞍棕色，按钮/标签/强调元素 |
| 辅色调 | `#c4943a` | 金色，渐变终点，会员/精选标识 |
| 主渐变 | `linear-gradient(135deg, #8b4513, #c4943a)` | 按钮、选中态、头部横幅 |
| 卡片背景 | `#fff` | 白色卡片 |
| 主文字 | `#333` | 标题、正文 |
| 次要文字 | `#666` | 作者、标签 |

## 3. 页面标准结构

每个列表页遵循以下标准结构（保持一致性）：

```
┌──────────────────────────────┐
│  页面标题 + 副标题（可选）     │  ← page-header
├──────────────────────────────┤
│  搜索栏（可选）               │  ← search-bar
├──────────────────────────────┤
│  分类/筛选标签（横向滚动）     │  ← filter-scroll / filter-tabs
├──────────────────────────────┤
│  骨架屏（加载中）             │  ← LoadingSkeleton
│  OR 内容列表/网格             │  ← 主体内容
│  OR 空状态                   │  ← EmptyState
├──────────────────────────────┤
│  加载更多 / 已全部加载         │  ← load-more
└──────────────────────────────┘
```

### 标准代码模板：

```vue
<template>
  <view class="page">
    <!-- 标题 -->
    <view class="page-header">
      <text class="page-title">页面名</text>
      <text class="page-subtitle">副标题</text>
    </view>

    <!-- 筛选标签 -->
    <scroll-view scroll-x class="filter-scroll" show-scrollbar="false">
      <view class="filter-inner">
        <text
          v-for="t in tabs" :key="t.key"
          :class="['filter-tab', { active: activeTab === t.key }]"
          @click="switchTab(t.key)"
        >{{ t.label }}</text>
      </view>
    </scroll-view>

    <!-- 骨架屏 -->
    <LoadingSkeleton v-if="loading && list.length === 0" type="card" />

    <!-- 列表 -->
    <view v-else-if="list.length > 0" class="list">
      <!-- 卡片项 -->
    </view>

    <!-- 空状态 -->
    <EmptyState v-else-if="!loading" icon="📭" text="暂无数据" />

    <!-- 加载更多 -->
    <view v-if="loadingMore" class="load-more">加载更多...</view>
    <view v-if="!hasMore && list.length > 0" class="no-more">— 已全部加载 —</view>
  </view>
</template>
```

## 5. 开发规范（务必遵守）

### 5.1 共同模式
- 所有 API 调用通过 `../../api` 或 `@/api` 导入
- 使用 `<script setup lang="ts">` 语法
- 页面级状态用 `ref()` / `reactive()`
- 用户登录状态用 `useUserStore()` (Pinia)
- 导入路径：组件用 `@/components/xxx.vue`，API 用 `@/api`

### 5.2 加载态处理（必须覆盖三种状态）
```typescript
// 1. 骨架屏加载
const loading = ref(false)
// 2. 上拉加载更多
const loadingMore = ref(false)
// 3. 下拉刷新
const refreshing = ref(false)
```

### 5.3 错误处理
- 所有 API 调用必须 try/catch
- 网络错误显示 toast："加载失败，请检查网络连接"
- 空数据用 EmptyState 组件展示（不要直接显示空白）

### 5.4 生命周期
- 下拉刷新：`onPullDownRefresh` → 重置页码 → 重新获取 → `uni.stopPullDownRefresh()`
- 上拉加载：`onReachBottom` → 页码+1 → 追加数据

### 5.5 禁止事项
- ❌ 不要引入第三方 UI 库（已用 UniApp 原生组件）
- ❌ 不要使用其他色彩方案，严格遵循 1.1 色板
- ❌ 不要重复实现 LoadingSkeleton / EmptyState
- ❌ 不要使用 inline style（统一用 scoped style）
- ❌ 不要硬编码 `localhost:3000`（API 路径统一在 api 模块管理）
- ❌ 不要改变已有组件的 props 接口
