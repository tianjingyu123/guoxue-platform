| 小限 | 以出生年支为起点，男命顺行(寅→卯→辰…)，女命逆行(寅→丑→子…)，每年一宫 |
| 流年(太岁) | 当年地支所在宫位为流年命宫。如2024甲辰年，辰为流年命宫 |
| 斗君 | 以生月生时定正月命宫，正月起顺时针推至当年流月 |
| 大限四化 | 大限宫干使星曜产生四化。星曜在本命盘的能量发生10年期变化 |
| 流年四化 | 流年宫干使星曜产生四化。年度能量叠加 |
| 三代四化 | 本命四化+大限四化+流年四化叠加分析 |
| 运昌运曲 | 大限或流年宫干使文昌/文曲化科，利于考试升迁 |
| 运禄运权 | 大限或流年宫干使某星化禄/化权 |
