# 相术 — 术语词典

## 一、面相·基础

| 术语 | 定义 | 出处 |
|------|------|------|
| 面相十二宫 | 命宫(印堂)、财帛宫(鼻子)、兄弟宫(眉毛)、田宅宫(眼睑)、男女宫(眼下)、奴仆宫(下巴)、妻妾宫(眼角)、疾厄宫(山根)、迁移宫(天仓)、官禄宫(额头正中)、福德宫(耳垂上方)、父母宫(额角) | 《麻衣神相》 |
| 三停 | 上停(发际到眉)=早年运、中停(眉到鼻尖)=中年运、下停(鼻尖到下颏)=晚年运。三停匀称为佳 | 《麻衣神相》 |
| 五官 | 眉为保寿官、眼为监察官、鼻为审辩官、口为出纳官、耳为采听官。五官端正为贵 | 《麻衣神相》 |
| 五星 | 额为火星、鼻为土星、左耳为金星、右耳为木星、口为水星 | 《麻衣神相》 |
| 六曜 | 左眼为太阳、右眼为太阴、山根为月孛、印堂为紫气、左眉为罗睺、右眉为计都 | 《麻衣神相》 |
| 五岳 | 额为南岳衡山、下颏为北岳恒山、左颧为东岳泰山、右颧为西岳华山、鼻为中岳嵩山 | 《麻衣神相》 |
| 四渎 | 耳为江、目为河、口为淮、鼻为济。四渎流通为宜 | 《麻衣神相》 |
| 五行面型 | 金形面(方)、木形面(长)、水形面(圆)、火形面(尖)、土形面(厚) | 《麻衣神相》 |
| 三庭 | 同三停 | 《麻衣神相》 |
| 天地人三才 | 额为天、鼻为人、下颏为地 | 《柳庄相法》 |

## 二、面部·五官

### 额头
| 术语 | 定义 |
|------|------|
| 天庭 | 额上部。天庭饱满为贵 |
| 天中 | 额顶发际处 |
| 司空 | 额中部 |
| 中正 | 额下部近眉处 |
| 印堂 | 两眉之间。命宫所在，宜开阔明亮 |
| 日角 | 左眉上额角，代表父亲 |
| 月角 | 右眉上额角，代表母亲 |
| 伏羲骨 | 额头中央突起骨，大贵之相 |
| 川字纹 | 额头三条竖纹 |
| 悬针纹 | 印堂中间一道竖纹。主刑克 |

### 眉毛
| 术语 | 定义 |
|------|------|
| 眉形 | 剑眉(英武)、弯眉(柔美)、一字眉(直率)、八字眉(愁苦)、柳叶眉(清秀)、浓眉(刚毅)、淡眉(清雅) |
| 眉长过目 | 眉毛长度超过眼睛。主聪明有谋 |
| 眉压眼 | 眉毛过低压迫眼睛。主压抑 |
| 双眉相连 | 眉心相连。主心胸狭窄 |
| 眉尾散 | 眉毛末端散乱。主破财 |

### 眼睛
| 术语 | 定义 |
|------|------|
| 眼形 | 丹凤眼(贵)、桃花眼(风情)、圆眼(天真)、细长眼(机敏)、三角眼(阴险)、大小眼(心术不正) |
| 龙眼 | 眼大而有神，最有贵气的眼形 |
| 凤眼 | 眼形细长，眼角上挑，贵 |
| 象眼 | 眼角下垂，仁慈 |
| 三白眼 | 黑眼珠偏上/下，露出三面眼白。主不吉 |
| 四白眼 | 黑眼珠居中，四面见白。大凶 |
| 眼有神 | 目光有神采，精气充足 |
| 眼无神 | 目光呆滞，精气不足 |

### 鼻子
| 术语 | 定义 |
|------|------|
| 鼻准 | 鼻头。宜圆润有肉 |
| 山根 | 鼻梁根部，两眼之间。疾厄宫。宜高挺 |
| 年上 | 鼻梁中段 |
| 寿上 | 鼻梁下段近鼻头 |
| 兰台廷尉 | 左右鼻翼。宜有肉包裹 |
| 悬胆鼻 | 鼻如悬胆，圆润端正，大贵 |
| 鹰钩鼻 | 鼻头下勾。主阴险 |
| 蒜头鼻 | 鼻头肥大。主愚钝 |
| 狮子鼻 | 鼻头有肉鼻翼饱满。主财运好 |
| 露孔鼻 | 鼻孔外露。主漏财 |

### 嘴巴
| 术语 | 定义 |
|------|------|
| 口形 | 四字口(方正贵)、仰月口(乐观)、覆船口(苦相)、樱桃口(小巧)、吹火口(贫贱) |
| 口角 | 嘴角。宜微微上翘 |
| 唇色 | 红润为佳，苍白为弱 |
| 牙齿 | "牙为骨之余"。牙齿整齐紧密为吉 |

### 耳朵
| 术语 | 定义 |
|------|------|
| 耳形 | 贴脑耳(贵)、兜风耳(奔波)、垂珠耳(福寿)、反骨耳(叛逆)、无轮耳(根基浅) |
| 耳廓 | 外耳轮廓。廓反则性叛逆 |
| 耳垂 | 耳垂有肉为福，无耳垂根基浅 |
| 耳高于眉 | 耳位高过眉毛。主聪明早慧 |
| 耳低于鼻 | 耳位低。主晚成 |

### 颧骨·下颏
| 术语 | 定义 |
|------|------|
| 颧骨 | 权骨。宜有肉包裹 |
| 颧骨高耸 | 主权力欲强，颧骨无肉则克夫（女） |
| 下颏 | 地阁。晚年运。宜圆润丰满 |
| 双下颏 | 富贵之相 |
| 尖下颏 | 晚年运弱 |
| 地阁方圆 | 下颏圆润饱满。晚年好运 |

| 术语 | 定义 |
|------|------|

| 红润 | 气血充足，好运之兆 |
| 白净 | 清贵但不耐久 |

| 黑 | 肾虚、灾厄 |
| 气色明润 | 有光泽，吉 |
| 气色枯暗 | 无光泽，凶 |

## 四、手相

| 术语 | 定义 |
|------|------|
| 五行手型 | 金形手(方厚)、木形手(长瘦)、水形手(圆润)、火形手(尖细)、土形手(厚实) |
| 掌形 | 方形/长方形/圆形/三角形 |
| 五大主线 | 生命线、智慧线、感情线、事业线(命运线)、婚姻线 |
| 生命线 | 从虎口绕拇指丘下行。主健康、寿命 |
| 智慧线 | 横贯掌中。主智慧、思维方式 |
| 感情线 | 从小指下方向食指方向延伸。主感情模式 |
| 事业线(命运线) | 从掌底直上中指。主事业发展 |
| 婚姻线 | 小指根部外侧短线。主婚姻状况 |
| 八大丘 | 木星丘(食指根)/土星丘(中指根)/太阳丘(无名指根)/水星丘(小指根)/金星丘(拇指根)/太阴丘(掌外侧)/火星丘(掌中上/下)/地球丘(掌根) |
| 川字掌 | 生命线/智慧线/感情线三条平行延伸。主独立有主见 |
| 断掌 | 智慧线和感情线合并为一条横贯线。主果断刚烈 |
| 假断掌 | 几乎合并但未完全合并 |
| 十字纹 | 某处有十字交叉。吉凶因地而异 |
| 岛纹 | 如岛状分叉。主流年有阻碍 |
| 星纹 | 三线交于一点。主突发之事 |
| 方格纹 | 四线围合。主保护 |
