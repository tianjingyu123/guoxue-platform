## 一、基础概念

| 术语 | 定义 | 出处 |
|------|------|------|
| 奇门遁甲 | 三式之一（太乙/六壬/奇门），以洛书九宫为框架，配八门九星八神三奇六仪，推演时空吉凶 | 《烟波钓叟赋》 |
| 奇 | 乙丙丁三奇。乙为日奇，丙为月奇，丁为星奇 | 《烟波钓叟赋》 |
| 六仪 | 戊己庚辛壬癸。甲遁于六仪之下，故称"遁甲" | 《烟波钓叟赋》 |
| 遁甲 | 甲为十干之首，藏于六仪之下不出头。甲子遁戊、甲戌遁己、甲申遁庚、甲午遁辛、甲辰遁壬、甲寅遁癸 | 《烟波钓叟赋》 |
| 三奇六仪 | 乙丙丁+戊己庚辛壬癸，共九干，配九宫 | 《烟波钓叟赋》 |
| 阳遁 | 冬至后顺布六仪逆布三奇。阳遁九局（1-9局） | 《烟波钓叟赋》 |
| 阴遁 | 夏至后逆布六仪顺布三奇。阴遁九局（1-9局） | 《烟波钓叟赋》 |
| 局 | 奇门盘。18种基本格局：阳遁9局+阴遁9局 | 《烟波钓叟赋》 |

## 六、定局·起局

| 术语 | 定义 |
|------|------|
| 节气定局 | 以节气确定阴阳遁和局数。冬至一阳生起阳遁1局，夏至一阴生起阴遁9局 |
| 拆补法 | 按节气分三元（上中下），每元五天，依节气定局数标准表取局 |
| 茅山法 | 以节气时刻精确到时辰，实际交接时刻定局，更精细 |
| 置闰法 | 超神接气置闰法。当符头超节气超过9天则置闰 |
| 自选局 | 用户自行选择阳遁1-9局或阴遁1-9局 |
| 超神 | 节气未到而甲子等符头先到 |
| 接气 | 节气已到而甲子等符头后到 |
| 正授 | 节气与符头同时到达 |
| 三元 | 上元中元下元，每元5天。一节气15天分三元 |
| 符头 | 甲子、甲午、己卯、己酉等。三元之首 |
| 值符 | 天盘九星之值符（当值的星），随时干而转 |
| 值使 | 人盘八门之值使（当值的门），随时支而转 |
| 天盘 | 九星所在之盘，动态变化 |
| 地盘 | 九宫八卦原始盘，静态基础 |
| 人盘 | 八门所在之盘 |
| 神盘 | 八神所在之盘 |
| 天乙 | 即值符，天乙贵人所在 |
| 伏吟 | 星不动（天盘星与地盘星相同），主迟滞 |
| 反吟 | 星对冲或门对冲，主反覆、快速 |
| 门反吟 | 八门落对宫 |
| 星反吟 | 九星落对宫 |
| 五不遇时 | 时干克日干且阴阳同性。如甲日庚午时。百事不宜 |

## 七、阳盘vs阴盘vs飞盘

| 术语 | 定义 |
|------|------|
| 阳盘奇门 | 传统奇门，重节气定局、三奇六仪、星门神仪全盘推演 |
| 阴盘奇门 | 王凤麟体系，简化定局、强调移星换斗化解 |
| 转盘 | 八门九星以值符值使为轴心整体旋转移动 |
| 飞盘 | 八门九星按洛书九宫次序跳涧飞布 |
| 飞宫方式 | 阳顺阴逆（阳遁顺飞阴遁逆飞）vs 阴阳皆顺 |
| 暗干 | 阴盘概念，未显示的隐藏天干能量 |
| 移星换斗 | 阴盘核心化解法——转宫/拆填/添加三法 |
| 拆补 | 转宫法+拆填法，移星换斗的具体操作 |
| 天门 | 乾宫所在方位 |
| 地户 | 巽宫所在方位 |
| 值符加时干 | 天盘值符星加临时干所在宫 |
| 值使加时支 | 人盘值使门加临时支所在宫 |
