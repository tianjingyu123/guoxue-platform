## 一、基础概念

| 术语 | 定义 | 出处 |
|------|------|------|
| 易 | 变易、简易、不易。宇宙万物变化的规律 | 《周易·系辞传》 |
| 易经 | 群经之首。含64卦卦辞、384爻爻辞 + 十翼（易传） | — |
| 周易 | 周代的易书。文王演64卦，周公系爻辞，孔子作十翼 | — |
| 十翼 | 彖传(上下)、象传(上下)、系辞传(上下)、文言传、说卦传、序卦传、杂卦传。辅助理解易经的十篇文章 | 孔子(传) |
| 八卦 | 乾兑离震巽坎艮坤。伏羲画八卦 | 《周易·说卦传》 |
| 六十四卦 | 八卦两两相重而成。上卦(外卦)+下卦(内卦) | 文王 |
| 卦名 | 六十四卦各有名称。如乾、坤、屯、蒙……未济 | 《周易》 |
| 卦象 | 卦所象征的事物。如乾为天、坤为地 | 《说卦传》 |

## 三、基础术语

| 术语 | 定义 |
|------|------|
| 爻 | 构成卦的基本符号。阳爻(—)、阴爻(--) |
| 阳爻 | "—"，用九表示。代表刚、动、男、天 |
| 阴爻 | "--"，用六表示。代表柔、静、女、地 |
| 六位 | 一卦六爻，自下而上：初爻、二爻、三爻、四爻、五爻、上爻 |
| 初爻 | 最下位。代表事物萌芽期 |
| 上爻 | 最上位。代表事物终结/极端 |
| 中爻 | 二爻和五爻。二为下卦之中，五为上卦之中。居中多吉 |
| 当位 | 阳爻居阳位(1/3/5)，阴爻居阴位(2/4/6)为当位 |
| 不当位 | 阳爻居阴位或阴爻居阳位 |
| 正应 | 初与四、二与五、三与上有阴阳相应 |
| 敌应 | 相应之位同为阳爻或同为阴爻 |
| 比 | 相邻两爻的关系。相比相亲 |
| 承 | 下爻对上爻的承接关系。阴承阳为顺 |
| 乘 | 上爻对下爻的凌驾。阴乘阳为逆 |
| 据 | 阳爻在上据阴爻。阳据阴为顺 |

## 四、卦的结构

| 术语 | 定义 |
|------|------|
| 上卦(外卦) | 六爻卦的上三爻。代表外部、远处、上方 |
| 下卦(内卦) | 六爻卦的下三爻。代表内部、近处、下方 |
| 互卦 | 二三四爻组成下互卦，三四五爻组成上互卦。代表事物发展过程 |
| 综卦 | 将本卦上下颠倒。代表同一事物从对面看 |
| 错卦 | 本卦各爻阴阳全变。代表事物之反面 |
| 变卦 | 本卦动爻阴阳互变后的卦。代表事物发展结果 |
| 本卦 | 原始卦，代表当前状态 |
| 之卦 | 即变卦 |
| 体卦 | 无动爻的卦（梅花易数中） |
| 用卦 | 有动爻的卦（梅花易数中） |
| 体用 | 体卦为己，用卦为事/人。体用生克定吉凶 |
| 卦主 | 一卦之主爻。多取五爻或少数爻 |
| 成卦之主 | 卦中起决定作用的一爻 |

## 五、爻辞结构

| 术语 | 定义 |
|------|------|
| 卦辞 | 文王所系，总括一卦大义 |
| 爻辞 | 周公所系，说明一爻之义 |
| 彖传 | 孔子释卦辞。总论一卦之德 |
| 大象 | 象传释卦象的部分。如"天行健，君子以自强不息" |
| 小象 | 象传释爻象的部分 |
| 文言传 | 专释乾坤二卦的深度阐释 |
| 元亨利贞 | 乾卦四德。元者善之长，亨者嘉之会，利者义之和，贞者事之干 |
| 吉凶悔吝 | 四种基本断辞。吉（善）、凶（恶）、悔（后悔可改）、吝（羞耻难改） |
| 无咎 | 没有过错。易经追求的至高境界 |
| 厉 | 危险 |
| 眚 | 灾祸 |
| 孚 | 诚信 |

## 七、河图洛书

| 术语 | 定义 |
|------|------|
| 河图 | 天一生水地六成之……一六北/二七南/三八东/四九西/五十中 |
| 洛书 | 戴九履一、左三右七、二四为肩、六八为足、五居中央 |
| 先天八卦 | 伏羲八卦。乾南坤北，离东坎西，兑东南艮西北，震东北巽西南 |
| 后天八卦 | 文王八卦。离南坎北，震东兑西，巽东南乾西北，坤西南艮东北 |

| 后天数 | 坎1坤2震3巽4中5乾6兑7艮8离9 |
| 天地之数 | 天数1+3+5+7+9=25，地数2+4+6+8+10=30，共55 |
