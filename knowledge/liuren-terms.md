## 一、大六壬·基础

| 术语 | 定义 | 出处 |
|------|------|------|
| 大六壬 | 三式之一。以月将加时，起天地盘，排四课，发三传，断吉凶 | 《六壬大全》 |
| 月将 | 每月之中气后所用之神将。正月亥登明、二月戌河魁…… | 《六壬大全》 |
| 占时 | 起课时的时间（时辰），核心输入 | 《六壬大全》 |
| 天地盘 | 地盘固定（十二支），天盘以月将加占时而成 | 《六壬大全》 |
| 四课 | 以日干日支为基准，各分阴阳，得四课。第一课为日干阳神，第二课为日干阴神，第三课为日支阳神，第四课为日支阴神 | 《六壬大全》 |
| 三传 | 起课的核心输出。初传(发用)、中传、末传，代表事情的开端、发展、结局 | 《六壬大全》 |
| 发用 | 初传。以四课中贼克/比用/涉害等九宗门法求出 | 《六壬大全》 |
| 九宗门 | 起三传的九种方法：贼克/比用/涉害/遥克/昴星/别责/八专/伏吟/反吟 | 《六壬大全》 |

## 四、九宗门

| 宗门 | 条件 | 说明 |
|------|------|------|
| 贼克 | 四课有一下贼上，取贼上神 | 最常用 |
| 比用 | 多个贼克时，取与日干同性者 |
| 涉害 | 比用无法决断，看各神涉害深浅 |
| 遥克 | 四课无贼克，取遥克(隔位克) |
| 昴星 | 四课无克且无遥克，取昴星法 |
| 别责 | 四课不全(三课)，取别责法 |
| 八专 | 四课仅二课(干支同位)，取八专法 |
| 伏吟 | 天盘地盘完全相同 |
| 反吟 | 天盘地盘完全相反 |
| 涉害法 | 涉害取法之争：孟仲季法 vs 深浅法 |
| 昴星法 | 阳日取地盘酉上神为初传 |
| 别责法 | 阳日取日干合之上神为初传 |

## 八、中六壬

| 术语 | 定义 |
|------|------|
| 中六壬 | 介于大六壬与小六壬之间，月将加时+天罡定局 |
| 天罡 | 辰。天地之纲纪 |
| 天罡定局 | 以天罡所在宫位定吉凶。天罡加四孟(寅申巳亥)→吉、加四仲(子午卯酉)→中、加四季(辰戌丑未)→凶 |
| 月将加时 | 同大六壬，月将加于占时 |
| 课传 | 同大六壬的四课三传体系（简化版） |

## 十、金口诀

| 术语 | 定义 |
|------|------|
| 金口诀 | 大六壬简化版。四位直断：人元+贵神+月将+地分 |
| 四位 | 人元(天干)、贵神(天将)、月将(地支)、地分(地支) |
| 地分 | 取时支或方位支。金口诀的起点 |
| 人元 | 以五鼠遁法取地分天干 |
| 五动 | 将克神(财动)、神克将(官动)、将克人元(贼动)、神克人元(盗动)、将克地分(鬼动) |
| 三动 | 方克干(鬼动)、干克方(妻动)、神克方(贼动) |
| 五合 | 干合、支合、将神合等 |
| 四位生克 | 四位之间的生克关系链条 |
