## 三、理气·二十四山

| 术语 | 定义 |
|------|------|
| 二十四山 | 以八干四维十二支划分360°，每山15°。壬子癸丑艮寅甲卯乙辰巽巳丙午丁未坤申庚酉辛戌乾亥 |
| 一卦三山 | 每卦管三山。坎管壬子癸、艮管丑艮寅、震管甲卯乙、巽管辰巽巳、离管丙午丁、坤管未坤申、兑管庚酉辛、乾管戌乾亥 |
| 天元龙 | 子午卯酉+乾坤艮巽。正中 |
| 地元龙 | 壬丙甲庚+辰戌丑未。逆子 |
| 人元龙 | 癸丁乙辛+寅申巳亥。顺子 |
| 三元龙 | 天元地元人元合称。玄空飞星排盘基础 |
| 二十四山阴阳 | 阳山：壬子癸寅甲乙辰午坤申戌乾。阴山：丑艮卯巽巳丙丁未庚酉辛亥 |
| 天地人三卦 | 每山分三卦：地卦(0-5°)、天卦(5-10°)、人卦(10-15°) |
| 出卦 | 山向线压在三卦分界线上。大凶 |
| 出宫 | 山向线压在二十四山分界线上。凶 |
